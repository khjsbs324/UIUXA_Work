# 📌 [서비스 흐름도 시안 1] 정시우 클라이언트 - 놋쇠 마패 3D 용기 각인 선행 플로우

## 1. 세부 단계별 명세
| 단계 | 사용자 행동 | 시스템 반응 & UX 로직 | 입출력 데이터 |
| :---: | :--- | :--- | :--- |
| **Step 1** | 메인 랜딩 3D 마패 용기 선택 | 360도 3D 용기 렌더링 뷰포트 활성화 | 입력: 터치/드래그 / 출력: 3D 뷰포트 |
| **Step 2** | 서체 및 문구 입력 | 훈민정음 한자 서체 투영 실시간 음각 렌더링 | 입력: 텍스트 / 출력: 3D 레이저 투영 |
| **Step 3** | VIP 멤버십 등급 가입 | 1·2·3마패 등급 선택 및 적립 혜택 수령 | 입력: 회원 정보 / 출력: VIP 혜택 카드 |
| **Step 4** | 놋쇠 참(Charm) 조합 선택 | 마패 키링 백꾸 굿즈 장식 결합 | 입력: 참 옵션 / 출력: 조합 캡처 이미지 |
| **Step 5** | 주문 결제 완료 | 주문 승인 및 리필 카트리지 콤보 배송 | 입력: 결제 정보 / 출력: 주문 완료 번호 |
