# 📌 [사단(士團)] 임채원 서비스 흐름도 시안 2 (서비스_흐름도_시안2_임채원.md)

## 1. 흐름 개요 및 기획 의도: TPO 상황별 듀얼 레이어링 휠 & 안전 검증 플로우
* **특징:** 사용자가 원형 휠을 통해 TPO 상황(비즈니스/산책/다이닝/휴식)을 선택하면 1·2·3마패 듀얼 배합 팁을 추천받고, 향조 충돌 검증 및 분사 부위 가이드를 거쳐 듀얼 번들을 구매하는 플로우.
* **주요 분기점:** 4대 상황 분기, 향조 충돌 안전 검증 분기, 각인 옵션 선택 분기.

## 2. 상세 서비스 흐름도 (Mermaid 분기 차트)

```mermaid
flowchart TD
    Start(["메인 접속"]) --> WheelSpin["TPO 360° 시나리오 휠 회전"]
    WheelSpin --> Occasion{"상황(Occasion) 선택"}
    
    Occasion -->|비즈니스 미팅| Rec1["1마패(백단 2회) + 2마패(솔잎 1회)"]
    Occasion -->|주말 야외 산책| Rec2["2마패(유자솔잎 단독 3회)"]
    Occasion -->|저녁 다이닝/데이트| Rec3["2마패(유자 1회) + 3마패(침향 2회)"]
    Occasion -->|심야 휴식/명상| Rec4["3마패(침향 단독 1회)"]

    Rec1 --> RatioValid{"향조 조화도 & 펌핑 검증"}
    Rec2 --> RatioValid
    Rec3 --> RatioValid
    Rec4 --> RatioValid

    RatioValid -->|과다 분사/충돌| SafeAlert["⚠️ 과다 분사 주의: 최적 지속시간 보정 안내"] --> PulseGuide
    RatioValid -->|황금 비율 적합| PulseGuide["체온 부위별(손목/목선/쇄골) 분사 가이드 표시"]

    PulseGuide --> BundleChoice{"구매 유형 선택"}
    BundleChoice -->|추천 듀얼 번들 담기| DiscountApply["15% 듀얼 세트 할인 자동 적용"] --> EngraveOpt
    BundleChoice -->|1개 향만 단품 선택| SingleOnly["단품 담기"] --> EngraveOpt

    EngraveOpt --> NeedEngrave{"스트랩 각인 추가 여부"}
    NeedEngrave -->|각인 추가 (+5,000원)| TextInput["텍스트 입력 ➔ 3D 실시간 렌더링 검수"] --> CartStep
    NeedEngrave -->|기본 완제품| CartStep["Slide Cart 담기 ➔ 결제"]

    CartStep --> Done(["주문 완료 & TPO 착향 팁 알림톡 전송"])
```

## 3. 예외 및 실패 복구 시나리오 (Exception Scenarios)
1. **[각인 글자 수 초과]:** 25자 초과 시 붉은색 테두리 경고와 함께 실시간 줄임말 제안.
2. **[듀얼 향 중 1종 품절 시]:** 대체 가능한 유사 시간대 향(예: 정오 솔잎 ➔ 새벽 백단향) 대체 조합 추천 모달 팝업.
