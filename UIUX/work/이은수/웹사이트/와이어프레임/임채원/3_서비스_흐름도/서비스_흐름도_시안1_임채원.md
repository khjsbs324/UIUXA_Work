# 📌 [사단(士團)] 임채원 서비스 흐름도 시안 1 (서비스_흐름도_시안1_임채원.md)

## 1. 흐름 개요 및 기획 의도: 24H 가로 시간축 슬라이더 탐색 & 구매 분기 플로우
* **특징:** 사용자가 06:00~24:00 시간 슬라이더를 조작하여 시간대별 추천 향을 확인하고, 단품 구매, 듀얼 번들 할인, 또는 시향 킷으로 분기되는 실전 인터랙션 플로우.
* **주요 분기점:** 접속 로컬 시간 자동 감지 분기, 구매 옵션 분기(단품 vs 번들), 재고 유무에 따른 리필 예약 루프.

## 2. 상세 서비스 흐름도 (Mermaid 분기 차트)

```mermaid
flowchart TD
    Start(["사용자 메인 접속"]) --> TimeDetect{"접속 로컬 시간 감지"}
    TimeDetect -->|오전 06:00~11:59| Dawn["06:00 새벽 백단향 자동 포커스"]
    TimeDetect -->|낮 12:00~17:59| Noon["12:00 정오 솔잎 자동 포커스"]
    TimeDetect -->|저녁 18:00~23:59| Dusk["18:00 황혼 유자 자동 포커스"]
    TimeDetect -->|심야 24:00~05:59| Mid["24:00 심야 침향 자동 포커스"]

    Dawn --> UserDrag{"사용자 슬라이더 조작 여부"}
    Noon --> UserDrag
    Dusk --> UserDrag
    Mid --> UserDrag

    UserDrag -->|다른 시간대 선택| UpdateCard["해당 시간대 향 카드 & 지속 곡선 실시간 갱신"]
    UserDrag -->|현재 시간대 유지| UpdateCard

    UpdateCard --> StockCheck{"해당 시간대 보틀 재고 확인"}
    StockCheck -->|재고 부족/품절| OutOfStock["⚠️ 일시 품절 알림 ➔ 다음 차수 우선 예약 링크 제공"] --> PreOrder(["예약 등록 완료"])
    StockCheck -->|재고 정상| BuyChoice{"구매 유형 선택"}

    BuyChoice -->|단품 바로 구매| SingleCart["15ml 단품 Slide Cart 담기"]
    BuyChoice -->|듀얼 시간대 번들| DualCart["2개 시간대 15% 세트 할인 번들 담기"]
    BuyChoice -->|향 확인 후 결정| TastingRedirect["5종 테이스팅 킷 신청으로 이동"]

    SingleCart --> CartDrawer["Quick Slide Cart Drawer 열림"]
    DualCart --> CartDrawer
    CartDrawer --> Checkout(["간편 결제 진행 및 주문 완료"])
```

## 3. 예외 및 실패 복구 시나리오 (Exception Scenarios)
1. **[시간대 로딩 지연]:** 네트워크 지연 시 기본 12:00 정오 향으로 즉시 렌더링 후 비동기 데이터 갱신.
2. **[품절 시 이탈 방지]:** 재고 소진 시 단순 '품절' 문구 대신 3개월 정기 리필 우선 배정 링크로 유도.
