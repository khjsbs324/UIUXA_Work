  ├─► [트랙 A: 24H 타임라인] 06:00~24:00 슬라이더 조작 ➔ 해당 시간대 추천 향 카드 노출
  ├─► [트랙 B: TPO 휠 큐레이션] 비즈니스/산책/다이닝/휴식 휠 회전
  │     └─► {조건 분기 1: 듀얼 조합 조화도 검증}
  │           ├─ 충돌/과다분사 시: ⚠️ 황금 비율 자동 보정 안내
  │           └─ 조화로움 통과 시: 체온 부위별 펌핑 가이드 노출

  │     └─► {조건 분기 2: 가죽 스트랩 각인 신청}
  │           ├─ 각인 선택: 이니셜 입력 ➔ 25자 검증 ➔ 3D 렌더링 검수
  │           └─ 기본형 선택: Slide Cart로 직결

        └─► {사후 O2O 루프: QR 코드 스캔} ➔ 25,000원 100% 환급 바우처 자동 활성화

## 3. 실전 5대 예외 처리 및 복구 시나리오 (Exception Scenarios)

1. **[향조 조합 충돌 예외]:** 1마패(우디)와 3마패(오리엔탈) 과다 조합 시 시스템이 "지나치게 무거운 향조" 경고를 띄우고, 2마패(솔잎)를 포인트로 섞도록 자동 밸런스 제안.
2. **[각인 입력 오류 예외]:** 25자 초과 입력 또는 비속어 필터링 시 실시간 붉은색 테두리 경고와 함께 조선 해서체/고딕 한자 변환 가이드 제공.
3. **[카트리지 품절 예외]:** 특정 시간대 향 소진 시 단순 '품절' 대신 "다음 정기 구독 차수 우선 예약권 발급"으로 전환하여 이탈 방지.
4. **[결제 실패 세션 복구]:** 통신 에러나 한도 초과로 결제 창이 닫혀도 고객의 시간대 조합 및 각인 데이터가 24시간 동안 임시 저장되어 1초 복구 가능.
5. **[테이스팅 킷 사후 리마인드]:** 5종 샘플 수령 후 14일 동안 본품 미구매 시 "25,000원 바우처 만료 D-3" 알림톡을 발송하여 재유입 유도.
