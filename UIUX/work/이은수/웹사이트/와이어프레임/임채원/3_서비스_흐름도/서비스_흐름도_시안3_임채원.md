# 📌 [사단(士團)] 임채원 서비스 흐름도 시안 3 (서비스_흐름도_시안3_임채원.md)

## 1. 흐름 개요 및 기획 의도: 포터블 15ml 올데이 키트 쇼케이스 & 1초 결제 플로우
* **특징:** 주머니에 쏙 들어가는 15ml 마패 오브제 용기 3종 세트와 가죽 트래블 파우치 실물 쇼케이스를 보고, 선물 포장 및 간편 결제로 직결되는 고속 커머스 플로우.
* **주요 분기점:** 세트 구성 선택 분기(단품 vs 3종 풀세트), 선물 포장 옵션 분기, 결제 수단 분기.

## 2. 상세 서비스 흐름도 (Mermaid 분기 차트)

```mermaid
flowchart TD
    Start(["메인 접속"]) --> ShowcaseView["15ml 올데이 포터블 키트 쇼케이스 탐색"]
    ShowcaseView --> KitType{"구매 구성 선택"}

    KitType -->|15ml 단품 (1·2·3마패)| SingleSelect["향 옵션 선택 (34,000~39,000원)"] --> PouchOpt
    KitType -->|15ml 3종 풀세트| FullSetSelect["1·2·3마패 3종 + 가죽 파우치 (98,000원)"] --> PouchOpt

    PouchOpt --> LeatherColor{"가죽 파우치 컬러 선택"}
    LeatherColor -->|앤틱 브라운| StrapCheck
    LeatherColor -->|딥 나이트 블랙| StrapCheck

    StrapCheck --> StrapEngrave{"노리개 스트랩 각인 신청 여부"}
    StrapEngrave -->|각인 신청| InputName["이니셜 6자 입력 & 각인 프리뷰"] --> WrapOpt
    StrapEngrave -->|미신청| WrapOpt{"선물 포장 옵션"}

    WrapOpt -->|한지 비단 보자기 포장 (+3,000원)| WrapAdd["고급 선물 포장 적용"] --> CartDrawer
    WrapOpt -->|기본 친환경 패키지| CartDrawer["Slide Cart Drawer 열림"]

    CartDrawer --> PayMethod{"간편 결제 수단 선택"}
    PayMethod -->|네이버페이 / 카카오페이| Quick1Sec["1초 생체인증 결제"] --> SuccessCheck
    PayMethod -->|일반 신용카드| CardForm["카드 정보 입력"] --> SuccessCheck

    SuccessCheck -->|결제 승인 완료| Done(["주문 완료 & 배송 알림톡 발송"])
    SuccessCheck -->|한도초과/승인실패| RetryLoop["🔄 결제 수단 변경 안내"] --> PayMethod
```

## 3. 예외 및 실패 복구 시나리오 (Exception Scenarios)
1. **[결제창 이탈 방지]:** 결제 진행 중 이탈 시도 시 "지금 구매 시 가죽 파우치 무료 각인 혜택 유지" 모달 노출.
2. **[품절 색상 선택 시]:** 실시간 가죽 원단 재고 체크를 통해 품절 색상 즉시 비활성화 및 2순위 색상 추천.
