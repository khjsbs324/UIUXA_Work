# 📌 [사단(士團)] 민서준 서비스 흐름도 시안 4 (서비스_흐름도_시안4_민서준.md)

## 1. 흐름 개요 및 기획 의도: Cipher 코드 기반 포뮬러 복원 & 리필 구독 플로우
* **특징:** 고객이 발급받은 Cipher Hash 번호를 입력하여 이전 배합과 각인 데이터를 1초 만에 복원하고 리필 카트리지를 정기 구독하는 락인 플로우.
* **주요 분기점:** Cipher 코드 유효성 검증 분기, 단회 리필 vs 정기 구독 주기 분기, 친구 선물하기 분기.

## 2. 상세 서비스 흐름도 (Mermaid 분기 차트)

```mermaid
flowchart TD
    Start(["메인 접속"]) --> CipherInput["Cipher Hash 코드 입력 (#SADAN-8842)"]
    CipherInput --> CodeVerify{"코드 유효성 검증"}

    CodeVerify -->|유효하지 않은 코드| ErrorGuide["⚠️ 코드 오류 안내 ➔ 휴대폰 번호로 내 레시피 찾기"] --> CipherInput
    CodeVerify -->|정상 코드| RestoreData["이전 3축 배합 비율 및 각인 텍스트 1초 내 즉각 복원"]

    RestoreData --> ActionSelect{"재주문 방식 선택"}
    ActionSelect -->|1회 리필 단품 구매| SingleRefill["15ml/50ml 알루미늄 리필 카트리지 담기"] --> CartStep
    ActionSelect -->|정기 리필 구독 (15% 할인)| SubPlan["3개월/6개월 정기 배송 주기 선택"] --> CartStep
    ActionSelect -->|친구에게 선물하기| GiftLink["디지털 첩보 증서 선물 링크 생성"] --> SendDone(["카카오톡 선물 전송"])

    CartStep["Slide Cart Drawer 결제"] --> Done(["주문 완료 & 다음 리필 주기 알림톡 설정"])
```
