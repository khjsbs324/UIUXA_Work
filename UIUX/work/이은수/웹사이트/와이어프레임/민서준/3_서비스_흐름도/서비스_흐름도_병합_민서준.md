## 2. 최적 병합 엔드투엔드 서비스 분기 흐름도

```text
[1. 사용자 메인 유입]
  │
  ├─► [트랙 A: 커스텀 조향 랩] 3축 피펫 슬라이더 조작 (Base/Point/All-day)
  │     └─► {조건 분기 1: 3축 비율 합산 100% 검증}
  │           ├─ 비율 불균형/초과: ⚠️ 황금 비율(40:35:25) 자동 보정 안내
  │           └─ 100% 정상 균형: Extrait 25% 부향률 실시간 연산 ➔ 3D 각인 아틀리에로 이동
  │
  ├─► [트랙 B: 24종 원료 도록] 산지 지도 및 고전 삽화 도록 탐색
  │     └─► '이 원료로 조향하기' 클릭 시 피펫 슬라이더로 해당 원료 자동 바인딩 ➔ 트랙 A 이동
  │
  ├─► [트랙 C: 완제품 보석함] 마스터 1·2·3마패 완제품 3열 쇼케이스 탐색 ➔ 바로 주문
  │
  └─► [트랙 D: 이전 레시피 재주문] Cipher Hash 코드(#SADAN-8842) 입력
        └─► {조건 분기 2: 코드 유효성 검증}
              ├─ 오류 코드: ⚠️ 휴대폰 번호로 내 레시피 찾기 모달
              └─ 정상 코드: 이전 배합 데이터 1초 복원 ➔ 트랙 A 이동

[2. 3D 각인 아틀리에 & 렌더링 검수]
  각인 문구 입력 ➔ 서체 선택
  │
  └─► {조건 분기 3: 3D WebGL 지원 여부}
        ├─ 렌더링 성공: 360° 3D 인터랙티브 보틀 회전 검수
        └─ 구형 브라우저/지연: 2D 고해상도 벡터 일러스트 프리뷰로 자동 전환

[3. 장바구니 및 할인 판별]
  Cipher Hash 코드 발급 ➔ Slide Cart Drawer 열림
  │
  └─► {조건 분기 4: 디스커버리 100% 바우처 보유 여부}
        ├─ 바우처 보유: 25,000원 100% 즉시 차감 (최종 결제액 0원 또는 차액 결제)
        └─ 바우처 미보유: 일반 결제 금액 적용

[4. 결제 방식 및 사후 리필 루프]
  │
  ├─► {조건 분기 5: 결제 승인 결과}
  │     ├─ 결제 실패/한도 초과: 🔄 24시간 세션 복구 & 다른 결제 수단 유도
  │     └─ 승인 완료: 주문 완료 & 디지털 어사 첩보 증서 PDF 발송
  │
  └─► [사후 리텐션 루프]: 고유 Cipher 코드로 언제든 1초 원클릭 리필 및 3개월 정기 구독 순환
```

## 3. 실전 5대 예외 처리 및 복구 시나리오 (Exception Scenarios)

1. **[3축 비율 불균형 예외]:** 피펫 슬라이더 합산이 100%가 되지 않을 경우 세이프티 가이드가 최적의 황금 비율(Base 40 : Point 35 : All-day 25)로 1클릭 자동 보정.
2. **[3D 렌더링 지연 예외]:** WebGL 초기화 실패 또는 3초 이상 렌더링 지연 시 2D 벡터 일러스트 프리뷰로 즉각 전환하여 이탈 방지.
3. **[각인 글자 수 초과 예외]:** 25자 초과 입력 시 붉은색 테두리 경고와 함께 조선 해서체 줄임말 추천 모달 제공.
4. **[Cipher 코드 분실 복구]:** 레시피 코드를 잊어버린 고객도 카카오톡 본인 인증만으로 역대 배합 히스토리 1초 내 복구.
5. **[결제 실패 세션 복구]:** 결제 중 네트워크 에러 발생 시 고객이 조합한 포뮬러와 각인 텍스트를 24시간 동안 임시 보관하여 재입력 없이 복원.
