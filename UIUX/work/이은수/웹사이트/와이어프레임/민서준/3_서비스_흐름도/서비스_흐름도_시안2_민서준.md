# 📌 [사단(士團)] 민서준 서비스 흐름도 시안 2 (서비스_흐름도_시안2_민서준.md)

## 1. 흐름 개요 및 기획 의도: 3D 마패 각인 렌더링 & 360도 보틀 검수 플로우
* **특징:** 사용자가 캘리그라피 서체와 각인 문구를 입력하고 360도 3D 마패 보틀을 회전하며 실시간 검수한 뒤 선물 포장을 선택하여 결제하는 비스포크 플로우.
* **주요 분기점:** 각인 텍스트 유효성 검증 분기, 3D WebGL 렌더링 정상 여부(2D 폴백 루프), 패키징 옵션 분기.

## 2. 상세 서비스 흐름도 (Mermaid 분기 차트)

```mermaid
flowchart TD
    Start(["3D 각인 아틀리에 접속"]) --> TextInput["각인 텍스트 입력 (한글/영문/한자)"]
    TextInput --> TextValidate{"글자수(25자) & 비속어 필터 검증"}

    TextValidate -->|25자 초과/부적절 단어| TextError["⚠️ 글자수 초과 경고 ➔ 표준 해서체 줄임말 추천"] --> TextInput
    TextValidate -->|정상 텍스트| FontSelect["캘리그라피 서체 선택 (조선 해서체 / 모던 고딕 / 영문 필기체)"]

    FontSelect --> RenderEngine{"3D WebGL 렌더링 지원 여부"}
    RenderEngine -->|렌더링 성공| WebGLView["360° 3D 인터랙티브 마패 보틀 실시간 회전 검수"]
    RenderEngine -->|구형 브라우저/실패| Fallback2D["고해상도 2D 벡터 일러스트 프리뷰로 자동 전환"]

    WebGLView --> ConfirmCheck{"각인 결과 최종 확정"}
    Fallback2D --> ConfirmCheck

    ConfirmCheck -->|수정 희망| TextInput
    ConfirmCheck -->|확정 완료| PackageOpt{"선물 포장 패키지 선택"}

    PackageOpt -->|조선 비단 보자기 & 노리개 (+5,000원)| RoyalWrap["고급 왕실 포장 적용"] --> CartStep
    PackageOpt -->|기본 친환경 한지 패키지| EcoWrap["기본 포장 적용"] --> CartStep

    CartStep["Slide Cart Drawer 담기"] --> PayStep(["주문 완료 & 각인 완료 알림톡 발송"])
```

## 3. 예외 및 실패 복구 시나리오 (Exception Scenarios)
1. **[한자 변환 실패]:** 특수 한자 입력 시 유니코드 폰트 깨짐 방지를 위해 사단 전용 서체 이미지로 실시간 치환.
2. **[3D 로딩 지연]:** 3초 이상 렌더링 지연 시 로딩 스피너와 함께 2D 고화질 프리뷰 우선 노출.
