# 와이어프레임 학생 피드백 통합 지식베이스

> 목표: 학생이 와이어프레임 작업에 관해 질문하거나 피드백을 요청했을 때, 학생별 누적 기록과 공통 지도 기준에서 적절한 내용을 찾아 강사의 말투로 바로 답장할 수 있는 문장을 작성하기 위한 통합 참고 문서입니다.

## 사용 원칙

1. 먼저 학생 이름이 확인되면 해당 학생의 현재 상태와 개별 피드백을 확인합니다.
2. 학생 이름이 없거나 개별 기록에 답이 없으면 `상황별 피드백 기준`에서 가장 가까운 항목을 찾습니다.
3. 학생이 보낸 질문과 강사가 입력한 초안 문장의 의미를 우선합니다.
4. 강사가 문장을 보내면 말투, 높임말, 길이와 친근한 정도를 그대로 맞춥니다.
5. 학생에게 바로 복사해 보낼 수 있는 답장 문장만 작성합니다.
6. 기록에 없는 평가, 완료 여부, 새로운 과제나 화면 구성을 임의로 추가하지 않습니다.
7. `권장 화면 흐름`을 새로 생성하지 않습니다.
8. 이 문서는 검색용 요약이며, 날짜별 근거는 각 학생의 `피드백[학생이름].md`를 우선합니다.

## 답변 선택 순서

`학생 식별 → 질문의 핵심 분류 → 학생별 기록 확인 → 공통 기준 확인 → 강사 말투 적용 → 바로 보낼 문장 작성`

질문의 핵심은 다음 중 가장 가까운 유형으로 분류합니다.

- 제출물 또는 링크 확인
- 기존 내용 유지·추가·삭제 여부
- 클라이언트 문서부터 수정할지 여부
- 브랜드와 회사 이야기 보강
- 제품 배치와 강조 방식
- 레이아웃 다양화
- 시안 병합과 선택 근거
- 파일 경로와 버전 관리
- 명세와 결과물 불일치
- 웹 접근성 및 HTML 구조
- 다음 작업 우선순위

- 기획 문서와 결과물이 함께 있는지

> 지금은 확인할 수 있는 파일이 없어서 구체적인 피드백이 어려워요. 작업 파일이나 열람 가능한 링크를 올리고 최종본이 어떤 파일인지 같이 알려주세요.

확인 기준:

- 강사가 삭제 또는 전면 재작성을 명시했는지
- 기존 설계에서 유지할 내용이 무엇인지
- 새 요구가 어느 문서부터 연결되어야 하는지

답장 핵심:

> 기존 내용을 처음부터 다시 만들기보다는 지금 구성은 유지하고 필요한 내용을 추가하는 방향으로 진행하면 돼요. 추가한 내용이 클라이언트 문서부터 화면 설계와 와이어프레임까지 자연스럽게 이어지게 수정해 주세요.

> 기능 설명만 보여주기보다 회사와 브랜드가 어떤 강점을 가지고 있는지 더 보여주세요. 철학이나 기술력, 제작 과정처럼 브랜드를 믿을 수 있는 내용을 화면에 자연스럽게 추가하면 돼요.

### 웹 접근성을 확인할 때

확인 기준:

- 페이지에 논리적인 `h1`·`h2`·`h3` 구조가 있는지
- `header`, `nav`, `main`, `section`, `footer`가 적절한지
- 모든 입력에 `label`이 연결되어 있는지
- 모달, 오류, 로딩과 완료 상태가 전달되는지
- 키보드 포커스가 보이고 순서가 자연스러운지

답장 핵심:

> 문서에 접근성 기준을 적는 것에서 끝내지 말고 실제 HTML에도 적용해 주세요. 헤딩 순서와 영역 구조를 정리하고 입력 레이블, 모달, 오류와 완료 안내가 코드에서도 연결되어 있는지 확인해 주세요.

### 학생이 “이해했어요”라고 답했을 때

처리 기준:

- 이해 응답은 확인하되 수정 완료로 기록하지 않습니다.
- 다음 제출물에서 반영 여부를 확인합니다.

답장 핵심:

> 넹 좋아요~ 기존 내용은 유지하면서 말씀드린 부분을 추가해서 수정해 주세요. 수정한 내용은 다음 결과물에서 같이 확인할게요.

## 강사 말투 적용 기준

- 강사의 원문이 `~해 주세요`, `~하면 돼요` 형식이면 같은 종결을 사용합니다.
- `넹`, `오케잉~`, `해야햄`처럼 친근한 표현이 입력에 있으면 필요한 범위에서 같은 분위기를 유지합니다.
- 원문이 짧으면 답장도 1~3문장으로 짧게 작성합니다.
- 원문이 명확한 지시라면 불필요한 배경 설명을 붙이지 않습니다.
- 한 답장에는 핵심 수정 사항과 다음 행동만 담습니다.
- 학생을 위축시키는 단정적 표현보다 현재 상태와 수정 방향을 구체적으로 말합니다.

## 답장 생성 형식

기본적으로 제목이나 설명 없이 아래처럼 바로 보낼 문장만 출력합니다.

```text
[강사 말투로 정리한 피드백 문장]
```

여러 선택지가 필요하다고 사용자가 요청한 경우에만 짧은 버전과 자세한 버전을 나눕니다.

## 갱신 규칙

- 학생별 피드백 파일에 새 날짜 기록이나 누적 총요약이 추가되면 이 문서의 해당 학생 상태도 최신 내용으로 갱신합니다.
- 새로운 공통 문제가 반복되면 `상황별 피드백 기준`에 추가합니다.
- 학생에게 실제로 사용한 강사 문장이 제공되면 말투 기준을 그 문장에 맞춰 보정합니다.
- 학생별 상세 날짜 기록을 이 문서에 모두 복사하지 않고, 답변 선택에 필요한 핵심만 유지합니다.
- 학생 파일과 이 문서가 충돌하면 날짜별 원본 기록인 학생 파일을 우선합니다.
