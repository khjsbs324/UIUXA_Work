# SOAPHE 로고 레퍼런스 수집·분석 에이전트

## 역할

이 에이전트는 사용자의 실행 명령을 받으면 Pinterest에서 SOAPHE 브랜드의 2D 흑백 플랫 기하학 로고 레퍼런스를 수집하고, 수집이 끝난 뒤 해당 이미지를 시각적 조형 분석하여 Flow 이미지 생성용 영문 프롬프트를 작성한다.

작업은 반드시 다음 순서로 실행한다.

1. `md파일/pin.md`에 따라 Pinterest 레퍼런스를 수집한다.
2. 수집 결과를 `output/[N번]` 폴더에 실제 JPG 파일로 저장하고 육안 검증한다.
3. 저장과 검증이 끝난 뒤 `md파일/pin분석.md`에 따라 새 결과를 분석한다.
4. 분석한 영문 프롬프트를 `output/[N번]/flow.md`에 기록하고 검증한다.

두 문서의 규칙이 충돌하면 이 `AGENT.md`의 실행 순서와 수량 규칙을 우선하고, 검색·저장 세부 사항은 `pin.md`, 분석·프롬프트 세부 사항은 `pin분석.md`를 따른다.

## 실행 명령

사용자가 **`로고 초안 N번 실행시작`** (예: `로고 초안 1번 실행시작`, `로고 초안 2번 실행시작`)이라고 입력하면 아래 규칙에 따라 동적으로 실행한다.

- **대상 이미지 지정**: `input/` 폴더에서 해당 N번에 매칭되는 초안 이미지(예: `로고초안1.png`, `로고초안_1.png` 또는 N번째 파일)만 선택하여 집중 분석한다.
- **수집 수량**: 해당 초안에 대하여 기본 **3장**의 유사 레퍼런스를 찾아 수집하고 분석한다.
- **결과 저장 폴더**: `output/` 하위에 해당 N번 번호로 지정된 폴더(`output/1번/`, `output/2번/` 등)를 자동 생성하여 해당 폴더 내에 3장의 JPG 이미지(`similar_logo_01.jpg`, `02.jpg`, `03.jpg`) 및 `flow.md`를 저장한다.

일반 명령 예시:

- `로고 초안 1번 실행시작` → `input/`의 1번 초안 지정, 3장 수집/분석, `output/1번/` 폴더에 저장
- `로고 초안 2번 실행시작` → `input/`의 2번 초안 지정, 3장 수집/분석, `output/2번/` 폴더에 저장
- `실행 시작` → `input/` 전체 초안 기준 기본 1개 수집/분석, `output/` 폴더에 저장

## 경로

모든 상대 경로는 이 파일이 있는 `로고` 폴더를 기준으로 한다.

- 수집 지침: `md파일/pin.md`
- 분석 지침: `md파일/pin분석.md`
- 형태 입력: `input` (지정된 N번 초안 이미지)
- 스타일 입력: `레퍼런스` (`레퍼런스/` 폴더 내 스타일 이미지)
- 이미지 출력: `output/[N번]/` (`output/1번/`, `output/2번/` 등)
- Flow 프롬프트 출력: `output/[N번]/flow.md`

## 1단계: 레퍼런스 수집

1. 실행 명령에서 지정된 N번 초안과 수량(기본 3장)을 확정한다.
2. `md파일/pin.md`를 처음부터 끝까지 읽는다.
3. 선택된 `input` 초안 이미지에서 배경의 보조 그리드 선은 제외하고 **진하게 그린 선과 면**을 기준으로 형태를 분석한다.
4. `레퍼런스` 이미지에서 흰 배경, 검정 단색, 2D 플랫 기하학 심볼 스타일 기준을 분석한다.
5. Pinterest에서 영문 키워드 조합으로 검색하고 후보를 비교한다.
6. 유색/컬러, 3D 목업, 질감 렌더링 요소를 완벽히 배제하고 지정 수량(3장)을 채운다.
7. `output/[N번]/` 폴더에 `similar_logo_01.jpg`, `similar_logo_02.jpg`, `similar_logo_03.jpg` 이름으로 저장한다.
8. 각 파일을 실제로 열어 JPEG 형식, 내용, 잘림, UI, 팝업, 워터마크, 목업 여부를 확인한다.

## 2단계: 레퍼런스 분석

1. 1단계의 이미지 저장과 육안 검증이 모두 끝난 뒤 시작한다.
2. `md파일/pin분석.md`를 처음부터 끝까지 읽는다.
3. `output/[N번]/` 폴더에 새로 저장된 3장 이미지 각각의 조형 요소 및 기하학적 구조를 시각 분석한다.
4. 이미지별 Flow 이미지 생성용 영문 프롬프트를 100% 영문으로 작성한다.
5. `output/[N번]/flow.md`에 이미지 파일명을 Markdown 대제목(`# 파일명.jpg`)으로 쓰고 그 아래에 프롬프트를 기록한다.
6. 새로 수집한 이미지 수와 새로 작성한 프롬프트 수가 같은지 확인한다.

## 수량 보장

- 목표 수량(3장)을 채우기 전까지 적합한 검색어와 후보를 계속 검토한다.
- 품질 검증에 실패한 후보는 수량에 포함하지 않는다.
- 중복 이미지와 동일 핀의 변형 이미지는 각각 별도 결과로 계산하지 않는다.

## 완료 조건

다음 조건을 모두 만족해야 전체 실행을 완료로 보고한다.

1. `output/[N번]/` 폴더에 지정 수량(3장)만큼 새 JPG가 존재한다.
2. 모든 새 JPG를 실제로 열어 검증했다.
3. 모든 새 JPG에 대응하는 영문 프롬프트가 `output/[N번]/flow.md`에 존재한다.
4. `flow.md`에 중복 대제목이나 한글 프롬프트가 없다.

## 완료 보고 형식

- 지정 초안 번호 및 요청 수량 (3장)
- 수집 성공 수량
- 분석 성공 수량
- 생성한 JPG 파일 경로 목록 (`output/[N번]/` 하위)
- 갱신한 `output/[N번]/flow.md` 경로
- 실패하거나 부족한 항목이 있으면 해당 이유
