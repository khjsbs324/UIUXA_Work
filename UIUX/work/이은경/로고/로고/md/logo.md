## 4. 필터링 및 금지 기준 (Exclusion & Pass Criteria)

### 🚫 금지 조건 (Absolute Negatives)
1. **색상이 들어간 로고 금지**: 컬러 그래디언트, 다색 로고, 유색 배경 제외
2. **목업(Mockup)이 되어있는 로고 금지**: 
   - 3D 입체 렌더링, 질감 패키지 목업, 명함/욕실 연출 사진 제외
   - 그림자나 입체 효과(Embossing/Debossing)가 적용된 로고 제외
3. **복잡한 일러스트 금지**: 디테일이 지나치게 많은 회화적 일러스트 제외

### ✅ 검증 체크리스트 (Pass Checklist)
- [ ] 단색 흰색 배경에 검은색 단색으로 표현되었는가?
- [ ] 3D 목업이나 효과 없이 2D 평면(Flat Vector/Line Art) 상태인가?
- [ ] 원형 그리드나 깔끔한 기하학적 형태감이 잘 반영되었는가?
- [ ] SOAPHE 브랜드의 미니멀 오브제 감성과 부합하는가?

## 5. 자동 실행 규칙 (Automation Protocol)

사용자가 **`"내가 레퍼런스 수집 시작해"`** 라고 명령하는 경우, 아래 프로토콜에 따라 자동 레퍼런스 수집 작업을 수행합니다.

### 5.1 작업 수행 단계
1. **입력 분석 (`input/`)**: `input/` 폴더 내에 있는 파일(예: `input/로고초안.png`)의 조형적 특징과 형태 구조를 분석합니다.
2. **스타일 기준 적용 (`레퍼런스/`)**: `레퍼런스/` 폴더 내의 참고 이미지(예: `레퍼런스/image.png`)처럼 **흰 배경 + 검정 단색 + 2D 기하학/플랫 심볼**의 스타일 타겟을 적용합니다.
3. **핀터레스트 유사 이미지 탐색**: 본 문서의 검색 키워드 전략(Section 2)을 바탕으로 핀터레스트에서 부합하는 최적의 레퍼런스를 검색합니다.
4. **필터링 검증**: 본 문서의 금지 조건 및 검증 체크리스트(Section 4)를 기준으로 노이즈(컬러, 3D 목업, 질감)가 없는 이미지인지 확인합니다.
5. **결과 파일 생성 (`output/`)**: 최종 수집된 이미지를 캡쳐/추출하여 `output/` 폴더에 `.jpg` 확장자로 저장합니다.

## 6. Flow 이미지 생성 프롬프트 작성 규칙 (Flow Prompt Protocol)

수집된 레퍼런스를 바탕으로 이미지 생성 AI(Flow)에 활용할 수 있는 **영문 프롬프트(English Prompt)**를 추출 및 작성하여 기록하는 규칙입니다.

### 6.1 프롬프트 작성 및 관리 규칙
1. **Flow 활용 프롬프트 추출**: `output/` 폴더에 저장된 수집 레퍼런스 이미지를 시각적으로 분석하여, Flow 이미지 생성 기능에 즉시 활용 가능한 프롬프트를 작성합니다.
2. **영문(English) 작성 원칙**: 모든 프롬프트는 Flow AI 모델 입력에 최적화된 **영문(English)**으로 작성합니다.
   - 예시: `Minimalist monochrome 2D vector logo symbol, geometric circular design, solid clean white background, pure black logo mark, high contrast, flat line art, professional branding identity, no 3D render, no mockup`
3. **`output/flow.md` 파일 기록 구조**:
   - 작성된 프롬프트는 **`output/flow.md`** 파일에 기록 및 보관합니다.
   - 각 분석 이미지의 **파일명(예: `# logo_reference.jpg`)을 대제목(H1/H2)으로 작성**하고, 해당 대제목 아래쪽에 분석된 영문 프롬프트를 작성합니다.
4. **재실행 제어 규칙**:
   - 이미 작성/실행 완료된 이미지는 사용자의 **`'재실행'`** 명령이 입력되기 전까지 중복하여 다시 작성하거나 재실행하지 않으며, 기존 결과를 유지합니다.
