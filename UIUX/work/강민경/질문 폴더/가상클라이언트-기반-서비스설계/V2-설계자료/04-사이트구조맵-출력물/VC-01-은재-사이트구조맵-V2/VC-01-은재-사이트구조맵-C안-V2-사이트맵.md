# VC-01 은재 — 사이트구조맵 C안 V2 상세본

## 1. Client 전체 분석 근거

- Client: VC-01 은재 / 아날로그 장문 기록
- 프로젝트 목적: 통합 다이어리 브랜드의 메인 랜딩·카테고리·브랜드 소개 경험을 Client 요구에 맞게 설계
- Client 목표: 긴 글을 부담 없이 시작하고 일정·회고·제품 탐색을 기록 흐름으로 연결
- 상황: 아날로그 장문 기록과 관련된 정보를 탐색하고 제품·콘텐츠를 비교한 뒤 기록 행동을 판단
- 핵심 과업: 핵심 정보 확인 → 제품군·콘텐츠 비교 → 선택·보류 → 기록 또는 이전 위치 복귀
- 불편: 정보가 흩어지거나 선택 기준이 불명확하면 판단을 중단할 수 있음
- 판단 기준: 사용 상황 적합성, 정보의 명확성, 비교 가능성, 다시 시작할 수 있는 경로
- 성공 조건: 핵심 과업을 메인 → 제품군 허브 → 상세·비교 → 행동 시작로 완료
- 실패 조건: 제품을 단순 나열하거나 상태·근거·다음 행동을 알 수 없음
- 요구 ID: REQ-001
- 연결 제품: PROD-001·002·003·031·032·033·061·062·063·064·095
- 대표 15개 선정: 미실행·사용자 지시로 보류
- 입력 근거: Client V5 보강본, 제품콘텐츠-도출결과-V2, 통합 브랜드·공유자료

## 2. 구조안 전략

- 안: C안
- 전략: 제품군·포트폴리오 허브형
- 핵심 진입 경로: 메인 → 제품군 허브 → 상세·비교 → 행동 시작
- 주요 페이지 범위: 메인 랜딩, 제품군 허브, 제품 목록·필터, 상세·비교, 브랜드 소개, 행동 시작
- 다른 안과의 차이: 제품군의 전체 방향과 포트폴리오 탐색을 먼저 제공합니다.

## 6. 사용자 흐름

### 정상

진입 → 핵심 과업 확인 → 제품군 탐색 → 상세·비교 → 행동 시작 → 저장 또는 다음 콘텐츠.

### 분기

제품을 바로 고르는 경우: 메인 → 제품군 → 상세 → 행동 시작.
콘텐츠를 먼저 보는 경우: 메인 → 브랜드 소개 → 관련 제품 → 비교.

### 예외

결과 없음 → 검색·필터 초기화 → 전체 제품군 복귀.
비교 취소 → 이전 목록 유지.
행동 중단 → 보류 상태와 복귀 경로 제공.
저장 실패 → 오류 원인·재시도·임시 보류 제공.
