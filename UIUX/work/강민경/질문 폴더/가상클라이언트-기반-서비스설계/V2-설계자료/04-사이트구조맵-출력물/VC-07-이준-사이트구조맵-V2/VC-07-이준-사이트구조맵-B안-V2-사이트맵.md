- 1차: 메인 / 사용 상황 / 재시작 콘텐츠 / 관련 제품 / 브랜드 이야기 / 복귀 도구
  - 사용 상황: 중단 / 바쁜 일정 / 다시 시작 / 남은 단계
    - 3차: 사례 상세 / 진행 상태 / 관련 제품 / 복귀 안내
