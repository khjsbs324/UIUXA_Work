# Client V5 사이트구조맵 보강 기준

## 목적

V4 제품 연결 Client를 사이트구조맵 입력으로 사용할 수 있도록 페이지 목적, 정보 구조, 행동 상태, 제품 배치와 브랜드 접점을 보강한다. V2·V3·V4 원본은 보존한다.

## Client별 보강 항목

### 1. 페이지 우선순위

- 핵심 페이지: Client 목표를 직접 해결하는 페이지
- 보조 페이지: 탐색·비교·신뢰 형성을 지원하는 페이지
- 영향 페이지: 요구사항은 연결되지만 핵심 행동에는 직접 영향이 적은 페이지

### 2. 메뉴·콘텐츠·기능 변환

| Client 요구·REQ | 메뉴 | 콘텐츠 | 기능 | 연결 페이지 | 근거·가정 |
|---|---|---|---|---|---|

### 3. 상태·예외 행동

- 신규 방문·탐색
- 제품 비교·보류
- 기록 또는 콘텐츠 진행
- 저장·중단·복귀
- 결과 없음·오류·취소·재시도

### 4. 제품 배치

- 연결 Product ID
- 연결 제품군
- 배치 페이지
- 제품이 해결하는 Client 과업
- 함께 제공할 콘텐츠·근거
- 대표 15개 선정 여부: 이 단계에서는 미실행

### 5. 브랜드 접점

- 브랜드 방향과 Client 요구의 연결
- 제작 과정·재료·기록 철학 중 관련 콘텐츠
- 제품을 포트폴리오로 인식시키는 설명 방식

### 6. 고유 차별점

- 다른 Client와 겹치는 요구
- 이 Client만의 불편·판단 기준
- 사이트 구조에서 반드시 유지할 차별 요소
