## 1. 가상 클라이언트 기본 정보

- 프로젝트 중심 주제: 통합 다이어리 브랜드 웹사이트의 브랜드·제품 탐색 경험.
- 제작 목적: 빠른 기록의 의미 선택 관점에서 사용자가 확인·선택·보류해야 하는 조건을 구체화합니다.
- 가상 Client 이름: 유진 (식별용 가상 이름)
- 제공 자료·근거: VC-03 빠른 기록의 입력 범위 심화.
- 매체: 반응형 웹(Desktop·Mobile).
- 우선순위: 요구사항 상태 `PROPOSED`.
- 필요한 정보·기능: 한 줄·사진·음성·기분 중 하나만으로 완료하고 나머지는 강제하지 않는다.

## 2. Client 요청사항

1. 요청: 한 줄·사진·음성·기분 중 하나만으로 완료하고 나머지는 강제하지 않는다.
2. 중요도: 후속 검증 후 확정
3. 관련 자료·추적: `CR-032`, SR-008·020, PAGE-001·010 후보.
4. 성공 기준: 선택한 입력 하나로 완료 상태를 이해한다.
5. 실패·금지 기준: 사진·문장·감정·태그를 전부 요구한다.
6. 누락·중복 점검: 유사 Client와 충돌은 요구사항 단계에서 비교하되, 이 Client 관점은 병합하지 않습니다.

## 2-2. Client별 후속 후보 산출 요구

- 사이트 구조맵 후보: 이 Client의 요구를 반영한 복수 구조 방향을 후속 단계에서 생성합니다.

- 서비스 흐름도 후보: 정상·분기·오류·취소·복귀를 포함한 복수 흐름 방향을 후속 단계에서 생성합니다.

- 화면설계서 후보: 화면 목적·콘텐츠·기능·상태·반응형·접근성을 포함한 복수 방향을 후속 단계에서 생성합니다.

- 제품 후보: 이 Client에 연결되는 복수 제품을 제품 단계에서 생성하고 Product ID를 부여합니다.

- 현재 상태: Client 분석 단계에서는 후보 산출 기준을 확정하며, 실제 구조맵·흐름도·화면설계서·제품 파일은 해당 단계 출력물에서 생성합니다.
