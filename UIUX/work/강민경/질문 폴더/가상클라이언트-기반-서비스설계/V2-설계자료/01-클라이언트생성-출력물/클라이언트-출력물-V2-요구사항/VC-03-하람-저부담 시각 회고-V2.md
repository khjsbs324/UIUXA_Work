- 제작 목적: 빈 화면과 문장 완성 부담 없이 가장 작은 단위로 기록하고 나중에 다시 본다.
- 가상 Client 이름: 하람 (식별용 가상 이름이며 실제 조사 참여자 이름이 아님)
- 제공 자료·근거: `INT-024~031`, `IR-009~011·018`; 감정 스티커는 제안 수용이라 조건부.
- 매체: 반응형 웹(Desktop·Mobile); 최종 산출물은 메인 랜딩·카테고리 서브·브랜드 소개로 연결.
- 우선순위: 높음; 후속 요구사항 분석에서 영향도 재평가
- 필요한 정보·기능: 사진·한 줄 중 하나로 시작, 선택적 꾸미기, 작은 완료 단위, 입력 보존 안내.

## 2. Client 요청사항

1. 요청: 사진·한 줄 중 하나로 시작, 선택적 꾸미기, 작은 완료 단위, 입력 보존 안내.
2. 중요도: 높음
3. 관련 자료·추적: `SR-008~011·018`, PAGE-001·010·016 후보.
4. 필요한 기능·과업: 사진 또는 짧은 입력 선택 → 선택적 표현 추가 → 저장 → 회고.
5. 성공 기준: 하나의 입력만으로 완료하고 꾸미기 여부를 직접 선택한다.
6. 실패·금지 기준: 사진·문장·감정·태그를 모두 요구하거나 지속 효과를 과장한다.
7. 누락·중복 점검: 동일 요구는 후속 요구사항 분석에서 비교하되, 이 파일의 Client 관점 자체는 병합하지 않음.
