## 2. 통합 화면 목록

### VC-01 은재

| 장 | 화면 목적 | 핵심 흐름 |
|---|---|---|
| 메인 | 장문 기록량과 여백 기준을 이해 | 공감 → 조건 진단 → 구조 비교 → 후보 레일 |
| 카테고리서브 | 사용 상황별 후보 비교 | 인덱스 → 필터 → 그리드 → 비교/보류 |
| 브랜드 소개 | 확인된 사실과 HOLD 범위 이해 | 선언 → 실측 과정 → Fact/HOLD → 다음 행동 |

### VC-02 지안

| 장 | 화면 목적 | 핵심 흐름 |
|---|---|---|
| 메인 | 미래 일정의 빈 날·충돌·이동 여유 판단 | 개요 → 날짜 → 시간축 → 중요도 → 알림 |
| 카테고리서브 | 일정 상황별 도구 비교 | 월간 → 빈 날짜 → 충돌 → 선택적 알림 |
| 브랜드 소개 | 필요한 순간만 선택하는 원칙 설명 | 개요/세부 → 선택권 → 알림 HOLD |

### VC-03 하람

| 장 | 화면 목적 | 핵심 흐름 |
|---|---|---|
| 메인 | 사진 또는 한 줄로 저부담 시작 | 하나 선택 → 꾸미기 선택 → 저장 → 재개 |
| 카테고리서브 | 시작 단위와 다시 보기 도구 비교 | 유형 인덱스 → 자산 필터 → 저장/회고 |
| 브랜드 소개 | 작은 시작과 기록 자율성 설명 | 최소 입력 → 표현 선택 → 상태 정직성 |
