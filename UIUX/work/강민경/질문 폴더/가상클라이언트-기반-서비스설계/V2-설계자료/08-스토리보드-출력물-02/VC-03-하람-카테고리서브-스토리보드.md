# VC-03 하람 · 카테고리 서브페이지 스토리보드

## 0. 계약

| 목적 | 저부담 기록 후보를 입력 단위와 회고 방식으로 묶어 비교한다. |
|---|---|
| 추적 | `CLIENT=VC-03`, `REQ=REQ-003`, `PAGE=PAGE-009·010·016`, `PRODUCTS=PROD-007·008·009·037·038·039·069·070·071·072` |

## 1. 카테고리

| 카테고리 | 제품 | 판단 질문 |
|---|---|---|
| 한 장 시작 | PROD-007·037·069 | 사진 한 장으로 오늘을 남길 수 있는가? |
| 한 줄 시작 | PROD-009·071·072 | 문장 하나만으로 완료 가능한가? |
| 선택적 표현 | PROD-008·038·039·070 | 꾸미기·감정·맥락을 선택적으로 더하는가? |
| 다시 보기 | PROD-008·070·071 | 나중에 원본과 맥락을 다시 찾을 수 있는가? |

## 2. 패널

### SCR-C01 · 시각적 Hero
사진 한 장과 빈 카드 한 줄을 나란히 보여주고 “작은 입력도 기록입니다”를 선언한다. 이미지 로딩 실패 시 카드 설명으로 대체한다.

### SCR-C02 · 입력 단위 탭
한 장/한 줄/표현/다시 보기 탭과 현재 선택 칩을 제공한다. 탭 전환 시 입력값을 초기화하지 않고, 결과 없음은 기본 단위로 복귀시킨다.

### SCR-C03 · 후보 그리드
카드에 입력 최소 단위, 건너뛰기 가능 여부, 사진 보존/삭제, 꾸미기 선택, `PROD/PAGE/REQ`를 표시한다.

### SCR-C04 · 비교·보류
“필수 입력 수”, “꾸미기 강제 여부”, “다시 보기 경로”, “미지원 상태”를 비교 행으로 제공한다. 구매가 아닌 저장/보류 CTA를 사용한다.

### SCR-C05 · 완료·복귀
하나만 입력해 완료, 꾸미기만 보류, 현재 화면 유지, 메인 복귀를 분리한다. 저장 충돌 시 유지/복구/초기화 선택을 제공한다.

## 3. 제작 상세·상태·검증

| 영역 | 실제 표시 | 행동 | 예외·상태 | 접근성/반응형 |
|---|---|---|---|---|
| Hero | `작은 입력도 기록입니다` + 사진/빈 카드 비주얼 | 카테고리 앵커 이동 | 이미지 실패→설명 카드 | alt, Mobile 세로 |
| 탭 | 한 장/한 줄/표현/다시 보기 | 탭 전환·선택칩 유지 | 결과 없음→기본 탭 | tablist/tabpanel, 키보드 |
| 카드 | 최소 입력·건너뛰기·보존 상태·PROD | 상세/비교/보류 | HOLD·자료 없음 | 카드 제목 순서, 44px |
| 비교 | 필수 입력 수·꾸미기 강제 여부·복귀 | 열 제거·보류 저장 | 충돌·오프라인 | 모바일 카드 변환 |

상태 전이: `Default → CategorySelected → Compare → Hold/Empty → Saved 또는 Return`. 입력값과 선택 카테고리는 전이마다 보존하며, 삭제·초기화는 영향 확인 후 실행한다.

테스트: 한 줄 후보 비교, 사진 권한 거부, 자료 없음, 꾸미기 없는 완료, 모바일 탭 키보드 이동, 비교 보류 후 복귀를 검증한다.
