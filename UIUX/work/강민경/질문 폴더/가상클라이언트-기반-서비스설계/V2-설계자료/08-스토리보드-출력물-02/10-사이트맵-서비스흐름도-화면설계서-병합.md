# 사이트맵·서비스 흐름도·화면 설계서 입력 병합본

상태: `INPUT_DESIGN_MERGED`
대상: VC-01 은재 · VC-02 지안 · VC-03 하람

이 파일은 스토리보드와 분리된 입력 설계자료 통합본이다. 스토리보드 결과는 `11-스토리보드-통합.md` 및 `11-스토리보드-통합.html`에서 관리한다.

| 사이트맵 | `V1-기존-설계자료/설계-출력물/사이트-구조맵/06-사이트맵.md` |

| 서비스 흐름도 | `06-서비스 흐름도-출력물`, `V1-기존-설계자료/설계-출력물/서비스-흐름도/07-서비스-흐름도.md` |

## 2. 공통 사이트 구조

| 구분 | 페이지 | 역할 |
|---|---|---|
| 메인 | `PAGE-001` | 브랜드 경험과 첫 과업을 한 장의 랜딩으로 연결 |
| 기록 방식 | `PAGE-002·003·004` | 사용 목적과 기록 방식 선택 |
| 디지털 기록 | `PAGE-009·010·011·015` | 일정·빠른 기록·저장·재개 |
| 기록 가이드 | `PAGE-016` | 템플릿·표현·기록 방법 안내 |
| 보조/브랜드 | `PAGE-019·020` | 도움말·브랜드 원칙 |
| 카테고리서브 | `PAGE-021` | 비판매 포트폴리오와 후보 비교 |

## 3. 클라이언트별 입력 통합

### VC-01 은재

| 입력 | 통합 결과 |
|---|---|
| 사이트맵 | `PAGE-001 → PAGE-002 → PAGE-003 → PAGE-004`, `PAGE-020·021` |
| 서비스 흐름 | 장문 기록 공감 → 빈도/문단/일정·메모 조건 → 구조 비교 → 후보 비교 → 직접 비교 또는 HOLD |
| 화면 설계 | Hero, 조건 진단, 속지 구조, 15개 후보 레일, 근거, 마지막 행동 |
| 요구사항/제품 | `REQ-001`, 직접 후보 11개 + 확장 검토 4개 |

### VC-02 지안

| 입력 | 통합 결과 |
|---|---|
| 사이트맵 | `PAGE-001 → PAGE-003 → PAGE-009 → PAGE-011`, `PAGE-019·020·021` |
| 서비스 흐름 | 월간 개요 → 빈 날/일정 날 → 시간축 충돌·이동 여유 → 중요도 → 선택적 알림 |
| 화면 설계 | 달력 미리보기, 날짜 선택, 시간축, 알림 선택, 상황별 도구, 복귀 |
| 요구사항/제품 | `REQ-002`, 일정·시간축·선택적 알림 상황 후보 |

### VC-03 하람

| 입력 | 통합 결과 |
|---|---|
| 사이트맵 | `PAGE-001 → PAGE-009 → PAGE-010 → PAGE-015`, `PAGE-016·020·021` |
| 서비스 흐름 | 사진/한 줄/나중에 중 하나 → 입력 보존 → 꾸미기 선택 또는 건너뛰기 → 저장 → 다시 보기/재개 |
| 화면 설계 | 최소 입력, 권한 거부 대안, 선택형 꾸미기, 저장 상태, 회고 |
| 요구사항/제품 | `REQ-003`, 사진·한 줄·저부담 회고 관련 후보 |
