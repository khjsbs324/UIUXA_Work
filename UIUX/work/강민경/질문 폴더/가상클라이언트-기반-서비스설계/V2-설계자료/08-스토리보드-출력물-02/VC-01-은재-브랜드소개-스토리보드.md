## 0. 문서 계약

| 항목 | 내용 |
|---|---|
| 목적 | 은재가 이 브랜드가 무엇을 믿고 어떤 기준으로 제품·콘텐츠를 만드는지 이해한다. |
| 페이지 성격 | 기록 철학·제작 과정·근거 공개를 서사적으로 보여주는 브랜드/포트폴리오 페이지 |
| 진입/이탈 | 메인 `SCR-M04` 또는 카테고리 근거 노드 → `SCR-B01~B05` → 관련 제품·비교 |

| 원칙 | 확인된 사실과 미확정 물성을 분리하고 감성 문장만으로 품질을 보장하지 않는다. |

## 1. 서사 순서

`왜 기록량을 보는가` → `어떻게 구조를 설계하는가` → `무엇을 확인했는가` → `무엇은 아직 모르는가` → `제품/비교로 이어가기`

## 2. 화면별 패널

### SCR-B01 · 선언: 기록의 길이를 존중한다

| 항목 | 상세 |
|---|---|
| 목적 | 브랜드 특징을 짧고 분명하게 정의한다. |
| 비주얼 | 종이의 빈 공간과 필기 흔적을 세로 타임라인으로 전개; 장식보다 여백 우선 |
| 카피 | “우리는 기록을 줄이지 않고, 기록할 자리를 설계합니다.” |
| 행동 | `설계 기준 보기` 앵커, 스크린리더용 요약 문장 제공 |

### SCR-B02 · 설계 기준 3축

| 항목 | 상세 |
|---|---|
| 목적 | 장문 기록에 필요한 기준을 제품 구조와 연결한다. |
| 3축 | 기록 영역(넓은 줄·충분한 여백) / 흐름(일정+메모 조합) / 지속성(교체·보관·휴대) |
| 인터랙션 | 축 선택 시 관련 PAGE와 PROD가 강조되고, 선택 근거가 펼쳐짐 |
| 연결 | PROD-001·002·031·032·061·062·064 |

### SCR-B03 · 제작 과정 포트폴리오

| 항목 | 상세 |
|---|---|
| 목적 | 제품 결과가 아니라 판단 과정을 보여준다. |
| 단계 | 기록 상황 관찰 → 속지 구조 실측 → 조합 테스트 → 공개 기준 정리 |
| 카드 정보 | 단계 설명, 확인 자료 ID, 연결 제품, 다음/이전 단계 |
| 예외 | 자료가 없는 과정은 “공개 준비 중”으로 표시하며 사례를 만들어 채우지 않는다. |

### SCR-B04 · 사실과 HOLD를 나란히 공개

| 항목 | 상세 |
|---|---|
| 목적 | 은재가 온라인에서 확정할 수 있는 것과 직접 확인해야 할 것을 구분한다. |
| 좌측 | 확인된 실측·구성: 줄 간격, 페이지 구조, 일정표/메모 조합 |
| 우측 | HOLD: 촉감, 장기 내구성, 실제 무게감 등 자료 미확인 항목 |
| 행동 | 근거 ID 펼침, 오프라인 확인 메모, 관련 제품 비교로 이동 |
| 금지 | “부드럽다/튼튼하다” 같은 보장형 표현을 근거 없이 사용하지 않는다. |

### SCR-B05 · 브랜드에서 개인 판단으로

| 항목 | 상세 |
|---|---|
| 목적 | 브랜드 이해를 은재 자신의 선택 과업으로 전환한다. |
| 요약 | “내 기록 조건에 맞는 구조를 확인했는가?” 체크리스트와 미확정 항목 요약 |
| CTA | `내 기록 조건 비교하기`→PAGE-002 / `카테고리 기준 보기`→PAGE-021 / `확인 필요 항목 보류`→PAGE-007 |
| 완료/복귀 | 현재 앵커·읽은 근거·선택값을 보존하고 메인으로 돌아갈 수 있다. |
