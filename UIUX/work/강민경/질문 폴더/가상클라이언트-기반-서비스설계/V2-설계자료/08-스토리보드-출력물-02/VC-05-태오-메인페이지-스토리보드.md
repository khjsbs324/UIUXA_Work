## 2. 상태·반응형·검증

`Default → DeviceSelected → StatusKnown/Unknown → Conflict 또는 SafeHold → Resume/Return`.
기기 선택과 마지막 위치는 유지하지만 실제 기록 원문·계정·동기화 완료를 생성하지 않는다. Mobile은 상태 카드가 세로로, 기기 비교는 내부 가로 스크롤로 제공한다. 테스트는 기기 전환, 미지원 표시, 충돌 원본 보존, 오프라인 복귀, 200% 확대를 포함한다.
