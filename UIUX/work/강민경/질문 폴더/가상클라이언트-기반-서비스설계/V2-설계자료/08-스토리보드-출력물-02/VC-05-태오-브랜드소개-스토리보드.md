## 2. 상태·에셋·테스트

`FACT`: 현재 위치·선택값·상태명 보존. `HOLD`: 외부 API·자동 동기화·자동 병합. 에셋은 `DATA-020-05` 상태 문구와 `DATA-020-06` 충돌 예시이며 없으면 텍스트 표로 대체한다. 지원/미지원 경계, 원본 보호, 충돌 보류, Mobile 읽기 순서를 테스트한다.
