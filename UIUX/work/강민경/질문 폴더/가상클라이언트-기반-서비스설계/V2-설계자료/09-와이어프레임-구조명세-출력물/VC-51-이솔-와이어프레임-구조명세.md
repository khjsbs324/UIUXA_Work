# VC-51 이솔 · 와이어프레임 구조명세

`REQ-051` · 저연결성 긴 페이지 복귀 · Section 단위 오류·기존 내용 유지·복귀 위치 보존.

| 페이지 | 구조 | 핵심 UI/행동 | 상태 |
|---|---|---|---|
| 메인 | 긴 Page 목차→Section 로딩→부분 오류→텍스트 대안 | 실패 영역만 재시도/건너뛰기 | Offline·Resume |
| 카테고리 | 텍스트 카탈로그→제품 비교→복귀 위치 | 이미지 없이 탐색 | Section Error |
| 브랜드 | 브랜드/근거 Section 저장→오류 안내→원래 앵커 | 읽은 내용 보존 | 자동 새로고침 금지 |

Desktop은 목차 2col+본문 10col, Mobile은 현재 Section·상태를 상단 고정한다. 오류가 전체 페이지를 대체하지 않으며, 확인한 내용·선택·스크롤 앵커를 유지하고 `재시도 / 건너뛰기 / 원래 위치`를 제공한다.
