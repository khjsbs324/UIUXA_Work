# VC-22 선율 · 와이어프레임 구조명세

`REQ-022` · 기록 공개 부담 · 입력 전 처리 범위·대체 경로 확인.

| 페이지 | 구조 | 콘텐츠/행동 | 상태 |
|---|---|---|---|
| 메인 | 입력 전 고지→처리 범위→거부 대안→시작 | 저장·분석·공유 범위 | 미지원 분석 HOLD |
| 카테고리 | 입력 유형별 공개 범위→권한 비교 | 사진·감정·일정별 사용처 | 권한 거부·Empty |
| 브랜드 | 원본 보호→최소 수집→비공개 원칙 | 내용 입력 전 설명 | 정책 미정 |

Desktop은 데이터 유형 4col+범위 설명 8col, Mobile은 유형→범위→대안이다. 입력 전 `무엇을 하지 않는지`도 보여주고 거부 시 한 줄/로컬 대안을 제공한다.
