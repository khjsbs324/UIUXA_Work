# VC-05 태오 · 클라이언트별 와이어프레임 구조명세

상태: `DETAILED_WIREFRAME_STRUCTURE_DRAFT` · `REQ-005` · `PAGE-009·012·019`

## 1. 구조 계약

모바일에서 시작한 기록을 태블릿·PC에서 이어갈 때 현재 위치·최신 상태·다음 행동을 확인한다. 충돌 시 원본 보호·수동 복구·안전한 보류를 제공하며 자동 동기화는 확정하지 않는다. 제품은 `PROD-013·014·043·044·045·077·078`이다.

## 2. 메인 `PAGE-001`

`005-HEADER → 005-HERO → 005-DEVICE-RANGE → 005-STATUS-PREVIEW → 005-RECOVERY → 005-ACTION`.

| ID | 콘텐츠/카피 | 배치 | 상태·행동 | 이동 |
|---|---|---|---|---|
| `005-HERO` | `이어짐은 약속이 아니라 확인할 상태입니다` | 상태 Notice + CTA | Validation HOLD 고정 | `009` |
| `005-DEVICE-RANGE` | 모바일·태블릿·PC 지원 범위 | 기기 3카드 | 미지원·미정 | `012` |
| `005-STATUS-PREVIEW` | 위치·시점·다음 행동 | 3 상태 카드 | Pending·Unknown·Conflict | `019` |
| `005-RECOVERY` | 원본·수동 병합·보류 | 복구 방식 패널 | 근거 없음 HOLD | `019` |
| `005-ACTION` | 상태 확인·보류·원래 위치 | 3 CTA | 저장 실패·복귀 | `012·001` |

## 3. 카테고리 `PAGE-012`

| ID | 필드 | 컴포넌트 | 전이/예외 | 반응형 |
|---|---|---|---|---|
| `012-DEVICES` | 선택 기기·지원 범위 | Device rail | 선택 없음·미지원 | Mobile 가로 |
| `012-STATUS` | 마지막 위치·시점·다음 행동 | Status panel | Unknown/Pending | 날짜 아래 |
| `012-CONFLICT` | 원본/최신본 변경점 | Diff panel | 충돌·오프라인 | 세로 비교 |
| `012-RECOVERY` | 원본 유지·수동 복구·보류 | 선택 카드 | 자동 병합 금지 | 전폭 카드 |
| `012-ACTION` | 계속·보류·초기화 | 확인 Modal | 취소·저장 오류 | Fullscreen |

전이는 `DeviceDefault → Selected → Status → ConflictReview → KeepOriginal/ManualResume/Hold`. 입력·위치·상태 시점을 보존한다.

## 4. 브랜드 `PAGE-020`

`020-HERO(상태 공개) → 020-PRINCIPLE(최신/원본/복귀) → 020-PROCESS → 020-BOUNDARY(자동 연동 HOLD) → 020-NEXT`.

## 5. 공통 규격

Desktop은 기기 비교와 상태 패널을 8:4, Tablet은 세로, Mobile은 상태 우선 순서로 배치한다. `aria-live` 상태 공지, 충돌 변경점 제목 연결, 44px 버튼, 200% Zoom, 키보드 대체 조작을 적용한다.
