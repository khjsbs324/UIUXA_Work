# VC-03 하람 · 클라이언트별 와이어프레임 구조명세

상태: `DETAILED_WIREFRAME_STRUCTURE_DRAFT` · `REQ-003` · `PAGE-001·009·010·015`

## 1. 구조 계약

핵심 과업은 사진 또는 한 줄 하나로 시작 → 꾸미기 선택/건너뛰기 → 저장 → 다시 보기다. 사진·문장·감정·태그를 모두 요구하지 않으며, 권한 거부 시 한 줄 대안을 즉시 제공한다. 연결 제품은 `PROD-007·008·009·037·038·039·069·070·071·072`다.

## 2. 메인 `PAGE-001`

`003-HEADER → 003-HERO → 003-ONE-INPUT → 003-OPTIONAL → 003-REVIEW → 003-STATE → 003-ACTION`.

| ID | 콘텐츠/카피 | 배치·컴포넌트 | 상태·행동 | 이동 |
|---|---|---|---|---|
| `003-HERO` | `오늘은 한 장 또는 한 줄이면 충분해요` | H1+사진/한 줄 Split | 이미지 실패에도 CTA 유지 | `009·010` |
| `003-ONE-INPUT` | 사진 한 장·한 줄·나중에 | Radio 카드 3개 | 미선택·권한 거부·입력 보존 | `009·010` |
| `003-OPTIONAL` | 꾸미지 않고 저장 / 표현 보기 | 동등 CTA + 자산 레일 | 자산 없음·HOLD | `016` |
| `003-REVIEW` | 최근 기록·원본/보존 상태 | 카드 + 상태 배지 | 데이터 없음·삭제 | `015` |
| `003-STATE` | Local·Error·Offline 범위 | 상태 패널 + 도움 링크 | Saving/Error/Offline | `015` |

## 3. 카테고리 `PAGE-009·010`

| ID | 화면 골격 | 필수 필드 | 검증/예외 | 모바일 |
|---|---|---|---|---|
| `009-TYPE` | 유형 선택→입력 | 유형 1개 | 권한 거부→한 줄 | 1열 Radio |
| `010-INPUT` | 입력→미리보기→저장 | 사진 1개 또는 한 글자 이상 | 빈 값·공백·이미지 오류 | 입력→Preview |
| `010-OPTIONAL` | 기분·날짜·꾸미기 | 모두 선택 | 선택 없이 완료 | Accordion |
| `010-STATUS` | 저장 상태 | 결과/범위 | Local/Offline/Error | 결과 상단 |

전이는 `Default → Editing → Ready → Saving → Saved/Local 또는 Error/Offline → Resume`. 입력은 전이마다 유지한다.

## 4. 브랜드 `PAGE-020`

`020-HERO(작은 시작) → 020-PRINCIPLE(건너뛰기) → 020-PROCESS(입력 축소) → 020-BOUNDARY(감정 해석/지속 효과 HOLD) → 020-NEXT`.

## 5. 공통 규격

Desktop 1200은 유형 3열·입력/Preview 8:4, Tablet은 2열, Mobile은 1열·Primary 전폭. H1/H2 계층, Radio legend, aria-live Saving/Error, 44px Target, 200% Zoom, Reduced motion을 적용한다. HTML 스토리보드는 이 ID와 상태를 그대로 반영한다.
