# VC-12 해솔 · 와이어프레임 구조명세

`REQ-012` · `PAGE-001·010·012·019·020` · 목적: 개인정보·권한·저장·삭제·내보내기 범위를 확인 후 시작 여부 결정.

| 페이지 | 구조 | 필드/행동 | 상태 |
|---|---|---|---|
| 메인 | 입력 전 고지→데이터 유형→저장 범위→대체 경로 | 사진·감정·일정, Local/미지원 | 권한 거부·HOLD |
| 카테고리 | 저장 위치→삭제/내보내기→권한 비교 | 항목별 영향·확인일 | 범위 미정·결과 없음 |
| 브랜드 | 최소 수집→원본 보호→보존 한계 | 정책 근거·도움 링크 | `안전하게 저장` 과장 금지 |

Desktop은 데이터 유형 목록 4col+범위 설명 8col, Mobile은 유형→범위→행동 순이다. 삭제·내보내기 영향 확인 Modal, 오류 시 입력값 보존, 개인정보 원문 저장 금지를 구조에 반영한다.
