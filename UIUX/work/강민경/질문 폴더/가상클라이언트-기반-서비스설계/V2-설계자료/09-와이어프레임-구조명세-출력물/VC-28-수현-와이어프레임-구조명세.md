# VC-28 수현 · 와이어프레임 구조명세

`REQ-028` · 오래된 기록 재탐색 · Analog/Digital 방법과 한계 분리.

| 페이지 | 구조 | 필드/행동 | 상태 |
|---|---|---|---|
| 메인 | 매체 선택→재탐색 방법→수동 색인→한계 | 종이 위치·디지털 위치 | OCR/AI 검색 HOLD |
| 카테고리 | Analog/Digital 비교→주제·날짜·위치 | 수동 인덱스·원본 유지 | 자료 없음·결과 없음 |
| 브랜드 | 원본 보호→다시 찾기 과정→자동 기능 한계 | 보관 원칙 | 영구 보존 과장 금지 |

Desktop은 매체 비교 6:6, Mobile은 매체→방법→한계 순이다. 검색 결과가 없으면 새 기록 시작·수동 색인·원본 위치 확인을 제공하고 자동 이전을 암시하지 않는다.
