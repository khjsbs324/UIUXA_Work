# VC-23 도윤 · 와이어프레임 구조명세

`REQ-023` · 복잡한 필터 회피 · 최소 입력으로 후보를 보고 선택적으로 조건 확장.

| 페이지 | 구조 | 필드/행동 | 상태 |
|---|---|---|---|
| 메인 | 기본 후보→핵심 조건 1~2개→상세 필터 선택 | 목적·분량만 우선 | 미선택은 정상 |
| 카테고리 | 결과 먼저→필터 Drawer→적용 미리보기 | 핵심/상세 분리·전체 해제 | Empty·조건 충돌 |
| 브랜드 | 적절한 구조·필터 절제 | 긴 질문 대신 점진 공개 | 기본값=선호 금지 |

Desktop은 결과 8col+필터 4col, Mobile은 결과→필터 Bottom sheet다. 필터 미선택을 오류로 표시하지 않으며 현재 조건·결과 수·전체 초기화를 항상 표시한다.
