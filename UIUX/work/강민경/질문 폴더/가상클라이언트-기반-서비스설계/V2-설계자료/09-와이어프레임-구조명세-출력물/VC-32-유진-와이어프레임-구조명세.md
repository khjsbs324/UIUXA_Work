# VC-32 유진 · 와이어프레임 구조명세

`REQ-032` · 빠른 기록의 의미 선택 · 한 줄·사진·음성·기분 중 하나로 완료.

| 페이지 | 구조 | 콘텐츠/행동 | 상태 |
|---|---|---|---|
| 메인 | 최소 단위 4종→완료 의미→상태 도움 | 유형 하나 선택 | 다른 입력 비강제 |
| 카테고리 | 유형 선택→최소 필드→미리보기→저장 | 유형별 필수/선택 | 빈 값·권한 거부 |
| 브랜드 | 작은 시작→지속 가능성→원본 보호 | 의미를 사용자가 선택 | 감정 추론 HOLD |

Desktop은 유형 4열, 입력/Preview 8:4, Mobile은 유형→입력→결과다. 유형 전환 시 기존 입력을 유지하고 최종 저장에는 현재 선택만 포함한다.
