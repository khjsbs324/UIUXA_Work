# VC-01 은재-아날로그 장문 기록 — 서비스 흐름도

상태: CANONICAL_REWRITTEN_SOURCE_ALIGNED
작성 방식: 클라이언트별 단일 기준 파일

## 1. 클라이언트 목표와 근거

- 상황: 매주 일정과 생각을 종이에 여러 문단으로 기록하며 새 다이어리를 고를 때 온라인 사진만으로 결정하지 않고 줄 간격·메모 공간·커버 물성·내부 구성을 확인한다.
- 목표: 실제 기록량에 맞는 속지 조합과 장기 사용 조건을 확인해 선택하거나 정보 부족 후보를 보류한다.
- 핵심 과업·행동 흐름: PAGE-002 → PAGE-003 → PAGE-004 → PAGE-005/006 → PAGE-007 → PAGE-008
- 요구: 목적·분량별 속지 선택, 실측 기반 비교, 적합·부적합 조건, 확인된 사실과 미확인 물성 분리.
- 성공 조건: 필요한 조합과 피할 조합을 설명하고 근거가 부족하면 구매 대신 보류한다.
- 실패 조건: 촉감·내구성을 사진에서 확정하거나 가격·재고·배송을 근거 없이 제공한다.
- 연결 제품: PROD-001·PROD-002·PROD-003·PROD-031·PROD-032·PROD-033·PROD-061·PROD-062·PROD-063·PROD-064·PROD-095
- 연결 페이지: PAGE-001
- 연결 요구사항: REQ-001
