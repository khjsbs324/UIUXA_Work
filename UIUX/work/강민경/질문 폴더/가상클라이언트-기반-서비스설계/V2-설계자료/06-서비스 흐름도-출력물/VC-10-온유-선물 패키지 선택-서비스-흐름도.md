## 1. 클라이언트 목표와 근거

- 상황: 받는 사람의 기록 취향과 숙련도를 완전히 모르는 상태에서 부담 없는 선물을 고른다.
- 목표: 확인된 조건만으로 안전한 후보와 확인이 더 필요한 후보를 구분한다.
- 핵심 과업: 선물 상황 선택 → 숙련도·사용 장면 확인 → 구성·난도 비교 → 정책 상태 확인 → 보류
- 행동 흐름: Gift 진입 → 모름 허용 → 후보 비교 → 포함 구성·준비물 확인 → 질문 목록 확보
- 요구: 선물 상황 필터, '모름' 선택, 과한 맞춤 추정 금지, 미정 정책 표시, 구매 CTA 차단.
- 성공 조건: 안전한 후보와 피할 조건, 받는 사람에게 확인할 질문을 구분한다.
- 실패 조건: 누구나 좋아함·가상 후기·구매 완료 흐름을 제공한다.
- 연결 제품: PROD-022·PROD-023·PROD-024·PROD-052·PROD-053·PROD-054·PROD-089·PROD-090·PROD-092
- 연결 페이지·원문 ID: PAGE-001

## 4. 예외·상태 전이

- 결과 없음: 선물 상황 필터, '모름' 선택, 과한 맞춤 추정 금지, 미정 정책 표시, 구매 CTA 차단. 기준으로 재탐색·조건 완화·보류를 제공한다.
- 오류·로딩 실패: 확인된 내용과 현재 위치를 보존하고 실패 영역만 재시도한다.
- 미지원·미정: 사실·가설·HOLD를 분리하고 실행 가능한 기능처럼 표현하지 않는다.
- 중단·복귀: 선택값과 판단 맥락을 보존해 다시 시작할 수 있게 한다.
- 실패 방지: 누구나 좋아함·가상 후기·구매 완료 흐름을 제공한다.
