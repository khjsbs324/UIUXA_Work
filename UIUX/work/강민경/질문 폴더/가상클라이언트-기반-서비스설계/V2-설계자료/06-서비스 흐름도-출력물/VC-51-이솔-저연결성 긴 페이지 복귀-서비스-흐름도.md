# VC-51 이솔-저연결성 긴 페이지 복귀 — 서비스 흐름도

상태: CANONICAL_REWRITTEN_SOURCE_ALIGNED
작성 방식: 클라이언트별 단일 기준 파일

## 1. 클라이언트 목표와 근거

- 상황: 모바일 저연결성에서 긴 메인과 카테고리를 이동하다 일부 콘텐츠 로딩이 실패한다.
- 목표: 이미 확인한 브랜드·제품 정보와 현재 위치를 유지하고 실패 Section만 건너뛴다.
- 핵심 과업: 긴 페이지 탐색 → 지연·실패 인지 → 기존 내용 유지 → 재시도·건너뛰기 → 복귀
- 행동 흐름: 메인 → 제품 레일 실패 → 텍스트 대안 → 카테고리 → 뒤로 → 원래 Section
- 요구: Section 단위 Error, 확인한 내용 보존, 이미지 비의존 탐색, 복귀 위치 유지.
- 성공 조건: 실패한 부분을 제외하고 브랜드와 제품 탐색을 계속한다.
- 실패 조건: 전체 페이지를 빈 오류 화면으로 대체하거나 자동 새로고침한다.
- 연결 제품: PROD-020·PROD-050·PROD-086·PROD-088
- 연결 페이지·원문 ID: PAGE-001,PAGE-021

## 4. 예외·상태 전이

- 결과 없음: Section 단위 Error, 확인한 내용 보존, 이미지 비의존 탐색, 복귀 위치 유지. 기준으로 재탐색·조건 완화·보류를 제공한다.
- 오류·로딩 실패: 확인된 내용과 현재 위치를 보존하고 실패 영역만 재시도한다.
- 미지원·미정: 사실·가설·HOLD를 분리하고 실행 가능한 기능처럼 표현하지 않는다.
- 중단·복귀: 선택값과 판단 맥락을 보존해 다시 시작할 수 있게 한다.
- 실패 방지: 전체 페이지를 빈 오류 화면으로 대체하거나 자동 새로고침한다.
