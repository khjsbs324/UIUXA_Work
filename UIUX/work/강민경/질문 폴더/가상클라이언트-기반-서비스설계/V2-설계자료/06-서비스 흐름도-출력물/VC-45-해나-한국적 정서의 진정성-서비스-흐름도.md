# VC-45 해나-한국적 정서의 진정성 — 서비스 흐름도

상태: CANONICAL_REWRITTEN_SOURCE_ALIGNED
작성 방식: 클라이언트별 단일 기준 파일

## 1. 클라이언트 목표와 근거

- 상황: 전통 요소와 한국적 분위기를 사용한 브랜드 페이지에서 장식인지 실제 브랜드 태도인지 판단한다.
- 목표: 문화적 이미지를 과잉 소비하지 않고 기록·재료·사용 태도와 연결된 표현을 확인한다.
- 핵심 과업: 브랜드 Hero → 시각 모티프 → 사용 이유 → 제품·화면 적용 → 한계
- 행동 흐름: 이미지·패턴 → 설명 → 원칙 → 제품 소재·구조 → 관련 카테고리
- 요구: 문화 요소의 절제, 기능·재료와의 연결, 장식적 과잉 금지, 가칭 브랜드 의미와 분리.
- 성공 조건: 한국적 정서가 어떤 설계 원칙에 연결됐는지 설명한다.
- 실패 조건: DAMORI 이름 의미나 전통성을 임의 확정하고 장식을 반복한다.
- 연결 제품: PROD-081
- 연결 페이지·원문 ID: PAGE-001,PAGE-020

## 4. 예외·상태 전이

- 결과 없음: 문화 요소의 절제, 기능·재료와의 연결, 장식적 과잉 금지, 가칭 브랜드 의미와 분리. 기준으로 재탐색·조건 완화·보류를 제공한다.
- 오류·로딩 실패: 확인된 내용과 현재 위치를 보존하고 실패 영역만 재시도한다.
- 미지원·미정: 사실·가설·HOLD를 분리하고 실행 가능한 기능처럼 표현하지 않는다.
- 중단·복귀: 선택값과 판단 맥락을 보존해 다시 시작할 수 있게 한다.
- 실패 방지: DAMORI 이름 의미나 전통성을 임의 확정하고 장식을 반복한다.
