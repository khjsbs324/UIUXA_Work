# VC-46 지율-긴 페이지의 스크린리더 탐색 — 서비스 흐름도

상태: CANONICAL_REWRITTEN_SOURCE_ALIGNED
작성 방식: 클라이언트별 단일 기준 파일

## 1. 클라이언트 목표와 근거

- 상황: 스크린리더 Heading 목록과 Landmark로 메인·카테고리의 긴 구조를 빠르게 탐색한다.
- 목표: 반복 카드와 레일을 건너뛰고 원하는 브랜드·제품·카테고리 Section에 도달한다.
- 핵심 과업: Skip → Landmark → Heading → 제품 레일 설명 → 다음 Section
- 행동 흐름: Header → Main → Section 제목 → 레일 제어 → 관련 Page → 복귀
- 요구: 반복 콘텐츠 Skip, 의미 있는 Section 제목, 레일 범위·현재 위치, 중복 대체 텍스트 제거.
- 성공 조건: 모든 제품을 듣지 않고 원하는 Section과 제품군으로 이동한다.
- 실패 조건: 시각 순서와 DOM 순서가 다르거나 반복 카드가 탈출 불가능하다.
- 연결 제품: PROD-021·PROD-049·PROD-085·PROD-087
- 연결 페이지·원문 ID: PAGE-001

## 4. 예외·상태 전이

- 결과 없음: 반복 콘텐츠 Skip, 의미 있는 Section 제목, 레일 범위·현재 위치, 중복 대체 텍스트 제거. 기준으로 재탐색·조건 완화·보류를 제공한다.
- 오류·로딩 실패: 확인된 내용과 현재 위치를 보존하고 실패 영역만 재시도한다.
- 미지원·미정: 사실·가설·HOLD를 분리하고 실행 가능한 기능처럼 표현하지 않는다.
- 중단·복귀: 선택값과 판단 맥락을 보존해 다시 시작할 수 있게 한다.
- 실패 방지: 시각 순서와 DOM 순서가 다르거나 반복 카드가 탈출 불가능하다.
