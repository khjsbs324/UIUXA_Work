## 1. 상황 카드

- 사용 상황: 매주 일정과 생각을 종이에 여러 문단으로 기록하며 새 다이어리를 고를 때 온라인 사진만으로 결정하지 않고 줄 간격·메모 공간·커버 물성·내부 구성을 확인한다.
- 목표: 실제 기록량에 맞는 속지 조합과 장기 사용 조건을 확인해 선택하거나 정보 부족 후보를 보류한다.
- 핵심 과업: 
- 성공 기준: 필요한 조합과 피할 조합을 설명하고 근거가 부족하면 구매 대신 보류한다.
- 실패 방지: 촉감·내구성을 사진에서 확정하거나 가격·재고·배송을 근거 없이 제공한다.

## 3. 상태 전이 규칙

- 오류·빈 결과: 현재 입력을 보존하고 재시도·조건 완화·이전 단계 중 하나를 제공한다.
- HOLD: 미확정 근거와 보류 사유를 표시하고 재개 위치를 저장한다.
- 완료: 필요한 조합과 피할 조합을 설명하고 근거가 부족하면 구매 대신 보류한다. 충족 여부를 확인한 뒤 완료·다음 행동을 제공한다.
- 복구: 오프라인·충돌 시 최신 유지·현재 유지·병합 선택을 제공한다.
