## 1. 상황 카드

- 사용 상황: 기록 목적은 알지만 많은 제품 중 감성 이미지가 아니라 자신의 조건에 맞는 차이를 빠르게 찾고 싶다.
- 목표: 목적·분량·형태·휴대성으로 후보군을 좁히고 같은 속성으로 비교한다.
- 핵심 과업: 카테고리 진입 → 핵심 필터 → 결과 → 최대 비교 후보 선택 → 근거 확인
- 성공 기준: 짧은 단계 안에 후보군을 좁히고 선택 또는 보류 이유를 확인한다.
- 실패 방지: 가격·판매량·베스트 배지로 적합성을 대신한다.

## 3. 상태 전이 규칙

- 오류·빈 결과: 현재 입력을 보존하고 재시도·조건 완화·이전 단계 중 하나를 제공한다.
- HOLD: 미확정 근거와 보류 사유를 표시하고 재개 위치를 저장한다.
- 완료: 짧은 단계 안에 후보군을 좁히고 선택 또는 보류 이유를 확인한다. 충족 여부를 확인한 뒤 완료·다음 행동을 제공한다.
- 복구: 오프라인·충돌 시 최신 유지·현재 유지·병합 선택을 제공한다.
