## 1. 상황 카드

- 사용 상황: 탐색 재개 상황에서 사용자는 관련 정보를 탐색하고 선택 또는 보류를 판단합니다.

- 핵심 과업: 진입 → 핵심 정보 확인 → 조건 비교
- 성공 기준: 복원될 범위를 확인하고 짧은 단계 안에 비교를 재개한다.
- 실패 방지: 이전 선택을 최신 사실로 갱신하거나 취소 경로를 숨긴다.

## 3. 상태 전이 규칙

- 오류·빈 결과: 현재 입력을 보존하고 재시도·조건 완화·이전 단계 중 하나를 제공한다.
- HOLD: 미확정 근거와 보류 사유를 표시하고 재개 위치를 저장한다.
- 완료: 복원될 범위를 확인하고 짧은 단계 안에 비교를 재개한다. 충족 여부를 확인한 뒤 완료·다음 행동을 제공한다.
- 복구: 오프라인·충돌 시 최신 유지·현재 유지·병합 선택을 제공한다.
