## 1. 상황 카드

- 사용 상황: 모바일에서 제품 레일 첫 카드만 보고 세로 페이지의 한 카드로 오해한다.
- 목표: 가로로 더 볼 수 있음을 인지하고 현재 위치를 확인하며 다음 Section으로 빠져나온다.
- 핵심 과업: 레일 인지 → 스와이프·다음 버튼 → 카드 비교 → 전체 카테고리 이동
- 성공 기준: 다음 제품 존재와 전체 카테고리 경로를 이해한다.
- 실패 방지: 자동 캐러셀, 무한 루프, 본문 가로 스크롤, 제스처 전용 조작.

## 3. 상태 전이 규칙

- 오류·빈 결과: 현재 입력을 보존하고 재시도·조건 완화·이전 단계 중 하나를 제공한다.
- HOLD: 미확정 근거와 보류 사유를 표시하고 재개 위치를 저장한다.
- 완료: 다음 제품 존재와 전체 카테고리 경로를 이해한다. 충족 여부를 확인한 뒤 완료·다음 행동을 제공한다.
- 복구: 오프라인·충돌 시 최신 유지·현재 유지·병합 선택을 제공한다.
