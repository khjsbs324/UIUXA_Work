## 상세 제작 명세

| 항목 | 제작 기준 |
|---|---|
| 콘텐츠 우선순위 | 페이지 목적 → 탐색·비교 → 근거 → 다음 행동 |
| 인터랙션 | 스크롤·필터·카드·아코디언·CTA의 선택 상태와 전환을 명시 |
| 데이터 정책 | 미확정 정보는 HOLD·준비 중으로 표시하고 확정 표현 금지 |
| 상태 | 기본·로딩·빈 결과·오류·완료를 모두 설계 |
| 반응형·접근성 | 모바일 1열·44px CTA·순차 Heading·키보드·대체 텍스트 |
| 검증 | 전체 여정과 오류·빈 결과·복귀 경로를 확인 |
- 판매 전환보다 포트폴리오 분류·시각적 Hero·탐색 이해를 우선한다.
