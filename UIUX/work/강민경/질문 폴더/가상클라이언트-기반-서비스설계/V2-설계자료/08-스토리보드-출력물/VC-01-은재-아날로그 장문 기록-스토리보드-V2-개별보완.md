## 1. 클라이언트 맥락

- 상황: 매주 일정과 생각을 종이에 여러 문단으로 기록하며, 사진만으로 다이어리를 결정하지 않고 줄 간격·메모 공간·커버 물성·내부 구성을 확인한다.
- 목표: 실제 기록량에 맞는 속지 조합과 장기 사용 조건을 확인해 선택하거나 정보 부족 후보를 보류한다.
- 핵심 여정: PAGE-002 → PAGE-003 → PAGE-004 → PAGE-005/006 → PAGE-007 → PAGE-008
- 요구: 목적·분량별 속지 선택, 실측 기반 비교, 적합·부적합 조건, 확인된 사실과 미확인 물성 분리
- 성공 조건: 필요한 조합과 피할 조합을 설명하고 근거가 부족하면 구매 대신 보류
- 실패 조건: 촉감·내구성을 사진에서 확정하거나 가격·재고·배송을 근거 없이 제공

### SCR-01 · 장문 기록 목적 진입

| 항목 | VC-01 명세 |
|---|---|
| 화면 목적 | 장문 기록량과 물성 확인이 필요한 이유를 이해시키고 비교를 시작하게 한다. |
| 진입/종료 | 메인 또는 PAGE-001 → PAGE-002 기록 목적 확인 |
| Visual Layout | Sticky 진행 헤더 → 장문 기록 상황 Hero → 기록량 선택 CTA → 다음 단계 |
| UI/인터랙션 | 기록 빈도·문단 길이 선택, 현재 위치 저장, 도움말 |

| 5대 상태 | 기본 / 선택 로딩 / 선택 미완료 / 저장 오류 / 목적 확인 완료 |
| 반응형/접근성 | 모바일 단일 열, 라디오 역할, 선택 상태 텍스트, 첫 CTA 포커스 |
