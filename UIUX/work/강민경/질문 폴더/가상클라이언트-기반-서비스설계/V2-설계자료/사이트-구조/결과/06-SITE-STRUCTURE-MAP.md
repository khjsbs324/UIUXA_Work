# 06 사이트-구조맵

## 구조 설계 목적

승인된 가상 클라이언트 7명, SR-001~020, 66개 사이트·462개 경험 통합 분석을 실제 정보구조로 전환한다. HOLD인 SR-013~017은 제공 기능으로 확정하지 않고 검증·도움말 수준에서 분리한다.

## 핵심 변경

- 기존 2명 중심 구조를 7명 구조로 확장
- GNB 5개 유지
- `브랜드 소개`를 GNB에서 Footer로 이동
- `템플릿과 꾸미기`를 독립 GNB로 추가
- `빠른 기록`, `중단 후 복귀`, `장기 보존` Page 추가
- 디지털·아날로그를 독립 트랙으로 유지하되 `기록 방식 찾기`에서 연속선으로 비교

## 구조맵

```text
SITE
├─ AREA-001 시작과 선택
│  ├─ PAGE-001 홈
│  └─ PAGE-002 기록 방식 찾기
│     └─ PAGE-003 맞춤 기록 추천
├─ AREA-002 아날로그 기록
│  ├─ PAGE-004 아날로그 기록
│  ├─ PAGE-005 노트·속지 선택
│  ├─ PAGE-006 장문 기록 가이드
│  └─ PAGE-007 제품과 구성
│     └─ PAGE-008 제품 상세·비교
├─ AREA-003 디지털 기록
│  ├─ PAGE-009 디지털 기록
│  ├─ PAGE-010 빠른 기록
│  ├─ PAGE-011 일정과 시간 흐름
│  └─ PAGE-012 장문·보존 도구
├─ AREA-004 템플릿과 꾸미기
│  ├─ PAGE-013 템플릿과 꾸미기
│  ├─ PAGE-014 템플릿 탐색·비교
│  └─ PAGE-015 꾸미기 자산
├─ AREA-005 기록 가이드
│  ├─ PAGE-016 기록 가이드
│  ├─ PAGE-017 작게 시작하기
│  ├─ PAGE-018 중단 후 다시 시작
│  └─ PAGE-019 이동·보존·도움말
└─ AREA-006 브랜드와 신뢰
   └─ PAGE-020 브랜드 소개
```

## Page 간 핵심 관계

- `PAGE-001 → PAGE-002/004/009/013/016`: 홈의 5개 핵심 진입
- `PAGE-002 ↔ PAGE-003`: 비교 설명과 맞춤 추천 왕복
- `PAGE-003 → PAGE-004/009/013/017`: 추천 결과에서 강제하지 않고 선택 가능한 이동
- `PAGE-005/006 → PAGE-007/008`: 기록 조건을 실물 제품 판단으로 연결
- `PAGE-009 → PAGE-010/011/012`: 입력 부담·시간·보존 목적별 분기
- `PAGE-010 → PAGE-015/017/018`: 빠른 기록의 표현·시작·복귀 연결
- `PAGE-014 ↔ PAGE-015`: 구조 템플릿과 표현 자산을 비교하되 통합하지 않음
- 모든 핵심 Page → `PAGE-019`: 제한·미검증·이동·보존 도움말
- `PAGE-020`: Footer 진입. GNB 폭을 늘리지 않음

## 내비게이션

- GNB: 기록 방식 찾기, 아날로그 기록, 디지털 기록, 템플릿과 꾸미기, 기록 가이드
- Utility: 활성 근거 없음. 검색·로그인·마이페이지는 추가하지 않음
- Footer: 브랜드 소개, 이동·보존·도움말
- Breadcrumb: 2Depth 이상 적용 후보
- Cross Link: 추천 결과, 아날로그↔디지털 비교, 빠른 기록↔작게 시작하기, 모든 Page↔도움말

## HOLD·금지 반영

- SR-013 다범주 통합, SR-014 다기기 최신 상태, SR-015 외부 달력 충돌, SR-016 가격 정책, SR-017 복귀 효과는 검증 전 제공 기능으로 확정하지 않는다.
- 로그인·마이페이지·커뮤니티·독립 Shop·실물 주문·배송은 활성 구조에 추가하지 않는다.
- AI 추천 결과는 원본 사실과 분리하고 수정 가능한 초안으로만 표현한다.
