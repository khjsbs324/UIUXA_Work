# 06 통합 분석 반영 결정

## 유지

- GNB 폭 5개
- 기록 방식 찾기, 아날로그 기록, 디지털 기록, 기록 가이드
- 최대 Depth 3
- 검색·로그인·마이페이지·커뮤니티 미채택

## 변경

- 핵심 Client 2명 → 7명
- Page 16개 → 20개
- 브랜드 소개 GNB → Footer
- 템플릿과 꾸미기 GNB 신설
- 빠른 기록, 장문·보존 도구, 중단 후 다시 시작 Page 신설
- 제품 상세과 소재 비교를 `제품 상세·비교`로 통합
- 도움말을 이동·보존·검증 상태까지 확장

## 이유

- 66개 사이트 통합 분석에서 작은 시작, 템플릿 비교, 꾸미기 자산 분리, 복귀, 장기 보존이 반복 확인됨
- 기존 구조는 은재·지안 중심이라 하람·소담·나린·이준 요구가 독립 진입점으로 반영되지 않음
- 태오의 요구는 HOLD이므로 기능이 아닌 비교 정보와 검증 상태로만 반영
