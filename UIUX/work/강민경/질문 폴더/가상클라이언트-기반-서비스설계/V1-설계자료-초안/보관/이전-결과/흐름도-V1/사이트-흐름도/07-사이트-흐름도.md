# VC-002 기반 사이트-흐름도

상태: `UPDATED_AFTER_VC_DEVELOPMENT`  
대표 Client: `VC-002 미래 일정·시간 흐름 통제 발주형`

## 목적

사이트맵의 12개 Page가 어떤 방향으로 연결되고, 사용자가 어느 Page에서 핵심 일정 경험과 보조 정보로 이동하는지 정의한다. 사용자 행동·판단을 상세히 다루는 서비스-흐름도와 달리 이 문서는 **Page 간 이동 관계**에 집중한다.

## 전체 Page 흐름

```text
PAGE-001 홈
├─ PAGE-002 기록 방식
│  └─ PAGE-003 기록 스타일 찾기
│     └─ PAGE-004 디지털 기록
├─ PAGE-004 디지털 기록
│  └─ PAGE-005 일정 관리
│     ├─ PAGE-006 시간 흐름
│     └─ PAGE-007 중요 일정 상기 [조건부]
├─ PAGE-008 기록 가이드
│  ├─ PAGE-009 디지털 기록 시작
│  ├─ PAGE-010 선택·비교 가이드
│  └─ PAGE-011 도움말·제공 범위
└─ PAGE-012 브랜드 소개
```

## 방향성 연결

| From | To | 연결 목적 | 유형 |
|---|---|---|---|
| PAGE-001 | PAGE-002 | 기록 방식 비교 | Primary |
| PAGE-001 | PAGE-004 | 디지털 기록 직접 진입 | Primary |
| PAGE-001 | PAGE-008 | 가이드 탐색 | Primary |
| PAGE-001 | PAGE-012 | 브랜드 이해 | Primary |
| PAGE-002 | PAGE-003 | 선택 지원 진단 | Child |
| PAGE-003 | PAGE-004 | 디지털 적합 결과 후 진입 | Cross Link |
| PAGE-004 | PAGE-005 | 오늘/이후 일정과 가장 가까운 일정 확인 진입 | Child |
| PAGE-005 | PAGE-006 | 현재 시간대·개요·선택 일정 세부 확인 | Child |
| PAGE-005 | PAGE-007 | 중요 일정의 저장된 상기 확인·수정·끄기 | Conditional Child |
| PAGE-006 | PAGE-007 | 선택 일정의 상기 사용 여부와 조건 설정 | Conditional Cross Link |
| PAGE-007 | PAGE-006 | 상기 미사용·취소 후 시간 흐름 복귀 | Return |
| PAGE-007 | PAGE-005 | 저장·끄기 결과 확인 후 일정 관리 복귀 | Return |
| PAGE-008 | PAGE-009 | 시작 방법 확인 | Child |
| PAGE-008 | PAGE-010 | 선택 기준 확인 | Child |
| PAGE-008 | PAGE-011 | 제한·FAQ 확인 | Child |
| PAGE-004·005·007 | PAGE-011 | 제공 범위와 조건 확인 | Support Cross Link |
| PAGE-012 | PAGE-002·004 | 브랜드 원칙에서 실제 선택으로 이동 | Cross Link |

## 핵심 경로

`PAGE-001 → PAGE-004 → PAGE-005 → PAGE-006 → PAGE-007(조건부)`

## 선택 지원 경로

`PAGE-001 → PAGE-002 → PAGE-003 → PAGE-004`

## 보조 정보 경로

`PAGE-001 → PAGE-008 → PAGE-009·010·011`

## 상태별 복귀 경로

- 일정 Empty·세부 Error: `PAGE-006 → PAGE-005` 또는 `PAGE-011`
- 상기 Validation Error: `PAGE-007` 안에서 조건 수정
- 상기 취소: `PAGE-007 → PAGE-006`
- 상기 저장·끄기 완료: `PAGE-007 → PAGE-005`
- 제공 범위 확인: `PAGE-011 → 호출 Page`

## 검토

- 사이트맵 12개 Page 반영: 완료
- 방향 없는 고립 Page: 0
- 핵심 일정 경로: 3Depth 이내
- 조건부 Page: PAGE-007
- HOLD 기능 Page 생성: 0
- 외부 일정 연동·검색·계정: 미포함
- 최신 VC-002의 현재 시간대·가장 가까운 일정·저장·수정·끄기·취소 복귀 관계: 반영
