# VC-09 윤슬-카테고리·제품 비교 — 서비스 흐름도 v4

상태: REWORKED_SOURCE_ALIGNED

- 상황: 기록 목적은 알지만 많은 제품 중 감성 이미지가 아니라 자신의 조건에 맞는 차이를 빠르게 찾고 싶다.
- 목표: 목적·분량·형태·휴대성으로 후보군을 좁히고 같은 속성으로 비교한다.
- 핵심 과업: 카테고리 진입 → 핵심 필터 → 결과 → 최대 비교 후보 선택 → 근거 확인.
- 행동 흐름: 전체 탐색 → 조건 적용 → 결과 없음 복구 또는 후보 비교 → 상세 왕복 → 선택·보류.
- 요구: 명확한 카테고리, 핵심·상세 필터 분리, 비교 기준, Empty 복구, 판매 순위 비의존.
- 성공 조건: 짧은 단계 안에 후보군을 좁히고 선택 또는 보류 이유를 확인한다.
- 실패 조건: 가격·판매량·베스트 배지로 적합성을 대신한다.
- 연결 제품: PROD-004·PROD-012·PROD-030·PROD-034·PROD-065
