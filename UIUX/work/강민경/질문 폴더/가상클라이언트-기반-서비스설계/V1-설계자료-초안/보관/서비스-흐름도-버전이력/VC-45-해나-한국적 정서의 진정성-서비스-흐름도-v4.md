# VC-45 해나-한국적 정서의 진정성 — 서비스 흐름도 v4

상태: REWORKED_SOURCE_ALIGNED

- 상황: 전통 요소와 한국적 분위기를 사용한 브랜드 페이지에서 장식인지 실제 브랜드 태도인지 판단한다.
- 목표: 문화적 이미지를 과잉 소비하지 않고 기록·재료·사용 태도와 연결된 표현을 확인한다.
- 핵심 과업: 브랜드 Hero → 시각 모티프 → 사용 이유 → 제품·화면 적용 → 한계.

- 요구: 문화 요소의 절제, 기능·재료와의 연결, 장식적 과잉 금지, 가칭 브랜드 의미와 분리.
- 성공 조건: 한국적 정서가 어떤 설계 원칙에 연결됐는지 설명한다.
- 실패 조건: DAMORI 이름 의미나 전통성을 임의 확정하고 장식을 반복한다.
