# VC-46 지율-긴 페이지의 스크린리더 탐색 — 서비스 흐름도 v1

상태: DRAFT_CONTINUOUS_RUN
입력: V4 제품 연결 · V5 사이트 구조맵 보강 · final-design 사이트 구조맵

## 1. 클라이언트 맥락

- 상황: 스크린리더 Heading 목록과 Landmark로 메인·카테고리의 긴 구조를 빠르게 탐색한다.
- 목표: 반복 카드와 레일을 건너뛰고 원하는 브랜드·제품·카테고리 Section에 도달한다.
- 핵심 과업: Skip → Landmark → Heading → 제품 레일 설명 → 다음 Section.
- 행동 흐름 원문: Header → Main → Section 제목 → 레일 제어 → 관련 Page → 복귀.
- 핵심 요구: 반복 콘텐츠 Skip, 의미 있는 Section 제목, 레일 범위·현재 위치, 중복 대체 텍스트 제거.
- 성공 조건: 모든 제품을 듣지 않고 원하는 Section과 제품군으로 이동한다.
- 실패·금지 조건: 시각 순서와 DOM 순서가 다르거나 반복 카드가 탈출 불가능하다.
- 연결 제품: PROD-021·PROD-049·PROD-085·PROD-087

## 4. 예외·상태

- 결과 없음: 조건 완화, 초기화, 직접 탐색, 보류 경로를 제공한다.
- 로딩·이미지·연결 실패: 확인된 콘텐츠를 보존하고 실패 영역만 재시도하거나 건너뛴다.
- 근거 부족·미정 정책: 확인 사실과 미확정 범위를 분리한다.
- 취소·복귀: 선택·필터·스크롤 위치를 가능한 범위에서 보존한다.
- 중단: 지금 하기·나누기·보류·삭제 중 선택하고 재개 경로를 제공한다.
- 클라이언트 금지 조건: 시각 순서와 DOM 순서가 다르거나 반복 카드가 탈출 불가능하다.

## 5. 연결 검증

- V4 요구사항과 제품 연결을 핵심 과업·단계별 행동에 연결한다.
- V5 사이트 구조의 진입·콘텐츠·기능·예외 경로를 반영한다.
- 제품 ID는 후보 연결로만 사용하며 가격·재고·성능을 임의 확정하지 않는다.
- 이 파일은 VC-46 개별 문서이며 다른 클라이언트와 사전 병합하지 않는다.
