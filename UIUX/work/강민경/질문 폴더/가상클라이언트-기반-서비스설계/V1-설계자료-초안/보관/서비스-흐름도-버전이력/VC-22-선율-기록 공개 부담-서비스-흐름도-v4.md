# VC-22 선율-기록 공개 부담 — 서비스 흐름도 v4

상태: REWORKED_SOURCE_ALIGNED

- 상황: 기록 공개 부담 상황에서 사용자는 관련 정보를 탐색하고 선택 또는 보류를 판단합니다.
- 목표: 내용을 입력하기 전에 처리 범위를 이해한다.
- 핵심 과업: 진입 → 핵심 정보 확인 → 조건 비교/상태 확인 → 선택·보류 → 이전 맥락으로 복귀.
- 행동 흐름: 원문 미기재
- 요구: 입력 전 사용 범위, 미지원 분석 표시, 거부해도 가능한 대체 경로.
- 성공 조건: 내용을 입력하기 전에 처리 범위를 이해한다.
- 실패 조건: 기록 후에만 정책을 보여주거나 감정을 추론한다.
- 연결 제품: PROD-039·PROD-072

    K --> C
