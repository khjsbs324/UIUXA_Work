# 06회차 — 상품·패키지 15개 검사

- 수량: 5개 목적 × 3개 = 15개.
- 문제: 패키지 이름만으로 Analog·Digital 구성 차이가 불충분할 수 있음.
- 개선: 모든 Card에 `매체 / 분량 / 시작 난도 / 포함 구조 / 근거 상태 / 주의점` 고정.
- 선물 3개: 받는 사람의 성격·감정 추론 금지, 숙련도·상황·구성만 사용.
- 실물 후보: 규격·재료·가격·재고를 공식 자료 전까지 표시하지 않음.
- Digital 후보: 실제 저장·백업·내보내기 제공으로 오인시키지 않음.
- 중복 이름 0, 카테고리 누락 0. 판정: `INTERNAL_PASS`.
