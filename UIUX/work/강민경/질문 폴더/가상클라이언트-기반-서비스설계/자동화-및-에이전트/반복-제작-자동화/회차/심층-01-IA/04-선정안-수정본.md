# 심층 01회차 — IA 선정안 수정본

## 선정

대안 B를 `IA-CANDIDATE-B1`로 수정 채택한다.

## 수정 구조

```text
HOME / PAGE-001
├─ 기존 GNB 5개 유지
├─ 기록 솔루션 찾기 / PAGE-021 [CANDIDATE_PAGE, HOME CROSS-ENTRY]
│  ├─ 오늘 시작하기 / START
│  ├─ 오래 남기기 / DEPTH
│  ├─ 시간을 바라보기 / TIME
│  ├─ 나답게 표현하기 / EXPRESSION
│  └─ 마음을 건네기 / GIFT [STRATEGIC_SAMPLE]
└─ 브랜드 소개 / PAGE-020 [FOOTER + HOME EDITORIAL ENTRY]
```

PAGE-021은 GNB 6번째 항목이 아니다. 메인 상황 카드·대표 솔루션·관련 상세 Page에서 들어오는 횡단 콘텐츠 허브다.

## PAGE-021 Page 계약

| 필드 | 값 |
|---|---|
| 사용자 표시명 | 기록 솔루션 찾기 |
| 내부 Page ID | PAGE-021 |
| 상태 | CANDIDATE_PAGE |
| Parent | PAGE-001 Cross-entry |
| 주요 Cross link | 005·007·008·010~012·014·015·017~019 |
| 핵심 Client | VC-01·03·04·06·08~10·14·15 |
| 품질 Client | VC-05·07·11~13 |

| 금지 | 가격·재고·구매 가능·다운로드 가능 임의 표시 |

## 카드 공통 계약

- 솔루션 이름
- 기록 목적
- 유형: 실물 / Digital / Mixed
- 분량·사용 상황
- 시작 난도
- 포함 구조
- 획득 상태: 시작 가능 / 상세 정보 / 공식 자료 필요 / 정책 확인 필요
- 근거 상태와 확인일
- 적합·부적합 조건
- 관련 상세 Page

## 기존 구조 영향

- GNB: 변경 없음
- 전체 Page: 활성 20 + 후보 1
- 기존 Page 삭제·통합: 없음
- PAGE-007·014: 상세 탐색 역할 유지
- PAGE-001: PAGE-021 진입 Section 추가 후보
- PAGE-020: 대표 Editorial 진입을 메인에 추가하되 Footer 유지

## 회차 판정

`INTERNAL_REVISE_COMPLETE`, 아직 `INTERNAL_PASS` 아님.

남은 재검증:

1. 수정된 레이블로 6개 조건부 시나리오 재실행
2. Page 수·Parent·Cross link 정적 검사
3. ER-003~007과 기존 Shop 제외 결정의 충돌 해소 문장 검증
4. 다음 서비스 흐름 단계에 정확한 전달 계약 작성
