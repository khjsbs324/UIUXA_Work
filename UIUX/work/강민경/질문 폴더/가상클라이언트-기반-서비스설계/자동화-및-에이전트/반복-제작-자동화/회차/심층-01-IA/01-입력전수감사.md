# 심층 01회차 — IA 입력 전수 감사

상태: `EVIDENCE_AUDIT_COMPLETE`

## 1. 읽은 기준 입력

- `06-SITE-STRUCTURE-MAP.md`
- `06-SITEMAP.md`
- `06-STRUCTURE-DECISIONS.md`
- `06-UNMAPPED-ITEMS.md`
- `06-TRACEABILITY.md`
- `04-정보구조-계층화.md`
- `04-클라이언트-추적과-이동경로.md`
- 기존 VC-01~07 상세 문서와 SR-001~020
- 전략 검증형 VC-08~15와 ER-001~017
- 제출 요구: 메인·카테고리·브랜드 소개, 상품·패키지 최소 15개

## 2. 기존 구조의 확인된 장점

1. 5개 GNB와 최대 Depth 3이라 전체 폭과 깊이가 안정적이다.
2. Analog·Digital의 성공 조건 차이를 보존한다.
3. 구조 템플릿과 표현 자산을 분리한다.
4. HOLD인 동기화·가격·복귀 효과를 활성 기능으로 확정하지 않는다.
5. 로그인·마이페이지·커뮤니티를 근거 없이 추가하지 않는다.

## 3. 실제 충돌

| 충돌 ID | 기존 결정 | 새 요구 | 영향 |
|---|---|---|---|
| IA-C01 | 독립 Shop 제외 | 카테고리 페이지·상품 15개 | 상품 탐색을 Commerce로 볼지 콘텐츠로 볼지 재정의 필요 |
| IA-C02 | PAGE-001~020 고정 | PAGE-021 횡단 카테고리 후보 | Page ID와 기존 수량 보고 갱신 필요 |
| IA-C03 | Analog·Digital 1Depth | 사용 목적 5개 카테고리 | 두 분류 축의 위계 충돌 가능 |
| IA-C04 | 제품은 PAGE-007·008 | 템플릿·선물 포함 15개 | `상품`의 범위가 실물에서 기록 솔루션으로 확대됨 |
| IA-C05 | 실제 가격·배송 HOLD | 상품 카드 기대 | 판매 CTA와 정보 CTA를 명확히 분리해야 함 |
| IA-C06 | 브랜드 소개 Footer | 포트폴리오 대표 3페이지 | 대표성은 높이되 GNB 폭을 늘릴 필요는 없음 |

## 4. 용어 재정의 필요

`상품·패키지`를 실제 판매 상품으로 확정하면 기존 근거와 충돌한다. 이번 IA에서는 다음처럼 제한한다.

- `기록 솔루션`: 실물 제품 후보, Digital 템플릿, 표현 자산, 시작 패키지를 포함하는 상위 콘텐츠 단위
- `상품 카드`: 비교 가능한 콘텐츠 카드. 가격·구매 가능 여부를 의미하지 않음
- `카테고리 페이지`: 기록 솔루션을 목적별로 탐색하는 콘텐츠 허브
- `획득 경로`: 구매·다운로드·사용 시작 중 실제 지원 상태를 표시하는 필드

## 5. 검증 가설

`기존 GNB를 유지하면서 목적 기반 카테고리를 횡단 콘텐츠 허브로 추가하면, Analog·Digital 구조를 파괴하지 않고 제출 조건과 신규 Client의 상품 탐색 요구를 충족할 수 있다.`

반증 조건:

- 기존 PAGE-007·014와 역할 차이를 설명하지 못함
- 15명 중 핵심 과업 경로가 더 길어짐
- 카테고리 레이블만 감성적이고 비교 속성이 불명확함
- 상품과 실제 판매 기능이 혼동됨
