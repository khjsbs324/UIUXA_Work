# 심층 01회차 — 수정 후 재검증

검증 대상: IA-CANDIDATE-B1.  
대상: 1차에서 IA 수정 가능 `CONDITIONAL`이었던 VC-05·07·08·10·12·14.

## VC-05 태오 — 연속성 오인

### 재실행

`PAGE-001 → PAGE-021 → PKG-006 보존 조건 체크 → PAGE-012 → PAGE-019`

- PAGE-021 카드 유형: Digital
- 획득 상태: `상세 정보`
- 근거 상태: `정책 확인 필요`
- 부적합 조건: 실제 다기기 동기화를 원하는 경우 현재 범위와 맞지 않음
- PAGE-012·019: 상태 개념과 검증 시나리오만 제공

결과: 제공 기능 오인 없이 보존 조건까지 도달. `PASS_FOR_IA`.

## VC-07 이준 — 복귀 기능 승격 위험

### 재실행

`PAGE-001 → PAGE-021 START → 작게 시작하기 PAGE-017 → PAGE-018`

- PAGE-018 링크에 `검증 중인 재시작 방식` 설명 포함
- 자동 이월·스트릭·보상 없음
- 공백 채우기 강제 없음
- PAGE-017에서 PAGE-010 직접 시작 우회 제공

결과: 조건부 Page 상태와 우회가 명확함. `PASS_FOR_IA`.

## VC-08 다온 — 추상 카테고리 이해

### 재실행

`PAGE-001 상황 카드 → PAGE-021 기록 솔루션 찾기 → START`

- H1: `지금 필요한 기록 장면부터 골라보세요`
- START 설명: `한 줄·사진·작은 노트처럼 준비 없이 시작하는 방법`
- Analog·Digital 용어는 보조 Badge로만 사용
- 전체 후보 직접 보기도 제공

결과: 생활 언어와 구체 예시가 연결됨. 실제 5초 테스트는 미실행이므로 `PASS_FOR_IA / USABILITY_TEST_REQUIRED`.

## VC-10 온유 — 선물 정책 오인

### 재실행

`PAGE-001 → PAGE-021 GIFT → PKG-013~015 비교`

- GIFT 전체에 `전략 샘플` 표시
- 카드의 획득 상태: `정책 확인 필요`
- 가격·포장·교환·배송 제거
- 성격 추천 대신 숙련도·기록 상황·구성 난도 비교

결과: 실제 구매 가능 오인 없이 패키지 구성 비교 가능. `PASS_FOR_IA / COMMERCE_HOLD`.

## VC-12 해솔 — 데이터 상태 혼합

### 재실행

`PAGE-001 → PAGE-021 → 실물·Digital 카드 비교 → PAGE-019`

- 실물: `개인 데이터 저장 없음`, 공식 제품 자료 상태 표시
- Digital: Local·권한·백업 상태 필드 표시
- Mixed: 실물 구성과 Digital 예시의 데이터 범위를 각각 표시
- 데이터 질문은 PAGE-019로 연결

결과: 카드 유형별 데이터 범위가 분리됨. `PASS_FOR_IA / POLICY_HOLD`.

## VC-14 마루 — 탐색 상태 오인

### 재실행

`PAGE-001 → PAGE-021 → 이 기기에 남은 예시 → 비교 재개/초기화`

- 자동 복원 표현 제거

- 계속하기와 초기화가 같은 시야에 존재

결과: 보존 범위를 오해하지 않고 재개 가능. `PASS_FOR_IA / PERSISTENCE_POLICY_HOLD`.
