# 심층 01회차 — IA 대안 3종

## 평가 기준

각 항목 0~3점. `근거 정합성` 또는 `과제 충족`이 2점 미만이면 탈락한다.

1. 근거 정합성
2. 과제 충족
3. 초보 탐색성
4. 기존 구조 보존
5. 상품 비교 확장성
6. 브랜드 차별성
7. 구현 가능성
8. HOLD 오인 방지

## 대안 A — 기존 20 Page 유지·메인 내 카테고리 Section

```text
PAGE-001 홈
├─ 목적별 솔루션 5개 Section
├─ 대표 카드 15개
└─ 기존 PAGE-007·014·015 상세로 분기
```

- 장점: Page 추가 없음, 기존 결정과 가장 안전하게 호환.
- 단점: 메인에 15개 카드·브랜드·방식 선택이 몰려 목적이 과도함.
- Client 영향: VC-08 첫 선택과 VC-09 비교 과업이 같은 화면에서 충돌.
- 과제 위험: 별도 카테고리 페이지 제출 조건을 충족한다고 보기 어려움.

| 기준 | 점수 |
|---|---:|
| 근거 정합성 | 3 |
| 과제 충족 | 1 |
| 초보 탐색성 | 1 |
| 기존 구조 보존 | 3 |
| 상품 비교 확장성 | 1 |
| 브랜드 차별성 | 2 |
| 구현 가능성 | 2 |
| HOLD 오인 방지 | 2 |
| 합계 | 15/24 — 탈락 |

## 대안 B — PAGE-021 목적 기반 횡단 카테고리 허브

```text
PAGE-001 홈
└─ PAGE-021 기록 솔루션 카테고리 [CANDIDATE_PAGE]
   ├─ START 오늘 시작하기
   ├─ DEPTH 오래 남기기
   ├─ TIME 시간을 바라보기
   ├─ EXPRESSION 나답게 표현하기
   └─ GIFT 마음을 건네기

상세 Cross link
START → PAGE-010·017
DEPTH → PAGE-005·007·008·012
TIME → PAGE-011
EXPRESSION → PAGE-014·015
GIFT → 전략 샘플 상세 후보
```

- 장점: 기존 GNB·상세 Page를 보존하면서 과제의 카테고리 Page를 독립적으로 충족.
- 단점: 목적 축과 매체 축이 공존해 설명·Breadcrumb 계약이 필요.
- Commerce 경계: 구매가 아닌 비교·상세·시작 경로를 제공하고 실제 획득 상태를 표시.
- PAGE 상태: 사용성 검증 전 `CANDIDATE_PAGE`, 최종 병합 승인 시 정식 반영 여부 결정.

| 기준 | 점수 |
|---|---:|
| 근거 정합성 | 3 |
| 과제 충족 | 3 |
| 초보 탐색성 | 3 |
| 기존 구조 보존 | 3 |
| 상품 비교 확장성 | 3 |
| 브랜드 차별성 | 3 |
| 구현 가능성 | 2 |
| HOLD 오인 방지 | 3 |
| 합계 | 23/24 — 검증 진출 |

## 대안 C — 목적 중심으로 전체 GNB 재구성

```text
GNB
├─ 오늘 시작
├─ 오래 남기기
├─ 시간 관리
├─ 표현과 템플릿
└─ 선물
```

- 장점: 목적 기반 브랜드 관점이 가장 강함.
- 단점: 기존 66개 사이트 경험 분석과 20 Page 구조를 크게 폐기·재매핑해야 함.
- Client 위험: VC-01의 물성 비교와 VC-02의 일정 과업이 카테고리 안에서 깊어질 수 있음.
- 운영 위험: 선물 근거가 전략 가설인데 GNB로 과도하게 승격됨.

| 기준 | 점수 |
|---|---:|
| 근거 정합성 | 1 |
| 과제 충족 | 3 |
| 초보 탐색성 | 3 |
| 기존 구조 보존 | 0 |
| 상품 비교 확장성 | 3 |
| 브랜드 차별성 | 3 |
| 구현 가능성 | 1 |
| HOLD 오인 방지 | 1 |
| 합계 | 15/24 — 탈락 |

## 1차 결과

대안 B만 필수 기준을 모두 충족했다. 그러나 점수만으로 채택하지 않고 15명 Client 대표 과업을 실제 경로로 실행한다.
