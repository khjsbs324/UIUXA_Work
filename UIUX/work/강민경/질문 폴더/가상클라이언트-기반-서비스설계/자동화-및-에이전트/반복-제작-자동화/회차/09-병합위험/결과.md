# 09회차 — 최종 병합 위험 검사

| 위험 | 예방 |
|---|---|
| 기존 PAGE-001 덮어쓰기 | 보관본 생성 후 대표 후보와 차이 적용 |
| PAGE-021 정식 승격 오인 | `ADD_CANDIDATE` 유지 |
| 전략 상품의 실제 판매 오인 | Sample Badge와 정책 HOLD 유지 |
| SR·ER 범위 표기 누락 | 명시 추적표 부록 사용 |
| 기존 Flow ID 충돌 | 대표 Flow는 `FLOW-REP-*` 유지 후 병합 시 매핑 |
| Screen·Story 불일치 | Screen Section 순서를 Story 입력으로 고정 |
| HOLD 누락 | HOLD-01~08을 최종 문서 제한 절에 삽입 |

- 삭제 대상 0, 원본 보존 계획 존재, Rollback 가능.
- 판정: `INTERNAL_PASS`.
