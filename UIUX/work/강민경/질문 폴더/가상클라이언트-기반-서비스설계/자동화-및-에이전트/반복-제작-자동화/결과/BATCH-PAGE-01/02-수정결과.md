# BATCH-PAGE-01 수정 결과

## 수정 1 — 카테고리 이중 계약

| 사용자 표시 | 내부 분류 | 포함 후보 |
|---|---|---|
| 오늘 시작하기 | START | 빠른 기록·입문 키트·한 줄 템플릿 |
| 오래 남기기 | DEPTH | 장문 노트·리필·보존 템플릿 |
| 시간을 바라보기 | TIME | 일정·주간·일간 구조 |
| 나답게 표현하기 | EXPRESSION | 표지·스티커·꾸미기 자산 |
| 마음을 건네기 | GIFT | 선물용 시작·장문·표현 패키지 |

사용자에게는 생활 언어를 보여주고, 필터·데이터·추적에는 내부 분류를 사용한다. Analog·Digital은 독립 범주가 아니라 보조 필터로 제공한다.

## 수정 2 — 브랜드 재료·주장 구조

`020-04 Material`을 다음으로 변경한다.

1. 확인한 것: 공식 자료가 있는 재료·구조·사용 조건
2. 확인 중인 것: 촉감·내구·환경 정보 등 추가 검증 필요
3. 약속하지 않는 것: 근거 없는 친환경·완벽한 보존·무조건 지속 효과

공식 자료가 없으면 제품명·인증·수치를 표시하지 않고 검증 기준만 설명한다.

## 수정 3 — 메인 모바일 우선순위

모바일 기본 노출은 Hero→상황 진입→대표 패키지→신뢰 원칙→CTA다. 두 방식 비교와 브랜드 미리보기는 요약 카드로 줄이고 상세 Page로 연결한다.
