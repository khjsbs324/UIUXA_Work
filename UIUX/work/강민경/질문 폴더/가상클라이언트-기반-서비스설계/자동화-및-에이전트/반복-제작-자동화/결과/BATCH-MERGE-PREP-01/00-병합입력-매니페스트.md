# BATCH-MERGE-PREP-01 병합 입력 매니페스트

상태: `MERGE_INPUT_READY`

## 기준 입력

| 영역 | 현재 기준 | 병합 사용 |
|---|---|---|
| Client | 기존 VC-01~07 + 전략 검증 VC-08~15 | 상태 구분 유지 |
| 요구 | SR-001~020 + ER-001~017 | 전체 Mapping |
| 기존 사이트 구조 | 06-SITE-STRUCTURE-MAP·06-SITEMAP | 원본 기준 |
| 기존 서비스 흐름 | 07-서비스-흐름도 | 원본 기준 |
| 기존 화면설계 | 08-우선화면-설계서·상태 추적표 | 원본 기준 |
| 기존 스토리보드 | PAGE-001·002·003·010 결과 | 상세 기준 샘플 |
| 대표 Page 후보 | BATCH-PAGE-01 | 변경 후보 |
| 대표 Flow | BATCH-FLOW-01 | 병합 후보 |
| 대표 Screen | BATCH-SCREEN-01 | 병합 후보 |
| 상품 15개 | BATCH-CONTENT-01 | 전략 샘플 레이어 |
| 대표 Story | BATCH-STORY-01 + VARIANTS-01 | 선정 구조 |

## 병합 순서

1. ID와 상태 사전 생성
2. 기존 Page·Flow·Screen 보존본 확인
3. Client·REQ 미매핑 검사
4. PAGE-021 `ADD_CANDIDATE` 적용안 작성
5. 사이트맵 후보 병합
6. 서비스 흐름 후보 병합
7. 화면설계 후보 병합
8. 대표 스토리보드 3개 병합
9. 전체 추적성·HOLD·접근성 감사
10. 사용자 승인용 변경 요약 작성

## 실행 차단

이 매니페스트는 병합 준비용이며 실제 최종 병합을 승인하지 않는다. `FINAL_MERGE_APPROVAL=GRANTED` 전에는 원본 기준 파일을 수정하지 않는다.
