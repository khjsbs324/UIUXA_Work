# DAMORI (다모리) 화면설계서 다수 후보안 (A/B/C) 명세서 (V1)

문서 ID: `SPEC-DAMORI-CANDIDATES-V1`  
버전: `V1`  
위치: `17-가상클라이언트-대량생성/` 전용 독립 폴더  
목적: 20개 화면 전체 및 50인 클라이언트 요구를 반영하는 3대 화면설계 구조안(A/B/C) 비교 기획

---

## 1. 화면설계서 후보안 A (고정형 분하식 레이아웃안)

- **특징**: 상단 고정 GNB(76px), 좌측 카테고리 사이드바(240px), 중앙 콘텐츠 본문(700px), 우측 관련 정보(260px) 고정 3열 레이아웃
- **적용 화면**: PAGE-001 ~ PAGE-020 전 화면 고정 분할
- **장점**: 대화면 데스크톱에서 정보밀도가 높음
- **단점**: 모바일/태블릿 반응형 전환 시 레이아웃 파괴 현상 발생 및 긴 스크롤 랜딩 서사 부족

---

## 2. 화면설계서 후보안 B (카드 카러셀 레일 위주 레이아웃안)

- **특징**: 세로 스크롤을 줄이고 수평 가로 스크롤 카드 카러셀 레일을 다수 배치하는 카드 중심 레이아웃안
- **적용 화면**: PAGE-001 (상품 15~50개 레일), PAGE-007 (라인업 레일), PAGE-013 (템플릿 레일)
- **장점**: 모바일 스와이프 조작감이 우수함
- **단점**: 아날로그 노구 물성 수치(120gsm 미유광 평산지)나 세부 가이드 서사 파악 시 수평 스크롤 피로 유발

---

## 3. 화면설계서 후보안 C (하이브리드 랜딩 + 카드 레일 반응형 레이아웃안 - 최적안)

- **특징**: 메인페이지(PAGE-001)에 6:6 랜딩 서사 + 15~100개 상품 가로/세로 카드 레일을 병합하고, 서브페이지(PAGE-021)에 시각 Hero + 4대 필터 칩 매트릭스를, 브랜드 소개(PAGE-020)에 톤다운 명조 서사 및 WCAG 2.1 접근성을 수용하는 최적 레이아웃안

### 20개 화면 설계서 인덱스 (SCR-001 ~ SCR-020)
- `SCR-001 / PAGE-001 메인`: 76px sticky GNB, Hero 6:6 2열, 001-PRODUCTS (15~50개 스크롤 레일), 5대 과업 카드, 24시간 타임라인, 10초 폼 모달, 원본보호 미리보기, 신뢰 밴드, 복귀 응원 밴드
- `SCR-002 / PAGE-002 방식 탐색`: 4대 자율 필터 칩 (목적/분량/장소/보존)
- `SCR-003 / PAGE-003 맞춤 추천`: 성격검사 없는 선택지 기반 나만의 추천
- `SCR-004~008`: 아날로그 메인, 120gsm 무지/방안/줄글 선택, 수기 가이드, 제품 라인업, 윤슬(VC-09) 1대1 수치 비교
- `SCR-009~012`: 디지털 메인, 10초 저부담 폼, 24시간 일간 타임라인 (HOLD 배지), 오프라인 PDF/CSV 백업
- `SCR-013~015`: 템플릿 메인, 소담(VC-04) 원본보호 사본 탐색, 나린(VC-06) 표현 자산 스티커 독립 레이어
- `SCR-016~019`: 기록 가이드 메인, 작게 시작, 이준(VC-07) 죄책감 없는 복귀, 여울(VC-13) WCAG 2.1 접근성 가이드
- `SCR-020 / PAGE-020 브랜드 소개`: "나만의 애착공방 기억의 서재" 서사, 단색 불박 도장 각인, 미유광 평산지 출처
- `SCR-021 / PAGE-021 카테고리 서브`: 포트폴리오용 상단 시각 비주얼 Hero + 10대 카테고리 과감한 탐색 수용

---

## 4. 후보안 A/B/C 비교 및 검증

- **반응형 대응성 (Desktop/Tablet/Mobile)**: C안 (100%) > B안 (85%) > A안 (60%)
- **접근성 및 포트폴리오 완성도**: C안 (최우수: 메인 PAGE-001, 카테고리 PAGE-021, 브랜드소개 PAGE-020 3대 화면 완성)
