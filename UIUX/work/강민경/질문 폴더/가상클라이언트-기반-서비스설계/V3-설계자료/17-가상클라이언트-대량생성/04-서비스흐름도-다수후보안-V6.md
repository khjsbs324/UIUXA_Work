# DAMORI (다모리) 서비스 흐름도 다수 후보안 (A/B/C) 명세서 (V6)

단계: `05-설계`  
버전: `V6` (51인 가상 클라이언트 및 200개 제품 인벤토리 100% 수용 서비스 흐름)  
위치: `17-가상클라이언트-대량생성/` 전용 독립 폴더  
기획 목적: 51인 클라이언트 V6 명세서와 200개 제품 인벤토리를 기반으로 3대 서비스 흐름 구조안(A/B/C) 및 5대 핵심 사용자 여정(User Flow A~E) 정밀 비교 기획  

---

## 1. 서비스 흐름 후보안 A (선형 5단계 표준 과업 흐름안)

### 1-1. 구조 특징 및 흐름도
- **특징**: 진입 → 탐색 → 1:1 비교 → 상세 실측 검증 → 과업 완료의 전형적인 5단계 선형(Sequential) 흐름.
- **표준 경로**: `PAGE-001 (메인)` → `PAGE-002 (방식 찾기)` → `PAGE-021 (카테고리 솔루션)` → `PAGE-020 (브랜드 철학)` → `Compare Tray 완료`
- **장점**: 흐름이 명확하고 예측 가능하며, 첫 방문 사용자의 혼란을 방지함.
- **단점**: 10초 저부담 퀵 작성(VC-03)이나 죄책감 없는 즉시 복귀(VC-07) 등 단축 경로 지원이 미흡함.

---

## 2. 서비스 흐름 후보안 B (원터치 퀵 모달 단축 흐름안)

### 2-1. 구조 특징 및 흐름도
- **특징**: 서브페이지 전환 없이 메인 랜딩(PAGE-001)에서 팝업 모달과 슬라이드 드로어(Drawer)를 통해 10초 이내에 과업을 완결하는 초고속 단축 흐름.
- **표준 경로**: `PAGE-001` → `원터치 퀵 모달 팝업` → `로컬 즉시 저장` → `완료`
- **장점**: 10초 저부담 회고형 사용자(VC-03, VC-32)의 인지 피로를 없애고 이탈률을 최소화함.
- **단점**: 120gsm 미유광 평산지의 장인 제본 서사(PAGE-020)나 200개 제품 상세 스펙 대조(PAGE-021)로의 유입이 감소함.

---

## 3. 서비스 흐름 후보안 C (하이브리드 예외/상태복귀 통합 최적안 - RECOMMENDED)

### 3-1. 구조 특징 및 설계 의도
- **핵심 특징**: 후보안 A의 체계적인 5단계 선형 탐색과 후보안 B의 원터치 퀵 모달을 결합하고, `ST-HOLD`(외부 연동 안전 보류), `ST-LOCAL`(오프라인 IndexedDB 무손실 캐시), '죄책감 없는 복귀 밴드'를 전면 통합한 최적 하이브리드 흐름안.
- **9대 필수 흐름 명세 준수**: Trigger, Input, State, Branch, Error, Cancel, Recovery, Termination, Data Scope 전수 탑재.

### 3-2. 5대 핵심 사용자 여정 (User Flow A ~ E)

#### 1) User Flow A: 아날로그 장문 사색 여정 (VC-01 은재, VC-15 새봄, VC-17 채운)
- **Trigger**: 야간 23시 번역 작업 종료 후 컴퓨터 모니터 피로 회피 및 만년필 수기 작성 욕구
- **Input**: 종이 평량(120gsm), 제본 방식(180도 평면), 잉크 번짐률 0% 필터 선택
- **State**: `PAGE-001 (메인)` → `15개 상품 레일` → `PAGE-021 (카테고리 허브)` → `PROD-001 실측 카드` → `PAGE-020 (180도 Smyth Sewn 실제본 공정)`
- **Branch**: 단차 2mm 이상 발생 우려 시 3D 평면 뷰어로 실측 수치(단차 0mm) 사전 확인
- **Error / Recovery**: 이미지 로드 실패 시 고대비 텍스트 물성 라벨로 즉시 대체 표시
- **Termination**: 만년필 최적화 120gsm 평산지 하드커버 노구 소장 결정 완료

#### 2) User Flow B: 디지털 시간축 통제 여정 (VC-02 지안, VC-05 태오, VC-16 한결)
- **Trigger**: 출근길 08:30 지하철에서 당일 24시간 타임라인 확인 및 일정 충돌 방지
- **Input**: 24시간 시간축 모드 토글, 30분 단위 일정 블록 이동
- **State**: `PAGE-001` → `24시간 타임라인 위젯` → `PAGE-021 (디지털 플래너)` → `HOLD 배지 확인`
- **Branch**: 외부 연동 미검증 시 `ST-HOLD` 배지 활성화로 자동 덮어쓰기 원천 차단
- **Error / Recovery**: 동기화 지연 시 '로컬 단독 안전 시간표' 모드로 300ms 이내 전환
- **Termination**: 모바일/PC/패드 3단 화면 비율 완벽 일치 상태로 일정 확인 완료

#### 3) User Flow C: 10초 저부담 빠른 회고 여정 (VC-03 하람, VC-32 유진)
- **Trigger**: 취침 전 침대 머리맡에서 10초 이내 하루 감정/사진 1장 기록
- **Input**: 사진 1장 업로드 + 3줄 이내 단문 회고 + 감정 칩 1회 터치
- **State**: `PAGE-001` → `001-START 퀵 스냅샷 바` → `10초 무설정 팝업 모달`
- **Branch**: 텍스트 3줄 초과 시 자동 확장되지 않고 간결한 요약 모드로 유지
- **Error / Recovery**: 이미지 업로드 지연 시 로컬 썸네일 즉시 생성 후 백그라운드 저장
- **Termination**: 10초 이내 LocalStorage에 안전 저장 및 작성 완료 피드백 카드 노출

#### 4) User Flow D: 템플릿 구획 및 꾸미기 여정 (VC-04 소담, VC-06 나린, VC-30 서진)
- **Trigger**: 주말 오전 독서/재정 템플릿 탐색 및 흑백 라인아트 스티커 꾸미기
- **Input**: 주제별 태그 선택, 스티커 레이어 ON/OFF 토글
- **State**: `PAGE-001` → `PAGE-021 (템플릿 & 꾸미기)` → `서식 캔버스 프리뷰` → `PROD-006`
- **Branch**: 스티커 부착 시 텍스트 본문과 100% 분리된 독립 레이어로 자동 배치
- **Error / Recovery**: 서식 변경 시에도 기존 작성 텍스트 원본 보존율 100% 유지
- **Termination**: 텍스트 가독성 훼손 없는 감성 다이어리 템플릿 내 서재 저장 완료

#### 5) User Flow E: 죄책감 없는 기록 복귀 여정 (VC-07 이준, VC-20 주원, VC-51 이솔)
- **Trigger**: 2주간 야근/출장으로 중단된 일기를 다시 작성하기 위해 재진입
- **Input**: '미안함 없는 복귀 밴드' 1-클릭
- **State**: `PAGE-001` → `응원 밴드 툴팁` → `최근 작성 위치 자동 포커스`
- **Branch**: 연속 작성 실패(Streak) 경고 배지 및 빨간 점 팝업 100% 영구 차단
- **Error / Recovery**: 네트워크 단절 시 `ST-LOCAL` 캐시에서 최근 작성 위치 0ms 복구
- **Termination**: 부담감 0% 상태로 1-클릭 이전 기록 위치에서 자연스러운 필기 재개 완료

## 4. 후보안 A/B/C 비교 및 정밀 검증

1. **51인 클라이언트 예외 수용성**: 후보안 C (100%) > 후보안 A (80%) > 후보안 B (70%)
2. **오프라인/복귀 상태 처리 (ST-LOCAL)**: 후보안 C (100%) > 후보안 A (60%) > 후보안 B (50%)
3. **포트폴리오 적합성**: 후보안 C (최우수: 메인, 카테고리 솔루션, 브랜드 소개 3대 페이지 완벽 결합)
