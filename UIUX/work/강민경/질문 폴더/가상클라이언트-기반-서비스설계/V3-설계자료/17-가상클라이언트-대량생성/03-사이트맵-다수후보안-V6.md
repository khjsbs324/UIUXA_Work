# DAMORI (다모리) 사이트맵 다수 후보안 (A/B/C) 명세서 (V6)

단계: `05-설계`  
버전: `V6` (51인 가상 클라이언트 및 200개 제품 인벤토리 100% 연동 다수 구조안 비교)  
위치: `17-가상클라이언트-대량생성/` 전용 독립 폴더  
기획 목적: 51인 클라이언트 V6 명세서와 200개 제품 인벤토리(PROD-001~200)를 연결하는 3대 사이트맵 구조안(A/B/C) 정밀 비교 기획  

---

## 1. 사이트맵 후보안 A (과업 분리형 4-Depth 계층 구조안)

### 1-1. 구조 특징 및 설계 의도
- **핵심 특징**: 사용자의 기록 목적과 숙련도에 따라 5대 과업(기록 방식 찾기 / 아날로그 기록 / 디지털 기록 / 템플릿과 꾸미기 / 기록 가이드)으로 엄격히 분리된 4단계 깊이의 구조.
- **51인 클라이언트 수용성**: 51인의 개별 시나리오가 1:1로 정확한 하위 전용 페이지에 격리 배치되어 간섭이 전혀 없음.

### 1-2. 계층 구조도 (IA Architecture)

```text
다모리(DAMORI) — 후보안 A
├─ PAGE-001: 메인 랜딩 (브랜드 서사 & 대표 상품 15선 탐색)
├─ 1. 기록 방식 찾기 (GNB 1)
│  ├─ PAGE-002: 기록 방식 자율 탐색 (VC-08 다온 무설정 필터)
│  └─ PAGE-003: 1:1 맞춤 추천 결과 (VC-21 민서 예산별 솔루션)
├─ 2. 아날로그 기록 (GNB 2)
│  ├─ PAGE-004: 아날로그 기록 메인
│  ├─ PAGE-005: 120gsm 미유광 평산지 속지 선택 (VC-01 은재, VC-17 채운)
│  ├─ PAGE-006: 180도 Smyth Sewn 수기 가이드 (VC-36 나윤)
│  ├─ PAGE-007: 실물 노구 라인업 20종 (PROD-001 ~ PROD-020)
│  └─ PAGE-008: 종이 물성 1:1 상세 대조 (VC-15 새봄 친환경 라벨)
├─ 3. 디지털 기록 (GNB 3)
│  ├─ PAGE-009: 디지털 기록 메인
│  ├─ PAGE-010: 10초 저부담 빠른 기록 폼 (VC-03 하람, VC-32 유진)
│  ├─ PAGE-011: 24시간 일간 타임라인 플래너 (VC-02 지안, VC-16 한결)
│  └─ PAGE-012: 다기기 연속성 & 오프라인 보존 도구 (VC-05 태오, VC-51 이솔)
├─ 4. 템플릿과 꾸미기 (GNB 4)
│  ├─ PAGE-013: 템플릿 & 에셋 메인
│  ├─ PAGE-014: 주제별 구획 서식 탐색 (VC-04 소담)
│  └─ PAGE-015: 독립 레이어 스티커 & 데코 자산 (VC-06 나린, VC-30 서진)
├─ 5. 기록 가이드 (GNB 5)
│  ├─ PAGE-016: 가이드 허브 메인
│  ├─ PAGE-017: 작게 시작하는 기록 안내 (VC-20 주원)
│  ├─ PAGE-018: 죄책감 없는 복귀 밴드 (VC-07 이준)
│  └─ PAGE-019: 웹 접근성 & 장벽 없는 환경 안내 (VC-13 여울, VC-46 지율)
└─ Footer: PAGE-020 브랜드 소개 (애착공방 기억의 서재 철학)
```

- **장점**: 51개 클라이언트의 모든 세부 문제점과 전용 제품군이 명확히 분리 매핑됨.
- **단점**: 깊이가 4단계로 깊어져 단순 탐색 사용자의 클릭 수가 3회 이상으로 증가할 수 있음.

## 2. 사이트맵 후보안 B (10대 제품 카테고리 중심 3-Depth 구조안)

### 2-1. 구조 특징 및 설계 의도
- **핵심 특징**: 200개 제품 인벤토리(PROD-001~200)의 탐색 속도와 카테고리 횡단 비교를 최우선으로 배치한 3단계 커머스/아카이브 중심 구조.
- **제품 수용성**: 10대 카테고리별 20개 제품이 최상단 메뉴에서 1-클릭으로 직결되어 탐색 시간이 가장 짧음.

### 2-2. 계층 구조도 (IA Architecture)

```text
다모리(DAMORI) — 후보안 B
├─ PAGE-001: 통합 제품 아카이브 메인
├─ 1. 실물 노구 & 리필 속지 (GNB 1)
│  ├─ CAT-01: 아날로그 노트 20종 (PROD-001~020)
│  └─ CAT-02: 리필 속지 20종 (PROD-021~040)
├─ 2. 디지털 플래너 & 빠른 폼 (GNB 2)
│  ├─ CAT-03: 디지털 플래너 20종 (PROD-041~060)
│  └─ CAT-04: 10초 빠른 기록 폼 20종 (PROD-061~080)
├─ 3. 템플릿 & 꾸미기 자산 (GNB 3)
│  ├─ CAT-05: 템플릿 구획 서식 20종 (PROD-081~100)
│  └─ CAT-06: 독립 레이어 스티커 20종 (PROD-101~120)
├─ 4. 아카이브 케이스 & 각인 (GNB 4)
│  ├─ CAT-07: 15mm 슬림 바인더 20종 (PROD-121~140)
│  └─ CAT-08: 황동 실링 왁스 각인 20종 (PROD-141~160)
├─ 5. 스타터 세트 & 케어 툴킷 (GNB 5)
│  ├─ CAT-09: 하이브리드 스타터 20종 (PROD-161~180)
│  └─ CAT-10: 노구 보존 케어 툴킷 20종 (PROD-181~200)
└─ Footer: 브랜드 소개 및 이용 안내
```

- **장점**: 200개 제품 인벤토리 접근성이 매우 우수하며 15개 대표 레일과의 상호작용이 신속함.
- **단점**: VC-07(죄책감 없는 복귀), VC-13(스크린리더 접근성) 등 비판매 가이드 서사가 제품군에 가려질 위험이 있음.

## 3. 사이트맵 후보안 C (하이브리드 브랜드 랜딩 통합 최적안 - RECOMMENDED)

### 3-1. 구조 특징 및 설계 의도
- **핵심 특징**: 3대 웹 포트폴리오 산출물(PAGE-001 메인 랜딩, PAGE-021 카테고리 솔루션 허브, PAGE-020 브랜드 소개)을 중심 축으로 삼고, 후보안 A의 51인 클라이언트 과업 분리와 후보안 B의 200개 제품 고속 탐색 레일을 유기적으로 통합한 최적 하이브리드 구조안.
- **3대 대표 페이지 역할**:
  - **PAGE-001 (메인 랜딩)**: 브랜드 소개 요약 서사 + 대표 15개 상품 가로 스크롤 레일 + 4대 자율 필터 칩
  - **PAGE-021 (카테고리 솔루션 허브)**: 상단 비주얼 Hero + 10대 카테고리 200개 제품 1:1 Compare Tray + 비상업 솔루션 탐색
  - **PAGE-020 (브랜드 소개페이지)**: 120gsm 미유광 평산지 촉감 + 180도 Smyth Sewn 실제본 공정 + 한국적 미니멀 서사

├─ [핵심 1] PAGE-001: 메인 랜딩 페이지
│  ├─ Section 1: Hero — 애착공방 기억의 서재 서사

## 4. 후보안 A/B/C 정밀 다차원 비교

1. **51인 가상 클라이언트 수용도**:
   - 후보안 C (100%): 3대 페이지와 공통 서브를 통해 51인 전원 요구 완벽 충족
   - 후보안 A (95%): 충족도 높으나 탐색 뎁스 4단계로 일부 클라이언트 마찰 발생
   - 후보안 B (80%): 제품 중심 편중으로 비판매 가이드 요구 수용 미흡

2. **200개 제품 인벤토리 수용성**:
   - 후보안 C (100%): PAGE-001(15선 레일) + PAGE-021(200개 Compare Tray) 연계 최우수
   - 후보안 B (95%): 200개 제품 분류는 빠르나 브랜드 서사 연결성 부족
   - 후보안 A (90%): 카테고리 분산으로 제품 일괄 비교 인터페이스 제한

3. **포트폴리오 평가 및 최종 적합성**:
   - **후보안 C 최종 선정 (RECOMMENDED)**: 메인(PAGE-001), 카테고리(PAGE-021), 브랜드소개(PAGE-020)의 3대 핵심 산출물 목표와 완벽하게 일치하며, 기획의 논리성과 시각적 사용성을 극대화함.
