# DAMORI (다모리) 신규 리서치 기반 통합 화면설계서 (Screen Specification Document)

문서 ID: `SPEC-DAMORI-REBUILT-50VC-FINAL`  
상태: `APPROVED_SINGLE_DOC`  
위치: `15-리서치-클라이언트-신규재구축/` 신규 전용 독립 폴더  
대상: `SCR-001` ~ `SCR-020` (전체 20개 화면 100% 매핑)

---

## 1. 20개 전체 화면 설계 명세 인덱스

- `SCR-001 / PAGE-001 메인페이지`: 최소 15개~50개 전수 라인업 가로/세로 스크롤 카드 레일 (`scroll-snap`), Hero 6:6 2열, 5대 과업 카드, 24시간 타임라인, 10초 폼 모달, 원본보호 미리보기, 신뢰 원칙 밴드, 복귀 응원 밴드 수록.
- `SCR-002 / PAGE-002 기록 방식 탐색`: 4대 자율 필터 칩 (목적/분량/장소/보존)
- `SCR-003 / PAGE-003 맞춤 기록 추천`: 성격검사 강제 없는 선택지 기반 나만의 추천
- `SCR-004 ~ SCR-008 아날로그 계층`: 180도 평면 제본, 120gsm 미유광 평산지, 만년필 잉크 번짐 라벨 수치 명세.
- `SCR-009 ~ SCR-012 디지털 계층`: 10초 저부담 4대 폼, 24시간 일간 타임라인, 외부 달력 HOLD 배지, PDF/표준 포맷 백업.
- `SCR-013 ~ SCR-015 템플릿/꾸미기 계층`: 입력 구조(Structure)와 시각 표현(Asset)의 원본 데이터 100% 보존 분리.
- `SCR-016 ~ SCR-019 기록 가이드 계층`: 이준(VC-07) 중단 후 죄책감 없는 복귀, 여울(VC-13) WCAG 2.1 접근성 가이드.
- `SCR-020 / PAGE-020 브랜드 소개`: "흘러가는 취향을 한 장의 삶의 페이지로, 나만의 애착공방 기억의 서재" 서사 및 단색 불박 도장 각인 브랜딩.
