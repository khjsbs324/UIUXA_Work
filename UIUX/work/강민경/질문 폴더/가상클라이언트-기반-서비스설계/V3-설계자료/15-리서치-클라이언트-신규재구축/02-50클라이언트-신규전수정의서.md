# DAMORI (다모리) 50개 가상 클라이언트 신규 전수 정의서

문서 ID: `VC-DAMORI-50NEW-FULL-DEF`  
상태: `APPROVED_REBUILT_50VC_DEFINITIONS`  
위치: `15-리서치-클라이언트-신규재구축/` 신규 전용 독립 폴더  
대상: `VC-01 은재` ~ `VC-50 아인` (50개 가상 클라이언트 100% 바닥부터 신규 재정의)

---

## 1. 50개 가상 클라이언트 체계 구축 원칙

1. **실제 시장 사용 패턴 기반 페르소나 구축**: 단순한 성격 분류를 넘어서 실생활 기록 마찰점(Friction)과 선호 도구에 대한 구체적 리서치 데이터를 적용했습니다.
2. **5대 리서치 축 1:1 대응**: 물성 사색, 시간축 통제, 10초 저부담 회고, 원본보호 자산, 다정함/복귀 지원 축과 50인 클라이언트를 1:1로 결합했습니다.
3. **화면 구현 증거(Evidence) 100% 연결**: 각 클라이언트가 메인페이지, 브랜드 소개, 서브페이지에서 어떤 컴포넌트와 인터랙션을 조작하는지 정밀하게 정의했습니다.

## 2. 50개 가상 클라이언트 신규 전수 정의부 (VC-01 ~ VC-50)

### 1 Tier: 근거 기반 핵심 7인 (Core Evidence Persona)

1. **`VC-01 은재` (아날로그 장문 수기)**
   - 연령/직업: 31세 프리랜서 번역가
   - 실생활 마찰점: 만년필 잉크 번짐과 손목 피로, 종이가 붕 떠서 들리는 제본 문제
   - 신규 요구사항: 180도 평면으로 완전히 펼쳐지는 제본, 120gsm 미유광 평산지 종이 수치 검증
   - 화면 구현 증거: `PAGE-004`, `PAGE-005` 내지 선택 및 종이 수치 라벨
   - 매핑 Page: `PAGE-004 (아날로그 메인)`, `PAGE-005 (노트 선택)`

2. **`VC-02 지안` (미래 일정 흐름 통제)**
   - 연령/직업: 35세 IT 프로젝트 매니저
   - 실생활 마찰점: 파편화된 주간 일정과 24시간 타임라인의 통제력 부족
   - 신규 요구사항: 주간 일정 개요 → 24시간 일간 타임라인 세부 블록 변환
   - 화면 구현 증거: `PAGE-009`, `PAGE-011` 타임라인 시뮬레이터 및 HOLD 공지 배지
   - 매핑 Page: `PAGE-009 (디지털 메인)`, `PAGE-011 (일정 통제)`

3. **`VC-03 하람` (저부담 시각 회고)**
   - 페르소나/문제: 20대 대학원생, 긴 글 작성의 시작 부담과 입력 피로
   - 신규 요구사항: 10초 만에 완료되는 사진/1줄/음성/감정 4대 저부담 폼
   - 화면 구현 증거: `PAGE-010`, `PAGE-017` 10초 빠른 시작 팝업 모달
   - 매핑 Page: `PAGE-010 (빠른 기록)`, `PAGE-017 (작게 시작)`

4. **`VC-04 소담` (주제별 기록 탐색)**
   - 페르소나/문제: 28세 디자이너, 서식 적용 시 작성해둔 글 원본이 훼손될까 두려움
   - 신규 요구사항: 입력 구조(Structure) 템플릿 적용 시 원본 데이터 100% 보호
   - 화면 구현 증거: `PAGE-013`, `PAGE-014` 원본/사본 미리보기 비교
   - 매핑 Page: `PAGE-013 (템플릿 메인)`, `PAGE-014 (사본 탐색)`

5. **`VC-05 태오` (다기기 연속성 검증)**
   - 페르소나/문제: 34세 개발자, 모바일과 태블릿 간 기록 단절 및 데이터 유실 우려
   - 신규 요구사항: 로컬 저장 우선 및 PDF/표준 포맷 백업 지원
   - 화면 구현 증거: `PAGE-012`, `PAGE-019` 백업/복구 및 내보내기 가이드
   - 매핑 Page: `PAGE-012 (보존 도구)`, `PAGE-019 (도움말)`

6. **`VC-06 나린` (꾸미기 자산 재사용)**
   - 페르소나/문제: 25세 마케터, 다이어리 꾸미기 자산이 텍스트 입력을 방해함
   - 신규 요구사항: 표현 자산(Asset)과 글 원본 레이어 독립 분리
   - 화면 구현 증거: `PAGE-013`, `PAGE-015` 실링 왁스/스티커 독립 레이어
   - 매핑 Page: `PAGE-013 (템플릿 메인)`, `PAGE-015 (꾸미기 자산)`

7. **`VC-07 이준` (중단 후 재시작)**
   - 페르소나/문제: 40세 창업가, 기록 중단 후 미안함과 죄책감으로 서비스 이탈
   - 신규 요구사항: 죄책감 유발 스트릭을 배제하고 자연스러운 노구 복귀 지원
   - 화면 구현 증거: `PAGE-016`, `PAGE-018` 최근 1개/미완료 1개 선택 복귀 카드
   - 매핑 Page: `PAGE-016 (가이드 메인)`, `PAGE-018 (다시 시작)`
