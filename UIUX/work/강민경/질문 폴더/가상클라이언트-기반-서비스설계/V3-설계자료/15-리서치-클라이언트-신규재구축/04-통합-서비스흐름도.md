## 1. 서비스 흐름 개요 및 5대 핵심 사용자 동선 (User Flow A ~ E)

- **User Flow A (은재 VC-01 아날로그 동선)**: `PAGE-001 (홈 메인)` → `001-PRODUCTS (15~50개 스크롤 레일)` → `PAGE-004 (아날로그 기록 메인)` → `PAGE-005 (노트 & 내지 선택)` → `PAGE-008 (120gsm 미유광 평산지 수치 비교)` → 소장 결정
- **User Flow B (지안 VC-02 디지털 시간축 동선)**: `PAGE-001` → `001-SCHEDULE 미리보기` → `PAGE-009 (디지털 메인)` → `PAGE-011 (24시간 일간 타임라인)` → `HOLD 배지 확인` → 시간 통제
- **User Flow C (하람 VC-03 저부담 빠른 동선)**: `PAGE-001` → `001-START 버튼` → `10초 빠른 시작 팝업 모달` → `PAGE-010 (사진/1줄/음성/감정 폼)` → 저부담 기록 완료
- **User Flow D (소담 VC-04 & 나린 VC-06 템플릿/자산 동선)**: `PAGE-001` → `001-TEMPLATE 미리보기` → `PAGE-013 (템플릿 메인)` → `PAGE-014 (사본 서식 적용, 원본보호)` → `PAGE-015 (스티커 독립 레이어)` → 서식 완성
- **User Flow E (이준 VC-07 복귀 동선)**: `PAGE-001` → `001-GUIDE 응원 밴드` → `PAGE-016 (가이드 메인)` → `PAGE-018 (미안함 없는 선택 복귀)` → 노구 재개

## 2. 예외 및 분기 노드 명세

1. `ST-HOLD (외부 연동 검증 중)`: 권한 미확인 시 자동 연결을 차단하고 주황색 배지로 직접 입력 안내
2. `ST-LOCAL (로컬 저장 우선)`: 오프라인 단절 시 입력 내용을 기기에 안전하게 보존하고 온라인 복구 시 자동 연동
3. `ST-CONFLICT (데이터 충돌)`: 두 버전을 나란히 보여주고 사용자가 사본을 선택 보존하도록 제어
