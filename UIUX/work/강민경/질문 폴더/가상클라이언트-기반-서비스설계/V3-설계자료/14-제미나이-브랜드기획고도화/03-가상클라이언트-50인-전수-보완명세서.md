## 1. 50개 가상 클라이언트 보완 분석 개요

클라이언트 요구사항의 완성도를 극대화하기 위해 50개 가상 클라이언트 전수의 **(1) 핵심 페르소나/문제, (2) 요구사항/가치, (3) 구현 기능/증거, (4) 예외/금지 사항, (5) 매핑 Page ID**를 100% 전수 보완 작성했습니다.

---

## 2. 50개 가상 클라이언트 정밀 보완 명세 (VC-01 ~ VC-50)

### 1 Tier: 근거 기반 핵심 7인 (Core Evidence Persona)

1. **`VC-01 은재` (아날로그 장문 기록)**
   - 페르소나/문제: 만년필 잉크 번짐과 손목 피로 없는 장문 사색 노트 갈망
   - 요구사항/가치: 180도 평면 펼침 제본, 120gsm 미유광 평산지 물성 검증
   - 구현 기능/증거: `PAGE-004`, `PAGE-005` 종이 수치 표기 및 미유광 질감 뷰
   - 예외/금지: 촉감과 생산 사양을 미검증 상태에서 단정 금지
   - 매핑 Page: `PAGE-004 (아날로그 메인)`, `PAGE-005 (노트 선택)`

2. **`VC-02 지안` (미래 일정 흐름 통제)**
   - 페르소나/문제: 주간 일정 개요와 24시간 타임라인의 통제력 필요
   - 요구사항/가치: 주간 개요 → 일간 타임라인 세부 블록 변환
   - 구현 기능/증거: `PAGE-009`, `PAGE-011` 24시간 일간 타임라인 스위처
   - 예외/금지: 외부 달력 자동 동기화를 무조건 완성으로 과장 금지 (HOLD 배지)
   - 매핑 Page: `PAGE-009 (디지털 메인)`, `PAGE-011 (일정 통제)`

3. **`VC-03 하람` (저부담 시각 회고)**
   - 페르소나/문제: 긴 글 작성의 시작 부담과 입력 피로
   - 요구사항/가치: 10초 만에 완료되는 사진/1줄/음성/감정 4대 저부담 폼
   - 구현 기능/증거: `PAGE-010`, `PAGE-017` 10초 빠른 시작 팝업 모달
   - 예외/금지: 필수 입력 필드 강제 및 시작 부담 유발 금지
   - 매핑 Page: `PAGE-010 (빠른 기록)`, `PAGE-017 (작게 시작)`

4. **`VC-04 소담` (주제별 기록 탐색)**
   - 페르소나/문제: 서식 적용 시 작성해둔 글 원본이 훼손될까 두려움
   - 요구사항/가치: 입력 구조(Structure) 템플릿 적용 시 원본 데이터 100% 보호
   - 구현 기능/증거: `PAGE-013`, `PAGE-014` 원본/사본 미리보기 비교
   - 예외/금지: 사본 생성 전 원본 데이터 자동 Mutate 금지
   - 매핑 Page: `PAGE-013 (템플릿 메인)`, `PAGE-014 (사본 탐색)`

5. **`VC-05 태오` (다기기 연속성 검증)**
   - 페르소나/문제: 모바일과 태블릿 간 기록 단절 및 데이터 유실 우려
   - 요구사항/가치: 로컬 저장 우선 및 PDF/표준 포맷 백업 지원
   - 구현 기능/증거: `PAGE-012`, `PAGE-019` 백업/복구 및 내보내기 가이드
   - 예외/금지: 동기화 미검증 상태에서 실시간 연동 확정 금지
   - 매핑 Page: `PAGE-012 (보존 도구)`, `PAGE-019 (도움말)`

6. **`VC-06 나린` (꾸미기 자산 재사용)**
   - 페르소나/문제: 다이어리 꾸미기 자산이 텍스트 입력을 방해함
   - 요구사항/가치: 표현 자산(Asset)과 글 원본 레이어 독립 분리
   - 구현 기능/증거: `PAGE-013`, `PAGE-015` 실링 왁스/스티커 독립 레이어
   - 예외/금지: 꾸미기 요소가 텍스트 가독성을 침해하지 않도록 제한
   - 매핑 Page: `PAGE-013 (템플릿 메인)`, `PAGE-015 (꾸미기 자산)`

7. **`VC-07 이준` (중단 후 재시작)**
   - 페르소나/문제: 기록 중단 후 미안함과 죄책감으로 서비스 이탈
   - 요구사항/가치: 죄책감 유발 스트릭을 배제하고 자연스러운 노구 복귀 지원
   - 구현 기능/증거: `PAGE-016`, `PAGE-018` 최근 1개/미완료 1개 선택 복귀 카드
   - 예외/금지: "N일 동안 작성하지 않았습니다" 등 처벌형 문구 금지
   - 매핑 Page: `PAGE-016 (가이드 메인)`, `PAGE-018 (다시 시작)`
