# DAMORI (다모리) 서비스 흐름도 다수 후보안 (A/B/C) 명세서 (V1)

문서 ID: `FLOW-DAMORI-CANDIDATES-V1`  
버전: `V1`  
위치: `17-가상클라이언트-대량생성/` 전용 독립 폴더  
목적: 50인 클라이언트 및 200개 제품 인벤토리를 수용하는 3대 서비스 흐름 구조안(A/B/C) 비교 기획

---

## 1. 서비스 흐름 후보안 A (선형 단계별 과업 흐름안)

- **특징**: 진입 → 탐색 → 1대1 비교 → 상세 확인 → 과업 완료의 전형적인 5단계 선형 흐름
- **정상 흐름**: `PAGE-001 (메인)` → `PAGE-002 (방식찾기)` → `PAGE-004/009 (아날로그/디지털)` → `PAGE-005/010 (세부 과업)` → `완료`
- **장점**: 흐름이 매우 직관적이고 시스템 예측 가능성이 높음
- **단점**: 이준(VC-07) 미안함 없는 노구 복귀나 하람(VC-03) 10초 저부담 즉시 저장 등의 우회/단축 경로가 반영되지 못함

---

## 2. 서비스 흐름 후보안 B (다중 즉시 모달 단축 흐름안)

- **특징**: 메인페이지(PAGE-001)에서 세부 서브페이지 이동 없이 10초 폼 모달, 템플릿 사본 모달 등을 즉시 열어 빠르게 완료하는 모달 위주의 빠른 흐름안
- **정상 흐름**: `PAGE-001` → `001-START (10초 빠른 폼 팝업)` → `즉시 저장 완료`
- **장점**: 10초 저부담 사용자(VC-03, VC-16)의 빠른 이탈을 막고 기록 시작 마찰을 최소화함
- **단점**: 깊이 있는 브랜드 소개 서사(PAGE-020)나 120gsm 미유광 평산지 상세 수치 탐색(PAGE-008)으로의 유입이 줄어듦

---

## 3. 서비스 흐름 후보안 C (하이브리드 예외/복귀 통합 흐름안 - 최적안)

- **특징**: 정상 5단계 선형 흐름과 10초 빠른 모달 단축 흐름을 동시에 지원하며, `ST-HOLD` (외부 연동 검증 중 배지), `ST-LOCAL` (오프라인 IndexedDB 저장), 죄책감 없는 복귀 안내를 모두 품은 통합 흐름안

### 주요 5대 사용자 여정 (User Flow A ~ E)
- **User Flow A (은재 VC-01 아날로그 사색)**: `PAGE-001 (홈)` → `001-PRODUCTS (15~50개 스크롤 레일)` → `PAGE-004 (아날로그 메인)` → `PAGE-005 (노트 선택)` → `PAGE-008 (120gsm 미유광 수치 라벨)` → 소장 결제
- **User Flow B (지안 VC-02 디지털 시간축)**: `PAGE-001` → `001-SCHEDULE` → `PAGE-009 (디지털 메인)` → `PAGE-011 (24시간 일간 타임라인)` → `HOLD 배지 확인` → 오프라인 직접 통제
- **User Flow C (하람 VC-03 저부담 빠른 회고)**: `PAGE-001` → `001-START 10초 폼 버튼` → `10초 팝업 모달` → `PAGE-010 (사진/1줄/음성/감정 입력)` → 저부담 완료
- **User Flow D (소담 VC-04 & 나린 VC-06 템플릿/자산)**: `PAGE-001` → `001-TEMPLATE` → `PAGE-013 (템플릿 메인)` → `PAGE-014 (사본 서식 미리보기, 원본보호)` → `PAGE-015 (스티커 레이어)` → 적용
- **User Flow E (이준 VC-07 노구 복귀)**: `PAGE-001` → `001-GUIDE 응원 밴드` → `PAGE-016 (가이드 메인)` → `PAGE-018 (미안함 없는 보류/복귀)` → 노구 재개

---

## 4. 후보안 A/B/C 비교 및 검증

- **50인 클라이언트 예외 수용성**: C안 (100%) > A안 (80%) > B안 (70%)
- **복귀 및 오프라인 상태 처리**: C안 (100%) > A안 (60%) > B안 (50%)
- **포트폴리오 흐름 완성도**: C안 (최우수: 메인, 카테고리 서브, 브랜드 소개 3대 제출물과 완전 연동)
