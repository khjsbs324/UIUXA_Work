## 1. 프로젝트 및 클라이언트 생성 기본 정보 설정

- **프로젝트 중심 주제**: 브랜드 서사(기억의 서재)와 상품 탐색(최소 15~100개 스크롤 레일)이 통합된 다모리(DAMORI) 애착공방
- **제작 목적**: 포트폴리오 3대 웹 스토리보드(메인 PAGE-001, 카테고리 서브 PAGE-021, 브랜드 소개 PAGE-020) 및 200개 제품 인벤토리 도출
- **제공 자료**: 브랜드 결정사항(`01-브랜드-결정사항.md`), 20개 콘텐츠 인벤토리, 209개 레퍼런스 검수 데이터
- **필요 정보 및 기능**: 아날로그 물성 노구, 10초 저부담 폼, 24시간 일간 타임라인, 원본 데이터 보존 템플릿, 미안함 없는 복귀 가이드, WCAG 2.1 접근성
- **적용 매체**: 데스크톱 (1200px+), 태블릿 (768px~1023px), 모바일 (360px~767px)

## 2. 가상 클라이언트 대량 생성 및 디테일 분해 (VC-01 ~ VC-50)

### 1 Tier: 근거 기반 핵심 7인 (Core Evidence Persona)

1. **`VC-01 은재` (31세, 프리랜서 번역가)**
   - 상황/목표: 모니터 피로 해소를 위해 밤 시간에 손글씨로 2페이지 이상 장문 사색 일기 작성
   - 불편/마찰점: 만년필 잉크 번짐과 실핏줄 현상(Feathering), 떡제본 노트의 중앙 솟아오름 통증
   - 요구사항: 180도 평면 펼침 Smyth Sewn 실제본 노구, 120gsm 미유광 평산지 잉크 번짐률 0% 수치 보증
   - 성공 조건: 30분 이상 필기 시 손목 통증 없음, 뒷비침 투과도 3% 이하로 양면 서술 완벽 가능
   - 실패 조건: 80gsm 용지 잉크 번짐 발생 및 노트 중앙부 15mm 솟아오름
   - 중요도: 높음 (핵심 아날로그 요구)
   - 정보 유형: 사실(Fact) & 절차(Procedure)
   - 정보 단계: 아날로그 기록 → 노트 & 내지 선택 → 120gsm 무지 Blank 속지
   - 연결 페이지: `PAGE-004 (아날로그 메인)`, `PAGE-005 (노트 선택)`, `PAGE-008 (제품 상세 수치)`
   - 화면 구성: [헤더] 로고, GNB | [내비] 120gsm 미유광 필터 | [바디] 180도 제본 미리보기, 잉크 테스트 수치표 | [푸터] 4열 전역 푸터

2. **`VC-02 지안` (35세, IT 프로젝트 매니저)**
   - 상황/목표: 3개 IT 프로젝트 일정을 관리하며 주간 개요와 하루 24시간 타임라인 블록을 동시 통제
   - 불편/마찰점: 파편화된 일정과 외부 구글 달력의 예고 없는 자동 동기화로 인한 일터/개인 시간 덮어씌움
   - 요구사항: 주간 일정 개요 → 24시간 일간 타임라인 스위처, 외부 연동 검증 중 `HOLD` 주황 배지 안내
   - 성공 조건: 30분 단위 세부 행동 통제, 캘린더 자동 덮어쓰기 완전 차단
   - 실패 조건: 연동 검증 미확인 상태에서 예고 없이 내 일정 데이터 변경
   - 중요도: 높음 (핵심 디지털 시간축 요구)
   - 정보 유형: 절차(Procedure) & 과정(Process)
   - 정보 단계: 디지털 기록 → 시간축 통제 → 24시간 일간 타임라인 블록
   - 연결 페이지: `PAGE-009 (디지털 메인)`, `PAGE-011 (일정 통제)`
   - 화면 구성: [헤더] GNB | [내비] 주간/일간 탭 스위처 | [바디] 24시간 세로 시간축 리스트, HOLD 배지 | [푸터] 도움말 링크

3. **`VC-03 하람` (24세, 대학원생)**
   - 상황/목표: 논문 작성 지친 저녁 시간에 긴 글 작성 부담 없이 10초 만에 시각적 하루 회고 남기기
   - 불편/마찰점: 입력 시작 시 카테고리, 제목, 태그 입력을 강제하여 진입 피로(Entry Friction) 극심
   - 요구사항: 사진 1장, 1줄 메모, 음성 녹음, 감정 이모티콘 4대 10초 무설정 빠른 폼 모달
   - 성공 조건: 단 1회 클릭으로 모달 팝업 진입 후 10초 이내 저장 완료
   - 실패 조건: 필수 제목/태그 필드 미입력 시 저장 불가 에러 팝업
   - 중요도: 높음 (핵심 저부담 시각 요구)
   - 정보 유형: 절차(Procedure)
   - 정보 단계: 디지털 기록 → 10초 빠른 기록 → 4대 무설정 폼 팝업
   - 연결 페이지: `PAGE-010 (빠른 기록)`, `PAGE-017 (작게 시작)`

4. **`VC-04 소담` (28세, 그래픽 디자이너)**
   - 상황/목표: 독서, 여행 회고 등 서식 템플릿 적용 시 기존에 적어둔 글 원본 텍스트 데이터 100% 보호
   - 불편/마찰점: 서식 템플릿 변경 시 작성해둔 글 원본 데이터가 자동 변경되거나 손실됨
   - 요구사항: 입력 구조(Structure) 템플릿과 글 원본 100% 보존 미리보기 및 사본 생성
   - 성공 조건: 템플릿 적용 전후 글 원본 텍스트 1자도 손실 없음
   - 실패 조건: 서식 변경 후 원본 텍스트 포맷 파괴
   - 중요도: 높음 (핵심 템플릿 요구)
   - 정보 유형: 개념(Concept) & 사실(Fact)
   - 정보 단계: 템플릿과 꾸미기 → 사본 템플릿 탐색 → 독서 회고 서식 사본

   - 중요도: 높음 (핵심 데이터 연속성)

   - 중요도: 보통 (꾸미기 자산 요구)
