# 다모리 정보구조·사이트맵 통합본

문서 상태: `CANONICAL_20PAGES + PAGE021_CANDIDATE`

## 1. 구조 판정

- 정식 기준: PAGE-001~020, 20페이지
- PAGE-021 카테고리 솔루션 허브: 대표 웹디자인 검증용 후속 후보
- GNB: 방식 찾기 / 아날로그 / 디지털 / 템플릿과 꾸미기 / 기록 가이드
- Footer: 브랜드 소개, 상태·제공 범위, 접근성·도움
- 검색·로그인·마이페이지·Shop은 현재 GNB에 넣지 않음

## 2. 사이트맵

```text
PAGE-001 홈
├─ 방식 찾기
│  ├─ PAGE-002 기록 방식 찾기
│  └─ PAGE-003 맞춤 추천
├─ Analog
│  ├─ PAGE-004 아날로그 기록
│  ├─ PAGE-005 노트·속지 선택
│  ├─ PAGE-006 장문 기록 가이드
│  ├─ PAGE-007 제품과 구성
│  └─ PAGE-008 제품 상세·비교
├─ Digital
│  ├─ PAGE-009 디지털 기록
│  ├─ PAGE-010 빠른 기록

│  └─ PAGE-012 장문·보존 도구
├─ Template/Expression
│  ├─ PAGE-013 템플릿과 꾸미기
│  ├─ PAGE-014 템플릿 탐색·비교

├─ Guide/Recovery

│  ├─ PAGE-017 작게 시작하기

후속 후보
└─ PAGE-021 카테고리 솔루션 허브
```

## 3. 대표 3페이지

| Page | 역할 | 제작 상태 |
|---|---|---|
| PAGE-001 | 브랜드 5초 인지, 방식 선택, 작은 시작 | 웹디자인 초안 핵심 |
| PAGE-020 | 철학, Layer, 원본 보호와 복귀 태도 | 웹디자인 초안 핵심 |
| PAGE-021 | 조건·카테고리·비교 UI 검증 | 후보임을 표시한 프로토타입 |

## 4. 구조 규칙

- 핵심 과업은 3Depth 이내로 유지한다.
- 감성 콘텐츠와 기능 탐색을 분리하지 않되 CTA 목적은 혼합하지 않는다.
- 제품명보다 목적·상황·구조·물성·보관 조건을 먼저 제시한다.
- 미지원 기능은 비활성 버튼으로 유혹하지 않고 설명과 대안을 제공한다.
- PAGE-021을 채택하더라도 PAGE-004~008을 삭제한 것으로 간주하지 않는다.
