문서 상태: `COPY_DRAFT + PRODUCT_UNVERIFIED`

## 1. 카피 기준

대표 슬로건은 아직 확정하지 않는다. 다음 문구를 우선 비교 후보로 사용한다.

1. 나에게 맞는 기록, 다시 이어지는 기록.
2. 오늘의 한 줄이, 오래 남도록.
3. 완벽하지 않아도, 나의 기록.
4. 나의 속도로 쌓는 생활의 기록.
5. 쓰고, 담고, 다시 이어가다.

## 4. 상품·콘텐츠 데이터 판정

PROD-001~015의 명칭·가격·소재·규격·성능은 가상 카탈로그 데이터다. 실제 판매 상품이나 확정 사양으로 사용하지 않는다.

디자인 초안에서 필요한 경우 다음 필드만 사용한다.

| 필드 | 처리 |
|---|---|
| ID·가상 명칭 | SAMPLE 표시 후 사용 가능 |
| 기록 목적·사용 상황 | 사용 가능 |
| 구조·소재 후보 | UNVERIFIED 표시 |
| 크기·종이 무게·제본·가격 | 실제 근거 전 공개 금지 |
| 성능·친환경성·호환성 | 사실 표현 금지 |
| 비교 상태 | 확인됨 / 직접 확인 / 미검증으로 분리 |

검증 전 공개 금지 예시: 3초·10초 성능 보장, 100/120gsm, 180도 완전 펼침, 잉크 번짐 방지, 완벽 호환, 자동 저장·동기화, 가격과 재고.
