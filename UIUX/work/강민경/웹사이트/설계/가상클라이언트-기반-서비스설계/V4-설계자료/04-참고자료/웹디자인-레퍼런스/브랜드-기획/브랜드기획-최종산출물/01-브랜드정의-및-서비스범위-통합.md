# 다모리 브랜드 정의 및 서비스 범위 통합본

문서 상태: `CANONICAL`

## 1. 브랜드 정의

| 항목 | 통합 기준 | 상태 |
|---|---|---|
| 한글명 | 다모리 | 현재 작업명 |
| 영문명 | DAMORI | 현재 작업명 |
| 유형 | 기록 라이프스타일 브랜드 | 핵심 정의 |
| 기능형 정의 | 목적과 생활에 맞는 기록 방식을 찾고 아날로그 또는 디지털로 부담 없이 시작하고 다시 이어가도록 돕는다. | CANONICAL |
| 감정형 정의 | 기록이 멈춰도 괜찮도록 나의 속도와 취향이 오래 남는 방법을 함께 찾는다. | CANONICAL |
| 대표 상징 | 갓을 쓴 아기 거북이 | 방향 후보 |
| 공식 어원 | 미정 | HOLD |
| 최종 슬로건 | 미정 | 후보 비교 필요 |

50자 소개 초안:

> 종이와 화면 사이에서 지금의 목적과 생활에 맞는 기록 방식을 함께 찾습니다.

## 2. 핵심 경험

```text
기록 방식 이해와 비교
→ 가능한 가장 작은 시작 선택
→ 기록 수행 또는 정보 탐색
→ 중단해도 비난 없이 복귀
→ 저장·보존·미지원 상태를 이해
```

브랜드는 하나의 기록 방식, 일정한 분량이나 연속 기록을 정답으로 강요하지 않는다. 추천은 수정 가능한 초안이어야 하며, Analog와 Digital은 동등하고 독립적인 선택지로 제시한다.

## 3. 브랜드 가치와 약속

- 기록 자율성
- 완벽함보다 지속 가능성
- 선택 피로를 낮추는 구조
- 작은 시작과 부담 없는 복귀
- Analog와 Digital의 서로 다른 장점 존중
- 감성과 실용성의 균형
- 원본·사본·미리보기의 구분
- 확인된 사실과 미확정 정보의 투명한 구분
- 사용자를 평가하거나 재촉하지 않는 태도

## 4. 브랜드 구조

| Layer | 역할 | 현재 범위 |
|---|---|---|
| Brand | 진단·비교·추천·가이드·철학 | LIVE/PROTOTYPE/정보 제공 |
| Analog | 손글씨, 구조, 물성, 소장·보관 조건 | 정보·비교 프로토타입 |
| Digital | 빠른 기록, 일정, 장문·상태 이해 | 클릭·입력 프로토타입 |
| Template/Expression | 구조와 표현을 분리한 미리보기 | 사본 기반 프로토타입 |
| Guide/Recovery | 작은 시작, 중단 후 복귀, 보존 도움 | 안내·선택 프로토타입 |

## 5. 웹사이트 MVP

현재 MVP가 검증할 질문은 세 가지다.

1. 사용자가 자신에게 맞는 기록 방식을 이해하고 고를 수 있는가?
2. 한 줄·사진·음성·기분 등 작은 단위로 시작할 수 있는가?
3. 저장·보존·충돌·복구 상태를 오해하지 않고 이해할 수 있는가?

현재 실제 제공으로 주장하지 않는 항목:

- 회원가입·로그인·마이페이지
- 서버·클라우드 저장과 자동 동기화
- 외부 달력 연결과 실제 알림
- AI 자동 추천·분류
- 실제 파일 업로드·백업·복구·내보내기
- 가격·재고·결제·주문·배송
- 독립 Shop, 유료 자산 마켓, 커뮤니티

## 6. 대상 사용자

핵심 사용자는 기록·다이어리·생산성 도구에 관심이 있지만 고정 양식과 과도한 기능에 피로를 느끼고, 여러 도구를 시도한 뒤 중단 경험이 있는 사람이다. 기능성과 감성, 시작 구조와 자유도, 사용성과 소장 가치를 함께 원한다.

주요 문제:

- 고정된 플래너는 생활과 기록량에 맞지 않음
- 빈 노트는 자유롭지만 시작 부담이 큼
- 완벽주의와 연속 기록 압박으로 중단함
- 디지털 기능·알림 과다로 피로함
- 제품 물성과 디지털 상태를 판단할 근거가 부족함
- 중단 뒤 무엇부터 다시 할지 모름

## 7. 보이스

- 차분하고 따뜻한 존댓말
- 가능한 선택과 다음 행동을 먼저 제시
- 추천에는 이유와 수정 가능성을 포함
- 오류에는 보존 상태와 복구 행동을 포함
- 미지원 기능에는 이유와 가능한 대안을 포함
- `완벽한`, `정답`, `실패`, `게으름`, `안전하게 백업`, `완벽하게 동기화` 같은 표현을 사용하지 않음
