# 다모리 화면설계 통합본

문서 상태: `CANONICAL_SCREEN_DRAFT`

## 1. 공통 화면 구조

| 영역 | 필수 정보·행동 | 규칙 |
|---|---|---|
| Header | DAMORI 식별, GNB 5개, 현재 위치, 작은 시작 CTA | 검색·계정·Shop 자동 추가 금지 |
| Context | 페이지 제목, 사용자 목적, 현재 단계 | 감성 문구 뒤에 구체적 목적 제공 |
| Main | 핵심 콘텐츠와 Primary Action | 한 화면의 Primary Action은 한 목적에 집중 |
| State | Empty·Saving·Error·Offline·Conflict·HOLD | 색 외 Label·Icon·문장 제공 |
| Recovery | 취소·뒤로·다시 시도·호출 화면 복귀 | 입력·원본 유지 범위 명시 |
| Footer | 브랜드, 도움, 제공 범위 | 미확정 정책·SNS·커머스 생성 금지 |

## 3. 대표 화면 설계 우선순위

### PAGE-001 홈

1. Header
2. Hero: 브랜드 정의, Analog/Digital 동등 이미지, 방식 찾기 CTA
3. 작은 시작: 짧은 입력 선택, 실제 저장이 아닌 프로토타입 고지
4. 목적 기반 탐색 경로
5. Analog/Digital 비교 Section
6. Template/Expression 원본 보호 예시
7. 중단 후 복귀 안내
8. 투명한 상태·제공 범위
9. Footer

### PAGE-020 브랜드 소개

1. 기록이 멈춰도 괜찮다는 브랜드 선언
2. Brand·Analog·Digital·Template Layer 설명
3. 기록 자율성·작은 시작·복귀·원본 보호
4. 종이·패브릭·화면 상태의 Editorial 이미지
5. 방식 찾기와 기록 가이드로 복귀

### PAGE-021 카테고리 허브 후보

1. Page가 후보 프로토타입임을 명시
2. 목적·구조·물성·보관·사용 상황 Filter
3. 가상 항목 Card와 검증 상태
4. 2~3개 비교 Tray
5. 확인된 사실·직접 확인·미검증 구분
6. 실제 구매 CTA 대신 조건 저장·비교 행동

## 4. 접근성과 반응형

- 1440px 이상 12컬럼·64px 이상 Side Margin 후보
- 1024~1439px 12컬럼·40px Margin 후보
- 768~1023px 8컬럼·32px Margin 후보
- 360~767px 4컬럼·20px Margin 후보
- 320~359px 4컬럼·16px Margin 후보
- 모든 포인터 대상 최소 44×44px
- 일반 텍스트 4.5:1, 큰 텍스트와 중요 UI 경계 3:1 이상
- 320 CSS px와 200% 확대에서 핵심 정보·행동 유지
- 비교표는 좁은 화면에서 속성별 순차 Card로 전환
- 시각 순서와 DOM·키보드 순서를 일치시킴
