# 다모리 UX 서비스 흐름 통합본

문서 상태: `CANONICAL`

## 1. 전체 흐름

```text
진입과 브랜드 이해
→ 방식 비교 또는 직접 선택
→ Analog / Digital / Template / Guide 진입
→ 작은 행동·비교·미리보기 수행
→ 결과와 상태 이해
→ 중단 시 보류·나누기·새 기록 중 선택
→ 도움을 본 뒤 원래 과업으로 복귀
```

## 2. 주요 경로

### 방식 찾기

`PAGE-001 → PAGE-002 → PAGE-003 → PAGE-004 또는 PAGE-009`

추천은 확정 진단이 아니라 근거가 보이는 수정 가능한 초안이다. 사용자는 질문을 건너뛰고 직접 탐색할 수 있다.

### Analog 적합성

`PAGE-004 → PAGE-005/006/007 → PAGE-008 → 조건 확인 또는 보류`

제품 성능은 공식 근거가 있는 항목과 직접 확인해야 하는 항목을 분리한다.

### Digital 작은 시작

`PAGE-001 또는 PAGE-009 → PAGE-010 → 입력 유지 상태 확인 → PAGE-017 또는 종료`

한 줄·사진·음성·기분은 프로토타입 선택지다. 실제 서버 저장·동기화로 표현하지 않는다.

### Template/Expression

`PAGE-013 → PAGE-014 구조 미리보기 → PAGE-015 표현 미리보기 → 적용 또는 취소`

원본, 사본과 미리보기를 구분하고 취소 시 원본이 유지됨을 설명한다.

### 중단 후 복귀

`PAGE-016 → PAGE-018 → 지금 하기 / 보류 / 작은 단위로 나누기 / 새 기록`

밀린 기록을 모두 완료하게 만들지 않으며 사용자를 평가하지 않는다.

### 상태와 보존

`관련 화면 → PAGE-019 → 가능한 해결 행동 → 호출 화면 복귀`

Local·Pending·Conflict·Recovery는 설명용 또는 프로토타입 상태다. 실제 백업·외부 연동 완료를 주장하지 않는다.

## 3. 공통 상태

| 상태 | 사용자에게 알려야 할 것 | 행동 |
|---|---|---|
| READY | 지금 가능한 행동 | 계속 |
| NEEDS_COMPARISON | 판단 근거 부족 | 비교 기준 보기 |
| EMPTY | 아직 입력·결과 없음 | 시작·조건 변경 |
| SAVING/PENDING | 완료 여부 미확정 | 입력 유지, 기다리기·재시도 |
| ERROR | 실패한 행동과 보존 상태 | 오류 위치에서 복구 |
| OFFLINE/LOCAL | 현재 기기에만 임시로 존재 | 범위 이해, 나중에 재시도 |
| CONFLICT | 다른 버전 존재 | 비교 후 직접 선택 |
| CONDITIONAL | 조건 미충족 | 제한 확인 후 보류 |
| HOLD/UNVERIFIED | 현재 제공·확정 불가 | 설명과 가능한 대안 |

## 4. 금지 흐름

- 회원가입을 첫 행동의 전제 조건으로 만들지 않음
- 알림·외부 달력·동기화를 실제 연결 흐름으로 만들지 않음
- Toast만으로 저장·오류를 전달하지 않음
- 자동 추천이나 최신 버전이 원본을 덮어쓰지 않음
- 미지원 기능을 활성 CTA로 만들지 않음
