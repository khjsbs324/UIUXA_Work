# 제출물·포트폴리오 프로세스 통합본

문서 상태: `CANONICAL_PROCESS`

## 1. 제출물

1. 스타일 가이드 초안 PNG
2. 스타일 가이드 초안 기반 웹디자인 초안 HTML
3. 스타일 가이드 최종안 PNG
4. 웹디자인 최종 HTML
5. 디자인 기획 설명과 포트폴리오 제작 과정

초안과 최종안은 13장 모두 달라질 필요가 없으며 최소 3장에서 의미 있는 차이를 보여준다.

## 2. 현재 이후 진행 순서

```text
선호 디자인 기반 스타일가이드 초안
→ 브랜드 기획 병합
→ DAMORI 접목 스타일가이드 초안 PNG
→ 해당 가이드 기반 웹디자인 초안 HTML
→ 선호·비선호와 사용성 평가
→ 최소 3장 스타일가이드 고도화
→ 스타일가이드 최종안 PNG
→ 웹디자인 최종 HTML
→ 기획 설명·제작 과정 정리
```

## 3. 과정 증빙

- 각 단계의 입력 문서와 적용 이유
- 유지·변경·HOLD 항목
- 초안과 최종안의 Before/After
- Colors·Typography·Card 등 최소 3개 핵심 변경
- 웹 화면에서 발견된 문제와 가이드 환류
- 접근성·반응형·상태 검증 결과
- 원본과 신규 결과물 경로
