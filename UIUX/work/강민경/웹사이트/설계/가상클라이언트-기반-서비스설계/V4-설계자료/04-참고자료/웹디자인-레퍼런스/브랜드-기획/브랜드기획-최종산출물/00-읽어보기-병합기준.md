# 다모리 브랜드기획 최종 병합 산출물

문서 상태: `MERGED_CANONICAL_DRAFT`

이 폴더는 다음 세 자료군을 단계와 목적에 맞게 병합한 작업 기준본이다.

1. `12-제미나이-통합최종산출물(2)`
2. `V1-기존-설계자료`
3. `스타일가이드-작업전달자료`

원본 세 폴더는 수정하지 않았다. 본 폴더의 문서는 이후 브랜드 접목 스타일가이드 초안, 웹디자인 초안과 최종안 제작의 입력으로 사용한다.

## 1. 우선순위

충돌 시 다음 순서로 판단한다.

1. `다모리-브랜드정의서-기획내용정리.md`의 범위·상태·금지 원칙
2. V1의 승인·조건부·후보·HOLD 추적 자료
3. V1의 상세 화면설계·스토리보드
4. 제미나이 통합본과 스타일가이드 전달자료의 확장 제안

파일명이나 본문에 `FINAL`, `APPROVED`, `전수`, `100%`가 적혀 있어도 상위 기준과 충돌하면 확정 근거로 사용하지 않는다.

## 2. 상태 용어

| 상태 | 의미 | 디자인 처리 |
|---|---|---|
| `CANONICAL` | 병합본의 현재 기준 | 초안 제작에 직접 사용 가능 |
| `DRAFT` | 비교·검증용 초안 | 확정값처럼 소개하지 않음 |
| `PROTOTYPE` | 샘플 상호작용 | 실제 서비스·저장으로 오인시키지 않음 |
| `INFORMATION_ONLY` | 정보 제공만 가능 | 실행·결제 CTA 금지 |
| `CONDITIONAL` | 조건 충족 시 사용 | 조건과 제한을 가까이 표시 |
| `HOLD` | 근거·정책·기술 미확정 | 활성 기능으로 노출 금지 |
| `OUT` | 현재 범위 밖 | 메뉴·CTA 생성 금지 |
| `UNVERIFIED` | 수치·사양·성능 미검증 | 출처와 확인일 없이는 사실 표현 금지 |

## 4. 현재 확정 결론

- 작업 브랜드명은 `DAMORI(다모리)`다.
- 다모리는 아날로그·디지털을 함께 다루는 기록 라이프스타일 브랜드다.
- 핵심 경험은 `기록 방식 선택 → 작은 시작 → 부담 없는 복귀 → 상태와 보존 이해`다.
- 현재 결과물은 브랜드 웹 경험과 클릭 프로토타입이며 쇼핑몰·클라우드 기록 서비스가 아니다.
- 공식 어원, 최종 슬로건, 최종 로고, 최종 색상·폰트, 실제 상품·가격·성능은 미확정이다.
- 기본 구조는 PAGE-001~020의 20페이지다. PAGE-021은 대표 카테고리 허브 후보로만 관리한다.
