# 다모리 대표 3페이지 스토리보드·와이어프레임 통합본

문서 상태: `DRAFT_FOR_WEB_DESIGN`

## 1. PAGE-001 홈

### 목표

5초 안에 기록 라이프스타일 브랜드, Analog/Digital 동등성, 방식 선택과 작은 시작 가능성을 이해하게 한다.

### Desktop 흐름

```text
[Sticky Header]
[Editorial Hero: H1 + Lead + 방식 찾기 CTA + Analog/Digital 동등 Visual]
[작은 시작 Prototype: 한 줄/사진/음성/기분]
[목적 기반 탐색 4~5개]
[Analog ↔ Digital 비교 Split]
[Template 구조 ↔ Expression 예시]
[중단 후 복귀 Editorial Band]
[제공 범위·HOLD·UNVERIFIED 안내]
[Footer]
```

Card Grid를 페이지 전체에 반복하지 않는다. Hero, Split Section, Full-width Image, Editorial Text와 기능 Card를 혼합한다.

### 핵심 카피

- H1: `기록을 내 방식으로 이어가세요`
- Lead: `종이와 화면 중 하나를 정답으로 고르지 않고, 지금의 목적과 상황에 맞는 시작점을 찾아보세요.`
- Primary CTA: `내 기록 방식 찾아보기`
- Secondary CTA: `작게 시작하기`

## 2. PAGE-020 브랜드 소개

### 목표

도구 판매보다 기록 자율성, 작은 시작, 중단 후 복귀, 원본 보호라는 태도를 전달한다.

### 흐름

```text
[Serif 후보를 사용한 짧은 Hero]
[기능형 정의 + 감정형 정의]
[Brand / Analog / Digital / Template Layer]
[재료·기록 흔적 Editorial Image]
[원본과 사본·미리보기 원칙]
[중단 후 복귀 문장]
[방식 찾기 / 기록 가이드 CTA]
```

## 3. PAGE-021 카테고리 허브 후보

### 목표

실제 상품 판매가 아니라 사용자가 제품명보다 기록 조건을 먼저 비교할 수 있는지 검증한다.

### 흐름

```text
[후보 프로토타입 고지]
[목적·분량·구조·물성·보관 Filter]
[가상 항목 Grid]
[검증 상태 Drawer]
[2~3개 비교 Tray]
[적합·덜 적합 조건]
[방식 찾기로 돌아가기]
```

가격·재고·구매 버튼을 사용하지 않는다. 가상 항목에는 `SAMPLE/UNVERIFIED`를 표시한다.

## 4. 반응형 재배열

- Desktop: 12컬럼, Hero Split과 비대칭 Editorial Span 허용
- Tablet: 8컬럼, 3열을 2열로 전환
- Mobile: 4컬럼, Text → CTA → Visual 순서
- Mobile 비교표: 행렬 표 대신 속성별 Card와 고정 비교 Tray
- Sticky 요소는 콘텐츠를 가리지 않고 44px Touch Area를 유지

## 5. 상호작용

- Hover·Pressed 약 120ms 후보
- Accordion·상태 패널 약 200ms 후보
- Modal·Drawer 약 320ms 후보
- 자동 재생·무한 부유·Parallax·흔들리는 오류 금지
- Reduced Motion에서 동일한 정보와 상태 제공
- 실제 동작하지 않는 기능은 활성 버튼으로 만들지 않음
