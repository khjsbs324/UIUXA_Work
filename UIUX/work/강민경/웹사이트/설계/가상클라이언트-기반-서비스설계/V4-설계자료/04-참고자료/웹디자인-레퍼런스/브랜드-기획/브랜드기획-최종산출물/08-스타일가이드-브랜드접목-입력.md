# 스타일가이드 × DAMORI 브랜드 접목 입력서

문서 상태: `DRAFT_INPUT_FOR_13_PNG`

## 1. 접목 목표

기존 스타일가이드 초안의 Token·Semantic·State·접근성 구조를 유지하면서 DAMORI의 차분한 기록성, 따뜻한 물성, 선택 자율성과 복귀 태도를 시각 언어에 반영한다.

## 2. 유지할 시스템

- Primitive → Semantic → Component 구조
- 13개 Typography 역할
- 4/8px Core Spacing과 44px Touch Area
- Button 24, Badge 10, Progress 10, Question Number 12, Quiz Option 8, Timer 3, Card 4 Variants
- Brand와 Success·Warning·Danger·Focus의 의미 분리
- 색 외 Icon·Label·문장으로 상태 전달

## 3. DAMORI 후보 시각 언어

| Canvas | `#F7F3E8` Cream | 검증 후보 |

| Brand | `#4F603F` Deep Olive | 검증 후보 |

| Decorative | `#71815D`, `#B8C5A9` | 장식 후보 |

Olive는 성공색이 아니며 Sage는 성공 배경이 아니다. Clay는 오류색이 아니다. 후보 팔레트는 PNG 제작 전에 대비를 다시 계산한다.

### Typography 후보

- UI·본문: Pretendard Variable 또는 Noto Sans KR
- 짧은 Hero·About 제목: Noto Serif KR 후보
- 영문·숫자: Inter 또는 Pretendard
- 손글씨: 라이선스 검증 후 12자 이내 비필수 장식만
- 본문 최소 16px, 행간 약 1.6, 읽기 폭 65ch 이하

### Image·Graphic

- 자연광, 저채도, Cream·Sage·패브릭 계열
- Analog와 Digital을 같은 장면에서 동등하게 표현
- 종이·패브릭 질감은 Hero·About에 2~4% 후보
- 기록 조각 Collage는 한 영역 3~5개 이내
- 마스코트는 한 페이지 최대 1회 후보이며 상태·CTA를 대신하지 않음
- 레퍼런스 자산은 직접 복제하지 않으며 사용 권한 미확인 이미지는 최종 산출물에 사용하지 않음

| 페이지 | 브랜드 접목 |

| 8 Badge | LIVE·PROTOTYPE·HOLD·UNVERIFIED 예시 검토 |

## 5. 금지

- 최종 슬로건·로고·제품 사양·가격을 확정값으로 표현
- 쇼핑몰·실제 클라우드·AI 서비스로 보이게 함
- Olive를 성공 상태색으로 재사용
- 낮은 대비 Beige 본문과 모든 면의 Texture
- 모든 Section의 Rounded Card화
- 마스코트와 감성 사진이 정보·상태보다 먼저 보이게 함
- 3초·10초를 성능 보장 문구로 사용
