# DAMORI HOME Storyboard

- 프로젝트 브랜드명: `DAMORI / 다모리`
- Screen ID: `PAGE-00`
- 상태: `CURRENT_WORKING_PAGE_STORYBOARD`
- 기준: `05-v4-storyboard-v1.md` Master에서 HOME만 분리 도출

## 1. Page Name

`HOME / MAIN`

## 2. Page Purpose

DAMORI의 존재 이유와 기록 경험을 소개하고, 아날로그·디지털 기록 도구의 포트폴리오 탐색으로 연결한다.

## 3. User Goal

브랜드가 제안하는 부담 없는 기록 관점을 이해하고, 자신에게 필요한 기록 경험과 관련 제품 정보를 자연스럽게 발견한다.

- DN: `DN-03`, `DN-04`, `DN-06`, `DN-12`
- RG: `RG-03`, `RG-04`, `RG-06`
