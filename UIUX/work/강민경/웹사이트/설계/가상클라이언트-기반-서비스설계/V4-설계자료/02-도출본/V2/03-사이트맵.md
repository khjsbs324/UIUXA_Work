# 03. 사이트맵

## 전역 구조

전역 메뉴는 `메인`, `카테고리`, `브랜드` 세 항목이다. 페이지는 3개, 구역은 16개이며 추가 페이지는 없다.

| 페이지 | 목적 | 하위 구역 |
|---|---|---|
| 메인 페이지 (HOME) | 브랜드 이해에서 제품 탐색으로 이어지는 스크롤형 포트폴리오 | 0.1 첫인상·메인 비주얼 → 0.2 브랜드 핵심 소개 → 0.3 기록 경험 → 0.4 기록 방식과 제품 연결 → 0.5 제품 15개 포트폴리오 → 0.6 마무리·페이지 이동 |
| 카테고리·서브 페이지 (PRODUCTS) | 제품군·확인 정보·비교 관점을 보여주는 정보 페이지 | 1.1 시각적 제품 소개 → 1.2 제품군 탐색 → 1.3 제품 특징·사양 정보 → 1.4 자율 탐색 기준 안내 |
| 브랜드 소개 페이지 (BRAND) | 존재 이유와 기록 관점을 독립적인 이야기로 전달 | 2.1 브랜드 소개 → 2.2 브랜드 존재 이유 → 2.3 기록 철학 → 2.4 핵심 가치 → 2.5 아날로그·디지털 원칙 → 2.6 제품 원칙 |

## 주요 연결

- 0.3 → 0.4 → 1.2 → 1.3: 기록 경험을 제품 정보 탐색으로 이어 주는 주요 경로 C.
- 0.5 → 1.3: 제품 후보 관심을 확인 정보로 연결.
- 1.3 ↔ 2.6: 제품 정보와 제품을 바라보는 원칙을 연결.
- 모든 페이지는 전역 메뉴로 상호 이동.

상세 정보 관계는 `04-사이트구조맵`, 이동 방향은 `05-사이트흐름도`에서 구분해 다룬다.
