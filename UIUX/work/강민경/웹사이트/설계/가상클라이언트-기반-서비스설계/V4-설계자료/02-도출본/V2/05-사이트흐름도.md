# 05. 사이트 흐름도

페이지와 구역 사이에서 사용자가 어디서 출발해 무엇을 확인하고 어디로 이동하는지를 보여준다. 시스템 처리 흐름이 아니다.

## 진입과 전역 이동

| 출발 | 사용자 목적 | 이동 대상 | 도착 후 확인 | 다음 선택 |
|---|---|---|---|---|
| 메인 0.1 | 브랜드를 먼저 이해 | 0.2~0.4로 스크롤 | 가치, 기록 경험, 기록 방식 | 0.5 제품 보기 또는 브랜드 이동 |
| 메인 0.1 | 제품 세계를 먼저 확인 | 카테고리 1.1 | 제품 페이지의 역할과 시각적 맥락 | 1.2 제품군 → 1.3 정보 |
| 메인 0.5 | 관심 후보의 정보 확인 | 카테고리 1.3 | 물성·제본·사양의 확인 범위 | 1.4 기준 참고 또는 2.6 원칙 |
| 카테고리 1.3 | 제품 관점의 배경 이해 | 브랜드 2.6 | 제품 원칙이 검토용 예시임을 확인 | 브랜드 서사 재탐색 또는 카테고리 복귀 |
| 브랜드 2.5~2.6 | 실제 제품 정보 확인 | 카테고리 1.3 | 확인 정보와 추가 검증 항목 | 1.2·1.4 재탐색 |

## 주요 경로 C — 기록 경험에서 제품 정보로

`메인 0.3 기록 경험` → 사용자가 자신의 기록 방식과 연결 → `0.4 기록 방식과 제품 연결` → 아날로그 물성과 디지털 편의의 관계 이해 → `카테고리 1.2 제품군 탐색` → 임시 제품군의 정보 범위 확인 → `1.3 제품 특징·사양 정보` → 자료 확인 정보와 추가 확인 항목 구분.

## 재탐색과 종료

각 페이지의 전역 메뉴로 다른 페이지에 이동하거나 현재 페이지의 이전 구역을 다시 읽을 수 있다. 원하는 정보를 확인한 시점에 별도 제출·결제 절차 없이 탐색을 종료한다.
