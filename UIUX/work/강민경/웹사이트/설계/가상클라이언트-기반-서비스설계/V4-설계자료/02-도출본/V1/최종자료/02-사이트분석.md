# 02. DAMORI 사이트 분석 V1

## 분석 기준

가상 클라이언트의 Need를 메뉴·콘텐츠·기능으로 번역한다. 현재 3 Page에서 사용자가 실제로 접하는 정보만 포함한다.

## 1. 메뉴

| 메뉴 | 목적 | 사용자 목표 | 주요 콘텐츠 | 근거 Client / Need | 연결 관계 |
|---|---|---|---|---|---|
| HOME | 브랜드와 제품 세계를 한 흐름으로 소개 | DAMORI가 무엇인지 빠르게 이해하고 관심 제품으로 이동 | Hero, 가치, 기록 경험, Analog/Digital, 15개 Portfolio | C03·C06, DN-03·06·12 | PRODUCTS 1.2/1.3, BRAND 2.1/2.3 |
| PRODUCTS | 제품군과 정보를 비교·탐색 | 제품의 유형·특징·사양·비교 기준을 가입 없이 확인 | Visual Hero, Working Groups, Feature/Spec, Exploration Guide | C01·C02·C04·C07, RG-01·02·07·08 | HOME 0.4/0.5, BRAND 2.6 |
| BRAND | 브랜드의 존재 이유와 기록 관점을 독립적으로 전달 | 브랜드 철학과 제품 원칙의 배경을 이해 | Introduction, Purpose, Philosophy, Values, Analog/Digital, Principle | C03·C06·C01, DN-03·06·07 | HOME, PRODUCTS 1.3 |

## 2. 콘텐츠

| 콘텐츠 | 실제로 보여줄 내용 | 관련 Need | Page / Section | 표현 방식 |
|---|---|---|---|---|
| 브랜드 핵심 소개 | 프로젝트 브랜드명과 “바쁜 일상 속 기록의 쉼표” | 저부담 기록, 브랜드 신뢰 | HOME 0.1 | 큰 Headline + 기록 전 순간의 이미지 계획 |
| 핵심 가치 요약 | 사색의 깊이, 글 원본 보존성, 자율성 | DN-03·04·08 | HOME 0.2 | 3개 가치 구획 |
| 기록 경험 | 저부담 회고, 글 원본 보존, 편안한 복귀 | DN-03·04·06 | HOME 0.3 | 경험 장면 + 설명, Working Example 표기 |
| Analog/Digital 접근 | 물성과 편의를 상호 보완 관계로 설명 | DN-02·05 | HOME 0.4, BRAND 2.5 | Image/Text 교차 |
| Product Portfolio | Source Pool 기반 15개 Working Display Set | DN-12, RG-06 | HOME 0.5 | 3개 강조 + 12개 보조 |
| 제품군 탐색 | 공식 Category가 아닌 Working Group으로 정보 범위 안내 | RG-02·08 | PRODUCTS 1.2 | 임시 Group 6개와 설명 |
| 특징·사양 정보 | 확인된 정보와 추가 검증 정보를 구분 | RG-01·07 | PRODUCTS 1.3 | Material/Binding vs Specification |
| 탐색 기준 안내 | 기록 목적·환경·물성·정보 항목을 비교 관점으로 안내 | DN-08 | PRODUCTS 1.4 | 비실행 Guide + Related Range |
| 브랜드 철학·가치 | 기록은 의무가 아닌 편안한 쉼표, 3대 핵심 가치 | DN-03·06 | BRAND 2.1~2.4 | Editorial Story + 중앙 Quote |
| 제품 관점 | Analog/Digital 및 제품 원칙 Working Example | RG-01·07 | BRAND 2.5~2.6 | 교차 구성 + 원칙 예시 |

## 3. 기능

| 기능 | 필요한 이유 | 근거 Need | 적용 위치 | 범위 |
|---|---|---|---|---|
| Page 이동 | 브랜드·제품·철학을 사용자가 자유롭게 오가기 위함 | 자율성 | 공통 GNB | HOME/PRODUCTS/BRAND만 |
| Section 이동 | 긴 페이지에서 위치와 목적을 잃지 않게 함 | VC-40·46·51 | HTML Wireframe, Anchor | 정보 이동 |
| 제품 정보 확인 | Showcase 관심을 근거 있는 정보로 연결 | RG-01·07 | HOME 0.5 → PRODUCTS 1.3 | Product Detail Page 없음 |
| 비교 기준 참고 | 복잡한 진단 없이 스스로 판단 | RG-08 | PRODUCTS 1.4 | NON_EXECUTABLE |
| 관련 Page 이동 | 제품의 이유와 브랜드 철학을 상호 보완 | 브랜드 신뢰 | PRODUCTS ↔ BRAND | 단순 이동 |

현재 기능이 아닌 항목: Filter 실행, 자동 추천, Login, Save, Sync, Editor, Layer Control, Cart, Purchase.
