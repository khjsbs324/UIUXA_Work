# 04. DAMORI 사이트 구조맵 V1

## 사이트맵과의 차이

사이트맵은 Page/Section 계층을 정의하고, 구조맵은 메뉴·콘텐츠 그룹·정보 흐름과 Page 사이의 관계를 정의한다.

| Page | 메뉴 역할 | 콘텐츠 그룹 | 정보 순서 | Page 관계 |
|---|---|---|---|---|
| HOME | 전체 경험의 시작점 | Brand Narrative / Recording Experience / Product Bridge / Portfolio | 존재 이유 → 가치 → 경험 → 제품 접근 → 15개 Showcase | PRODUCTS의 Group·Spec으로 전환, BRAND 서사로 심화 |
| PRODUCTS | 제품 정보 탐색점 | Visual Context / Working Groups / Evidence / Exploration Guide | 무엇이 있는가 → 무엇이 다른가 → 무엇이 확인됐는가 → 무엇을 참고할까 | HOME의 관심을 정보로 구체화, BRAND 2.6과 원칙 연결 |
| BRAND | 브랜드 의미의 독립 경로 | Introduction / Purpose / Philosophy / Values / Medium / Principle | 브랜드가 무엇인가 → 왜 존재하는가 → 무엇을 믿는가 → 제품을 어떻게 보는가 | PRODUCTS 정보에 이유를 제공, HOME 첫인상을 심화 |

## 핵심 Section 관계

- HOME 0.3 → 0.4 → PRODUCTS 1.2 → 1.3
- HOME 0.5 → PRODUCTS 1.3
- HOME 0.2 → BRAND 2.4
- PRODUCTS 1.3 → BRAND 2.6
- BRAND 2.5/2.6 → PRODUCTS 1.2/1.3
