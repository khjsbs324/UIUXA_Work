# 01. 가상 클라이언트 통합

- 상태: V2 사용자 검토용
- 범위: 메인, 카테고리·서브, 브랜드 소개 3개 페이지
- 근거 계보: Source Client 51명 → Pure Need 10개 → 요구 그룹 8개 → 대표 Client 7명

## 통합 원칙

51명의 요구를 51개 화면으로 확대하지 않고 공통된 기록 경험과 제품 정보 요구로 통합한다. 앱·저장·동기화·편집 요구는 원래 요구로 보존하되 현재 3페이지 웹사이트 기능으로 표현하지 않는다.

| 대표 Client | 원래 요구 | 웹사이트에서 수용 | 범위 밖 | 반영 위치 |
|---|---|---|---|---|
| V4-C01 은재 | 장문 필기, 평면 펼침, 종이 정보 | 근거 있는 물성·제본·종이 정보 | 제품 성능 보증 | 카테고리 1.3, 브랜드 2.6 |
| V4-C02 지안 | 시간축으로 일정 흐름 파악 | 서식과 사용 맥락 안내 | 일정 관리·재설정 기능 | 카테고리 1.2~1.3 |
| V4-C03 하람 | 부담 없는 회고 | 낮은 부담의 기록 경험 | 기록 입력·저장 | 메인 0.2~0.3 |
| V4-C04 소담 | 글과 구조의 보존 | 글 원본 보존의 상위 메시지 | 편집기·레이어 관리 | 메인 0.3, 카테고리 1.3 |
| V4-C05 태오 | 기기 연속성과 로컬 소장 | 아날로그·디지털 관계의 배경 | 오프라인·동기화·내보내기 | 브랜드 2.5의 근거 |
| V4-C06 이준 | 중단 후 편안한 복귀 | 죄책감 없는 복귀 철학 | 자동 복귀·1클릭 기능 | 메인 0.3, 브랜드 2.3 |
| V4-C07 다온 | 진단 없이 자율 비교 | 비교 정보와 탐색 기준 안내 | 자동 추천·자동 결과 | 카테고리 1.3~1.4 |

## 공통 요구와 설계 영향

| 요구 그룹 | 통합 요구 | 화면 영향 |
|---|---|---|
| RG-01 | 물성·제본·종이 정보를 확인 | 1.3 확인 정보·제품 사양 |
| RG-02 | 시간축·서식의 사용 맥락 이해 | 1.2 임시 제품군, 1.3 정보 슬롯 |
| RG-03 | 기록 부담을 낮추고 편안하게 복귀 | 0.2~0.3, 2.3 |
| RG-04 | 글 원본을 존중하는 관점 | 0.3, 1.3 |
| RG-05 | 매체 사이 연속성 | 2.5 설명의 배경, 실행 기능 제외 |
| RG-06 | 긴 흐름 속에서 브랜드와 제품 이해 | 0.1~0.6 스크롤형 포트폴리오 |
| RG-07 | 제품 정보를 같은 기준으로 비교 | 1.3 |
| RG-08 | 가입·진단 없이 자율 탐색 | 1.4 비실행형 안내 |

## 범위 결론

- 직접 반영: 브랜드 이야기, 기록 경험, 제품 세계, 확인 가능한 제품 정보, 비교 기준, 브랜드 철학과 가치.
- 범위 밖 참고: 로그인, 저장, 동기화, 오프라인 실행, 편집기, 레이어 제어, 자동 추천, 장바구니와 구매.
- 페이지 역할: 메인은 스크롤형 포트폴리오, 카테고리는 정보 탐색, 브랜드는 독립적인 브랜드 이야기다.
