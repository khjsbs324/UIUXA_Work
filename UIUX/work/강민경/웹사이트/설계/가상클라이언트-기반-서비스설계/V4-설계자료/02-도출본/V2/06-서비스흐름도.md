# 06. 서비스 흐름도

사용자 상황, 목적, 행동, 화면 정보, 판단, 다음 이동을 연결한다. 실행형 필터나 추천 알고리즘은 없다.

## 경로 A — 브랜드 발견에서 제품 포트폴리오 이해

| 단계 | 사용자 상황·목적 | 행동 | 표시 정보 | 판단과 다음 이동 |
|---|---|---|---|---|
| A1 메인 진입 | DAMORI가 어떤 브랜드인지 궁금 | 0.1 확인 | 프로젝트 브랜드명, 기록의 쉼표, 제품 세계로 이어지는 첫인상 | 더 이해하려면 아래로 이동 |
| A2 핵심 소개 | 브랜드 기준을 빠르게 파악 | 0.2 읽기 | 사색의 깊이, 글 원본 보존성, 자율성 | 자신의 경험과 연결하려면 0.3 |
| A3 기록 경험 | 기록 부담과 복귀 방식을 확인 | 0.3 읽기 | 낮은 부담, 원본 존중, 편안한 복귀의 경험 예시 | 제품 접근을 보려면 0.4 |
| A4 접근 방식 | 제품이 기록 경험과 어떻게 연결되는지 확인 | 0.4 읽기 | 아날로그 물성과 디지털 편의의 상호 보완 | 후보를 보려면 0.5 |
| A5 포트폴리오 | 다양한 후보의 밀도와 역할 파악 | 제품 15개 훑기 | 레이아웃 검토용 15개 후보와 확인 상태 | 정보가 필요하면 1.3, 철학은 브랜드 |
| A6 종료·재탐색 | 필요한 수준까지 이해 | 0.6 또는 전역 메뉴 | 지원 정보와 세 페이지 이동 | 종료 또는 다른 페이지 |

## 경로 B — 제품 정보 탐색

| 단계 | 사용자 상황·목적 | 행동 | 표시 정보 | 판단과 다음 이동 |
|---|---|---|---|---|
| B1 카테고리 진입 | 구매보다 정보 범위를 먼저 파악 | 1.1 확인 | 약 200개 작업용 Source Pool과 페이지 역할 | 제품군을 보려면 1.2 |
| B2 제품군 탐색 | 어떤 종류의 정보가 있는지 확인 | 임시 그룹 읽기 | 공식 카테고리가 아닌 6개 구조 검토 그룹 | 상세 비교는 1.3 |
| B3 정보 비교 | 확인된 정보와 미확정 정보를 구분 | 물성·제본과 사양 열 비교 | 제한된 후보에 확인된 120gsm·180도·Smyth Sewn, 추가 확인 슬롯 | 기준이 필요하면 1.4 |
| B4 기준 참고 | 자신에게 필요한 확인 항목을 정리 | 안내 문장 읽기 | 목적·환경·물성·정보 완성도와 관련 정보 범위 | 1.2·1.3 재탐색 또는 종료 |

## 경로 C — 기록 경험에서 제품 정보 탐색

`0.3 기록 경험` → `0.4 기록 방식과 제품 연결` → `1.2 제품군 탐색` → `1.3 제품 특징·사양 정보` 순서를 유지한다. 이 경로는 자동 추천이 아니라 이야기에서 정보로 이동하는 앵커 경로다.

## 예외·범위

원하는 정보를 찾기 어려우면 1.4의 탐색 기준을 참고하고 1.2 또는 1.3으로 돌아간다. 조건 입력, 결과 계산, 로그인, 저장, 장바구니는 발생하지 않는다.
