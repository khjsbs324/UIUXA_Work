# 07. 화면설계서

- 화면: 메인 페이지 `PAGE-00 / HOME`, 카테고리·서브 페이지 `PAGE-01 / PRODUCTS`, 브랜드 소개 페이지 `PAGE-02 / BRAND`
- 구역: 총 16개
- 공통 작동: 전역 메뉴와 구역 앵커 이동만 제공
- 반응형: 데스크톱 다열, 태블릿 2열, 모바일 1열을 기본으로 정보 순서를 보존

## PAGE-00 메인 페이지

**화면 목적**: DAMORI의 존재 이유와 기록 경험을 이해시킨 뒤, 제품 세계와 레이아웃 검토용 제품 후보 15개를 보여 주고 카테고리·브랜드 페이지로 연결한다.

**주요 콘텐츠**: 첫인상, 핵심 가치, 기록 경험, 기록 방식과 제품의 관계, 제품 포트폴리오, 마무리.

**인터페이스 요소**: 전역 메뉴, 구역 링크, 카테고리·브랜드 이동 링크. 구매·장바구니·상품 상세는 없다.

**레이아웃**: 긴 스크롤 페이지. 2열 메인 비주얼, 3열 가치, 이미지·텍스트 교차, 강조 3개와 보조 12개의 제품 배열. 모바일에서는 모든 정보를 문서 순서대로 1열 배치한다.

**사용자 경로**: 경로 A 전체와 경로 C의 0.3→0.4 구간. 0.5에서 카테고리 1.3으로 이동할 수 있다.

| ID·이름 | 목적 | 핵심 내용과 제목 역할 | 본문·비주얼 | 제품·인터페이스 | 행동·연결 | 미확정 |
|---|---|---|---|---|---|---|
| 0.1 첫인상·메인 비주얼 | 첫 화면에서 브랜드 성격 인지 | 제목은 `DAMORI`, 보조 문구는 `바쁜 일상 속 기록의 쉼표`; 포트폴리오형 사이트임을 알림 | 기록을 시작하기 전의 책상, 노트, 펜, 여백이 있는 장면 | `제품 세계 살펴보기`는 카테고리 1.1 이동 | 아래로 읽거나 카테고리로 이동 | 실제 대표 이미지 선정 필요 |
| 0.2 브랜드 핵심 소개 | 판단 기준을 짧게 전달 | `기록을 오래 이어 가게 하는 세 가지 기준`이라는 역할 아래 사색의 깊이·글 원본 보존성·자율성 소개 | 각 가치의 의미를 한 문장으로 설명하는 3개 정보 구획 | 링크 없이 읽는 정보 | 0.3 또는 브랜드 2.4 | 최종 화면 문장 다듬기 필요 |
| 0.3 기록 경험 | 제품보다 먼저 사용자 경험을 제시 | `부담 없이 시작하고, 남기고, 돌아오기`라는 역할; 낮은 부담의 회고·글 원본 보존·편안한 복귀는 대표 경험 예시 | 작성 중인 기록, 축적된 기록, 다시 펼친 기록의 연속 장면 | 예시임을 명시해 공식 카테고리 오해 방지 | 0.4로 이동 | 실제 이미지 선정 필요 |
| 0.4 기록 방식과 제품 연결 | 기록 경험을 제품 세계로 전환 | `아날로그의 물성과 디지털의 편의를 함께 바라봅니다` | 종이 도구의 촉감과 디지털 사용 맥락을 대립이 아닌 상호 보완으로 설명 | `제품군 살펴보기`는 1.2 이동 | 0.5 또는 1.2 | 앱 기능으로 확정하지 않음 |

| 0.6 마무리·페이지 이동 | 긴 흐름을 정리하고 재탐색 | `기록을 위한 다음 장면을 살펴보세요` | 정책 페이지를 암시하지 않는 지원 정보 | 메인·카테고리·브랜드 링크 | 페이지 이동 또는 종료 | 실제 지원 문구 확인 필요 |

## PAGE-01 카테고리·서브 페이지

**화면 목적**: 현재 작업용 제품 Source Pool의 범위, 임시 제품군, 확인 정보와 추가 확인 항목, 자율 탐색 기준을 보여 준다.

**작동 방식**: 정보 열람과 구역 이동만 가능하다. 1.4는 조건을 입력하거나 자동 결과를 만드는 기능이 아니다.

**레이아웃**: 시각적 소개 2열 → 임시 제품군 3열/2열/1열 → 확인 정보와 사양 2열 → 탐색 안내와 관련 정보 범위 2열. 모바일에서는 제목·설명·정보·연결 순서로 배치한다.

| ID·이름 | 목적 | 핵심 내용과 제목 역할 | 본문·비주얼 | 제품·인터페이스 | 행동·연결 | 미확정 |
|---|---|---|---|---|---|---|
| 1.1 시각적 제품 소개 | 판매 화면이 아닌 정보 탐색 페이지임을 안내 | `제품의 모양보다, 기록에 쓰이는 맥락부터` | 여러 기록 도구와 사용 장면을 넓게 보여 주는 이미지 예정 영역 | 약 200개 작업용 후보 Source Pool 안내 | 1.2로 스크롤 | 대표 이미지 선정 필요 |
| 1.2 제품군 탐색 | 정보 범위를 빠르게 파악 | `구조 검토를 위한 임시 제품군`; 6개 그룹은 공식 카테고리가 아님 | 각 그룹은 제품 종류·사용 맥락·필요 정보의 예를 짧게 설명 | 그룹 01~06, 클릭 필터 없음 | 1.3으로 이동 | 공식 카테고리·개수 미확정 |
| 1.3 제품 특징·사양 정보 | 사실과 검증 대상을 구분해 비교 | `확인된 정보와 추가 확인이 필요한 정보를 나눠 봅니다` | 좌측은 물성·제본, 우측은 사양·사용 참고. 120gsm·180도·Smyth Sewn은 Source가 확인된 해당 후보 맥락에서만 표시 | 치수·페이지 수·종이 사양·필기 적합성·디지털 사용 정보는 검증 슬롯 | 1.4 또는 브랜드 2.6 | 제품별 적용 범위 재검증 필요 |
| 1.4 자율 탐색 기준 안내 | 사용자가 스스로 확인 순서를 정하게 지원 | `무엇을 먼저 확인할지 정하는 네 가지 관점` | 기록 목적, 사용 환경, 물성, 정보 완성도는 검토용 예시. 관련 제품 정보 범위를 함께 안내 | 버튼·칩·적용·자동 결과 없음 | 1.2·1.3 재탐색 또는 종료 | 최종 탐색 문구 확인 필요 |

## PAGE-02 브랜드 소개 페이지

**화면 목적**: DAMORI가 왜 존재하며 기록과 제품을 어떤 관점으로 바라보는지 하나의 서사로 이해시킨다.

**레이아웃**: 소개 → 이미지·텍스트 교차 → 중앙 인용 → 3개 가치 → 아날로그·디지털 교차 → 제품 원칙 예시. 모바일에서도 이 순서를 바꾸지 않는다.

| ID·이름 | 목적 | 핵심 내용과 제목 역할 | 본문·비주얼 | 제품·인터페이스 | 행동·연결 | 미확정 |
|---|---|---|---|---|---|---|
| 2.1 브랜드 소개 | 독립적인 브랜드 이야기 시작 | `DAMORI, 쉼표를 담는 프로젝트 브랜드` | 기록과 여백을 상징하는 넓은 도입 장면 | 프로젝트 작업명임을 명시 | 2.2 | 브랜드명 최종 승인 전 |
| 2.2 브랜드 존재 이유 | 일상 기록의 부담을 낮추는 목적 설명 | `기록을 해야 할 일에서 머물 수 있는 시간으로` | 바쁜 일상과 조용한 기록 장면의 대비 | 읽기 중심 | 2.3 | 실제 이미지 필요 |
| 2.3 기록 철학 | 감정적 중심 문장 전달 | `기록은 매일 이어가야 하는 의무가 아닌, 일상의 편안한 쉼표입니다.` | 충분한 여백 속 중앙 인용 | 읽기 중심 | 2.4 | Source 문장 유지 |
| 2.4 핵심 가치 | 세 판단 기준의 관계 이해 | 부담을 덜기 / 글 원본 존중 / 선택을 강요하지 않기 | Zero Strain·Data Integrity·Autonomy를 한국어 설명 우선으로 표시 | 3개 동등 구획 | 2.5 | 최종 표현 정리 필요 |

| 2.6 제품 원칙 | 제품 정보의 배경이 되는 관점 제시 | `제품을 바라보는 원칙의 검토용 예시` | 물성·정보·자율 선택에 관한 설명 3개를 예시로 표시 | 공식 원칙 개수로 확정하지 않음 | 카테고리 1.3 | 최종 원칙 수·문구 미확정 |

- 카테고리와 제품 원칙의 개수·이름은 미확정이다.
