# 01. DAMORI 가상 클라이언트 통합 V1

- 상태: `FINAL_DERIVATION_V1_FOR_USER_REVIEW`
- 프로젝트 브랜드명: `DAMORI / 다모리` (working name)
- Source: 51 Client → 10 Pure Need → 8 Requirement Group → 7 Representative Client

## 1. 통합 목적

51명의 개별 요구를 51개 화면으로 확대하지 않고, 공통된 기록 경험과 제품 정보 요구를 HOME·PRODUCTS·BRAND 3개 Page에 수렴한다. 개별 Client의 앱·저장·동기화 요구는 원본 근거로 보존하되 현재 Website 기능으로 바꾸지 않는다.

## 2. Source Client 개요

51명은 장문 필기, 시간축 계획, 저부담 회고, 글 보존, 매체 연속성, 중단 후 복귀, 제품 비교, 자율 탐색, 접근성, Portfolio 이해 등 서로 다른 관점을 제공한다. V1/V2/V3에 각 Client별 사이트 구조맵·서비스 흐름도·화면설계서가 존재하며 Coverage는 보조자료에서 추적한다.

## 4. 공통 Need

1. 기록을 부담이나 의무로 만들지 않을 것.
2. 남긴 글과 기록의 의미를 존중할 것.
3. 제품의 물성·서식·사양을 이해할 수 있을 것.
4. 가입이나 진단 없이 스스로 비교 기준을 선택할 것.
5. Analog와 Digital을 대립시키지 않고 맥락에 맞게 연결할 것.
6. 긴 페이지에서도 현재 위치와 다음 탐색 방향을 이해할 것.

## 6. 최종 범위

- 직접 반영: 브랜드 서사, 기록 경험, 제품군 방향, 제품 정보, 비교 기준, 브랜드 철학과 가치.
- 범위 밖 참고: Login, 저장, Sync, Offline 실행, Editor, Layer Control, 자동 추천, 구매 흐름.
- 최종 설계 결과: HOME은 Portfolio Landing, PRODUCTS는 정보형 Category/Sub, BRAND는 독립 Editorial Story로 도출한다.
