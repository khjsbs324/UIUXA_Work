# 02. 사이트 분석

가상 클라이언트 요구를 메뉴·콘텐츠·기능으로 번역한 결과다. 현재 사이트에서 실제 제공하는 범위만 포함한다.

## 메뉴

| 메뉴 | 목적 | 사용자 목표 | 주요 콘텐츠 | 근거 | 연결 |
|---|---|---|---|---|---|
| 메인 페이지 (HOME) | 브랜드와 제품 세계를 한 흐름으로 소개 | DAMORI가 무엇인지 이해하고 관심 정보로 이동 | 첫인상, 핵심 가치, 기록 경험, 제품 접근, 제품 15개, 마무리 | DN-03·06·12, RG-03·06 | 카테고리 1.2·1.3, 브랜드 2.1·2.3 |
| 카테고리·서브 페이지 (PRODUCTS) | 제품군과 정보의 탐색 기준 제공 | 제품 유형·특징·사양을 가입 없이 비교 | 제품 비주얼, 임시 제품군, 확인 정보·사양, 탐색 기준 | DN-01·02·07·08, RG-01·02·07·08 | 메인 0.4·0.5, 브랜드 2.6 |
| 브랜드 소개 페이지 (BRAND) | 존재 이유와 기록 관점을 설명 | 철학과 제품 원칙의 배경 이해 | 소개, 존재 이유, 기록 철학, 핵심 가치, 아날로그·디지털, 제품 원칙 | DN-03·06·07 | 메인, 카테고리 1.3 |

## 콘텐츠

| 콘텐츠 | 사용자에게 보여줄 내용 | 표현 방식 | 반영 위치 |
|---|---|---|---|
| 브랜드 핵심 소개 | 프로젝트 브랜드명과 바쁜 일상 속 기록의 쉼표 | 큰 제목과 기록 직전의 장면 | 0.1 |
| 핵심 가치 | 사색의 깊이, 글 원본 보존성, 자율성 | 세 개의 동등한 정보 구획 | 0.2, 2.4 |
| 기록 경험 | 낮은 부담의 회고, 원본 존중, 편안한 복귀 | 세 경험 예시와 누적 장면 | 0.3 |
| 기록 방식과 제품 | 아날로그 물성과 디지털 편의의 상호 보완 | 이미지·텍스트 교차 | 0.4, 2.5 |
| 제품 포트폴리오 | Source Pool에서 고른 레이아웃 검토용 제품 후보 15개 | 강조 3개와 보조 12개 | 0.5 |
| 제품군 탐색 | 공식 카테고리가 아닌 임시 제품군 | 6개 구조 검토 구획 | 1.2 |
| 확인 정보·제품 사양 | 자료 확인 정보와 추가 확인 항목의 구분 | 물성·제본과 사양의 균형 비교 | 1.3 |
| 탐색 기준 안내 | 목적·환경·물성·정보 완성도를 참고하는 방법 | 클릭 결과가 없는 비실행형 안내 | 1.4 |
| 브랜드 이야기 | 존재 이유에서 제품 원칙까지 이어지는 서사 | 긴 호흡의 편집형 구성 | 2.1~2.6 |

## 기능

| 기능 | 사용자 행동 | 적용 위치 | 제한 |
|---|---|---|---|
| 페이지 이동 | 메인·카테고리·브랜드 사이 이동 | 전역 메뉴 | 3개 페이지만 |
| 구역 이동 | 긴 페이지에서 원하는 구역으로 이동 | HTML 앵커 | 정보 이동만 수행 |
| 제품 정보 확인 | 포트폴리오에서 제품 정보 구역으로 이동 | 0.5 → 1.3 | 상품 상세 페이지 없음 |
| 비교 기준 참고 | 무엇을 확인할지 읽고 1.2·1.3을 재탐색 | 1.4 | 필터 실행·자동 결과 없음 |

현재 기능이 아닌 항목: 로그인, 저장, 동기화, 편집기, 자동 추천, 필터 실행, 장바구니, 결제.
