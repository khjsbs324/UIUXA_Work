# V2 보조자료 안내

이 폴더는 도식 Source, 화면 목록, Coverage, 추적성, 제품 후보와 QA를 보관한다. 사용자는 먼저 상위 폴더의 `08-와이어프레임.html`과 페이지별 SVG를 확인하면 된다.

- `.mmd`: SVG의 Mermaid Source
- `화면목록.json`: 3개 화면·16개 구역의 기계 판독 Registry
- `클라이언트-산출물-현황.md`: 51명 Coverage 요약
- `추적성-검증표.md`: Client 요구부터 화면까지의 연결
- `제품-작업목록.md`: 최종 선정 전 레이아웃 검토용 15개 후보
- `QA-결과.md`: 생성 후 검증 결과
