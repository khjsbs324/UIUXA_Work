# 07. DAMORI 통합 화면설계서 V1

- 화면: `PAGE-00 HOME`, `PAGE-01 PRODUCTS`, `PAGE-02 BRAND`
- Section: 16개
- 공통 GNB: `DAMORI / HOME | PRODUCTS | BRAND`
- 상태: 사용자 검토용 최종 도출 V1

## 공통 인터페이스·작동·접근성

- Page 이동과 Section Anchor 이동만 제공한다.
- Desktop의 2~3열 정보는 Tablet 2열, Mobile 1열로 의미 순서를 유지한다.
- Headline→본문→Visual 설명→행동 순서가 키보드와 스크린리더에서도 유지되어야 한다.
- 이미지 미선정 상태에는 이미지가 전달해야 할 내용을 대체 텍스트로 기록한다.
- 판매·계정·저장·추천·편집 기능을 포함하지 않는다.
