# 07. DAMORI 통합 화면설계서

- 상태: `FIRST_INTEGRATED_REVIEW_DRAFT`
- Screen: `PAGE-00 HOME`, `PAGE-01 PRODUCTS`, `PAGE-02 BRAND`
- 공통 GNB: HOME / PRODUCTS / BRAND
- 시각 단계: Content Fidelity 보강, Visual Fidelity 낮음

## 공통 작동·레이아웃

- Desktop은 넓은 여백, Text/Visual 교차, 다열 Portfolio를 사용한다.
- Tablet과 Mobile에서는 의미 순서를 유지하며 2열·1열로 축소한다.
- GNB와 Section Anchor로 화면·구간을 이동한다.
- 제품 구매, 계정, 저장, 자동 추천은 제공하지 않는다.
- 이미지가 정해지지 않은 영역은 무엇을 보여줄지 설명하는 대체 텍스트를 갖는다.
