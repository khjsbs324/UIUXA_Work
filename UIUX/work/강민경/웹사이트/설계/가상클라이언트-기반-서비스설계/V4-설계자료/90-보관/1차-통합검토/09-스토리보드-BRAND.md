# 09. Storyboard — BRAND

## Page Purpose

DAMORI가 어떤 프로젝트 브랜드이며 왜 존재하고, 기록과 Analog/Digital 제품을 어떤 관점으로 바라보는지 독립적인 Editorial Story로 전달한다.

## User Goal 및 근거

- Goal: 브랜드의 존재 이유·기록 철학·핵심 가치·제품 관점을 이해한다.
- Client: V4-C03 하람, C06 이준, C01·C07 보조
- DN/RG: DN-03·06·07·08, RG-03·06·07
- Flow: PATH A 서사 심화, PATH B/C 선택 연결
