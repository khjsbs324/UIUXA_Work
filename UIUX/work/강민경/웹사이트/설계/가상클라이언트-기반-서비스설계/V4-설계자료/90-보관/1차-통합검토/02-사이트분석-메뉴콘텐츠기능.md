# 02. 사이트 분석 — 메뉴·콘텐츠·기능

## 분석 기준

51 Source Client의 원래 요구를 7 Representative, 10 Pure DN, 8 RG로 묶고, 현재 3 Page 포트폴리오 Website에서 수용 가능한 정보 요구만 적용했다. 앱·저장·동기화·편집기 요구는 원본 근거로 보존하되 현재 기능으로 만들지 않는다.

## 현재 범위 밖 원래 요구

저장·동기화·오프라인 실행·레이어 편집·자동 추천·개인 계정은 `ORIGINAL_SERVICE_NEED` 또는 `OUT_OF_CURRENT_SCOPE_REFERENCE`이다. 이를 현재 Website 기능으로 구현하지 않는다.
