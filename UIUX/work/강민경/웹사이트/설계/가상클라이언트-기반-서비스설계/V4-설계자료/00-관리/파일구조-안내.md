# DAMORI V4 설계자료 구조 안내

- 현재 검토 Version: `V2`
- 사용자가 먼저 볼 위치: `02-도출본/V2/`
- 프로젝트 브랜드명: DAMORI / 다모리
- 현재 상태: 사용자 검토용 도출본이며 승인본이 아님

## 폴더 역할

| 폴더 | 역할 |
|---|---|
| `00-관리` | 진행 기준과 파일 구조 안내 |
| `01-과정자료` | 단계별 후보·과거 버전·비교·검수 자료 |
| `02-도출본` | 사용자가 비교하는 전체 도출 Version |
| `03-최종자료` | 사용자가 특정 Version을 승인한 뒤에만 사용하는 위치 |
| `04-참고자료` | 웹디자인 레퍼런스 등 설계 근거가 아닌 참고 자료 |
| `90-보관` | 이전 통합 검토본과 과거 기준본의 원문 보관 |

## Version 운영

`V1`은 첫 전체 도출본이며 내용과 SHA-256을 보존한다. `V2`는 V1을 바탕으로 한국어 가독성, 설명 깊이, 도식 상세도, CSS 반응형 와이어프레임을 개선한 검토본이다. 다음 Version은 사용자 검토 후 필요한 범위만 만든다.

## 최종자료 사용 조건

현재 승인 파일은 0개다. 사용자가 특정 Version을 명시적으로 승인한 뒤 승인된 도출본만 `03-최종자료`에 복사한다.
