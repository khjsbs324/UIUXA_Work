# 08회차 — 반응형·카피 밀도 검사

- Desktop: 메인 5개 상황 Card, 카테고리 Sidebar+Grid, 브랜드 Evidence 3열.
- Tablet: 상황 2열, Filter 상단 Disclosure, Evidence 2열.
- Mobile: 핵심 행동 우선 1열, Filter summary 고정, 비교 Tray는 Bottom panel 후보.
- 카피 원칙: 한 문장 한 판단, 사용자 비난·진단·정답 표현 금지.
- 상태 문구: 무엇이 일어났는지→입력 보존 여부→다음 행동 순서.
- Hero·Section 제목의 동일 의미 반복을 제거.
- 최종 시각 자산은 HOLD이나 레이아웃 계약은 독립적으로 실행 가능.
- 판정: `INTERNAL_PASS`.
