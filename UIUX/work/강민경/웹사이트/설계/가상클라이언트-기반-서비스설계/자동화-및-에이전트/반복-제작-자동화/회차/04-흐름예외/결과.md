# 04회차 — 서비스 흐름 예외·복귀 검사

| 예외 | 기존 위험 | 개선 계약 |
|---|---|---|
| 필터 결과 0 | 막힘 | 충돌 조건 표시·한 조건씩 해제 |
| 상세 자료 없음 | 허위 확정 | `공식 자료 필요`·비교 보류 |
| 비교 후보 초과 | 수치 미정 | 기존 선택 유지·추가 불가 이유 표시 |
| 탐색 중 이탈 | 상태 오해 | Local sample 범위·계속/초기화 |
| 브랜드 소개 이동 | 맥락 상실 | 호출 Page와 선택 조건 복귀 |
| 오프라인 | 동기화 오해 | 입력 유지·자동 동기화 약속 금지 |

- 정상·Empty·Error·Offline·Return 흐름 모두 존재.
- 판정: `INTERNAL_PASS`.
