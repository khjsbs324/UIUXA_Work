# BATCH-PAGE-01 독립 검토

## 직관 패스

### 강점

- 세 Page가 `시작 / 비교 / 신뢰`로 구분된다.
- PAGE-021 신설 이유가 제출 요구와 VC-09·10·14에 연결된다.
- 메인의 상품 노출을 5개로 제한해 15개 전체 목록과 역할을 분리했다.

### 문제

- PAGE-021의 범주 `시작·깊이·시간·표현·선물`이 상품 유형인지 사용자 목적 문구인지 불명확하다.
- PAGE-020의 Material은 공식 자료가 없으면 빈 감성 문장이 될 위험이 있다.
- PAGE-001 Section 6개가 모바일에서 길어질 수 있다.

## 창의 패스

### 강점

- Analog/Digital 구분보다 사용 순간을 먼저 보여주는 카테고리가 브랜드 차별화에 유리하다.
- 선물과 탐색 재개가 기존 기록 서비스 중심 구조에 새로운 상업·재방문 가치를 추가한다.

### 대안

- 상품 범주를 `오늘 시작 / 오래 쓰기 / 시간 보기 / 나답게 표현 / 함께 건네기`처럼 사용자 언어로 설정한다.
- 브랜드 소개 Material을 `확인한 것 / 확인 중인 것 / 약속하지 않는 것` 구조로 바꿔 자료 부족 자체를 투명성으로 전환한다.
- 메인 추천 패키지는 판매 순위 대신 `지금의 기록 장면` 5개로 제시한다.
