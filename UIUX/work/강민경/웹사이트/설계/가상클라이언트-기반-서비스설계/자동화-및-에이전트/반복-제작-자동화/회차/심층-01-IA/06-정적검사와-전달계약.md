## 충돌 해소

### 기존 `독립 Shop 제외`와 ER-003~007

PAGE-021은 Shop이 아니다.

- 결제·장바구니·재고·배송·회원 기능 없음
- 실물·Digital·Mixed 기록 솔루션을 같은 속성으로 탐색·비교
- 실제 획득 가능 여부는 상태 필드로만 표시
- 공식 자료나 정책이 없으면 `자료 필요`·`정책 확인 필요`

따라서 기존 `DECISION-010 독립 Shop 제외`를 유지하면서 과제의 카테고리·15개 카드 요구를 콘텐츠 구조로 충족한다.

## 서비스 흐름 단계 전달

후속 `DEEP-ITERATION-02`는 다음 네 흐름을 실제 분기표로 작성해야 한다.

1. `FLOW-CAT-01`: 메인 상황→PAGE-021→필터→상세→복귀
2. `FLOW-CAT-02`: PAGE-021→비교→공식 자료 부족→보류·조건 수정
3. `FLOW-GIFT-01`: 선물 상황→패키지 비교→정책 HOLD 확인→보류
4. `FLOW-RESUME-01`: 탐색 중단→Local sample 확인→계속·초기화

각 흐름은 Trigger, 입력, 상태, 분기, 오류, 취소, 복귀, 종료, 데이터 보존 범위를 포함해야 한다.
