# 02회차 — Client 중복·과잉 검사

## 충돌 쌍

- VC-03↔08: 입력 부담과 첫 선택 부담으로 분리 유지.
- VC-04↔09: 템플릿 목적 탐색과 상품 속성 비교로 분리 유지.
- VC-07↔14: 기록 복귀와 상품 탐색 재개로 분리 유지.
- VC-01↔15: 사용 물성과 재료 주장 검증으로 분리 유지.

## 개선

- 전략 검증형 VC-08~15에는 실제 사용자 사실 표현 금지.
- 최종 대표 Client 표에서는 `조사 기반 / 조건부 / 전략 검증` Badge 필수.
- 신규 Client 추가는 중단. 다음 반복은 기존 15명의 깊이를 높이는 데 사용.

- 판정: `INTERNAL_PASS`, 제거 0, 신규 추가 0.
