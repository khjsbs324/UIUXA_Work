# 단계별 출력 계약

## 가상 클라이언트

ID, 상태, 근거 강도, 대표 상황, 문제, 목표, 행동, 판단 기준, 요구, 제약, 충돌, 성공 조건, 근거 ID를 포함한다.

## 요구사항

REQ ID, Client ID, 유형, 내용, 중요도, 상태, 근거 수준, 충돌, 수용 조건, 다음 단계 사용 여부를 포함한다.

## 사이트맵

Page ID, 명칭, 목적, Parent, Depth, Page 상태, Client·REQ, 주요 콘텐츠·기능, Cross link를 포함한다.

## 서비스 흐름

Flow ID, Actor/Client, 시작, Trigger, 단계, 상태, 분기, 오류, 취소, 복귀, 종료, 관련 Page·REQ를 포함한다.

## 화면설계서

Screen ID, Page ID, 목표, 진입, Section, Content, UI, 행동, 상태, Validation, 반응형, 접근성, 다음 화면, 근거를 포함한다.

## 스토리보드

화면 목적, 콘텐츠 우선순위, 카피, 레이아웃, 컴포넌트, 행동, 상태·예외, 반응형, 접근성, 브랜드 표현, 관련 ID를 포함한다.

## 배치 보고

입력 범위, 생성·수정 수, KEEP·MERGE·REVISE·HOLD·EXCLUDE, 새 발견, 충돌, 미매핑, 검증 결과, 다음 배치 공백, 최종 전환 여부를 포함한다.
