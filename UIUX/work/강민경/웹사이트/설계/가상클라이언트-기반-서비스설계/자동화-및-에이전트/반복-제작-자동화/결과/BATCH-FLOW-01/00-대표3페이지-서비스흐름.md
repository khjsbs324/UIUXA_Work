## FLOW-REP-05 접근성·오류 횡단 흐름

- 모든 필터·탭·비교 담기는 키보드와 44px Target으로 동작한다.
- 색·사진·배지만으로 상태를 전달하지 않는다.
- Loading은 기존 선택을 유지한다.
- Empty는 충돌 조건과 해제 행동을 제공한다.
- Error는 입력·비교 후보를 유지하고 재시도·사본 확인을 제공한다.
- 320px Reflow에서 수평 전체 Page 스크롤을 만들지 않는다.
- 동작 감소 설정에서 자동 이동·강한 전환을 제거한다.
