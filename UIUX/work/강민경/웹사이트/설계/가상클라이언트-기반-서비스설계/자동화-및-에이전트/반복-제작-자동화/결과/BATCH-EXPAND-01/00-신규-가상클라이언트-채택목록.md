# BATCH-EXPAND-01 신규 가상 클라이언트 채택 목록

상태: `VALIDATION_CLIENTS_ADOPTED`  
주의: 아래 8명은 기존 사용자 조사에서 직접 확인된 인물이 아니다. BATCH-BASE의 설계 공백을 검증하기 위한 전략형 가상 클라이언트이며, 실제 사용자 사실과 분리한다.

## 중복 판정

- VC-08은 VC-03과 다르다. VC-03은 기록 입력 부담, VC-08은 브랜드·서비스 이해와 첫 선택 부담을 검증한다.
- VC-09는 VC-04와 다르다. VC-04는 기록 주제와 템플릿, VC-09는 실제 상품 카테고리·속성 비교를 검증한다.
- VC-10은 VC-01과 다르다. VC-01은 자기 사용 적합성, VC-10은 타인에게 주는 선물 실패 위험을 검증한다.
- VC-11은 모든 기존 Client의 공통 신뢰 원칙을 브랜드 소개 화면에서 검증하는 별도 발주 관점이다.
- VC-12는 VC-05의 동기화 기술과 달리 민감 정보의 수집·권한·삭제 통제를 검증한다.
- VC-13은 특정 기능이 아니라 전체 경험의 대체 수단과 조작 가능성을 검증한다.
- VC-14는 VC-07의 기록 복귀가 아니라 상품 탐색·비교 과업의 재개를 검증한다.
- VC-15는 VC-01의 촉감·사용 적합성과 달리 재료 정보와 브랜드 주장 검증을 중심으로 한다.

## 사용 제한

이 Client들의 요구는 자동으로 실제 기능이나 사용자 사실이 되지 않는다. `전략 검증 요구`로만 구조화하고, 사용자 조사·공식 제품 자료·정책 확인을 통해 승격한다.
