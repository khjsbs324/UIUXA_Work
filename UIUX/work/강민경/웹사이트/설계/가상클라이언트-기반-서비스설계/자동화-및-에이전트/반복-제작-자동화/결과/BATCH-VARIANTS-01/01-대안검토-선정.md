# 구조 대안 독립 검토와 선정

## 직관 패스

- MAIN-A는 첫 행동과 전체 이동이 가장 명확하다.
- CAT-A는 카테고리 이름이 감성적이므로 필터 안에 구체 속성명이 필요하다.
- BRAND-A는 근거 없는 역사·제조 이야기를 피하면서 브랜드 이유를 설명한다.
- 세 Page의 CTA가 `방식 찾기 / 후보 보기 / 방식으로 돌아가기`로 연결된다.

## 창의 패스

- 세 Page 모두 같은 카드 패턴만 쓰면 단조로울 위험이 있다.
- 메인은 장면 중심 Editorial card, 카테고리는 비교 중심 Data card, 브랜드는 Evidence story로 시각 문법을 달리해야 한다.
- 브랜드 거북이는 캐릭터 소개가 아니라 막힘·빈 상태·도움에서 동행자 역할을 보여줘야 한다.

## 통합 결정

| 결정 | 결과 |
|---|---|
| 정보 구조 | MAIN-A + CAT-A + BRAND-A |
| 공통 요소 | 동일 Header·상태 Badge·Focus·카피 말씨 |
| 페이지별 차이 | Editorial / Data / Evidence 시각 문법 |
| 마스코트 | 장식 배너 금지, 도움·상태 사례에서 제한 사용 |
| 상품 15개 | 카테고리 본문에만 전체 노출, 메인은 대표 5개 |

## 감사

- 대안 수: 9개
- 선정: 3개
- 결합 채택: MAIN-B의 원칙 문장 1개
- HOLD: BRAND-B·C의 역사·제조 Section
- 제외: MAIN-C, CAT-B·C의 상위 구조
- Critical 0, High 0, Medium 0
- 내부 판정: `INTERNAL_PASS`
- 품질 게이트 연속 통과: 2 후보이나 통합 감사 전 확정 금지
