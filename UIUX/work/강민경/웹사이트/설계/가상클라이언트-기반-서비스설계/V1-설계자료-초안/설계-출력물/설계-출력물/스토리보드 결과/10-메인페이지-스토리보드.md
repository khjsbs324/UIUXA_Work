## 1. 문서 정보

- Screen / Page ID: `SCR-001 / PAGE-001 홈`
- 화면 유형: 반응형 브랜드 웹 메인페이지 (상품 스크롤 레일 포함)
- 대표 Client: `VC-01 은재`, `VC-02 지안`, `VC-03 하람`
- 50개 Client 커버: VC-01~VC-50 전체 50인 공통 진입 및 과업 경로 수립
- 핵심 목적: 브랜드 가치 전달 및 15~50개 상품 라인업 탐색, 5대 GNB 과업 직접 이동

---

## 2. 사용자 시나리오

- **시나리오 1 (은재 VC-01)**: 아날로그 물성 노트를 찾는 은재는 메인 상단 Hero에서 180도 평면 펼침 노트 비주얼을 확인하고 `001-PRODUCTS` 레일에서 노구를 탐색한다.
- **시나리오 2 (지안 VC-02)**: 주간 일정을 통제하려는 지안은 `001-SCHEDULE` 타임라인 미리보기를 확인하고 디지털 기록(`PAGE-009`)으로 이동한다.
- **시나리오 3 (하람 VC-03)**: 기록 부담이 있는 하람은 `001-START` 카드의 "작게 1줄 시작하기" 팝업 모달을 통해 10초 만에 생각과 기분을 저장한다.

---

## 3. 화면 목표와 성공 조건

- **목적 1**: 정답 없는 자율 선택 방식 제시 (아날로그와 디지털의 위계 1대1 동등)
- **성공 조건**: 5초 이내에 `내 기록 방식 찾아보기` CTA 발견 및 `001-PRODUCTS` 상품 스크롤 레일 조작
- **예외 조건**: 외부 연동 기능은 `검증 진행 중(HOLD)` 배지를 표기하여 허위 과장 표기 방지

---

## 4. 전체 구성·와이어프레임 구조

1. `001-HEADER`: 로고, 5대 GNB 메뉴, 모바일 메뉴 버튼 (44x44px)
2. `001-01 Hero`: 6:6 아날로그/디지털 비주얼 + 2대 CTA
3. `001-PRODUCTS`: **최소 15개~50개 전수 라인업 가로 스크롤 카드 카러셀 (`scroll-snap`)**
4. `001-02 과업 5종`: 탐색/아날로그/디지털/템플릿/가이드 5개 카드
5. `001-03 Analog/Digital`: 아날로그 물성 vs 디지털 시간축 2열 동등 비교
6. `001-SCHEDULE`: 지안(VC-02) 주간 개요 → 일간 타임라인 시뮬레이션
7. `001-START`: 하람(VC-03) 10초 저부담 팝업 입력 모듈
8. `001-TEMPLATE`: 소담(VC-04) & 나린(VC-06) 원본 보호 템플릿/자산 미리보기
9. `001-04 신뢰 원칙`: 확인된 정보 / HOLD 투명 공지 밴드
10. `001-GUIDE`: 이준(VC-07) 중단 후 복귀 안내 밴드
11. `001-FOOTER`: 4열 전역 푸터 링크 그룹

## 6. 화면 상태 명세

- Normal State (`ST-001-DEF`): 모든 11대 레이아웃 정상 동작.
- Loading State (`ST-001-LOAD`): 텍스트 유지, 이미지/카러셀 영역 스켈레톤 적용.
- Error State (`ST-001-ERR`): "일시적인 오류로 미리보기를 불러오지 못했습니다." 안내 토스트.
- HOLD State (`ST-001-HOLD`): 외부 달력 연동 시 `검증 진행 중(HOLD)` 주황색 배지 표시.

---

## 7. 반응형 상세 규칙

- Desktop (`1200px+`): 12열 그리드, 6:6 Hero, 8종 가로 스크롤 카러셀, 2열 비교 카드.
- Tablet (`768px~1023px`): 8열 그리드, 1열 세로 Hero, 카러셀 스와이프 조작.
- Mobile (`360px~767px`): 4열 그리드, 전폭 버튼 변환, 44x44px 터치 타깃 보장.

---

## 8. 접근성·키보드 명세

- Key Navigation: Tab 이동 시 `#2457A7` 3px 명확 포커스 링 표시.
- Touch Target: 모든 클릭 영역 최소 44x44px 100% 준수.
- Screen Reader: `H1` 전역 1개, `aria-current="page"`, `aria-selected` 표기.
