# VC-12 해솔-개인정보·보존 통제 — 서비스 흐름도 v4

상태: REWORKED_SOURCE_ALIGNED

- 상황: 사진·감정·일정 등 민감한 내용을 입력하기 전에 무엇이 어디에 남고 삭제·내보내기가 가능한지 확인한다.
- 목표: 실제 지원 범위와 미지원·미정 범위를 이해한 뒤 기록 시작 여부를 결정한다.
- 핵심 과업: 입력 전 고지 → 권한·저장 범위 → 삭제·내보내기 영향 → 시작 또는 나가기.
- 행동 흐름: 기록 진입 → 데이터 설명 → 권한 선택 → 대체 입력 또는 진행 → 상태 도움.
- 요구: 이미지와 독립된 제품명·분류·차이, 레이아웃 안정성, 오류 후 탐색 유지.
- 성공 조건: 이미지 없이 두 후보의 차이를 설명하고 비교를 계속한다.
- 실패 조건: 파일명만 읽거나 카드·CTA가 사라진다.
- 연결 제품: PROD-038
