## 1. 클라이언트 맥락

- 상황: 모바일에서 제품 레일 첫 카드만 보고 세로 페이지의 한 카드로 오해한다.
- 목표: 가로로 더 볼 수 있음을 인지하고 현재 위치를 확인하며 다음 Section으로 빠져나온다.
- 핵심 과업: 레일 인지 → 스와이프·다음 버튼 → 카드 비교 → 전체 카테고리 이동.
- 행동 흐름 원문: Section 제목 → 다음 카드 일부 노출 → 수동 이동 → 현재 번호 → 전체 보기.
- 핵심 요구: 레일 내부에서만 가로 이동, 이전·다음 또는 번호, 명확한 전체 보기 CTA.
- 성공 조건: 다음 제품 존재와 전체 카테고리 경로를 이해한다.
- 실패·금지 조건: 자동 캐러셀, 무한 루프, 본문 가로 스크롤, 제스처 전용 조작.
- 연결 제품: PROD-021·PROD-051

## 4. 예외·상태

- 결과 없음: 조건 완화, 초기화, 직접 탐색, 보류 경로를 제공한다.
- 로딩·이미지·연결 실패: 확인된 콘텐츠를 보존하고 실패 영역만 재시도하거나 건너뛴다.
- 근거 부족·미정 정책: 확인 사실과 미확정 범위를 분리한다.
- 취소·복귀: 선택·필터·스크롤 위치를 가능한 범위에서 보존한다.
- 중단: 지금 하기·나누기·보류·삭제 중 선택하고 재개 경로를 제공한다.
- 클라이언트 금지 조건: 자동 캐러셀, 무한 루프, 본문 가로 스크롤, 제스처 전용 조작.

## 5. 연결 검증

- V4 요구사항과 제품 연결을 핵심 과업·단계별 행동에 연결한다.
- V5 사이트 구조의 진입·콘텐츠·기능·예외 경로를 반영한다.
- 제품 ID는 후보 연결로만 사용하며 가격·재고·성능을 임의 확정하지 않는다.
- 이 파일은 VC-47 개별 문서이며 다른 클라이언트와 사전 병합하지 않는다.
