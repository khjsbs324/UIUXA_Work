# VC-51 이솔-저연결성 긴 페이지 복귀 — 서비스 흐름도 v1

상태: DRAFT_CONTINUOUS_RUN
입력: V4 제품 연결 · V5 사이트 구조맵 보강 · final-design 사이트 구조맵

## 1. 클라이언트 맥락

- 상황: 모바일 저연결성에서 긴 메인과 카테고리를 이동하다 일부 콘텐츠 로딩이 실패한다.
- 목표: 이미 확인한 브랜드·제품 정보와 현재 위치를 유지하고 실패 Section만 건너뛴다.
- 핵심 과업: 긴 페이지 탐색 → 지연·실패 인지 → 기존 내용 유지 → 재시도·건너뛰기 → 복귀.
- 행동 흐름 원문: 메인 → 제품 레일 실패 → 텍스트 대안 → 카테고리 → 뒤로 → 원래 Section.
- 핵심 요구: Section 단위 Error, 확인한 내용 보존, 이미지 비의존 탐색, 복귀 위치 유지.
- 성공 조건: 실패한 부분을 제외하고 브랜드와 제품 탐색을 계속한다.
- 실패·금지 조건: 전체 페이지를 빈 오류 화면으로 대체하거나 자동 새로고침한다.
- 연결 제품: PROD-020·PROD-050·PROD-086·PROD-088

## 3. 단계별 상세

| 단계 | 사용자 행동 | 화면 역할 | 시스템 응답·분기 |
|---|---|---|---|
| 1 | 현재 목적과 상황 확인 | 메인/관련 진입 | 클라이언트 관련 진입점과 현재 위치 표시 |
| 2 | 긴 페이지 탐색 → 지연·실패 인지 → 기존 내용 유지 → 재시도·건너뛰기 → 복귀. | 핵심 과업 화면 | 필요한 정보만 우선 제공하고 건너뛰기 허용 |
| 3 | 후보·콘텐츠·기능 탐색 | 카테고리/상세/비교 | Section 단위 Error, 확인한 내용 보존, 이미지 비의존 탐색, 복귀 위치 유지.를 기준으로 차이와 근거 표시 |
| 4 | 적합성 판단 | 비교·추천 결과 | 불확실·미지원 범위를 명시하고 수정 허용 |
| 5 | 선택 또는 보류 | 선택 요약 | 선택 상태와 원래 위치 보존 |
| 6 | 완료·중단 후 처리 | 시작/저장/복귀 | 실패한 부분을 제외하고 브랜드와 제품 탐색을 계속한다.; 중단은 실패로 판정하지 않음 |

## 4. 예외·상태

- 결과 없음: 조건 완화, 초기화, 직접 탐색, 보류 경로를 제공한다.
- 로딩·이미지·연결 실패: 확인된 콘텐츠를 보존하고 실패 영역만 재시도하거나 건너뛴다.
- 근거 부족·미정 정책: 확인 사실과 미확정 범위를 분리한다.
- 취소·복귀: 선택·필터·스크롤 위치를 가능한 범위에서 보존한다.
- 중단: 지금 하기·나누기·보류·삭제 중 선택하고 재개 경로를 제공한다.
- 클라이언트 금지 조건: 전체 페이지를 빈 오류 화면으로 대체하거나 자동 새로고침한다.

## 5. 연결 검증

- V4 요구사항과 제품 연결을 핵심 과업·단계별 행동에 연결한다.
- V5 사이트 구조의 진입·콘텐츠·기능·예외 경로를 반영한다.
- 제품 ID는 후보 연결로만 사용하며 가격·재고·성능을 임의 확정하지 않는다.
- 이 파일은 VC-51 개별 문서이며 다른 클라이언트와 사전 병합하지 않는다.
