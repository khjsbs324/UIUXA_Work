# VC-11 가람-브랜드 신뢰 — 서비스 흐름도 v5

상태: REWORKED_SOURCE_ALIGNED

## 1. 원문 대조

- 상황: 차분하고 감성적인 브랜드가 많아 DAMORI가 해결하는 문제와 실제 적용 원칙을 확인하려 한다.
- 목표: 브랜드 약속을 제품·서비스·화면의 구체적 결정과 한계에 연결한다.
- 핵심 과업·행동 흐름: 브랜드 문제의식 → 원칙 → 제품·화면 적용 사례 → 근거·한계 → 관련 탐색. / 메인 메시지 → 브랜드 소개 → 원칙 카드 → 실제 적용 위치 → 카테고리 복귀.
- 요구: 문제→원칙→제품·서비스 반영, 확인된 근거와 한계, 추상 문구의 구체화.
- 성공 조건: 브랜드 원칙 하나가 화면·제품 판단에 어떻게 쓰였는지 설명한다.
- 실패 조건: 성과·인증·연혁·브랜드 의미를 근거 없이 만든다.
- 연결 제품: PROD-028·PROD-058·PROD-097
