# VC-002 기반 서비스-흐름도

상태: `UPDATED_AFTER_VC_DEVELOPMENT`  
대표 Client: `VC-002 미래 일정·시간 흐름 통제 발주형`  
기준 사이트맵: `06-사이트맵.md`

## 1. 서비스 흐름 목표

사용자가 사이트의 목적과 기록 방식을 이해한 뒤 디지털 기록을 선택하고, 현재 시간대와 가장 가까운 이후 일정을 개요에서 확인하며, 필요한 일정만 세부로 열고, 중요한 일정에 한해서 상기 사용·저장·수정·끄기·취소를 결정하는 흐름을 정의한다.

## 2. 핵심 시나리오

| 항목 | 내용 |
|---|---|
| 시작 상황 | 일정 관리 방식이 자신에게 맞는지 확인하려고 사이트에 진입 |
| 핵심 사용자 목표 | 시간 흐름과 향후 일정을 빠르게 확인 |
| 핵심 성공 조건 | 가장 가까운 일정 식별 → 세부 확인 → 중요 여부 판단 후 필요한 경우에만 상기 조건 저장 |
| 조건부 요구 | 중요 일정 상기의 시점·빈도·채널·끄기 제어 |
| 제외 범위 | 외부 일정 연동, 로그인, 계정, 검색, 커뮤니티 |
| 주요 매체 | 웹·모바일 |

   └─ 아니요

       ↓

       ├─ 아니요 → 아날로그 안내 또는 탐색 종료
       └─ 예 → PAGE-004 디지털 기록

PAGE-004 디지털 기록
   ↓
PAGE-005 일정 관리
   ↓
PAGE-006 시간 흐름

       ↓
      PAGE-007 중요 일정 상기 [CONDITIONAL_PAGE]

| Step | 사용자 행동 | 시스템 응답 | Page/State | 다음 조건 |
|---|---|---|---|---|
| SF-01 | 사이트 진입 | 브랜드 목적과 기록 방식 선택지 제공 | PAGE-001 | 디지털 직접 진입 또는 방식 비교 |
| SF-02 | 기록 방식 비교 선택 | Digital/Analog 차이와 적합 조건 제공 | PAGE-002 | 추가 진단 여부 |
| SF-03 | 판단 질문 확인 | 추천 근거와 부적합 조건 제공 | PAGE-003 | Digital 적합 여부 |
| SF-04 | 디지털 기록 선택 | 디지털 기록의 핵심 경험과 기능 우선순위 설명 | PAGE-004 | 일정 관리 진입 |
| SF-05 | 일정 관리 선택 | 오늘/이후 구분과 가장 가까운 일정, 중요 일정 진입점 제공 | PAGE-005 | 시간 흐름 확인 |
| SF-06 | 시간대 또는 일정 선택 | 현재 시간대·가장 가까운 일정·이후 일정 개요와 선택 세부 제공 | PAGE-006 | 일정 중요 여부 |
| SF-07 | 중요 일정의 상기 확인 | 상기 필요 여부와 미사용·취소 선택 제공 | PAGE-007 기본 | 사용 여부 결정 |
| SF-08 | 상기 조건 입력 | 시점·빈도·채널·끄기 조건 검증, 오류 원인과 수정 위치 제공 | PAGE-007 Validation Error | 유효성 판정 |
| SF-09 | 조건 저장 | 적용 조건 요약과 수정·끄기·확인 제공 | PAGE-007 Saved | PAGE-005 복귀 또는 PAGE-007 수정 |

## 5. 보조 흐름

### 선택 지원

`PAGE-001 → PAGE-002 → PAGE-003 → PAGE-004`

- 사용자가 바로 디지털 기록을 선택하기 어렵다면 거치는 흐름이다.
- 추천은 강제하지 않고 근거와 부적합 조건을 함께 제공한다.

### 도움 및 제약 확인

`PAGE-004·005·007 → PAGE-011 도움말·제공 범위 → 이전 Page 복귀`

- 기능 제한, 검증 상태 또는 조건부 제공 여부를 확인하는 보조 흐름이다.
- 외부 일정 연동은 HOLD 상태임을 보여줄 수 있으나 활성 기능으로 연결하지 않는다.

### 상기 미사용

`PAGE-007 → 상기 사용 안 함 → PAGE-006`

- 상기 기능을 강제하지 않는다.
- 사용자가 시간 흐름 확인만으로 목적을 달성할 수 있어야 한다.

### 저장 후 수정·끄기

`PAGE-005 저장된 상기 확인 → PAGE-007 → 조건 수정 또는 상기 끄기 → 결과 확인 → PAGE-005`

- 저장 결과에는 적용 일정, 시점, 빈도, 채널과 끄기 가능 여부를 요약한다.
- 수정은 기존 값을 유지한 상태에서 시작하며 취소하면 저장된 조건을 변경하지 않는다.
- 끄기는 상기만 중지하며 원본 일정 삭제로 표현하지 않는다.

### 일정 없음·로딩·오류

| 상태 | 표시 | 행동·복귀 |
|---|---|---|
| Loading | 시간 구조와 오늘/이후 레이블을 유지한 자리 표시 | 핵심 내비게이션 사용 가능 |
| Empty | 일정이 없는 범위가 오늘인지 선택 기간인지 명시 | 다른 기간 보기 후보 또는 PAGE-011 제공 범위 확인; 일정 생성 기능은 미확정 |
| Detail Error | 선택한 일정 세부를 불러오지 못한 이유와 재시도 제공 | PAGE-006 개요 유지 또는 PAGE-005 복귀 |
| Conditional | 상기 기능의 제공 조건 확인 필요 표시 | PAGE-011 확인 또는 상기 없이 PAGE-006 복귀 |

## 6. 예외·오류 흐름

| 예외 | 처리 | 복귀 위치 |
|---|---|---|
| 상기 시점이 일정 이후임 | 유효 범위 안내 후 시점 재입력 | PAGE-007 조건 입력 상태 |
| 빈도 또는 채널 미선택 | 필수 조건 표시 후 저장 차단 | PAGE-007 조건 입력 상태 |
| 사용자가 상기를 취소 | 입력값 적용 없이 시간 흐름으로 복귀 | PAGE-006 |
| 저장된 상기 수정을 취소 | 기존 저장값을 유지하고 결과 요약으로 복귀 | PAGE-007 저장 확인 상태 |
| 상기 끄기 | 원본 일정은 유지하고 상기 상태만 해제 | PAGE-005 |
| 일정이 없음 | 빈 범위와 확인 가능한 다음 경로 안내 | PAGE-005·006 |
| 제공 범위가 불명확 | 제한·검증 상태 확인 링크 제공 | PAGE-011 |
| 외부 연동 시도 | HOLD 상태 안내; 기능 실행 경로 미제공 | PAGE-011 |

## 8. 검토 결과

- 사이트맵 Page ID 밖의 신규 Page 생성: 0
- 핵심 정상 흐름: 1개
- 조건부 상기 흐름: 1개
- 선택 지원 흐름: 1개
- 오류·취소·HOLD 처리: 포함
- 외부 연동 자동 채택: 없음
- 저장·수정·끄기·취소 경로: 포함
- Loading·Empty·Detail Error 상태: 포함
- 접근성 전달: 시간 순서는 텍스트 순서를 유지하고 중요도·상태는 색상 외 레이블로 표시
- 화면 배치·컴포넌트: 메인페이지 스토리보드와 HTML 시각화에서 후속 반영
