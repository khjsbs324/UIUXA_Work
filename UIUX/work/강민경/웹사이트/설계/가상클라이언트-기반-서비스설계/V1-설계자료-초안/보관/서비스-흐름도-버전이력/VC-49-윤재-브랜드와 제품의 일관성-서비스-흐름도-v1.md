# VC-49 윤재-브랜드와 제품의 일관성 — 서비스 흐름도 v1

상태: DRAFT_CONTINUOUS_RUN
입력: V4 제품 연결 · V5 사이트 구조맵 보강 · final-design 사이트 구조맵

## 1. 클라이언트 맥락

- 상황: 브랜드가 자율성·다시 시작·장기 보관을 말하지만 제품 카드가 감성 이름과 장식만 보여주는지 확인한다.
- 목표: 각 핵심 브랜드 원칙이 제품 구조·정보·선택 방식에 반영됐는지 판단한다.
- 핵심 과업: 브랜드 원칙 → 대표 제품 → 제품 정보·상태 → 사용 장면 → 관련 원칙 복귀.
- 행동 흐름 원문: 원칙 카드 → 제품 사례 → Client 요구 → 한계 → 다른 제품 비교.
- 핵심 요구: 제품마다 브랜드 원칙 연결과 해결 요구를 명시하고 감성 이름만으로 차이를 만들지 않는다.
- 성공 조건: 제품 하나가 브랜드 원칙을 어떻게 실천하는지 설명한다.
- 실패·금지 조건: 추상 슬로건과 제품 이미지만 나란히 배치한다.
- 연결 제품: PROD-028·PROD-058·PROD-097

## 3. 단계별 상세

| 단계 | 사용자 행동 | 화면 역할 | 시스템 응답·분기 |
|---|---|---|---|
| 1 | 현재 목적과 상황 확인 | 메인/관련 진입 | 클라이언트 관련 진입점과 현재 위치 표시 |
| 2 | 브랜드 원칙 → 대표 제품 → 제품 정보·상태 → 사용 장면 → 관련 원칙 복귀. | 핵심 과업 화면 | 필요한 정보만 우선 제공하고 건너뛰기 허용 |
| 3 | 후보·콘텐츠·기능 탐색 | 카테고리/상세/비교 | 제품마다 브랜드 원칙 연결과 해결 요구를 명시하고 감성 이름만으로 차이를 만들지 않는다.를 기준으로 차이와 근거 표시 |
| 4 | 적합성 판단 | 비교·추천 결과 | 불확실·미지원 범위를 명시하고 수정 허용 |
| 5 | 선택 또는 보류 | 선택 요약 | 선택 상태와 원래 위치 보존 |
| 6 | 완료·중단 후 처리 | 시작/저장/복귀 | 제품 하나가 브랜드 원칙을 어떻게 실천하는지 설명한다.; 중단은 실패로 판정하지 않음 |

## 4. 예외·상태

- 결과 없음: 조건 완화, 초기화, 직접 탐색, 보류 경로를 제공한다.
- 로딩·이미지·연결 실패: 확인된 콘텐츠를 보존하고 실패 영역만 재시도하거나 건너뛴다.
- 근거 부족·미정 정책: 확인 사실과 미확정 범위를 분리한다.
- 취소·복귀: 선택·필터·스크롤 위치를 가능한 범위에서 보존한다.
- 중단: 지금 하기·나누기·보류·삭제 중 선택하고 재개 경로를 제공한다.
- 클라이언트 금지 조건: 추상 슬로건과 제품 이미지만 나란히 배치한다.

## 5. 연결 검증

- V4 요구사항과 제품 연결을 핵심 과업·단계별 행동에 연결한다.
- V5 사이트 구조의 진입·콘텐츠·기능·예외 경로를 반영한다.
- 제품 ID는 후보 연결로만 사용하며 가격·재고·성능을 임의 확정하지 않는다.
- 이 파일은 VC-49 개별 문서이며 다른 클라이언트와 사전 병합하지 않는다.
