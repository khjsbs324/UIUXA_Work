# VC-51 이솔-저연결성 긴 페이지 복귀 — 서비스 흐름도 v4

상태: REWORKED_SOURCE_ALIGNED

- 상황: 모바일 저연결성에서 긴 메인과 카테고리를 이동하다 일부 콘텐츠 로딩이 실패한다.
- 목표: 이미 확인한 브랜드·제품 정보와 현재 위치를 유지하고 실패 Section만 건너뛴다.
- 핵심 과업: 긴 페이지 탐색 → 지연·실패 인지 → 기존 내용 유지 → 재시도·건너뛰기 → 복귀.
- 행동 흐름: 메인 → 제품 레일 실패 → 텍스트 대안 → 카테고리 → 뒤로 → 원래 Section.
- 요구: Section 단위 Error, 확인한 내용 보존, 이미지 비의존 탐색, 복귀 위치 유지.
- 성공 조건: 실패한 부분을 제외하고 브랜드와 제품 탐색을 계속한다.
- 실패 조건: 전체 페이지를 빈 오류 화면으로 대체하거나 자동 새로고침한다.
- 연결 제품: PROD-020·PROD-050·PROD-086·PROD-088
