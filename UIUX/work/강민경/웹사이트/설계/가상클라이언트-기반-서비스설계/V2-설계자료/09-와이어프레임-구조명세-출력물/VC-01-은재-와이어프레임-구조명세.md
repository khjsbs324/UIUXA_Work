# VC-01 은재 · 클라이언트별 와이어프레임 구조명세

상태: `DETAILED_WIREFRAME_STRUCTURE_DRAFT`
입력: VC-01 클라이언트·REQ-001·사이트맵·서비스 흐름도·화면설계서

## 1. 제작 계약

| 항목 | 내용 |
|---|---|
| 핵심 과업 | 기록량·줄 간격·속지 조합·물성을 비교해 선택 또는 보류 |
| 필수 페이지 | 메인 `PAGE-001`, 카테고리 `PAGE-021`, 브랜드 소개 `PAGE-020` |
| 핵심 Page 흐름 | `PAGE-001 → PAGE-002 → PAGE-003 → PAGE-004 → PAGE-005/006 → PAGE-007/008` |
| 직접 제품 | `PROD-001·002·003·031·032·033·061·062·063·064·095` |
| 확장 검토 후보 | `PROD-011·012·025·026` — 직접 확정 제품 아님 |
| 금지 | 촉감·내구성 확정, 가격·재고·배송·결제, 감성 이미지 단독 판단 |

| 항목 | Desktop 1200 | Tablet 768 | Mobile 360 |
|---|---|---|---|

## 6. 공통 인터랙션·접근성

- 모든 상태는 색상과 상태명·설명을 병기한다.
- 200% 확대·320px에서 수평 본문 스크롤이 없어야 한다.
- 실측 비교표는 행/열 제목을 제공하고 모바일에서는 카드형으로 변환한다.
- 레일은 드래그만 제공하지 않고 이전/다음 버튼과 키보드 이동을 제공한다.
- 저장·보류·오류는 `aria-live`, 오류는 Error summary→해당 필드 Focus 순서로 처리한다.

## 7. 스토리보드 보완 입력

이 문서의 영역 ID·카피·상태·배치를 `08-스토리보드-출력물-02/VC-01-은재-*` 3개 문서의 상세 표와 HTML에 반영한다. 제품 후보 15개는 대표 후보와 확장 검토 후보를 구분해 표시한다.
