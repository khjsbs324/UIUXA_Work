# VC-44 로운 · 와이어프레임 구조명세

`REQ-044` · 이미지 실패 제품 판단 · 이미지 없이 제품명·분류·차이로 비교 유지.

| 페이지 | 구조 | 필드/행동 | 상태 |
|---|---|---|---|
| 메인 | 텍스트 우선 후보→이미지 보조→대체 안내 | 제품명·목적·차이 | 이미지 오류 격리 |
| 카테고리 | 결과 카드→속성 표→비교 | 이미지 없는 카드도 동일 높이 | Error·Offline |
| 브랜드 | 정보 우선→장식 보조→실패 복구 | 실패를 숨기지 않음 | Retry/HOLD |

Desktop 카드 고정 영역에 이미지와 텍스트를 분리하고, Mobile은 제품명→분류→차이→이미지 순이다. 이미지 실패 시 파일명만 보여주지 않고 설명·CTA·비교 기능을 유지한다.
