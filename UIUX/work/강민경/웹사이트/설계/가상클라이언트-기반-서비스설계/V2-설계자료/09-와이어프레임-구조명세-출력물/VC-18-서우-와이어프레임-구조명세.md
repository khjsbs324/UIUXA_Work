# VC-18 서우 · 와이어프레임 구조명세

`REQ-018` · 디지털 내보내기 판단 · 클라우드/내보내기/복원 세 기능 분리.

| 페이지 | 구조 | 필드/행동 | 상태 |
|---|---|---|---|
| 메인 | 세 기능 구분→형식/범위→미지원 대안 | 파일 형식·범위·복원 가능성 | 미지원·HOLD |
| 카테고리 | 기능별 카드→조건 비교→보류 | Export/Backup/Restore 구분 | 결과 없음·오류 |

Desktop은 3기능 비교 3열, Mobile은 기능→범위→수동 단계 순이다. 시작 CTA는 형식·범위 확인 후에만 활성화하고 실제 클라우드 저장을 확정하지 않는다.
