# VC-38 라온 · 와이어프레임 구조명세

`REQ-038` · 가칭 브랜드 인지 · 철학과 명칭 확정 상태 분리.

| 페이지 | 구조 | 콘텐츠/행동 | 상태 |
|---|---|---|---|
| 메인 | `[DAMORI(가칭)]` 표기→브랜드 방향→탐색 CTA | 가칭 고지·철학 | 로고/상표 HOLD |
| 카테고리 | 제품/콘텐츠에 가칭 배지→근거 | 명칭 확정과 무관한 구조 | 이름 미정 |
| 브랜드 | 철학·명칭 상태·로고 상태·슬로건 상태 | 각 상태별 설명 | 확정형 문구 금지 |

Desktop은 브랜드 상태 4col+철학 8col, Mobile은 가칭 고지→철학→상태→탐색이다. DAMORI 의미·상표·슬로건을 사실처럼 서술하지 않으며 모든 HTML/MD에 `(가칭)`을 유지한다.
