# VC-37 태윤 · 와이어프레임 구조명세

`REQ-037` · 콘텐츠/제품 탐색 구분 · 방법 정보와 후보 제품을 분리.

| 페이지 | 구조 | 콘텐츠/행동 | 상태 |
|---|---|---|---|
| 메인 | 방법 가이드→제품 탐색 진입→역할 배지 | `어떻게 기록할까` vs `무엇을 쓸까` | 광고 오인 차단 |
| 카테고리 | 콘텐츠 탭/제품 탭→공통 기준→상세 | 가이드·후보·CTA 분리 | 결과 없음·HOLD |
| 브랜드 | 정보 목적→제품 목적→연결 원칙 | 광고가 아닌 탐색 경계 | 강제 CTA 금지 |

Desktop은 콘텐츠 6col·제품 6col, Mobile은 목적 라벨→내용→다음 행동 순이다. 가이드 카드에는 구매 버튼을 두지 않고 제품 후보로 이동하는 별도 링크를 제공한다.
