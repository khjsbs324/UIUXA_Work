# VC-39 은호 · 와이어프레임 구조명세

`REQ-039` · 포트폴리오 과정 검증 · 상위 근거에서 하위 화면까지 한 결정 재현.

| 페이지 | 구조 | 필드/행동 | 상태 |
|---|---|---|---|
| 메인 | 브랜드 결정→과정 미리보기→대표 결과 | Source·Finding·Client·Page 연결 | HOLD 숨김 금지 |
| 카테고리 | 결정별 포트폴리오→근거→결과 | 단계·반려·수정 이력 | 누락·보류 |
| 브랜드 | 관찰→요구→제품→화면→검증 Timeline | 노드 클릭→원문 ID | 문서 수 성과 금지 |

Desktop은 Timeline 4col+결과 8col, Mobile은 노드→근거→결과 순이다. 각 결과 카드에 근거 ID와 결정 상태를 표시하고, 반려/HOLD 노드도 숨기지 않는다.
