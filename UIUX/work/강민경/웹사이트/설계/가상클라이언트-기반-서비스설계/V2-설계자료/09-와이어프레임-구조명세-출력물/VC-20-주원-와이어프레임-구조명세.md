# VC-20 주원 · 와이어프레임 구조명세

`REQ-020` · 기록 방식 전환 · 매체별 잔여 정보와 사용자의 수동 단계를 명시.

| 페이지 | 구조 | 필드/행동 | 상태 |
|---|---|---|---|
| 메인 | Analog/Digital 역할→전환 비용→수동 단계 | 무엇이 종이에 남고 무엇을 화면에서 확인하는지 | 자동 동기화 HOLD |
| 카테고리 | 매체 비교→전환 체크리스트→보류 | 원본 위치·수동 입력·미지원 | 단계 누락·오류 |
| 브랜드 | 균형 원칙→수동 연결→한계 | 완벽한 연동 금지 | 미지원 표시 |

Desktop은 매체 2열+단계 Timeline, Mobile은 원본→사용자 행동→결과 순이다. 전환 완료는 모든 수동 단계 확인 후에만 표시하고, 자동 검색·동기화 문구를 사용하지 않는다.
