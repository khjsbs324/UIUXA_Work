# VC-02 지안 · 클라이언트별 와이어프레임 구조명세

상태: `DETAILED_WIREFRAME_STRUCTURE_DRAFT`
입력: VC-02 클라이언트·REQ-002·사이트맵·서비스 흐름도·화면설계서

## 1. 화면 계약

| 항목 | 내용 |
|---|---|
| 핵심 과업 | 미래 일정 개요에서 빈 날을 찾고 시간 충돌·이동 여유를 확인한 뒤 필요한 일정만 알림 설정 |
| 페이지 | 메인 `PAGE-001`, 카테고리 `PAGE-003·009·011`, 브랜드 `PAGE-019·020` |
| 흐름 | `PAGE-003 → PAGE-009 → PAGE-011 → PAGE-019` |
| 제품 | `PROD-002·004·005·006·034·035·036·065·066·067·068` |
| 금지 | 외부 달력 연동 확정, 전 일정 알림 강제, 빈 날을 오류 처리 |

## 2. 공통 반응형 프레임

| 규격 | Desktop 1200 | Tablet 768 | Mobile 360 |
|---|---|---|---|
| Header | 72px·GNB·현재 날짜 | GNB 축소 | Menu·날짜 고정 |
| Calendar | 7열·월간 개요 | 4+3열 | 2열 또는 세로 날짜 목록 |
| Time axis | 8col 시간축 + 4col 판단 패널 | 위아래 | 내부 가로 시간축 |
| CTA | 결정/알림/보류 inline | 2열 | 전폭 Primary→Secondary |
| Status | 상단 고정 상태 요약 | 본문 상단 | 날짜 아래 즉시 표시 |

## 3. PAGE-001 메인 구조

`002-HEADER → 002-HERO → 002-CALENDAR-PREVIEW → 002-TIME-AXIS → 002-REMINDER → 002-PRODUCT → 002-ACTION`

| ID | 목적 | 콘텐츠·카피 | UI/배치 | 상태·행동 | 다음 |
|---|---|---|---|---|---|
| `002-HERO` | 일정 판단 가치 전달 | `비어 있는 날도 일정의 일부입니다` | 월간 개요 비주얼·CTA | 예시 데이터 고지 | `PAGE-003` |
| `002-CALENDAR-PREVIEW` | 빈 날/일정 날 구분 | 날짜·일정 수·빈 날 텍스트 | 7열 Calendar + 선택 날짜 | 날짜 선택 유지·Empty | `PAGE-003` |
| `002-TIME-AXIS` | 충돌 예고 | 시간대·이동 여유 | 시간축 Preview + 충돌 배지 | 충돌·이동 부족 | `PAGE-009·011` |
| `002-REMINDER` | 선택적 알림 원칙 | `모든 일정을 알릴 필요는 없습니다` | 알림 on/off 샘플 | 미설정·HOLD | `PAGE-019` |
| `002-PRODUCT` | 상황별 제품 탐색 | 월간·시간축·알림·변경 제품 | 사용 상황 레일 | 가격/연동 미표시 | `PAGE-021` |
| `002-ACTION` | 과업 진입 | `빈 날짜 찾기`, `충돌 확인`, `알림 없이 보기` | 3 CTA | 날짜·상태 보존 | `003·009·019` |

## 4. PAGE-003·009·011 카테고리/과업 구조

| 영역 | 필드 | 배치 | 행동 | 예외 |
|---|---|---|---|---|
| `003-OVERVIEW` | 월·후보 날짜·일정 밀도 | Calendar 중심 | 날짜 선택·조건 수정 | 결과 없음 |
| `009-DAY` | 선택 날짜·약속·빈 시간 | 날짜 Header + 카드 | 상세 열기·원래 날짜 복귀 | 선택 날짜 유실 방지 |
| `011-TIMELINE` | 시작/종료·장소·이동 여유 | 시간축 + 충돌선 | 충돌 상세·약속 보류 | 겹침·이동 부족 |
| `019-ALERT` | 일정 ID·알림 시점·설정 상태 | 선택 카드 | 설정·수정·해제 | 전 일정 강제 금지 |

상태 전이: `Overview → DateSelected → DayDetail → ConflictReview → Decide → OptionalReminder → Return`. 날짜와 원래 Section은 모든 전이에서 보존한다.

## 5. PAGE-020 브랜드 소개 구조

`020-HERO → 020-FLOW-PRINCIPLE → 020-CHOICE → 020-BOUNDARY → 020-NEXT`.

| ID | 콘텐츠 | UI | 상태/검증 |
|---|---|---|---|
| `020-HERO` | `필요한 순간에만 선택하게 합니다` | 선언문·일정 앵커 | H1·텍스트 완결 |
| `020-FLOW-PRINCIPLE` | 개요↔세부·빈 시간 존중 | 2축 흐름도 | 단계 순서 유지 |
| `020-CHOICE` | 알림 설정·수정·해제 | 상태 카드 3종 | 선택권 표시 |
| `020-BOUNDARY` | 외부 달력·자동 알림 미지원 | Fact/HOLD 표 | 활성 연결 CTA 0 |
| `020-NEXT` | 내 일정 흐름 확인 | PAGE-003·009·019 링크 | 날짜/스크롤 복귀 |

## 6. 검증 계약

- 상태는 색상·아이콘·텍스트를 함께 사용하고, 빈 날과 오류를 혼동하지 않는다.
- Mobile 시간축은 가로 이동하되 페이지 세로 스크롤을 가로채지 않는다.
- 테스트: 빈 날짜 선택, 충돌 확인, 날짜 왕복, 알림 해제, 외부 연동 HOLD, 저장 실패·재개, 키보드·200% 확대.
