# VC-27 예린 · 와이어프레임 구조명세

`REQ-027` · 브랜드 주장 검증 · 원칙 하나의 실제 화면/제품 적용과 제한을 설명.

| 페이지 | 구조 | 콘텐츠/행동 | 상태 |
|---|---|---|---|
| 메인 | 주장→적용 사례 1개→근거→한계 | 원칙·제품·화면 연결 | 인증/성과 HOLD |
| 카테고리 | 원칙별 제품→결정 근거→미정 | 적용/비적용 이유 | 근거 없음·보류 |
| 브랜드 | 문제→원칙→실제 결정→제한→출처 | 주장을 근거 ID와 연결 | 연혁·효과 생성 금지 |

Desktop은 원칙 5col+사례 7col, Mobile은 원칙→사례→한계다. 최소 한 사례의 결정 변경과 근거를 보여주지 못하면 선택 CTA 대신 보류를 제공한다.
