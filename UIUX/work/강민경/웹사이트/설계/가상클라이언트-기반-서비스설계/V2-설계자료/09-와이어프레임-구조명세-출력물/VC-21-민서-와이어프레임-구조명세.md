# VC-21 민서 · 와이어프레임 구조명세

`REQ-021` · 예산 미정 탐색 · 가격 확정 전 구성과 보류 이유를 판단.

| 페이지 | 구조 | 필드/행동 | 상태 |
|---|---|---|---|
| 메인 | 사용 상황→구성 중심 후보→가격 미정 고지 | 분량·구성·사용 장면 | 가격 HOLD |
| 카테고리 | 구성 필터→후보 비교→가격 없는 보류 | 포함 항목·추가 준비물·확인 필요 | Empty·HOLD |
| 브랜드 | 가격보다 선택 근거→미정 정책 | 가격을 만들지 않는 원칙 | 구매 CTA 0 |

Desktop은 후보 8col+구성 요약 4col, Mobile은 구성→미정 범위→보류 순이다. 할인·순위·가성비 문구를 사용하지 않고 `가격 정보 미정`을 상태로 유지한다.
