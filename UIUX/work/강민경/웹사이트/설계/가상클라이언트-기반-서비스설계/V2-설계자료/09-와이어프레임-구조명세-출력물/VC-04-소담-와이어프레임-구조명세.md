# VC-04 소담 · 클라이언트별 와이어프레임 구조명세

상태: `DETAILED_WIREFRAME_STRUCTURE_DRAFT` · `REQ-004` · `PAGE-013·014·015·016·021`

## 1. 구조 계약

일과·음악·책 주제를 먼저 선택하고, 기능 템플릿(필드·순서)과 표현 자산(보이는 방식)을 분리해 미리 본 뒤 비교·적용 초안·보류를 선택한다. 제품은 `PROD-010·011·012·040·041·042·073·074·075·076`이다.

## 2. 메인 `PAGE-001`

`004-HEADER → 004-HERO → 004-TOPIC-ATLAS → 004-ROLE-SPLIT → 004-PREVIEW → 004-DECISION`.

| ID | 콘텐츠 | 구조 | 상태·행동 | 이동 |
|---|---|---|---|---|
| `004-HERO` | `주제에 맞는 구조부터 찾아보세요` | 주제 필드 모자이크 | 이미지 실패→텍스트 | `013` |
| `004-TOPIC-ATLAS` | 독서·음악·일과·전환 | 좌측 Index·중앙 Sample·우측 Memo | 주제 선택·결과 없음 | `013` |
| `004-ROLE-SPLIT` | 기능 템플릿 vs 표현 자산 | 동등 2열 패널 | 혼합 후보 HOLD | `013·015` |
| `004-PREVIEW` | 필드·페이지·입력량 | 샘플 시트·근거 Accordion | 자료 없음·오류 | `014` |
| `004-DECISION` | 비교·보류·브랜드 기준 | 선택 편집지 | 적용 전 취소·복귀 | `014·020` |

## 3. 카테고리 `PAGE-013·014`

| ID | 필드 | 컴포넌트 | 검증 | 반응형 |
|---|---|---|---|---|
| `013-INDEX` | 주제·후보 수 | 고정 인덱스 | 탭/키보드 | Mobile 가로 |
| `013-SAMPLE` | 필드명·예시·페이지 | 중앙 시트·넘김 | 이미지 실패 대체 | 세로 시트 |
| `013-PINS` | 선택 필드·이유 | 핀보드 | 0개 Empty·6개 제한 후보 | 1열 |
| `014-COMPARE` | 필드·자유도·표현 분리 | 비교 패널 | 부적합 이유 | 카드 전환 |
| `014-DRAFT` | 적용 변경점 | Before/After + 확인 Modal | 취소·저장 실패 | Modal Fullscreen |

## 4. 브랜드 `PAGE-020`

`020-HERO(한 틀 강요 금지) → 020-WHY(주제 목적) → 020-ROLE(구조/표현) → 020-PROCESS → 020-FACT-HOLD → 020-NEXT`.

## 5. 공통 규격

1200은 Index 2col·Sample 7col·Memo 3col, 768은 Memo 하단, 360은 Index→Sample→Pins→Memo 순이다. 상태는 색상 외 명칭·설명을 사용하고, 예시 데이터·미확정 근거·적용 완료를 구분한다.
