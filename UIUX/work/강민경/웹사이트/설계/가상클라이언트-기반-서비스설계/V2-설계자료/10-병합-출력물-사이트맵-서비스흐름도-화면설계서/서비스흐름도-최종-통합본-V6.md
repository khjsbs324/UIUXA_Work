## 1. 다모리(DAMORI) 5대 핵심 사용자 여정 (User Flow A ~ E)

### 1) User Flow A: 아날로그 장문 사색 여정 (VC-01 은재, VC-15 새봄, VC-17 채운)
- **트리거 (Trigger)**: 매일 밤 번역 작업 종료 후 컴퓨터 모니터의 피로감을 피해 1시간 이상 만년필 수기 작성 욕구
- **입력 (Input)**: 120gsm 평량, 180도 Smyth Sewn 실제본, 잉크 번짐률 0% 필터 선택
- **상태 (State)**: `PAGE-001 (홈)` → `15개 상품 레일` → `PAGE-021 (카테고리 솔루션)` → `PROD-001 실측 카드` → `PAGE-020 (실제본 공정 서사)`
- **분기 (Branch)**: 단차 2mm 이상 발생 우려 시 실시간 3D 평면 뷰어로 단차 0mm 수치 확인
- **오류/복구 (Error/Recovery)**: 고화질 이미지 로드 실패 시 고대비 텍스트 라벨 즉시 대체 렌더링
- **종료 (Termination)**: 120gsm 미유광 평산지 하드커버 노구 소장 결정 완료

### 2) User Flow B: 디지털 시간축 통제 여정 (VC-02 지안, VC-05 태오, VC-16 한결)
- **트리거 (Trigger)**: 출근길 08:30 흔들리는 지하철에서 당일 24시간 타임라인 확인 및 일정 충돌 방지
- **입력 (Input)**: 24시간 시간축 모드 토글, 30분 단위 일정 블록 이동
- **상태 (State)**: `PAGE-001` → `24시간 타임라인 위젯` → `PAGE-021 (디지털 플래너)` → `ST-HOLD 배지 확인`
- **분기 (Branch)**: 외부 연동 미검증 시 `ST-HOLD` 배지 활성화로 자동 덮어쓰기 원천 차단
- **오류/복구 (Error/Recovery)**: 네트워크 지연 시 '로컬 단독 안전 시간표' 모드로 300ms 이내 전환
- **종료 (Termination)**: 3단 디바이스 화면 비율 100% 일치 상태로 일정 확인 완료

### 3) User Flow C: 10초 저부담 빠른 회고 여정 (VC-03 하람, VC-32 유진)
- **트리거 (Trigger)**: 취침 직전 침실 취침등 아래에서 10초 이내 하루 감정/사진 1장 기록
- **입력 (Input)**: 사진 1장 업로드 + 3줄 이내 단문 회고 + 감정 칩 1회 터치
- **상태 (State)**: `PAGE-001` → `001-QUICK 퀵 스냅샷 바` → `10초 무설정 팝업 모달`
- **분기 (Branch)**: 텍스트 3줄 초과 시 자동 확장되지 않고 간결한 요약 모드로 유지
- **오류/복구 (Error/Recovery)**: 이미지 업로드 지연 시 로컬 썸네일 즉시 생성 후 백그라운드 저장
- **종료 (Termination)**: 10초 이내 LocalStorage에 안전 저장 및 작성 완료 피드백 카드 노출

### 4) User Flow D: 템플릿 구획 및 꾸미기 여정 (VC-04 소담, VC-06 나린, VC-30 서진)
- **트리거 (Trigger)**: 주말 오전 독서/재정 템플릿 탐색 및 흑백 라인아트 스티커 꾸미기
- **입력 (Input)**: 주제별 태그 선택, 스티커 레이어 ON/OFF 토글
- **상태 (State)**: `PAGE-001` → `PAGE-021 (템플릿 & 꾸미기)` → `서식 캔버스 프리뷰` → `PROD-006`
- **분기 (Branch)**: 스티커 부착 시 텍스트 본문과 100% 분리된 독립 레이어로 자동 배치
- **오류/복구 (Error/Recovery)**: 서식 변경 시에도 기존 작성 텍스트 원본 보존율 100% 유지
- **종료 (Termination)**: 텍스트 가독성 훼손 없는 감성 다이어리 템플릿 내 서재 저장 완료

### 5) User Flow E: 죄책감 없는 기록 복귀 여정 (VC-07 이준, VC-20 주원, VC-51 이솔)
- **트리거 (Trigger)**: 2주간 야근/출장으로 중단된 일기를 다시 작성하기 위해 재진입
- **입력 (Input)**: '미안함 없는 복귀 밴드' 1-클릭
- **상태 (State)**: `PAGE-001` → `응원 밴드 툴팁` → `최근 작성 위치 자동 포커스`
- **분기 (Branch)**: 연속 작성 실패(Streak) 경고 배지 및 빨간 점 팝업 100% 영구 차단
- **오류/복구 (Error/Recovery)**: 네트워크 단절 시 `ST-LOCAL` 캐시에서 최근 작성 위치 0ms 복구
- **종료 (Termination)**: 부담감 0% 상태로 1-클릭 이전 기록 위치에서 자연스러운 필기 재개 완료

  - 문제점(Pain Point) 차단: 일반 80gsm 떡제본 노트 사용 시 만년필 잉크 실핏줄 번짐(Feathering)과 뒤비침(Bleed-through)이 심하고, 노트 중앙부가 솟아올라 손목 통증과 글씨 왜곡 발생.
  - 성공 조건 달성: 30분 이상 연속 필기 시 손목 통증이 없고 잉크 번짐 없이 양면 서술 완벽 지원.

  - 문제점(Pain Point) 차단: 파편화된 디지털 일정 앱과 외부 구글/아웃룩 캘린더의 예고 없는 동기화로 기존 수동 일정이 무단 덮어씌워지고 개인/업무 시간이 뒤섞임.
