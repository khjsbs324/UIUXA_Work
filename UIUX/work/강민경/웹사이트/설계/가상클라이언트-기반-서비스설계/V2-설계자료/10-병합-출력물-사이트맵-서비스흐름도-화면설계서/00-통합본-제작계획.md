# 통합본 제작 계획

상태: `PAUSED_BEFORE_FINAL_MERGE`
작성일: 2026-08-18
대상: VC-01~VC-51 전체 클라이언트

## 1. 사용자 확정 범위

최종 산출물은 설계자료 3개와 스토리보드 3개, 총 6개다.

### 설계자료 통합본

1. 사이트맵 최종 통합본 1개
2. 서비스 흐름도 최종 통합본 1개
3. 화면 설계서 최종 통합본 1개

### 스토리보드 통합본

1. 메인페이지 스토리보드 최종 통합본 1개
2. 브랜드 소개 페이지 스토리보드 최종 통합본 1개
3. 서브카테고리 페이지 스토리보드 최종 통합본 1개

## 2. 병합 원칙

- 51개 파일을 단순히 이어 붙이지 않는다.
- 각 클라이언트의 요구사항을 메인·브랜드 소개·서브카테고리 목적에 맞게 재분류한다.
- 공통 구조와 클라이언트별 차별 요구를 분리해 기록한다.
- Page·REQ·Flow·Screen·State·Product ID의 추적성을 유지한다.
- 판매·결제·로그인·검색·외부 연동 등 입력에 없는 기능을 임의로 확정하지 않는다.
- 확인되지 않은 정보는 Fact/HOLD/확인 필요 상태로 구분한다.

## 3. 파일 저장 위치

현재 출력 폴더:

`10-사이트맵-서비스흐름도-화면설계서-병합-출력물`

최종 파일명:

- `사이트맵-최종-통합본.md`
- `서비스흐름도-최종-통합본.md`
- `화면설계서-최종-통합본.md`
- `스토리보드-메인페이지-최종-통합본.md`
- `스토리보드-브랜드소개페이지-최종-통합본.md`
- `스토리보드-서브카테고리페이지-최종-통합본.md`

## 4. 제작 순서

1. 기존 사이트맵 파일 전수 수집 및 Page 구조 정규화
2. 기존 서비스 흐름도 VC-01~VC-51 전수 수집 및 상태/분기 통합
3. 기존 화면 설계서 VC-01~VC-51 전수 수집 및 9개 필드 정규화
4. 3개 설계자료 최종 검토
5. 메인페이지 스토리보드 통합
6. 브랜드 소개 페이지 스토리보드 통합
7. 서브카테고리 페이지 스토리보드 통합
8. 6개 파일 간 Page·Flow·Screen 연결 검증

## 5. 현재 중단 지점

- 10번 출력 폴더와 초기 병합 파일은 생성되어 있다.
- VC-01~03 중심의 초기 통합 내용이 일부 작성되어 있다.
- 51개 클라이언트 전체를 반영한 최종 6종 통합본은 아직 완료로 판정하지 않는다.
- 다음 작업자는 기존 초기 파일을 최종본으로 간주하지 말고 전수 병합부터 재검토한다.

## 6. 완료 기준

- [ ] 51개 클라이언트가 각 최종 파일에 누락 없이 등장
- [ ] 각 요구사항이 목적에 맞는 페이지/영역/흐름에 배치
- [ ] 동일 요구사항 중복·충돌·미확정 상태 표시
- [ ] 6개 파일의 링크·Page ID·REQ ID 일치
- [ ] 최종 자체검토표와 인수인계 갱신
