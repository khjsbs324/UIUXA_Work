# 서비스 흐름도 최종 통합본 · VC-01~VC-51

상태: `FINAL_SERVICE_FLOW_MERGED`

## 1. 공통 서비스 흐름

`진입/공감 → 최소 조건 확인 → 목적별 탐색 → 근거·상태 확인 → 선택/보류 → 저장·재개 → 브랜드 원칙 또는 다음 과업`

모든 흐름은 정상 경로뿐 아니라 Empty·Error·HOLD·Offline·Resume을 포함한다. 사용자가 선택하지 않아도 흐름을 계속 볼 수 있어야 하며, 확정되지 않은 기능은 `확인 필요`로 멈춘다.

## 2. 목적별 통합 플로우

### A. 메인페이지 흐름

`PAGE-001 Hero → 핵심 문제 인식 → 목적 선택 → 대표 콘텐츠/후보 탐색 → 근거 확인 → PAGE-002/003/009/020/021`

### B. 브랜드 소개 흐름

`PAGE-020 선언 → 제작/운영 원칙 → 사실과 HOLD 분리 → 관련 콘텐츠/후보 연결 → PAGE-001 또는 PAGE-021`

### C. 카테고리서브 흐름

`PAGE-021 시각 Hero → 카테고리 인덱스 → 최소 필터 → 후보 그리드/레일 → 비교 → 선택·보류 → 이전 조건 복귀`
