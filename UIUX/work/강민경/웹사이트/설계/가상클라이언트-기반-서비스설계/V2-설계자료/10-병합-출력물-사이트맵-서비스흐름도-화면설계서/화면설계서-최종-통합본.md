# 화면 설계서 최종 통합본 · VC-01~VC-51

상태: `FINAL_SCREEN_SPEC_MERGED`
기준 양식: 화면명 · 화면 목적 · 주요 콘텐츠 · 인터페이스 요소 · 레이아웃 · 작동 방식 · 연결 화면 · 사용자 경로 · 비고·주석

## 1. 공통 화면 설계 계약

모든 클라이언트는 메인·카테고리서브·브랜드 소개를 갖는다. 공통 골격은 `Header → Main/Hero → 목적별 콘텐츠 → 상태/근거 → 다음 행동 → Footer`이며, 아래 클라이언트 매트릭스의 요구를 각 화면의 콘텐츠·행동·상태에 배치한다. 접근성·반응형 실제 실행은 후속 검증으로 관리한다.

## 2. 목적별 화면 명세

### 메인페이지

| 필드 | 통합 기준 |
|---|---|
| 화면명 | 클라이언트 핵심 과업을 이해하는 랜딩 페이지 |
| 화면 목적 | 브랜드 방향과 첫 판단 과업을 한 장에서 연결 |
| 주요 콘텐츠 | Hero, 핵심 문제, 목적 선택, 대표 후보/콘텐츠, Fact/HOLD, 다음 CTA |
| 인터페이스 | GNB, 앵커, 선택 카드, 레일/그리드, 상태 배지, CTA |
| 레이아웃 | Desktop 12열 → Tablet 8열 → Mobile 4열, 정보 순서 유지 |
| 작동 방식 | 선택값·스크롤 위치 보존, 오류 영역 격리, HOLD 실행 차단 |
| 연결 화면 | `PAGE-002·003·004·009·010·011·015·016·019·020·021` |
| 사용자 경로 | 공감 → 최소 선택 → 근거 확인 → 비교/기록/브랜드 이동 |
| 비고 | 가격·결제·로그인·검색·외부 연동 확정 금지 |

### 브랜드 소개 페이지

| 필드 | 통합 기준 |
|---|---|
| 화면명 | 브랜드 원칙과 제작 근거를 공개하는 소개 페이지 |
| 화면 목적 | 브랜드 주장·과정·사실·HOLD를 구분해 신뢰 형성 |
| 주요 콘텐츠 | 선언, 관찰/실측/조합/공개 과정, 사실·미확정 표, 관련 후보 |
| 인터페이스 | 과정 노드, 근거 Accordion, Fact/HOLD 배지, 앵커 CTA |
| 레이아웃 | Hero → 원칙 → 과정 → 근거 → 관련 화면 → Footer |
| 작동 방식 | 근거 펼침, 관련 후보 이동, 원래 위치 복귀 |
| 연결 화면 | `PAGE-001·007·016·019·021` |
| 사용자 경로 | 선언 이해 → 근거 확인 → 후보/기록 과업 선택 |
| 비고 | 브랜드명·수치·운영정책은 입력자료에 있을 때만 확정 |

### 서브카테고리 페이지

| 필드 | 통합 기준 |
|---|---|
| 화면명 | 목적별 콘텐츠·제품 후보를 비교하는 카테고리서브 |
| 화면 목적 | 판매보다 사용 목적·근거·차이를 비교하게 함 |
| 주요 콘텐츠 | 시각 Hero, 카테고리 인덱스, 최소 필터, 그리드/레일, 비교표, 보류 사유 |
| 인터페이스 | 탭/앵커, 필터, 카드, 비교 바, 초기화, 전체 보기 |
| 레이아웃 | Hero → Index → Filter → Grid/Rail → Compare → Decision |
| 작동 방식 | 필터 결과 유지, 과필터 완화, 이미지 실패 시 정보 대체, 비교 상태 보존 |
| 연결 화면 | `PAGE-001·002·003·004·009·010·011·015·016·019·020` |
| 사용자 경로 | 범주 이해 → 최소 조건 → 후보 비교 → 선택/보류 → 원래 맥락 복귀 |
| 비고 | 대표 후보와 확장 후보, 확인됨과 HOLD를 분리 표시 |
