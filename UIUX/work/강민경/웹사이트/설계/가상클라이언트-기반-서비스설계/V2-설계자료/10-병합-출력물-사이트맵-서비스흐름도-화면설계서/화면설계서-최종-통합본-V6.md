단계: `05-설계 (병합 단계)`  
버전: `V6` (51인 가상 클라이언트 및 200개 제품 인벤토리 100% 수용 단일 통합 화면설계서)  
선정 후보안: `SPEC-CANDIDATE-C (하이브리드 반응형 컴포넌트 아키텍처 최적안)`

## 1. 반응형 3단 브레이크포인트 규격 및 접근성 원칙

- **Desktop (1200px+)**: 최대 폭 1200px 중앙 정렬, sticky GNB(76px), 2열/3열 유동 그리드 레이아웃
- **Tablet (768px ~ 1023px)**: 태블릿 터치 최적화 2열 카드 그리드, 터치 타깃 최소 44x44px
- **Mobile (360px ~ 767px)**: 1열 유동 블록, 가로 스크롤 카드 레일 (`scroll-snap-type: x mandatory`), 하단 24px 안전 패딩
- **WCAG 2.1 AA 접근성 규격**:
  - 본문 명도 대비 최소 4.5:1 이상, 대형 헤딩 3.0:1 이상 엄격 준수
  - 키보드 3px 고대비 포커스 링 (`focus-visible`)
  - 본문 바로가기 건너뛰기 링크 (Skip Link) 탑재

## 2. 3대 핵심 화면 표준 명세 (PAGE-001, PAGE-021, PAGE-020)

### 1) PAGE-001: 메인 랜딩 페이지 (Main Landing Page)
- **화면명**: 다모리 브랜드 서사 및 대표 라인업 탐색 랜딩
- **화면 목적**: 브랜드 철학("애착공방 기억의 서재")과 대표 15개 상품, 5대 과업을 한 화면에서 유기적으로 연결
- **주요 콘텐츠**: 76px GNB, Hero 6:6 2열, 대표 15선 스크롤 레일(PROD-001~015), 4대 자율 필터 칩, 10초 퀵 스냅샷 모달, 24시간 타임라인 위젯, 원본 보존 카드, 죄책감 없는 복귀 밴드, 4열 푸터
- **인터페이스 요소**: 가로 스크롤 스냅 버튼, 필터 칩 토글, 모달 팝업, 1-클릭 복귀 밴드, Skip Link
- **레이아웃**: 1200px 2열 → 768px 2열 → 360px 1열 세로 스택
- **작동 방식**: 스크롤 위치 및 필터 선택값 로컬 보존, ST-HOLD 상태 시 안전 차단, ST-LOCAL 오프라인 캐시
- **연결 화면**: `PAGE-002`, `PAGE-003`, `PAGE-004`, `PAGE-009`, `PAGE-010`, `PAGE-020`, `PAGE-021`
- **사용자 경로**: 브랜드 Hero 공감 → 15선 레일 탐색 → 4대 필터 선택 → 카테고리 솔루션 허브 이동

### 2) PAGE-021: 카테고리 솔루션 허브 (Category Solution Hub)
- **화면명**: 10대 카테고리 200개 제품 1:1 실측 대조 솔루션 허브
- **화면 목적**: 상업적 단순 판매가 아닌, 기록 목적·물성·차이를 1:1로 비교하고 최적의 솔루션을 발견하게 함
- **주요 콘텐츠**: 상단 비주얼 Hero 배너, 10대 카테고리 인덱스 탭, 200개 제품 그리드, 아날로그 vs 디지털 1:1 비교 카드, 플로팅 Compare Tray (최대 3종 대조)
- **인터페이스 요소**: 10대 카테고리 탭, 4열 제품 카드 그리드, Compare Tray 플로팅 바, 모달 스펙 대조표
- **레이아웃**: 4열 그리드(1200px) → 2열 그리드(768px) → 1열 그리드(360px)
- **작동 방식**: 실시간 필터링, 이미지 로드 실패 시 고대비 텍스트 대체, Tray 선택 상태 무손실 유지
- **연결 화면**: `PAGE-001`, `PAGE-004`, `PAGE-009`, `PAGE-020`
- **사용자 경로**: 상단 비주얼 확인 → 10대 카테고리 탐색 → Compare Tray 담기 → 1:1 실측 대조 완료

### 3) PAGE-020: 브랜드 소개 페이지 (Brand Storytelling)
- **화면명**: 애착공방 기억의 서재 브랜드 철학 및 장인 제본 공정
- **화면 목적**: 120gsm 미유광 평산지 생산 출처와 180도 Smyth Sewn 실제본 공정을 투명하게 공개하여 깊은 신뢰 형성
- **주요 콘텐츠**: "나만의 애착공방 기억의 서재" 서사, 종이와 화면 동등 존중 3대 철학, 180도 실제본 공정 실측(단차 0mm), 16x16px 불박 도장 각인 원칙, WCAG 2.1 AA 접근성 가이드
- **인터페이스 요소**: 공정 3D 각도 뷰어, 실측 검증 라벨 아코디언, 키보드 접근성 테스트 패널
- **레이아웃**: 중앙 단일 컬럼 서사 텍스트 + 2열 공정/각인 시각 카드
- **작동 방식**: 스크롤에 따른 서사 페이드인, 앵커 링크 부드러운 이동
- **연결 화면**: `PAGE-001`, `PAGE-021`
- **사용자 경로**: 브랜드 선언 확인 → 120gsm 평산지 공정 확인 → 단색 불박 각인 확인 → 메인/카테고리 복귀
