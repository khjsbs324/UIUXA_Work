## 2. 화면별 패널

### SCR-C01 · 시각적 Hero와 카테고리 선언

| 항목 | 상세 |
|---|---|
| 목적 | 카테고리가 판매 분류가 아니라 기록 조건을 해석하는 기준임을 먼저 알린다. |
| 레이아웃 | 전체 폭 종이 단면/줄 간격 비주얼, 오버레이 제목, 하단 4개 카테고리 앵커 |
| 카피 | “장문 기록은 한 종류의 종이가 아니라, 쓰는 리듬의 조합입니다.” |
| 상호작용 | 앵커 hover/포커스 시 대표 조건과 포함 제품 수 표시; 이미지 실패 시 실측 표로 대체 |
| 상태 | 이미지 로딩·대체·오프라인·접근성 텍스트·모션 감소 |

### SCR-C02 · 카테고리 선택과 조건 요약

| 항목 | 상세 |
|---|---|
| 목적 | 은재가 목적에 맞는 한 카테고리를 고르고 비교 기준을 유지한다. |
| UI | 4개 카테고리 탭, “내 진단값 적용” 토글, 선택 조건 칩, 전체 초기화 |
| 행동 | 탭 전환은 URL 앵커를 갱신하고 스크롤 위치를 보존; 토글은 진단값을 필터에 반영 |
| 예외 | 진단값 없음→기본 전체 표시와 입력 안내; 결과 0→조건 완화 제안 |

### SCR-C03 · 제품/콘텐츠 포트폴리오 그리드

| 항목 | 상세 |
|---|---|
| 목적 | 각 후보의 쓰임·근거·미확정 범위를 한 화면에서 비교한다. |
| 카드 | 제품명, 사용 장면, 기록 영역/줄 간격, 사실/HOLD, 관련 콘텐츠 PAGE, 비교 체크 |
| 정렬 | 기록 영역 큰 순·휴대 부담 낮은 순·근거 확인 우선(기본은 근거 확인 우선) |
| 행동 | 2~3개 비교 고정 바, 카드 상세, 보류 저장, 카테고리 변경 |
| 정책 | 판매 가격·재고·배송 노출 없음. “확인 필요”를 결함처럼 숨기지 않음. |

### SCR-C04 · 실측 비교 뷰

| 항목 | 상세 |
|---|---|
| 목적 | 사진이 아닌 줄 간격·기록 영역·구성 기준으로 후보를 판단한다. |
| 비교 행 | 페이지당 기록량, 줄 간격, 일정표 유무, 메모 영역, 확인 근거, 미확정 물성 |
| 상호작용 | 행 펼침→근거 ID, 열 제거, 비교 기준 저장, 모바일에서는 카드형 행으로 전환 |
| 실패 | 값 누락은 “정보 없음”으로 명시하고 구매 CTA 대신 보류/오프라인 확인 경로 제공 |

### SCR-C05 · 선택·보류·복귀

| 항목 | 상세 |
|---|---|
| 목적 | 충분히 확인된 후보는 선택하고, 부족한 후보는 판단을 보류한다. |
| CTA | `비교 결과 저장` / `정보 부족으로 보류` / `조건 다시 선택` |
| 완료 | 선택 이유·근거·미확정 항목 요약, PAGE-008 또는 메인으로 복귀 |
| 복구 | 저장 실패·오프라인·비교 충돌을 구분하고 임시 저장과 재시도 제공 |
