# VC-02 지안 · 카테고리 서브페이지 스토리보드

## 0. 문서 계약

| 목적 | 일정 관련 제품을 시간 관점의 의미 있는 카테고리로 묶어 비교한다. |
|---|---|
| 추적 | `CLIENT=VC-02`, `REQ=REQ-002`, `PAGE=PAGE-003·009·011`, `PRODUCTS=PROD-002·004·005·006·034·035·036·065·066·067·068` |

## 1. 카테고리

| 카테고리 | 제품 | 판단 질문 |
|---|---|---|
| 흐름 개요 | PROD-002·004·065 | 어느 날이 비어 있고 전체 흐름은 어떤가? |
| 시간 충돌 | PROD-005·034·066 | 약속과 이동 여유가 겹치는가? |
| 알림 선택 | PROD-035·067 | 무엇만 기억하면 충분한가? |
| 변경·전환 | PROD-006·036·068 | 계획이 바뀌었을 때 무엇을 유지하는가? |

## 2. 패널

### SCR-C01 · 시간축 Hero
월간 달력과 시간축이 겹친 시각물을 Hero로 사용한다. “일정을 더 많이 넣는 대신, 판단할 여백을 남깁니다.” 이미지 실패 시 텍스트 달력으로 대체한다.

### SCR-C02 · 카테고리 탭
4개 탭과 현재 선택 날짜 칩을 제공한다. 탭 전환 시 날짜와 스크롤 위치를 유지하고, 진단값이 없으면 전체 흐름을 기본값으로 표시한다.

### SCR-C03 · 후보 카드
각 카드에 시간 범위, 빈/충돌 상태, 이동 여유, 알림 선택권, `PROD/PAGE/REQ`를 표시한다. 비교 담기·보류·상세 보기 행동을 지원한다.

### SCR-C04 · 일정 비교 보드
행은 날짜·시간·장소·이동 여유·알림 상태·근거로 구성한다. 모바일에서는 카드형으로 바꾸며 충돌 원인을 먼저 읽어준다.

### SCR-C05 · 선택·복귀
약속 결정, 알림만 설정, 보류, 원래 날짜로 복귀를 분리한다. 저장 실패 시 임시 저장과 재시도를 제공한다.

## 3. 검증

- 외부 캘린더 자동 연동을 표현하지 않는다.
- 모든 알림이 기본 선택되지 않는다.
- 빈 날짜·충돌·이동 부족·알림 해제 상태가 색상과 텍스트로 전달된다.
