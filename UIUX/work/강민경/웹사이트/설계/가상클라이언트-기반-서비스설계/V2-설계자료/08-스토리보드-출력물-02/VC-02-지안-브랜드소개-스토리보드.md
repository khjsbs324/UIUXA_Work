## 2. 패널

### SCR-B01 · 선언
“좋은 일정 도구는 더 많이 알려주는 도구가 아니라, 필요한 순간에 선택하게 하는 도구입니다.”라는 브랜드 선언과 `일정 보기` 앵커를 제공한다.

### SCR-B02 · 설계 기준
개요/세부 맥락 유지, 빈 시간 존중, 선택적 알림의 3축을 카드로 보여준다. 각 축은 PROD-002·005·035와 연결된다.

### SCR-B03 · 제작 과정
월간 흐름 관찰 → 시간축 충돌 표시 → 알림 선택 상태 설계 → 변경 이력 보존의 4단계 포트폴리오를 보여준다.

### SCR-B04 · 사실과 미지원
확인된 것: 선택 날짜 유지, 충돌 표시, 알림 설정·수정·해제. 미지원/HOLD: 외부 달력 자동 연동, 모든 일정 자동 알림. 두 영역을 동일한 시각 무게로 공개한다.

### SCR-B05 · 개인 일정으로 연결
`내 빈 날짜 찾기`→PAGE-003, `충돌 확인`→PAGE-009, `알림 없이 저장`→PAGE-019를 병렬 제공한다. 읽은 앵커와 선택 날짜를 복귀 시 보존한다.
