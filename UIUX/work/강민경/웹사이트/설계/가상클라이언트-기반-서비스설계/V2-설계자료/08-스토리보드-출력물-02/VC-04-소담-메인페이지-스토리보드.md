## 2. 상태와 테스트

`Default → TopicSelected → Preview → Compare → ApplyDraft/Hold/Return` 전이에서 주제·스크롤 위치를 유지한다. `ST-004-EMPTY`(결과 없음), `ST-004-HOLD`(자료 미확인), `ST-004-ERR`(미리보기 실패), `ST-004-CONF`(적용 전 확인)을 제공한다.

테스트: 일과/음악/책 주제 이동, 기능·표현 혼동 방지, 미리보기 실패 대체, 적용 취소 후 원래 위치 복귀, 200% 확대와 키보드 탭 순서를 검증한다.

## 5. 상태 전이·데이터 계약

`ST-004-DEF → ST-004-TOPIC → ST-004-PREVIEW → ST-004-COMPARE → ST-004-DRAFT/HOLD`.

| 상태 | 조건 | 화면 문구 | 유지 데이터 | Primary / Secondary |
|---|---|---|---|---|
| `ST-004-DEF` | 첫 진입 | `주제를 하나 골라보세요` | 없음 | 주제 선택 |
| `ST-004-TOPIC` | 주제 선택 | `독서 후보를 정리했어요` | 주제·필터·스크롤 | 미리보기 / 조건 수정 |
| `ST-004-EMPTY` | 후보 없음 | `이 주제에 확인된 후보가 없어요` | 주제 유지 | 전체 보기 / 다른 주제 |
| `ST-004-PREVIEW` | 미리보기 열림 | `구성과 입력량을 확인하세요` | 페이지·확대·근거 | 비교 / 닫기 |
| `ST-004-HOLD` | 자료 미확인 | `아직 확인하지 못한 항목이 있어요` | 후보·근거 위치 | 보류 / 다른 후보 |
| `ST-004-ERR` | 콘텐츠 실패 | `미리보기를 불러오지 못했어요` | 선택·필터 전부 | 재시도 / 목록 복귀 |
| `ST-004-CONF` | 적용 전 이탈 | `선택한 구조를 적용하기 전입니다` | 초안·변경점 | 계속 / 취소 |

저장 데이터는 주제, 후보 ID, 비교 기준, 보류 사유, 마지막 영역만 보존한다. 실제 기록 원문·외부 계정·가격·재고를 생성하지 않는다.

## 9. VC-04 고유 연출 방향

- 일반적인 제품 랜딩처럼 쌓지 않고 **주제 인덱스 아틀라스**로 구성한다.
- Hero는 홍보 이미지가 아니라 `독서·음악·일과`가 서로 다른 필드 조각으로 분해되는 편집형 모자이크를 사용한다.
- 주제 선택은 카드 클릭만이 아니라 좌측 인덱스와 우측 샘플 페이지가 동시에 갱신되는 탐색 캔버스로 설계한다.
- 제품 카드는 가격·구매 CTA 대신 `필드 보기`, `표현과 분리`, `맞지 않는 이유`를 전면에 둔다.
- 마지막은 CTA Band가 아니라 선택한 주제·기능 템플릿·표현 자산을 한 장의 **선택 편집지**로 정리한다.
