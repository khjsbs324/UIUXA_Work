# 사이트구조맵·사이트맵 생성 및 검증 기준 V2

## 1. 입력 근거

- 개별 기준: 제품 연결 Client V4
- 통합 기준: 요구사항 분석 결과, 제품 콘텐츠 검증·보완본, 브랜드·공유자료
- 분석 순서: 통합 분석 결과 확인 → 개별 Client의 상황·목표·과업·불편·요구 대조 → 사이트구조맵 도출 → 사이트맵 출력
- 확정되지 않은 정보는 항목별로 `가정`과 `근거 확인 필요`를 표시한다.

## 2. 출력 구조

Client 하나당 A·B·C 구조안을 우선 생성한다. 각 안은 다음을 포함한다.

- `사이트구조맵 분석 결과`: Client 요구를 메뉴·콘텐츠·기능으로 변환한 내용
- `사이트맵`: 페이지 계층과 연결 관계
- `사이트맵.md`: 설명·표·검증·Mermaid 코드
- `사이트맵.mmd`: MD와 동일한 Mermaid flowchart만 수록
- `사이트맵.svg`: 동일 구조를 표현하는 한글 벡터 파일

## 3. 필수 추적표

| Client 요구·REQ | 메뉴 | 콘텐츠 | 기능 | 연결 페이지 | 근거/가정 |
|---|---|---|---|---|---|

제품 ID는 관련 REQ와 함께 기록하고, 대표 15개 선정 여부와 혼동하지 않는다.

## 4. 상태별·여정별 구조

- 공통: Header, 전역 내비게이션, 검색, Footer, 현재 위치
- 상태: 비회원 탐색, 비교·보류, 기록 진행, 저장·복귀(자료에 없으면 가정)
- 여정: 진입 → 핵심 정보 확인 → 비교·선택 → 기록 시작 → 저장·복귀
- 예외: 결과 없음, 오류, 취소, 재시도, 이전 위치 복귀

## 5. 출력 검증

- MD·MMD의 Mermaid 코드가 동일한가
- SVG 노드·연결이 Mermaid와 일치하는가
- SVG에 `<svg>` 루트와 한글 폰트 대체가 있는가
- 1·2·3차 계층과 전역·지역 내비게이션이 명시됐는가
- 중복 페이지·끊긴 링크·누락 요구가 없는가
- 출력 파일의 상대 경로와 용도가 작업 로그에 기록됐는가
