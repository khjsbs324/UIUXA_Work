- Client: VC-45 해나(한국적 정서의 진정성), REQ-045.
- 요구: 문화 요소를 절제하고 기능·재료와 연결하며 가칭 브랜드 의미와 분리한다.
- 연결 제품: PROD-081 — 무드 색상 선택표.

## 2. 구조 전략

## 4. 사용자 흐름·상태
