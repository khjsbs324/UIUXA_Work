## 4. 사용자 흐름·상태
- 정상: 전환 장부 → 역할·비용 → 수동 단계 → 후보 비교
- 분기: 자동 기능 미지원 → 수동 기록·보류; 데이터 범위 불명 → 시작 차단
- 오류·Offline: 마지막 확인일·미지원 범위 표시
- 상태: `DEFAULT / EMPTY / ERROR / OFFLINE / RESUME / HOLD`

## 5. 중복·끊김·가정 검증

- 계정·가격·동기화는 `HOLD`다.
