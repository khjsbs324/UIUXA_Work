## 2. 구조 전략

## 3. 페이지·콘텐츠·기능 계약

- 보류 이유, 텍스트 대안, 재시도, 현재 위치·복귀를 제공한다.

## 4. 사용자 흐름·상태
- Section 진입 → Offline/Error → 읽기 유지 → 보류/재시도 → 복귀.
- 상태: 읽기 유지, 실패 Section, 보류, 재시도, Resume, 오류·HOLD.

## 5. 중복·끊김·가정 검증
