## 3. 사이트맵·페이지

- 1차: 메인 / 선물 사례 / 확인 질문 / 관련 후보 / 브랜드 이야기
  - 선물 사례: 관계 / 용도 / 초보 / 모름
    - 3차: 사례 상세 / 질문 / 관련 패키지
  - 후보: 안전 후보 / 피할 조건 / 비교 / 보류
  - 브랜드: 방향 / 제작 / 포트폴리오·검토용 고지
