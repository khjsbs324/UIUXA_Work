- 정상: 안전 장부 → 확인 질문 → 후보 상태 → 비교·보류
- 분기: 모름 → 안전 후보; 질문 답변 → 조건 좁히기
- 오류·Offline: 질문·선택 상태를 유지하고 재시도
- 상태: `DEFAULT / EMPTY / ERROR / OFFLINE / RESUME / HOLD`
