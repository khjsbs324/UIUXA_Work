## 4. 사용자 흐름·상태
- 정상: 가격 장부 → 구성 필터 → 후보 비교 → 보류 이유 저장
- 분기: 가격 미정 → 구매 CTA 없음·알림 약속 없음
- 오류·Offline: 마지막 확인일과 변경 위험 표시
- 상태: `DEFAULT / EMPTY / ERROR / OFFLINE / RESUME / HOLD`

## 5. 중복·끊김·가정 검증

- 실제 판매·재고·배송은 `HOLD`다.
- 보류 이유를 유지하고 조건 초기화를 제공한다.
- 접근성 Label·Heading·키보드를 검증한다.
