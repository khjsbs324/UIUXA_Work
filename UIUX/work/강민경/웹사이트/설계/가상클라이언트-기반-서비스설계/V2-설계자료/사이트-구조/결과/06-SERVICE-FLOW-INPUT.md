# 06 서비스 흐름 단계 입력

> 후속 단계 입력 문서이며 서비스 흐름도 자체는 아니다.

## 범위

- Page: PAGE-001~020
- GNB: PAGE-002·004·009·013·016
- Footer: PAGE-019·020
- 조건부 Page: PAGE-018

## 핵심 흐름 후보

1. 처음 방문 → PAGE-002 방식 비교 → PAGE-003 맞춤 추천 → 아날로그/디지털/템플릿/작은 시작 선택
2. 은재 → PAGE-004 → PAGE-005·006 → PAGE-007·008 또는 PAGE-012
3. 지안 → PAGE-009 → PAGE-011 → 필요 시 PAGE-019
4. 하람 → PAGE-009 → PAGE-010 → PAGE-015 또는 PAGE-017
5. 소담·나린 → PAGE-013 → PAGE-014 또는 PAGE-015
6. 태오 → PAGE-009·012 → PAGE-019
7. 이준 → PAGE-017 → PAGE-018 → 지금 하기·보류·나누기·삭제 중 선택

## 공통 연결

- 모든 핵심 Page → PAGE-019 도움말·보존
- PAGE-003 추천 결과 → PAGE-004·009·013·017
- PAGE-010 빠른 기록 → PAGE-015 꾸미기 또는 PAGE-018 복귀
- PAGE-014 템플릿 비교 ↔ PAGE-015 꾸미기 자산
- PAGE-020 브랜드 소개는 Footer 진입만 제공

## 후속 단계 제약

- SR-013~017은 검증 분기로 표시하며 정상 제공 기능으로 단정하지 않는다.
- AI 추천은 원본과 분리된 수정 가능한 초안으로 표현한다.
- 로그인·검색·마이페이지·커뮤니티·Shop 흐름은 만들지 않는다.
- 서비스 흐름도 생성 여부: `아직 생성하지 않음`
