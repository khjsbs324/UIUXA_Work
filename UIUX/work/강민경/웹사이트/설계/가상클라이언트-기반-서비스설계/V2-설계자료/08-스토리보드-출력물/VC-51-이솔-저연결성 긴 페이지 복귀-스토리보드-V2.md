## 1. 상황 카드

- 사용 상황: 모바일 저연결성에서 긴 메인과 카테고리를 이동하다 일부 콘텐츠 로딩이 실패한다.
- 목표: 이미 확인한 브랜드·제품 정보와 현재 위치를 유지하고 실패 Section만 건너뛴다.
- 핵심 과업: 긴 페이지 탐색 → 지연·실패 인지 → 기존 내용 유지 → 재시도·건너뛰기 → 복귀
- 성공 기준: 실패한 부분을 제외하고 브랜드와 제품 탐색을 계속한다.
- 실패 방지: 전체 페이지를 빈 오류 화면으로 대체하거나 자동 새로고침한다.

## 3. 상태 전이 규칙

- 오류·빈 결과: 현재 입력을 보존하고 재시도·조건 완화·이전 단계 중 하나를 제공한다.
- HOLD: 미확정 근거와 보류 사유를 표시하고 재개 위치를 저장한다.
- 완료: 실패한 부분을 제외하고 브랜드와 제품 탐색을 계속한다. 충족 여부를 확인한 뒤 완료·다음 행동을 제공한다.
- 복구: 오프라인·충돌 시 최신 유지·현재 유지·병합 선택을 제공한다.
