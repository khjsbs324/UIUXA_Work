## 1. 상황 카드

- 사용 상황: 받는 사람의 기록 취향과 숙련도를 완전히 모르는 상태에서 부담 없는 선물을 고른다.
- 목표: 확인된 조건만으로 안전한 후보와 확인이 더 필요한 후보를 구분한다.
- 핵심 과업: 선물 상황 선택 → 숙련도·사용 장면 확인 → 구성·난도 비교 → 정책 상태 확인 → 보류
- 성공 기준: 안전한 후보와 피할 조건, 받는 사람에게 확인할 질문을 구분한다.
- 실패 방지: 누구나 좋아함·가상 후기·구매 완료 흐름을 제공한다.

## 3. 상태 전이 규칙

- 오류·빈 결과: 현재 입력을 보존하고 재시도·조건 완화·이전 단계 중 하나를 제공한다.
- HOLD: 미확정 근거와 보류 사유를 표시하고 재개 위치를 저장한다.
- 완료: 안전한 후보와 피할 조건, 받는 사람에게 확인할 질문을 구분한다. 충족 여부를 확인한 뒤 완료·다음 행동을 제공한다.
- 복구: 오프라인·충돌 시 최신 유지·현재 유지·병합 선택을 제공한다.
