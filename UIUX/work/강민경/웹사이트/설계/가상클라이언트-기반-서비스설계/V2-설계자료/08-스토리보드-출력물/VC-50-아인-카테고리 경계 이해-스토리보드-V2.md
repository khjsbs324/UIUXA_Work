## 1. 상황 카드

- 사용 상황: 같은 제품이 '다시 시작', 'Analog', '선물' 등 여러 위치에 나타나 중복 제품인지 다른 구성인지 헷갈린다.
- 목표: 카테고리 기준과 다중 소속 이유를 이해하고 같은 제품을 중복 후보로 세지 않는다.
- 핵심 과업: 카테고리 정의 → 제품 소속 → 다른 분류 경로 → 동일 Product 확인
- 성공 기준: 같은 제품과 다른 변형을 구분하고 현재 카테고리 포함 이유를 설명한다.
- 실패 방지: 이름·이미지만 바꿔 중복 제품을 새 후보로 계산한다.

## 3. 상태 전이 규칙

- 오류·빈 결과: 현재 입력을 보존하고 재시도·조건 완화·이전 단계 중 하나를 제공한다.
- HOLD: 미확정 근거와 보류 사유를 표시하고 재개 위치를 저장한다.
- 완료: 같은 제품과 다른 변형을 구분하고 현재 카테고리 포함 이유를 설명한다. 충족 여부를 확인한 뒤 완료·다음 행동을 제공한다.
- 복구: 오프라인·충돌 시 최신 유지·현재 유지·병합 선택을 제공한다.
