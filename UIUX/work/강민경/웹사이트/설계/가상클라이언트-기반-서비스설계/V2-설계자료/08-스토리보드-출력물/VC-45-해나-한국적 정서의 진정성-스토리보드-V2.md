## 1. 상황 카드

- 사용 상황: 전통 요소와 한국적 분위기를 사용한 브랜드 페이지에서 장식인지 실제 브랜드 태도인지 판단한다.
- 목표: 문화적 이미지를 과잉 소비하지 않고 기록·재료·사용 태도와 연결된 표현을 확인한다.
- 핵심 과업: 브랜드 Hero → 시각 모티프 → 사용 이유 → 제품·화면 적용 → 한계
- 성공 기준: 한국적 정서가 어떤 설계 원칙에 연결됐는지 설명한다.
- 실패 방지: DAMORI 이름 의미나 전통성을 임의 확정하고 장식을 반복한다.

## 3. 상태 전이 규칙

- 오류·빈 결과: 현재 입력을 보존하고 재시도·조건 완화·이전 단계 중 하나를 제공한다.
- HOLD: 미확정 근거와 보류 사유를 표시하고 재개 위치를 저장한다.
- 완료: 한국적 정서가 어떤 설계 원칙에 연결됐는지 설명한다. 충족 여부를 확인한 뒤 완료·다음 행동을 제공한다.
- 복구: 오프라인·충돌 시 최신 유지·현재 유지·병합 선택을 제공한다.
