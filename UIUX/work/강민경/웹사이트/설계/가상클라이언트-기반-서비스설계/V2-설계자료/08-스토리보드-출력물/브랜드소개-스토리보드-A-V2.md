# 브랜드소개 스토리보드 A V2

VERSION=V2
PAGE_TYPE=브랜드소개

## 도출 목적

브랜드가 무엇을 추구하고 어떤 태도로 제품을 만드는지 설명한다

## Visual Layout

브랜드 선언 → 핵심 특징 → 재료·사용 원칙 → 제품 연결

## 콘텐츠·인터랙션

- 사용자는 스크롤·카드·필터·앵커를 통해 다음 섹션으로 이동한다.
- 정상·로딩·빈 결과·오류·완료 상태를 페이지 맥락에 맞게 표시한다.
- 반응형·접근성: 모바일 1열, 44px CTA, 순차 Heading, 키보드 탐색, 대체 텍스트.
- 브랜드 방향·특징·차별점·기록 철학·제품 원칙을 설명한다.
- 브랜드 주장마다 연결되는 제품·콘텐츠 근거를 표시한다.

## 상세 제작 명세

| 항목 | 제작 기준 |
|---|---|
| 콘텐츠 우선순위 | 1순위: 페이지 목적과 핵심 카피 / 2순위: 탐색·비교 정보 / 3순위: 근거·다음 행동 |
| 섹션 전환 | 앵커 이동·스크롤 위치·현재 섹션을 표시하고 모바일에서는 한 열 순서로 재배치한다. |
| UI 인터랙션 | 카드 선택·필터·아코디언·레일·CTA의 선택 상태와 다음 화면을 명시한다. |
| 데이터 정책 | 확정 근거가 없는 가격·효능·납기·환경 효과는 생성하지 않고 미정·준비 중·HOLD로 표시한다. |
| 5대 상태 | 기본·로딩·빈 결과·오류·완료 상태를 각 섹션에 정의한다. |
| 반응형 | PC·태블릿·모바일의 열 수, 이미지 비율, CTA 위치, 스크롤 방향을 정의한다. |
| 접근성 | 순차 Heading, Landmark, 키보드 포커스, 44px 조작 영역, 대체 텍스트, 7:1 대비를 적용한다. |
| 추적 | PAGE·SECTION·REQ·PRODUCT·CTA 이벤트를 연결하고 병합 시 ID를 보존한다. |
| QA 기준 | 목적 발견 → 탐색/비교 → 근거 확인 → 다음 행동의 전체 여정을 정상·오류·빈 결과로 검증한다. |
