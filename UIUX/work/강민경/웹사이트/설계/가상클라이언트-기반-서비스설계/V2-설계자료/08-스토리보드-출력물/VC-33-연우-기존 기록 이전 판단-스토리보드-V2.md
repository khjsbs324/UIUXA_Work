## 1. 상황 카드

- 사용 상황: 기존 기록 이전 판단 상황에서 사용자는 관련 정보를 탐색하고 선택 또는 보류를 판단합니다.
- 목표: 실제 지원 전에는 원본을 유지하며 새 기록만 시작하거나 보류한다.
- 핵심 과업: 진입 → 핵심 정보 확인 → 조건 비교
- 성공 기준: 실제 지원 전에는 원본을 유지하며 새 기록만 시작하거나 보류한다.
- 실패 방지: 외부 앱 연동·완전 이전·자동 중복 제거를 약속한다.

## 3. 상태 전이 규칙

- 오류·빈 결과: 현재 입력을 보존하고 재시도·조건 완화·이전 단계 중 하나를 제공한다.
- HOLD: 미확정 근거와 보류 사유를 표시하고 재개 위치를 저장한다.
- 완료: 실제 지원 전에는 원본을 유지하며 새 기록만 시작하거나 보류한다. 충족 여부를 확인한 뒤 완료·다음 행동을 제공한다.
- 복구: 오프라인·충돌 시 최신 유지·현재 유지·병합 선택을 제공한다.
