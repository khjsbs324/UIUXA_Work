## 1. 상황 카드

- 사용 상황: 스크린리더 Heading 목록과 Landmark로 메인·카테고리의 긴 구조를 빠르게 탐색한다.
- 목표: 반복 카드와 레일을 건너뛰고 원하는 브랜드·제품·카테고리 Section에 도달한다.
- 핵심 과업: Skip → Landmark → Heading → 제품 레일 설명 → 다음 Section
- 성공 기준: 모든 제품을 듣지 않고 원하는 Section과 제품군으로 이동한다.
- 실패 방지: 시각 순서와 DOM 순서가 다르거나 반복 카드가 탈출 불가능하다.

## 3. 상태 전이 규칙

- 오류·빈 결과: 현재 입력을 보존하고 재시도·조건 완화·이전 단계 중 하나를 제공한다.
- HOLD: 미확정 근거와 보류 사유를 표시하고 재개 위치를 저장한다.
- 완료: 모든 제품을 듣지 않고 원하는 Section과 제품군으로 이동한다. 충족 여부를 확인한 뒤 완료·다음 행동을 제공한다.
- 복구: 오프라인·충돌 시 최신 유지·현재 유지·병합 선택을 제공한다.
