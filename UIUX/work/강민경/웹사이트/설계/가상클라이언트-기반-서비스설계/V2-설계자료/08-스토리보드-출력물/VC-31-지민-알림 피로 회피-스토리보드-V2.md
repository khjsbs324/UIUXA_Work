## 1. 상황 카드

- 사용 상황: 알림 피로 회피 상황에서 사용자는 관련 정보를 탐색하고 선택 또는 보류를 판단합니다.
- 목표: 알림 설정 없이 기록을 완료하고 원하는 때 직접 돌아온다.
- 핵심 과업: 진입 → 핵심 정보 확인 → 조건 비교
- 성공 기준: 알림 설정 없이 기록을 완료하고 원하는 때 직접 돌아온다.
- 실패 방지: 놓친 기록 경고·연속 일수·죄책감 문구를 필수 사용한다.

## 3. 상태 전이 규칙

- 오류·빈 결과: 현재 입력을 보존하고 재시도·조건 완화·이전 단계 중 하나를 제공한다.
- HOLD: 미확정 근거와 보류 사유를 표시하고 재개 위치를 저장한다.
- 완료: 알림 설정 없이 기록을 완료하고 원하는 때 직접 돌아온다. 충족 여부를 확인한 뒤 완료·다음 행동을 제공한다.
- 복구: 오프라인·충돌 시 최신 유지·현재 유지·병합 선택을 제공한다.
