## 1. 클라이언트 목표와 근거

- 상황: 기록 경험이 적어 Analog·Digital·Template 차이를 모르며 많은 전문 용어가 첫 행동을 늦춘다.
- 목표: 가입·설정 없이 자신에게 맞는 시작 경로를 이해하고 부담 없는 하나를 고른다.
- 핵심 과업: 상황 예시 확인 → 방식 차이 이해 → 직접 선택 또는 질문형 도움 → 선택 수정
- 행동 흐름: 메인 진입 → 대표 상황 → 방식 비교 → 후보 선택 → 이유 확인 → 수정·건너뛰기
- 요구: 용어 설명, 대표 상황, 건너뛰기, 직접 선택, 추천 초안 수정.
- 성공 조건: 첫 경로를 고르고 그 이유를 자신의 말로 설명한다.
- 실패 조건: 성격 진단·유형 확정·필수 설정으로 선택권을 제한한다.

## 4. 예외·상태 전이

- 결과 없음: 용어 설명, 대표 상황, 건너뛰기, 직접 선택, 추천 초안 수정. 기준으로 재탐색·조건 완화·보류를 제공한다.
- 오류·로딩 실패: 확인된 내용과 현재 위치를 보존하고 실패 영역만 재시도한다.
- 미지원·미정: 사실·가설·HOLD를 분리하고 실행 가능한 기능처럼 표현하지 않는다.
- 중단·복귀: 선택값과 판단 맥락을 보존해 다시 시작할 수 있게 한다.
- 실패 방지: 성격 진단·유형 확정·필수 설정으로 선택권을 제한한다.
