## 1. 클라이언트 목표와 근거

- 상황: 모바일에서 제품 레일 첫 카드만 보고 세로 페이지의 한 카드로 오해한다.
- 목표: 가로로 더 볼 수 있음을 인지하고 현재 위치를 확인하며 다음 Section으로 빠져나온다.
- 핵심 과업: 레일 인지 → 스와이프·다음 버튼 → 카드 비교 → 전체 카테고리 이동
- 행동 흐름: Section 제목 → 다음 카드 일부 노출 → 수동 이동 → 현재 번호 → 전체 보기
- 요구: 레일 내부에서만 가로 이동, 이전·다음 또는 번호, 명확한 전체 보기 CTA.
- 성공 조건: 다음 제품 존재와 전체 카테고리 경로를 이해한다.
- 실패 조건: 자동 캐러셀, 무한 루프, 본문 가로 스크롤, 제스처 전용 조작.
- 연결 제품: PROD-021·PROD-051
- 연결 페이지·원문 ID: PAGE-001,PAGE-021

## 4. 예외·상태 전이

- 결과 없음: 레일 내부에서만 가로 이동, 이전·다음 또는 번호, 명확한 전체 보기 CTA. 기준으로 재탐색·조건 완화·보류를 제공한다.
- 오류·로딩 실패: 확인된 내용과 현재 위치를 보존하고 실패 영역만 재시도한다.
- 미지원·미정: 사실·가설·HOLD를 분리하고 실행 가능한 기능처럼 표현하지 않는다.
- 중단·복귀: 선택값과 판단 맥락을 보존해 다시 시작할 수 있게 한다.
- 실패 방지: 자동 캐러셀, 무한 루프, 본문 가로 스크롤, 제스처 전용 조작.
