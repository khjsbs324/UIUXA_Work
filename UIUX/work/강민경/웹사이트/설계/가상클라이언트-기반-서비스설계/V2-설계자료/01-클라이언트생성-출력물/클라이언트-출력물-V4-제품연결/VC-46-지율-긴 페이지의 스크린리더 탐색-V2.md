- 제작 목적: 반복 카드와 레일을 건너뛰고 원하는 브랜드·제품·카테고리 Section에 도달한다.
- 가상 Client 이름: 지율 (식별용 가상 이름이며 실제 조사 참여자 이름이 아님)
- 제공 자료·근거: VC-13의 접근성 기준과 긴 랜딩·대량 제품 구조의 교차 공백.
- 매체: 반응형 웹(Desktop·Mobile); 최종 산출물은 메인 랜딩·카테고리 서브·브랜드 소개로 연결.
- 우선순위: 높음; 후속 요구사항 분석에서 영향도 재평가
- 필요한 정보·기능: 반복 콘텐츠 Skip, 의미 있는 Section 제목, 레일 범위·현재 위치, 중복 대체 텍스트 제거.

## 2. Client 요청사항

1. 요청: 반복 콘텐츠 Skip, 의미 있는 Section 제목, 레일 범위·현재 위치, 중복 대체 텍스트 제거.
2. 중요도: 높음
3. 관련 자료·추적: `VC-13`, `CR-046`, PAGE-001·020·021, 전 제품 레일 후보.
4. 필요한 기능·과업: Skip → Landmark → Heading → 제품 레일 설명 → 다음 Section.
5. 성공 기준: 모든 제품을 듣지 않고 원하는 Section과 제품군으로 이동한다.
6. 실패·금지 기준: 시각 순서와 DOM 순서가 다르거나 반복 카드가 탈출 불가능하다.
7. 누락·중복 점검: 동일 요구는 후속 요구사항 분석에서 비교하되, 이 파일의 Client 관점 자체는 병합하지 않음.
