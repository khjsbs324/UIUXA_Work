## 2. Client 요청사항

1. 요청: 꾸민 메모 재사용, 직접 만든 요소의 조건부 저장, 원본·미리보기·적용 결과 분리.
2. 중요도: 높음
3. 관련 자료·추적: `SR-009~011`, PAGE-013~015 후보.
4. 필요한 기능·과업: 기록 작성 → 표현 추가 → 재사용 상태 저장 → 다음 기록에서 탐색 → 적용·수정 → 미리보기.
5. 성공 기준: 꾸미기 없이도 저장하고 필요할 때만 기존 자산을 적용·제거한다.
6. 실패·금지 기준: 저작권·검색·분류 방식을 확정하거나 특정 미감을 일반화한다.
7. 누락·중복 점검: 동일 요구는 후속 요구사항 분석에서 비교하되, 이 파일의 Client 관점 자체는 병합하지 않음.
