## 1. 가상 클라이언트 기본 정보

- 프로젝트 중심 주제: 통합 다이어리 브랜드 웹사이트의 브랜드·제품 탐색 경험.
- 제작 목적: 이미 확인한 브랜드·제품 정보와 현재 위치를 유지하고 실패 Section만 건너뛴다.
- 가상 Client 이름: 이솔 (식별용 가상 이름이며 실제 조사 참여자 이름이 아님)
- 제공 자료·근거: 긴 랜딩·시각 Hero·다수 제품 이미지와 Offline 상태의 교차 공백.
- 매체: 반응형 웹(Desktop·Mobile); 최종 산출물은 메인 랜딩·카테고리 서브·브랜드 소개로 연결.
- 우선순위: 가설 검증 후 반영
- 필요한 정보·기능: Section 단위 Error, 확인한 내용 보존, 이미지 비의존 탐색, 복귀 위치 유지.

1. 요청: Section 단위 Error, 확인한 내용 보존, 이미지 비의존 탐색, 복귀 위치 유지.

3. 관련 자료·추적: `CR-051`, PAGE-001·021, Error·Offline·Resume 상태 후보.

### 직관 패스

- 메인·카테고리·브랜드 소개의 제출 요구에서 직접 발생한 공백이라는 점은 명확하다.

- VC-41·48·50은 모두 약 200개 제품과 관련되지만 각각 전체 방향 감각, 대표 15개 선정, 다중 카테고리 중복을 검증한다.

- 신규 후보를 더 늘리기 전에 12명의 역할을 요구 ID로 고정해야 한다.

### 창의 패스

- 기존 39명은 기능·상태·제품 사실 검증이 강하지만 포트폴리오형 랜딩의 서사와 시각적 판단 관점이 약했다.
- VC-43은 `제품이 있으나 판매하지 않는 페이지`라는 이번 과제의 특수성을 분리해 유용하다.

- VC-49는 브랜드 페이지와 제품 페이지가 서로 다른 이야기로 갈라지는 위험을 잡는다.
- 향후 신규 후보는 인구통계 장식이 아니라 새로운 과업·판단·실패를 추가할 때만 가치가 있다.
- 추가 탐색 가능 축은 제품 명명 이해, 카테고리 변경 시 비교 유지, 브랜드 서사의 기억 가능성, 인쇄·발표 환경이다.

## 5. 계층·라벨·내비게이션

- 정보 계층: 브랜드 방향 → 저연결성 긴 페이지 복귀 → Client 요구 → 제품군/콘텐츠 → 다음 행동.
- 권장 라벨: `브랜드 소개`, `제품 카테고리`, `대표 제품`, `전체 제품군`, `근거·상태`; 같은 의미의 중복 라벨은 금지.
- 시작 화면: 메인 랜딩 페이지(PAGE-001)
- 예상 경로: 메인 랜딩 → 관련 Section → 메인 랜딩 페이지(PAGE-001) → 제품/콘텐츠 상세 → 원래 위치 복귀.
- 탐색·검색: 전역 메뉴, 페이지 내 Section 이동, 카테고리 필터·검색, 뒤로가기 시 선택·스크롤 위치 보존.
- 예외 경로: 근거 부족·이미지 실패·저연결성·결과 없음은 상태를 표시하고 재시도·건너뛰기·보류를 제공.

## 6. 화면 구성 초안

- Header: 브랜드 식별, 전역 메뉴, 현재 위치, 접근 가능한 Skip.
- Navigation: 메인 랜딩 페이지(PAGE-001)와 관련 카테고리/브랜드/메인 연결.
- Core: Section 단위 Error, 확인한 내용 보존, 이미지 비의존 탐색, 복귀 위치 유지.
- Auxiliary: 근거·판정·제품 상태·대체 텍스트·현재 위치·다음 행동.
- Footer: 브랜드 기본 정보, 페이지 이동, 자료·상태 고지.
- 반응형: Mobile에서 제품 레일은 레일 내부만 가로 이동하며 세로 페이지 스크롤을 방해하지 않음.
- 접근성: Heading·Landmark·키보드 포커스·대체 텍스트·오류 상태를 제품·콘텐츠와 함께 검증.
