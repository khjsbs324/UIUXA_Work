## 1. 가상 클라이언트 기본 정보

- 프로젝트 중심 주제: 통합 다이어리 브랜드 웹사이트의 브랜드·제품 탐색 경험.
- 제작 목적: 가입·설정 없이 자신에게 맞는 시작 경로를 이해하고 부담 없는 하나를 고른다.
- 가상 Client 이름: 다온 (식별용 가상 이름이며 실제 조사 참여자 이름이 아님)
- 제공 자료·근거: 기존 기록 방식 선택 공백을 채우는 합성 검증 관점.
- 매체: 반응형 웹(Desktop·Mobile); 최종 산출물은 메인 랜딩·카테고리 서브·브랜드 소개로 연결.
- 우선순위: 높음; 후속 요구사항 분석에서 영향도 재평가
- 필요한 정보·기능: 용어 설명, 대표 상황, 건너뛰기, 직접 선택, 추천 초안 수정.

## 2. Client 요청사항

1. 요청: 용어 설명, 대표 상황, 건너뛰기, 직접 선택, 추천 초안 수정.
2. 중요도: 높음
3. 관련 자료·추적: `ER-001~004`, PAGE-001~003·021 후보.
4. 필요한 기능·과업: 상황 예시 확인 → 방식 차이 이해 → 직접 선택 또는 질문형 도움 → 선택 수정.
5. 성공 기준: 첫 경로를 고르고 그 이유를 자신의 말로 설명한다.
6. 실패·금지 기준: 성격 진단·유형 확정·필수 설정으로 선택권을 제한한다.
7. 누락·중복 점검: 동일 요구는 후속 요구사항 분석에서 비교하되, 이 파일의 Client 관점 자체는 병합하지 않음.
