###### 가장 먼저 수정할 문제

- `대한민국 No.1`, `대한민국 최초`, 흡수율 `92.4%`, 구독자 `12,000명`, 만족도 `98.4%`, 평점 `4.95`, GMP 번호, EVE 비건, 생분해와 임상 수치가 근거 자료 없이 확정된 사실처럼 작성되어 있습니다.
- 건강기능식품의 흡수율, 진피 도달, 위 자극과 원료 효능은 의료·건강 관련 표현이므로 출처와 허용 표현을 확인하기 전 실제 주장으로 사용하면 안 됩니다.
- 7명의 가상 클라이언트를 `실명 검증 리뷰`, `실제 구독자`, `리얼 보이스`로 표현하고 있습니다. 가상 클라이언트는 설계 입력이므로 실제 후기처럼 전환하면 안 됩니다.
- 가격 `114,000원`, 할인 가격 `79,800원`, 일일 `3,800원`, 30% 할인, 배송과 자유 해지 조건도 확정된 사업 자료가 없다면 가안 또는 확인 필요로 표시해야 합니다.
- 실제 주문처럼 보이는 이름, 전화번호와 주소가 폼 기본값으로 입력되어 있습니다. 개인정보 오해를 피하도록 빈 값이나 `홍길동`, `010-0000-0000`, `서울시 ○○구` 같은 명확한 예시 값으로 변경해야 합니다.
- 문서에서 `5대 상태`, Focus Trap, ESC 닫기와 접근성을 약속하지만 일부 페이지는 기본·로딩·완료만 작성되어 있고 실제 HTML의 접근성 속성도 페이지마다 다릅니다.
- 브랜드 소개와 카테고리 모달의 `label`에는 연결할 `for`가 없고 닫기 버튼에는 이름을 제공하는 `aria-label`이 없습니다.
- 이미지 요소는 없고 이모지와 CSS 오브제로 제품을 표현하고 있어 현재는 기능형 와이어프레임에 가깝습니다. 디자인 완성도를 평가하려면 이미지 영역, 이미지 역할, 비율과 대체 텍스트 기준을 추가해야 합니다.

## 누적 총요약

허지민 학생은 A:FIT의 메인페이지, 브랜드 소개와 카테고리 페이지를 스토리보드 문서와 HTML로 함께 구축했습니다. 세 페이지의 역할과 공통 GNB 연결이 명확하고, 화면 ID·목적·상태·반응형 기준을 문서화한 점과 계산기·필터·모달·폼을 실제로 시험할 수 있게 구현한 점이 강점입니다.

현재 가장 중요한 수정은 시각 요소를 더 추가하는 것이 아니라 콘텐츠의 사실성과 역할을 정리하는 것입니다. 가상 클라이언트는 설계 근거이지 실제 후기 데이터가 아니며, No.1·최초·흡수율·임상·인증·구독자·평점·가격과 정책은 확인된 근거가 없으면 확정 표현으로 사용할 수 없습니다. 이 항목들을 가상 데이터 또는 확인 필요로 구분하고, 문서에서 약속한 상태·접근성을 실제 HTML과 일치시킨 뒤 디자인 완성도를 보강해야 합니다.

와이어프레임 3단계에서는 `메인페이지_와이어프레임_시안1.html`의 기존 기능과 7명의 클라이언트를 유지하면서 A:FIT의 브랜드·디자인 완성도 요구를 추가합니다. 현재 7대 라인업은 최소 15개의 고유 상품으로 확장하고, 대표 상품을 Hero·회사 철학·기술과 제작 과정·라이프스타일 섹션에서 서로 다른 이야기와 레이아웃으로 강조해야 합니다. 핵심 제품을 충분히 설명한 뒤 전체 상품 모음과 카테고리 이동 경로를 제공하고, 기존 기능과 새 브랜드 콘텐츠를 최종 병합합니다.
