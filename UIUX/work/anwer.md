# 학생 질문 답변

## 학생 이름

임연우

## 질문

“사용자가 기존 와이어프레임을 보완하기 위해 레퍼런스를 분류하고 분석한다는 내용이 있는 경우, 레퍼런스를 방대하게 찾기보다 사용자가 고른 형식과 가까운 레퍼런스를 찾고 사용성·심미성·무드 세 가지를 각각 분류·분석한다”는 내용을 기존 분류·분석 skill 파일에 넣어서 사용하는 것인지, 아니면 그 형식으로 별도의 분류·분석 파일을 작성해야 하는지 질문함.

## 답변

연우야 과부화 멈춰 ㅋㅋㅋ 전자가 맞아용~

지금 바로 저 형식으로 레퍼런스 분석 결과 파일을 따로 만들라는 뜻이 아니라, **기존에 사용하던 분류·분석 skill 파일 맨 아래에 저 내용을 규칙으로 추가**하라는 뜻이야.

그다음 수정한 skill을 사용해서 다시 실행하면, 레퍼런스를 무작정 많이 찾는 게 아니라 네가 원하는 사이트 형식과 가까운 사례를 찾고 결과를 **사용성·심미성·무드** 세 가지로 나눠서 분류하고 분석하게 만드는 거야.

정리하면 `기존 skill 내용은 그대로 유지 → 파일 아래에 새 규칙 추가 → 수정한 skill로 다시 실행 → 나온 결과 확인` 순서로 하면 됑!

## 참고한 내용

- 강사가 “기존에 있던 분석 파일에서 원하는 사이트 형식만 남길 수 있도록 파일을 추가 수정한다”고 설명한 내용
- “기존 내용을 수정하라는 말이 아님”이라고 기존 내용을 유지하도록 안내한 내용
- “파일 밑에 추가”라고 규칙을 넣을 위치를 구체적으로 안내한 내용
- 레퍼런스를 방대하게 찾기보다 학생이 선택한 사이트 형식과 가까운 사례를 찾도록 한 내용
- 레퍼런스를 `사용성`, `심미성`, `무드`의 세 기준으로 각각 분류하고 분석하도록 한 내용
- “분류 내용은 분류에, 분석 내용은 분석에”라고 결과의 역할을 구분하도록 안내한 내용

위 내용을 종합하여, 별도의 분석 결과 파일을 먼저 작성하라는 의미가 아니라 **기존 분류·분석 skill 파일 아래에 새로운 실행 규칙을 추가한 뒤 그 skill을 다시 사용하는 것**으로 답변했습니다.

# 학생 질문 답변

## 학생 이름

이은경

## 질문

와이어프레임을 단계별로 어떻게 진행하고 수정해야 하는지에 대한 피드백 요청.

## 답변

은경아, 와이어프레임은 아래 순서대로 단계별로 진행하면 돼.

### 와이어프레임 1단계

초반에 생성한 와이어프레임을 기반으로 초안을 생성해줘.

### 와이어프레임 2단계

최소 15개의 상품이 배치되도록 설계해줘.

### 와이어프레임 3단계

브랜드 정보와 최소 15개의 상품이 각 섹션에 조화롭게 배치될 수 있도록 수정해줘.

기존 클라이언트와 설계 내용은 삭제하거나 처음부터 다시 만들지 않고 그대로 유지하면 돼. 기존 설계 중심의 클라이언트 요구에는 **브랜드와 디자인 완성도를 중요하게 여기는 요구사항**을 추가하고, 회사의 철학, 기술력, 성과, 제작 과정 등 회사와 브랜드의 강점을 보여주는 내용도 보강해줘.

제품은 한곳에 모두 나열하지 말고, 중요한 제품을 관련된 이야기와 함께 여러 섹션에서 각각 강조해줘. 핵심 제품을 충분히 강조한 다음에는 전체 제품을 한눈에 볼 수 있는 모음 영역을 제공하면 돼.

반복적인 카드 구성만 사용하지 말고 큰 이미지, 화면 분할, 좌우 교차 배치, 에디토리얼형 구성 등 다양한 레이아웃을 적용해줘.

## 참고한 내용

- 초반에 생성한 와이어프레임을 기반으로 초안을 생성하는 1단계 진행 기준
- 최소 15개의 상품이 배치되도록 설계하는 2단계 진행 기준
- 브랜드 정보와 최소 15개의 상품을 각 섹션에 조화롭게 배치하는 3단계 수정 기준
- 기존 클라이언트와 설계 내용을 삭제하거나 처음부터 다시 만들지 않도록 한 유지 기준
- 브랜드와 디자인 완성도에 관한 요구사항과 회사·브랜드의 강점을 보여주는 내용을 보강하도록 한 기준
- 중요 제품을 여러 섹션에서 강조한 뒤 전체 제품 모음 영역을 제공하도록 한 기준
- 반복적인 카드 구성 외에 다양한 레이아웃을 적용하도록 한 기준
