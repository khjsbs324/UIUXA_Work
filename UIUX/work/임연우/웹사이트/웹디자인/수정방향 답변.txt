- 가장 가져오고 싶었던 특징: 메인 페이지의 이어지는 구성 , 너무 촘촘하지 않은 내용 구성으로 편하게 읽을 수 있음, 부드러운 색상

2.스밈의 첫인상
- 사용자가 처음 느꼈으면 하는 세 단어: 부드러움, 공감, 믿음
- 정체성 : 1. 조용하고 절제된 프리미엄 웰니스 브랜드 2. 부드러운 공감과 믿을을 보여주는 웰니스 브랜드 
- 감성, 기술, 쇼핑 중 우선순위: 1. 기술 2. 감성 3. 쇼핑
- 현재 완성본이 그 방향과 맞는지: 현재는 기술을 잘 보여주나 너무 주저리 주저리 느낌이라 사용자들이 읽기에 집중도가 떨어질 것 같은 느낌
- 맞지 않는다면 가장 큰 이유: 내용을 압축하여 간략하지만 명확하게 기술을 보여주고 싶지만 너무 길게 기술이나 스토리를 늘어놓음

- 이동해도 되는 요소: 키와 몸무게를 작성하여 추천 사이즈 확인하는 박스 / 
- 삭제해도 되는 요소: 반복되어 보여주는 기술력과 수치데이터 / hero부분 우측 착용 이미지 / 대표작에 있는 체험하기 버튼 
- 가장 먼저 눌렀으면 하는 버튼: 스밈의 시작 알아보기 

4.색과 표현
- 현재 색에서 마음에 드는 부분: 연한 핑크베이지 같은 배경색과 브라운 계열의 상단바 텍스트 
- 여성적으로 느껴지는 부분: 핑크 계열 색상 사용 , 전체적으로 볼 때 여성전문 브랜드 같은 느낌
- 원하는 색과 사진 분위기: 중성적인 그레이와 베이지가 섞인 색상 or 그린 , 차분한 느낌과 공감이 될만한 사진 분위기 
- 유지하고 싶은 글꼴과 버튼 모양: 둥근 느낌의 버튼 모양 , 전체적인 글꼴 유지 원함

- 300인 구간을 유지하거나 줄이고 싶은 이유: 짧고 간단한 형식으로 줄이고 싶습니다. 사용자들이 해당 상품 페이지에 들어와 리뷰 페이지를 통해 해당 상품에 대한 더 많은 후기들을 눈으로 확인할 수 있게 

6.레이아웃
- 반복된다고 느낀 구간 세 곳: 메인페이지에서 스밈의 철학을 간단히 보여주는 곳과 바로 아래 top3 상품을 보여주는 레이아웃이 동일한 지그재그 형태 / hero부분과 대표 상품, 임상 증명 섹션에 동일한 수치 데이터 반복 사용 / 동일한 카드 크기와 둥글기, 여백 사용 / 제목과 설명의 순서도 계속 같은 형식으로 보여주고 있음 
- 반복되어 보이는 이유: 여백도 거의 동일하고 사용되는 지그재그 형태가 동일하기 때문에 반복되어 보이고 거의 동일한 레이아웃때문에 내용 또한 비슷하게 느껴질 수 있을 것 같음 / 동일한 카드의 크기와 둥글기를 가지고 있기에 더 중요하게 보여지는게 없음 
- 꼭 유지할 구간 세 곳: hero , 철학, 3초 맞춤 처방
- 여백을 바꾸고 싶은 위치와 방법: 딱히 바꾸고 싶은 위치라기보다는 전체적으로 여유로운 여백을 사용하되 내용들의 흐름이 끊기지 않고 이어지면서 자연스레 아래로 스크롤하며 읽을 수 있도록 변경하고 싶어요 현재는 거의 동일한 여백을 사용하기도 하지만 적당한 여백을 사용하는 것 같아도 메인페이지의 흐름이 뭔가 잘 이어지지 않는 느낌이에요 

7.기능과 이야기
- 3초 맞춤 처방의 역할과 원하는 위치: 이 페이지에 왜 들어왔는지 다시 한 번 생각할 수 있도록 만들고 '내가 이런 부분이 불편한데 어떤걸 사용해야하는데 맞는거지?' 라는 고민을 빠르게 해결해줄 수 있고 결정을 못 해 사이트를 이탈하는 것을 방지하기 위해 / 메인페이지로 브랜드를 이해한 후 그래서 난 어떤걸 사용해야할까 라는 고민이 생길 때 쯤 (제 생각은 대표 상품이 나온 뒤에 배치하는 것이 어떨까 싶긴 해용 )
- 이 기능은 상품 구매를 할 때 고민을 덜어줄 수 있는 보조 역할의 기능이에요 ! 사용자가 브랜드를 이해하고 나의 몸 상태에 대해 맞는 제품을 고민할 때 사용해야해요 , 처방이라는 단어를 사용해도 괜찮을 것 같아요 내 몸 상태에 맞는 알 맞는 제춤을 찾아주는 것이기에 처방이라는 단어가 의료쪽 언어로 들릴지 몰라도 이 부분에서만큼은 잘 어울린다고 생각해요 
- 브랜드 스토리에 남길 세 장면: 문제 , 해결 방법, 이 해결로 나온 결과물 
- 메인과 브랜드 스토리의 역할을 어떻게 나누고 싶은지: 메인은 '아 이런 브랜드고 이런 제품이 있구나' 라는 느낌을 받을 수 있도록 / 브랜드 스토리는 '아 이래서 이런 브랜드가 생겼고 이렇게 해결을 했구나' 라는 느낌을 받을 수 있도록 [브랜드 스토리는 메인의 보조역할 같은 느낌 , 메인을 읽다가 궁금해진 사람들이 추가로 브랜드를 이해할 수 있도록 돕는 페이지]

8.이미지
- 가장 잘 맞는 이미지 세 개: 문제 제시에 보여주는 이미지들외에는 좀 허술하고 부족하다는 느낌이 들어요 
- 가장 맞지 않는 이미지 세 개: 문제제기 이후에 나오는 문제해결 부분 [ZIG-ZAG 3 PILLARS] / 실제 착용 전·후 상체 정렬 비교 / 브랜드 이야기 hero 이미지 
- 중심으로 보여주고 싶은 이미지 종류: hero 부분에 처음으로 보여지는 이미지, 문제를 해결 했을 때 보여지는 이미지 , 착용 전 후 이미지 
- 수치를 보여주는 섹션에서는 제품을 위주로 (원단 확대), 문제점과 해결을 보여주는 섹션에서는 통증 문제 이미지와 실제 착용 이미지를 
- 사진 분위기는 따뜻한 자연광 이미지와 실제 후기 사진을 바탕으로 통일 
- 메인 첫 화면 오른쪽 이미지 : 착용 장면으로 수정 or 제거

- 이유: 색과 분위기가 잘 잡히면 나머지 카드 부분이나 다른 부분에서도 분위기에 맞춰 수정할 수 있을 것 같아요 
- 두 번째: 반복되는 카드 구조 
- 이유: 반복되면 지루하기도 하고 눈에 잘 들어오지 않을 수 있기에 수정 / 통일감이 들어 눈에 편안함을 줄 수 있을 것 같지만 너무 동일한 카드가 계속 이어지면 동일 내용이라고 생각할 수도 있을 것 같아요 
- 세 번째: 이미지 
- 이유: 알맞은 시작자료를 추가해주면 사용자들이 볼 때 어떤게 먼저 눈에 들어올지 파악할 수 있을 것 같아요
