## 피드백 내역

#### 피드백 배경

##### 2026-08-13

- 현재 와이어프레임은 기능과 설계 구성이 중심인 상태입니다.
- 강사가 GDWEB 참고 사례 3건과 이미지를 전달하며 브랜드 표현과 시각적 전개를 보강하도록 지도했습니다.
- 학생은 “브랜드를 더 돋보이게 만들면 되는지”, “클라이언트부터 다시 생성해야 하는지 또는 와이어프레임만 수정해야 하는지” 질문했습니다.
- 수정한 병합 와이어프레임을 제출하며 결과가 대체로 괜찮게 나온 것 같다고 판단했고, 강사도 개선 결과를 긍정적으로 확인했습니다.
- 다음 단계로 현재 와이어프레임의 부족한 부분을 설계 관점과 디자인 관점에서 더 세밀하게 분석하고 이를 보완할 클라이언트를 추가하도록 지도했습니다.

##### 2026-08-14

- 학생이 레퍼런스를 사용성·디자인·감성별로 분석할 때 분류 기준을 직접 정해도 되는지 질문했습니다.
- 학생은 자신이 원하는 사용성·디자인·감성과 관련된 레퍼런스만 남기고 나머지를 제외하는 방식이 맞는지 확인했습니다.
- 강사는 학생이 원하는 레퍼런스만 남기는 방향이 맞다고 확인했습니다.
- 학생이 분류·분석 skill 파일에 원하는 기준을 추가해 레퍼런스를 선별한 뒤 가상 클라이언트 생성 단계부터 다시 진행하면 되는지 질문했습니다.
- 학생은 원하는 와이어프레임 방향을 사용성, 디자인, 감성의 지향 사항과 지양 사항으로 나누어 정리했습니다.
- CLI가 분석 결과를 자연스러운 전환 동선, 직관적인 네이밍, 3대 페이지 체계와 웜 미니멀리즘 감성으로 다시 정리했으며, 이 내용을 클라이언트 요구사항에 입력해도 되는지 질문했습니다.

#### 강사 피드백

##### 2026-08-13

###### 와이어프레임 1단계

- 초반에 생성한 와이어프레임 기반으로 초안 생성

###### 와이어프레임 2단계

- 최소 15개 상품이 배치되도록 설계

###### 와이어프레임 3단계

- 브랜드 정보와 최소 15개 상품 배치가 각 섹션에 조화롭게 배치될 수 있도록 수정

- 기존 클라이언트와 설계 내용을 삭제하거나 처음부터 다시 만들지 않음
- 기존 설계 중심 클라이언트 요구에 **브랜드와 디자인 완성도를 중요하게 여기는 요구사항** 추가
- 회사의 철학, 기술력, 성과, 제작 과정 등 회사와 브랜드의 강점을 보여주는 내용 보강
- 제품을 한곳에 모두 나열하지 말고 중요한 제품은 관련된 이야기와 함께 여러 섹션에서 각각 강조
- 핵심 제품을 충분히 강조한 다음 전체 제품을 한눈에 볼 수 있는 모음 영역 제공
- 반복적인 카드 구성만 사용하지 말고 큰 이미지, 화면 분할, 좌우 교차 배치, 에디토리얼형 구성 등 다양한 레이아웃 적용

###### 와이어프레임 4단계

- 3단계에서 진행한 와이어프레임을 기반으로 아래 내용 진행

- 기존 내용을 빼는 방식보다 필요한 요구와 콘텐츠를 추가하는 방향으로 진행
- 현재 와이어프레임의 부족한 부분을 **설계 관점**과 **디자인 관점**으로 나누어 최대한 구체적으로 분석
- 분석된 부족한 부분을 보완할 수 있는 요구를 가진 클라이언트를 추가하고, 이를 기반으로 설계와 와이어프레임을 최종 병합
- 레퍼런스는 방대하게 수집하지 않고 학생이 선택한 사이트 형식과 가까운 사례 탐색
- 레퍼런스는 **사용성이 좋은 사이트**, **디자인이 좋은 사이트**, **감성을 잘 보여주는 사이트**로 각각 구분하여 분석
- 기존 분석 파일의 내용을 수정하거나 삭제하지 않고, 파일 아래에 레퍼런스 탐색 기준과 분류·분석 규칙 추가
- `분류`에는 레퍼런스를 사용성·심미성·무드로 나눈 결과를 작성하고, `분석`에는 각 사례에서 무엇을 참고하고 보완할지 작성
- 최종 메인페이지에는 필요한 정보를 충분히 담되, 레퍼런스별 장점을 목적에 맞게 선택하여 반영

- 설정한 기준에 맞는 레퍼런스만 남기고 관련성이 낮은 레퍼런스 제외
- 원하는 방향이 여러 가지라면 후보를 모두 유지한 뒤 더 좋은 방향 비교·검토

- 기존 가상 클라이언트와 설계 내용을 삭제하지 않고 분석 결과에서 필요한 요구사항만 추가·보완

- 차갑고 위압적인 메디컬 테크와 지나치게 역동적인 스포츠 피트니스 분위기 지양
- 샌드 베이지와 오프화이트 중심의 웜 미니멀리즘, 라이프스타일, 모던 웰니스와 에디토리얼 여백 지향
- CLI가 정리한 사용성 장점인 하드셀링 없는 자연스러운 전환 동선, 직관적인 체감형 한글 네이밍, 카테고리별 명확한 탐색 경로와 0원 30일 무료 시착을 요구사항에 반영
- CLI가 정리한 디자인·IA 장점인 회사 소개, 대표 제품 Top 3 지그재그 조명, 300인 실착 후기로 이어지는 3단 구조와 메인, 28개 상품 카탈로그 서브, 브랜드 이야기 서사의 3대 페이지 체계를 요구사항에 반영
- CLI가 정리한 감성 장점인 차가운 병원 톤 배제, 샌드 베이지와 오프화이트의 톤온톤, 편안한 일상 웰니스 룩북과 에디토리얼 여백을 요구사항에 반영
- 분석 내용은 한 문단으로 입력하지 않고 사용성 요구사항, 페이지 구성 요구사항, 디자인·감성 요구사항과 지양 사항으로 구분하여 입력

#### 학생의 질문·반응 및 이해도

##### 2026-08-13

- 학생이 수정 방향을 다음과 같이 정리했습니다.
  - 브랜드가 돋보이게 구성
  - 회사 이야기 추가
  - 다양한 레이아웃 활용
- 클라이언트 문서를 새로 만드는 것과 기존 문서에 추가하는 것의 차이를 질문했습니다.
- 강사의 설명 후 “이해했다”고 답하여 큰 방향은 인지한 것으로 확인됩니다.
- 병합 결과를 스스로 긍정적으로 평가했고 강사도 결과가 괜찮다고 확인했습니다.
- 다음 단계 설명을 들은 뒤 “점점 어렵다”고 반응하여, 설계·심미성·무드의 분류 기준과 클라이언트 요구로 전환하는 과정을 단계별로 설명할 필요가 있습니다.

##### 2026-08-14

- 사용성·디자인·감성의 구체적인 분류 기준을 본인이 정해도 되는지 질문했습니다.
- 원하는 레퍼런스만 남기고 나머지를 제외하는 방식으로 이해한 내용을 확인했습니다.
- 강사의 설명을 들은 뒤 직접 진행해 보겠다고 답했습니다.

- 수정한 분석 skill을 기준으로 가상 클라이언트 생성부터 다시 진행하는지 확인하여 전체 작업 순서를 점검했습니다.

- 감성에서는 차가운 메디컬 테크와 역동적인 스포츠 분위기를 제외하고 웜 미니멀리즘, 라이프스타일과 모던 웰니스를 원하는 방향으로 정리했습니다.
- 원하는 방향을 비교적 구체적으로 설명할 수 있는 단계에 도달했으며, 다음에는 이 기준을 클라이언트 요구와 실제 화면 구조로 정확히 연결하는 작업이 필요합니다.
- 강사가 정리한 방향을 가상 클라이언트 요구사항으로 그대로 사용해도 된다고 안내하자 학생은 “넹”이라고 답하여 진행 방법을 이해했습니다.

#### 작업 수정 지침

##### 2026-08-13

1. 기존 클라이언트 문서에 브랜드·회사 서사와 디자인 중심 요구사항을 추가합니다.
2. 추가 요구사항이 화면 설계서의 어느 섹션에 반영되는지 연결해 표시합니다.
3. 대표 제품 2~3개를 선정하고 각 제품의 역할, 사용자 가치, 강조 위치를 정합니다.
4. 대표 제품별 강조 섹션과 전체 제품 모음 섹션을 구분합니다.
5. 기존 예약·사이즈·시착 기능을 브랜드 경험 안에 자연스럽게 연결합니다.
6. 수정된 문서를 기준으로 와이어프레임의 순서, 크기, 여백, 이미지 비중과 레이아웃을 변경합니다.
7. 현재 와이어프레임의 부족한 점을 설계 관점과 디자인 관점으로 나누어 작성합니다.
8. 부족한 부분을 보완할 수 있는 클라이언트 요구사항을 기존 문서에 추가합니다.
9. 선택한 사이트 형식과 가까운 레퍼런스만 찾아 사용성·심미성·무드로 각각 분류합니다.
10. 각 분류의 사례를 분석한 뒤 클라이언트, 설계 문서와 와이어프레임에 반영하여 최종 병합합니다.

##### 2026-08-14

1. 원하는 사용성·디자인·감성의 세부 기준을 직접 작성합니다.
2. 각 기준에 부합하는 레퍼런스만 남기고 관련성이 낮은 자료는 제외합니다.
3. 원하는 방향이 여러 가지라면 후보를 성급하게 하나로 줄이지 않고 함께 비교합니다.
4. 후보별 장점과 적용 가능성을 검토해 더 적합한 방향을 선택합니다.
5. 판단이 어려운 후보와 기준은 강사에게 질문한 뒤 확정합니다.
