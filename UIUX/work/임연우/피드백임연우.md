###### 와이어프레임 4단계

- 기존 내용을 빼는 방식보다 필요한 요구와 콘텐츠를 추가하는 방향으로 진행
- 현재 와이어프레임의 부족한 부분을 **설계 관점**과 **디자인 관점**으로 나누어 최대한 구체적으로 분석
- 분석된 부족한 부분을 보완할 수 있는 요구를 가진 클라이언트를 추가하고, 이를 기반으로 설계와 와이어프레임을 최종 병합
- 레퍼런스는 방대하게 수집하지 않고 학생이 선택한 사이트 형식과 가까운 사례 탐색
- 레퍼런스는 **사용성이 좋은 사이트**, **디자인이 좋은 사이트**, **감성을 잘 보여주는 사이트**로 각각 구분하여 분석
- 기존 분석 파일의 내용을 수정하거나 삭제하지 않고, 파일 아래에 레퍼런스 탐색 기준과 분류·분석 규칙 추가
- `분류`에는 레퍼런스를 사용성·심미성·무드로 나눈 결과를 작성하고, `분석`에는 각 사례에서 무엇을 참고하고 보완할지 작성
- 최종 메인페이지에는 필요한 정보를 충분히 담되, 레퍼런스별 장점을 목적에 맞게 선택하여 반영

첫 화면에서 수치 영역과 여러 버튼을 빼는 판단은 맞아 `스밈 3대 대표작 알아보기`는 대표 상품 구간으로 이동하고 0.1mm·38g·99.8%가 반복되는 수치 묶음은 기술 근거 구간으로 이동해줘 첫 화면에서는 `스밈의 시작 알아보기` 하나가 가장 먼저 보이면 돼

첫 화면 정리 기준은
- 반드시 유지: 큰 브랜드 문장, 짧은 설명, `스밈의 시작 알아보기`, 착용 장면의 중심 시각 영역
- 다른 구간으로 이동: 3대 대표작 버튼, 0.1mm·38g 설명과 별도 수치 영역
- 삭제 가능: 99.8% 배지의 첫 화면 반복, 같은 내용을 다시 말하는 보조 문장과 버튼
- 첫 번째 행동: `스밈의 시작 알아보기`

[색과 표현]

기본 배경은 따뜻한 회색처럼 중성적인 색으로 두고 글자는 짙은 회색으로 접근해봐 그린을 사용하고 싶다면 기술 근거나 선택된 버튼처럼 중요한 지점에만 낮은 채도의 그린을 보조색으로 사용하면 돼 핑크 베이지는 넓은 배경보다 아주 작은 구간에 남기거나 빼도 돼

- 글자색: 짙은 회색
- 강조색: 낮은 채도의 그린 한 가지
- 축소할 색: 분홍빛이 강한 살구색과 여러 종류의 연한 강조색


[수치와 기술 정보]
모든 수치가 가상 브랜드 설정이라고 명확하게 답한 것은 중요해 이 경우 0.1mm·38g·99.8%를 실제 검증 결과나 임상 증명처럼 보여주면 안 되고 포트폴리오를 보는 사람도 어디까지가 기획 설정인지 알 수 있어야 해
0.1mm와 38g은 제품의 얇기와 무게를 설명하는 기획 사양으로 남길 수 있어 하지만 99.8%는 `완벽 은폐`처럼 시험으로 검증된 성능으로 읽히기 때문에 근거가 없는 상태에서는 메인의 핵심 신뢰 수치로 사용하기 어려워 99.8%를 꼭 유지하고 싶다면 `목표 은폐율 설정`처럼 기획 상태가 드러나야 하고 그렇지 않으면 대표 수치에서 제외하는 편이 안전해

300인 임상 증명 구간을 줄이겠다는 방향도 맞아 다만 실제 참여자와 후기가 없는 상태라면 리뷰 페이지에서 더 많은 실제 후기를 확인할 수 있다고 안내해서는 안 돼 현재는 `사용자 검증 구성안`이나 `착용 경험 예시`처럼 기획 단계로 보여주고 실제 리뷰가 준비된 뒤 리뷰 페이지와 연결하면 돼
수치 적용 기준은 아래와 같아
- 메인에서 우선 남길 수치: 0.1mm와 38g
- 조건부 유지: 99.8%는 근거 또는 목표 수치라는 상태가 있을 때만 사용
- 축소할 내용: 300인 임상 증명과 4.9점 후기의 큰 독립 구간
- 표현 방법: `검증 완료`가 아니라 `제품 기획 사양`, `설계 목표`, `사용자 검증 구성안`처럼 현재 상태 표시
- 기술의 역할: 첫 화면을 지배하는 장식이 아니라 문제 해결을 믿게 하는 짧은 근거


[반복 레이아웃과 여백]
철학과 대표 상품이 같은 지그재그 구조로 보이고 카드의 크기·둥글기·여백과 제목 순서가 반복된다는 분석은 정확해 같은 모양은 같은 종류의 정보를 비교할 때 유용하지만 목적이 다른 구간까지 같은 모양으로 만들면 사용자는 모두 비슷한 내용으로 받아들일 수 있어

철학은 브랜드의 생각을 이해하는 구간이고 대표 상품은 제품을 비교하는 구간이므로 같은 지그재그 틀을 반복할 필요가 없어 철학은 큰 문장과 하나의 장면이 이어지는 방식으로 정리하고 대표 상품은 세 상품의 이름·사용 상황·핵심 차이를 같은 기준으로 비교할 수 있게 정리하는 편이 좋아

여백도 모든 구간에 같은 크기로 넣기보다 관계가 가까운 제목과 설명은 붙이고 이야기가 바뀌는 지점에서만 더 크게 띄워줘 그러면 페이지가 카드 단위로 끊기는 대신 하나의 이야기 안에서 장면이 전환되는 느낌을 만들 수 있어
카드는 아래처럼 목적에 따라 나눠 사용하면 돼
- 카드 유지: 대표 상품 비교, 전체 상품 목록, 맞춤 찾기의 선택 항목
- 카드 축소: 수치, 임상 설정, 기술 설명과 브랜드 약속
- 카드 없이 구성: 첫 화면, 브랜드 철학, 문제 → 해결 → 결과의 핵심 장면
- 둥근 형태 유지: 버튼과 실제 선택·비교가 필요한 카드
- 무료 시착 행동: 상단과 여러 구간에서 반복하지 않고 대표 상품 뒤 또는 마지막 제안처럼 필요한 위치에 제한

[3초 맞춤 기능]
3초 맞춤 기능을 브랜드의 핵심 기술이 아니라 상품 선택을 돕는 보조 기능으로 정한 것은 맞아 사용자가 브랜드와 대표 상품을 먼저 이해한 뒤 `그래서 나에게 맞는 제품은 무엇인지` 고민할 때 제공해야 한다는 이유도 분명해

따라서 대표 상품 뒤에 배치하겠다는 방향으로 진행하면 돼 앞에서 세 상품의 차이를 이해한 사용자가 자신의 불편과 상황을 선택하고 관련 상품으로 이어질 수 있어 기능이 메인 이야기 중간을 끊는 문제도 줄어들어



[브랜드 스토리]
문제 → 해결 방법 → 결과물이라는 세 장면을 고른 것은 모두의매트를 1순위로 선택한 이유와 잘 연결돼 다만 실제 화면을 수정할 때는 세 장면이 무엇인지 조금 더 구체적으로 정해야 해

스밈에서는 오래 앉아 일하는 사람의 불편을 첫 장면으로 두고 얇고 가벼운 코어웨어를 설계하게 된 과정을 두 번째 장면으로 두며 그 결과로 만들어진 대표 제품과 일상 착용 경험을 세 번째 장면으로 두면 돼 가상 수치가 중심이 되기보다 사용자의 문제와 설계 과정과 제품 결과가 연결되는 것이 중요해

메인에서는 세 장면을 짧게 요약하고 브랜드 스토리에서는 시작 계기, 설계 기준과 과정의 내용을 자세히 설명해줘 같은 내용을 반복하는 것이 아니라 메인은 궁금증을 만들고 브랜드 스토리는 그 궁금증에 답하는 역할로 나누면 돼


[이미지 방향]
문제 제기 이미지는 현재 스밈과 가장 잘 맞고 문제 해결 지그재그, 착용 전후 비교와 브랜드 이야기 첫 화면 이미지는 현재 표현이 부족하다고 판단한 것으로 이해했어 여기에서 구분할 것은 이미지의 역할이 필요 없는 것인지 현재 이미지의 분위기와 표현이 맞지 않는 것인지야

연우의 답변을 종합하면 착용 전후와 문제 해결 장면의 역할은 필요하지만 현재 표현이 맞지 않는 쪽에 가까워 따라서 해당 영역을 삭제하기보다 첫 화면의 일상 착용 장면, 문제와 해결이 연결되는 장면, 원단과 제품 구조가 보이는 장면으로 역할을 다시 정해줘

따뜻한 자연광과 실제 생활에 가까운 분위기로 통일하겠다는 방향은 괜찮은데 과하면 AI처럼 보일 수 있어
이미지 우선순위는 아래처럼 정리하면 돼
- 첫 번째: 첫 화면의 자연스러운 일상 착용 장면
- 두 번째: 직장인의 불편과 착용 후 달라지는 사용 경험
- 세 번째: 제품 형태와 0.1mm 원단 구조를 설명하는 가까운 장면
- 보조 사용: 통증을 직접 강조하는 이미지와 착용 전후 비교
- 통일 기준: 따뜻한 자연광, 낮은 채도, 과장되지 않은 실제 생활 분위기


[수정 우선순위]
연우는 색과 분위기를 첫 번째로 선택했지만 현재 문제를 해결하려면 정보 위계와 첫 화면 정보량을 먼저 정하는 것이 좋아 색부터 바꾸면 같은 카드와 긴 설명에 새 색만 입혀져 다시 `색만 바뀐 느낌`이 생길 수 있기 때문이야

첫 번째는 첫 화면과 전체 페이지의 정보 우선순위를 정하는 일이야 큰 문장, 짧은 설명, 중심 착용 장면과 첫 번째 버튼만 남기고 기술은 신뢰 근거로 뒤에서 설명하는 기준을 먼저 확정해줘

두 번째는 반복되는 카드 구조와 구간 역할을 나누는 일이야 철학은 이야기 장면, 대표 상품은 비교, 맞춤 찾기는 선택이라는 서로 다른 목적이 화면에서도 구분되어야 해

1.첫 화면의 큰 문장, 짧은 설명, 착용 장면과 `스밈의 시작 알아보기`만 우선 남기기
2.기술은 첫인상이 아니라 믿음을 만드는 근거라는 기준으로 수치와 설명의 위치·분량 정리하기
3.철학, 대표 상품, 수치와 맞춤 찾기에서 카드가 필요한 구간과 카드 없이 보여줄 구간 나누기
4.3초 맞춤 기능을 대표 상품 뒤에 두고 `처방`보다 의료 오해가 적은 이름으로 정리하기
5.문제 → 해결 과정 → 제품 결과의 세 장면을 메인 요약과 브랜드 스토리 상세로 나누기
6.첫 화면 착용 장면, 문제·해결 장면과 제품 구조 이미지의 역할을 정하고 같은 사진 분위기로 통일하기
7.따뜻한 회색과 오트 베이지를 기본으로 하고 낮은 채도의 그린만 강조색으로 적용하기
8.0.1mm·38g·99.8%와 300인·4.9점이 모두 가상 설정이라는 상태가 화면에서 구분되는지 마지막으로 확인하기

정리하면 연우가 정한 1순위 레퍼런스와 `부드러움·공감·믿음`이라는 방향은 유지하면 돼, 기술을 없애는 것이 아니라 기술이 감성적인 첫인상과 경쟁하지 않도록 뒤에서 믿음을 만드는 근거로 사용하는 부분을 먼저 첫 화면의 정보와 구간별 역할을 줄인 뒤 반복 카드, 이미지와 색을 순서대로 정리해서 다시 보여주면댕
