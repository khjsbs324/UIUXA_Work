📐 카테고리 페이지 화면 설계 명세서 (Storyboard Specification)

1. Salomon 사용성 벤치마크 기반 다차원 탐색 아키텍처

  • 4대 축 교차 검색: 소속 컬렉션(5종), 운동 시점(Pre/In/Post 단일), 제형(스틱/미스트/젤 등 다중), 기능(쿨링/방수/세범 등 다중) 실시간 교차 필터링.
  • 실시간 조건 칩 요약: 사용자가 선택한 조건을 상단 요약 바에 칩 형태로 누적 노출하고 개별 [X] 해제 지원.
  • 2종류 스마트 리셋: 컬렉션 유지 상세 필터 초기화 vs 전체 16종 초기화 지원.

2. 16종 하드웨어 정합성 & 카드 균일화 시스템

  • 높이 균일화: CSS Flex/Grid 구조 및 2줄 클램프 아코디언([상세 펼쳐보기 ▼])으로 카드 그리드 불일치 완전 해소.
  • 아이소메트릭 벡터 렌더: 이모지를 배제하고 동일 45° 쿼터뷰 회색조 렌더 실루엣 표준 적용.
  • 정합성 동기화: #01~#16 전 SKU의 역할(대표 Core / 파생 Ext / 보조 Supp), 가격, 용량, 추천 상황 100% 일치.

3. 스펙 횡단 비교 시스템 (Difference Highlighting)

  • 하단 플로팅 바: 최대 3개 담김 실시간 집계 및 원클릭 모달 오픈.
  • 차이값 우선 강조: 선택된 기어 간 서로 다른 스펙 항목을 ● 차이 배지와 볼드 하이라이트로 직관적 비교 지원.
  • 모바일 접근성: 첫 번째 기준 항목 열 115px sticky 고정 및 상단 상품명 행 상시 고정.

4. 4단계 상태 뷰 출시 알림 모달

  • 개인정보 동의: 15% 얼리버드 혜택 안내 및 필수 동의 체크박스 유효성 검사.
  • 4종 상태 뷰: 입력 폼(Form) ➔ 처리 중(Submitting) ➔ 성공(Success) ➔ 오류 및 [다시 시도하기 ↺].
