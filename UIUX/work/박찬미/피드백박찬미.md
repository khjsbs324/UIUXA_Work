현재 HALO 와이어프레임은 플래그십 히어로, 5대 스포츠 컬렉션 탭, 상품 카드, Pre/In/Post 운동 루틴, 카라비너 컬러 선택과 출시 알림 모달까지 기본적인 쇼핑 흐름이 잘 잡혀 있어 특히 운동 전·중·후로 제품 사용 상황을 나눈 부분과 스포츠 종목별로 상품을 탐색하도록 만든 방향은 HALO의 특징으로 계속 유지하면 돼

다만 현재 화면에는 `5대 스포츠 컬렉션 20종`이라고 적혀 있지만 실제로 보이는 상품은 러닝 컬렉션의 4개뿐이야 나머지 컬렉션 탭도 화면상 버튼만 있고 각 컬렉션의 상품이나 콘텐츠는 구현되어 있지 않아 포트폴리오에서 상품 구성이 충분하다는 것을 보여주려면 숫자만 20종이라고 쓰는 것이 아니라 최소 15개 이상의 상품이 실제 화면 구조 안에서 확인되어야 해

또 현재 브랜드 정보는 히어로에 있는 `노터치 쿨링 선케어 기어`, `손 오염 0%`, `-4.2℃ 미스트` 같은 기능 문구에 집중되어 있어 사용자는 HALO가 어떤 문제에서 출발한 브랜드인지, 왜 스포츠 활동에 특화된 선케어를 만드는지, 어떤 기술과 제작 기준을 가지고 있는지까지는 알기 어려워 상품을 추가하는 것과 함께 브랜드의 철학, 기술력, 성과와 제작 과정도 화면에 보강해야 해
현재 만들어 둔 아래 요소는 삭제하거나 처음부터 다시 만들지 말고 그대로 유지해 줘
- HALO 로고와 GNB
- 플래그십 히어로와 출시 알림 CTA
- 5대 스포츠 컬렉션 탭
- 러닝 상품 카드 4개
- Pre/In/Post 3단계 운동 루틴
- 카라비너 컬러 선택
- 출시 알림 신청 모달

새 화면을 만드는 방식이 아니라 기존 구조 사이에 브랜드와 제품을 설명하는 섹션을 추가하고, 지금 있는 상품 영역을 실제 15개 이상의 상품이 보이는 구조로 확장하면 돼
클라이언트 요구사항에도 기존 기능과 설계 요구를 삭제하지 말고 아래 내용을 추가해 줘
HALO는 상품 탐색 기능뿐 아니라 브랜드의 철학, 스포츠 환경에 특화된 기술력, 제품 개발 과정과 검증 가능한 성과가 시각적으로 드러나는 높은 디자인 완성도를 요구한다 최소 15개 이상의 상품을 스포츠 컬렉션별로 구성하되, 핵심 제품은 브랜드 이야기와 실제 사용 장면 속에서 먼저 강조하고 전체 상품은 별도의 모음 영역에서 한눈에 비교할 수 있도록 설계 진행한 다음에 반복적인 카드만 사용하지 않고 큰 이미지, 화면 분할, 좌우 교차 배치와 에디토리얼형 레이아웃을 활용하면 돼



현재 설정한 5대 스포츠 컬렉션을 유지하면 상품을 한곳에 몰아넣지 않고 자연스럽게 15개 이상 구성할 수 있어 각 컬렉션에 최소 3개씩 배치하면 총 15개가 돼
예:
1.시티 러닝·마라톤: 퀵 스틱, 쿨링 미스트, 풀코스 스타터 팩
2.트레일 하이킹·클라이밍: 고지대 UV 스틱, 방수 선 밤, 트레일 리커버리 패치
3.서핑·수상 액티브: 워터프루프 선 스틱, 솔트 리셋 미스트, 아쿠아 스포츠 키트
4.테니스·라운딩: 페이스 선 쿠션, 암 슬리브 선케어, 코트 리프레시 미스트
5.피트니스·크로스핏: 세범 컨트롤 스틱, 쿨다운 바디 미스트, 짐백 미니 키트

기존 러닝 상품 4개를 유지하고 싶다면 다른 4개 컬렉션에 3개씩 추가해 총 16개로 구성해도 돼 중요한 것은 파일 제목이나 설명에만 상품 수를 적는 것이 아니라 상품명, 사용 상황, 핵심 기능, 용량 또는 구성과 가격이 실제 카드나 상세 영역에 나타나는 거야
각 상품은 이름만 다르게 만들지 말고 스포츠 환경에 따른 차이가 보여야 해 러닝은 휴대성과 빠른 덧바름, 하이킹은 강한 자외선과 장시간 지속, 수상 스포츠는 방수, 테니스와 라운딩은 얼굴·팔 노출, 피트니스는 땀과 유분 관리처럼 컬렉션별 기준을 분명히 해 줘



상품 15개를 한꺼번에 카드로 나열하기 전에 HALO가 왜 만들어졌는지 설명하는 브랜드 섹션을 추가해 줘 이 부분은 긴 회사 소개문보다 큰 이미지와 짧은 문장으로 구성하는 것이 좋아
예:
- 브랜드 시작: 운동 중 선크림을 다시 바르기 어렵고 손이 오염되는 문제에서 출발
- 브랜드 철학: 운동의 흐름을 멈추지 않는 선케어
- 핵심 기술: 카라비너 결합, 노터치 도포, 쿨링 미스트와 스포츠 환경별 지속 설계
- 제작 과정: 스포츠 상황 관찰, 용기와 결합 방식 테스트, 땀·물·휴대성 검증, 최종 제품 제작
- 성과: 실제로 확인할 수 있는 테스트 결과, 인증, 사용자 조사 또는 개발 횟수만 사용

현재 사용한 `손 오염 0%`, `-4.2℃`, `끈적임 0%` 같은 수치는 시각적으로 강조하기 좋지만 실제 근거가 있는지 반드시 확인해야 해 확인되지 않은 수치는 확정된 성과처럼 사용하지 말고 `테스트 예정`, `목표 수치` 또는 일반적인 기능 설명으로 조정해 줘

중요 제품을 전체 상품 카드 안에만 넣으면 다른 상품과 동일하게 보여서 HALO의 대표성이 약해져 핵심 제품 3개 정도를 선정하고 브랜드 이야기나 사용 상황과 연결해 화면 중간중간에 따로 강조해 줘
예:
-핵심 제품 1: 카라비너 퀵 스틱 — 러닝 중 멈추지 않고 3초 안에 덧바르는 상황을 큰 이미지로 표현
-핵심 제품 2: 쿨링 미스트 — 활동 중 올라간 피부 열감을 식히는 장면과 분사 구조를 화면 분할로 설명
-핵심 제품 3: 스포츠 스타터 키트 — Pre/In/Post 루틴에 어떤 제품이 연결되는지 타임라인 형태로 표현

같은 제품을 반복해서 보여주더라도 매번 같은 카드로 복사하지 말고 역할을 다르게 해야 해 첫 번째는 대표 이미지와 메시지, 두 번째는 기술 구조, 세 번째는 실제 사용 상황이나 루틴을 보여주는 방식으로 바꿔 줘, 핵심 제품과 브랜드 이야기를 충분히 보여준 다음 페이지 후반부에 전체 상품을 한눈에 비교할 수 있는 `Shop All` 영역을 제공해주고
전체 상품 모음에서는 다음 정보가 일관되게 보여야 해
예:
- 상품 이미지 영역
- 컬렉션명과 상품명
- 적용 스포츠 또는 사용 시점
- 핵심 기능 한 줄
- 용량이나 세트 구성
- 가격
- 상세 보기 또는 출시 알림 버튼

5대 컬렉션 탭은 유지하되 `전체`, `러닝`, `하이킹`, `수상`, `테니스·라운딩`, `피트니스` 필터로 확장하면 좋아 탭을 눌렀을 때 실제 상품이 바뀌는 상태도 설계해 줘 와이어프레임 단계라면 각 탭에서 어떤 상품이 노출되는지 명세 패널에라도 명확히 기록해야 해
현재는 히어로를 제외하면 상품 카드 4개, 루틴 카드 3개와 명세 패널처럼 작은 박스가 반복돼 정보 구조는 이해되지만 포트폴리오 화면에서는 전체가 비슷한 밀도로 보여 디자인의 강약이 부족해질 수 있어
아래 예시처럼 같이 섹션마다 다른 레이아웃을 사용하면 좋지
- 브랜드 철학: 화면 전체 너비의 큰 스포츠 이미지와 한 문장 카피
- 핵심 제품 1: 왼쪽에 큰 제품 이미지, 오른쪽에 문제·해결·기능 설명
- 핵심 제품 2: 이미지와 설명 위치를 반대로 배치한 좌우 교차 구성
- 기술력: 제품 단면도와 카라비너 결합 구조를 보여주는 화면 분할
- 제작 과정: 관찰 → 설계 → 테스트 → 제작 순서의 가로 타임라인
- 성과: 검증 가능한 숫자와 짧은 설명을 크게 보여주는 지표 영역
- Pre/In/Post 루틴: 카드 3개가 아니라 사용자의 운동 흐름을 따라가는 에디토리얼형 스토리
- 전체 상품: 비교가 쉬운 규칙적인 그리드

모든 구역을 다르게 만들 필요는 없지만, 브랜드 이야기와 핵심 제품은 큰 이미지와 여백을 사용하고 전체 상품 비교가 필요한 곳에서만 반복 카드 그리드를 사용하는 것이 좋아

정리하면 현재 설계의 핵심인 `플래그십 히어로 + 5대 스포츠 컬렉션 + Pre/In/Post 루틴 + 출시 알림`은 그대로 유지하고, 그 사이에 HALO의 브랜드 철학, 기술, 제작 과정과 핵심 제품의 이야기를 추가하면 돼 최소 15개 상품은 5개 컬렉션에 나누어 실제로 보이게 만들고, 핵심 제품을 먼저 다양한 레이아웃으로 강조한 뒤 마지막 전체 상품 모음에서 비교할 수 있도록 정리해 줘
1.기존 클라이언트 요구사항과 현재 와이어프레임 구성 보존
2.브랜드와 디자인 완성도를 중요하게 여기는 요구사항 추가
3.현재 5대 스포츠 컬렉션 기준으로 최소 15개 상품 목록 확정
4.브랜드 철학, 기술력, 제작 과정과 검증 가능한 성과 자료 정리
5.핵심 제품 3개 선정 및 각 제품의 강조 목적 결정
6.큰 이미지, 화면 분할과 좌우 교차 레이아웃으로 핵심 제품 섹션 추가
7.Pre/In/Post 루틴에 대표 제품 연결

2 컬렉션 탭과 상세 필터의 관계
현재 컬렉션 탭을 누르면 위의 스포츠 장면과 아래 상품 수가 함께 바뀌지만 두 영역이 떨어져 있어 사용자는 탭이 장면만 바꾼 것인지 상품 목록까지 제한한 것인지 바로 알기 어려워
- 상품 필터 상단에 `현재 컬렉션: 전체` 또는 `현재 컬렉션: 시티 러닝 & 마라톤` 상태 칩 추가
- 컬렉션 탭 선택 시 결과 수와 현재 조건을 화면 읽기 프로그램에도 전달
- 선택된 컬렉션, 운동 단계, 제형과 기능을 한 줄의 `현재 선택 조건` 영역에 모아 표시
- 조건별 칩에 개별 삭제 버튼 제공
- 현재 `필터 전체 초기화`는 운동 단계·제형·기능만 초기화하고 컬렉션은 유지하므로 버튼 이름을 `상세 필터 초기화`로 변경
- 별도로 `컬렉션 포함 전체 초기화`를 추가해 사용자가 초기화 범위를 선택할 수 있게 구성
- 컬렉션 탭을 누른 뒤 상품 영역으로 자동 이동시키기보다 상단에 `선택 컬렉션 상품 4개 보기` 버튼을 제공해 사용자가 원할 때 이동하도록 설계


3 필터의 선택 방식과 결과 상태
현재 각 필터 그룹에서 한 항목만 선택할 수 있는데 버튼 모양만 보면 여러 조건을 동시에 선택할 수 있는 것처럼 보일 수 있어 한 개만 고르는 단일 선택인지 여러 개를 조합하는 다중 선택인지 규칙을 화면에서 먼저 알려줘
- 운동 단계는 한 번에 하나만 선택하는 방식 또는 Pre와 In을 함께 고르는 다중 선택 중 하나로 확정
- 다중 선택을 사용할 경우 `Pre + In`처럼 현재 조합을 표시하고 같은 그룹의 `전체`와 개별 값이 동시에 선택되지 않도록 처리
- 결과 없음 화면에 현재 선택 조건과 `이 조건만 해제`, `상세 필터 초기화`, `전체 초기화` 세 가지 복구 방법 제공
- 필터 적용 전, 적용 후, 결과 없음과 데이터 오류 상태를 각각 설계
- 모바일에서 가로로 넘기는 필터 칩의 마지막 항목이 있다는 것을 알 수 있도록 오른쪽 흐림 처리나 다음 칩 일부 노출 적용

4 비교 기능의 중복과 동기화
상품 카드에서 비교함을 선택하면 상단 개수와 하단 비교 바가 함께 바뀌는 기본 흐름은 작동해 하지만 상세 모달의 `비교함 담기`는 같은 상품이 이미 있어도 다시 추가할 수 있어 한 상품이 두 번 들어가는 문제가 남아 있어

- 비교 배열에 상품 번호가 이미 있으면 추가하지 않고 `이미 비교함에 담긴 기어입니다` 상태 안내 표시
- 상품 카드 체크박스, 상세 모달 버튼, 상단 개수, 하단 비교 바와 비교표를 하나의 선택 상태로 연결
- 상세 모달 버튼을 `비교함 담기`와 `비교함에서 빼기`로 상태에 따라 변경
- 0개일 때 상단 비교 버튼을 비활성화하거나 상품 선택 안내 표시
- 1개일 때는 비교표를 바로 열기보다 `한 개를 더 선택하면 차이를 비교할 수 있습니다` 안내와 추천 비교 상품 제공
- 2개와 3개일 때만 비교표 실행
- 3개가 찼을 때 다른 카드의 비교 선택을 비활성화하고 `최대 3개` 이유를 가까운 위치에 표시
- 비교 바의 제거 버튼과 접기 영역을 `span`이나 클릭 가능한 `div`가 아닌 키보드로 실행 가능한 `button`으로 변경
- 모바일에서는 비교 바를 기본 접힘 상태로 시작하고 기기 하단 안전 영역을 포함해 본문과 버튼을 가리지 않도록 처리

5 모바일 탐색과 긴 페이지 관리
390픽셀 화면에서 문서 전체 가로 넘침은 없었고 햄버거 메뉴, 상품 보기 전환과 비교표 가로 스크롤도 확인됐어 이 부분은 유지하면 돼 다만 제작 과정, 컬렉션 탭, 세 종류 필터와 상품 캐러셀처럼 가로로 움직이는 영역이 한 페이지에 여러 번 나오므로 사용 방법을 눈치로만 알아야 하는 문제가 있어

- 제작 과정은 `1 / 4`, 이전·다음 버튼과 진행 막대를 함께 제공
- 컬렉션 탭은 선택한 탭이 화면 중앙에 오도록 이동하고 탭 아래에 선택 결과 수 표시
- 상품 캐러셀은 카드 한 장과 다음 카드 일부가 보이게 하고 `1 / 16` 위치 정보와 스크롤 스냅 적용
- 모바일의 기본 보기 방식을 `전체 세로 펼침`으로 할지 `스와이프 카드`로 할지 한 가지로 정하고 사용자가 마지막 선택을 유지할 수 있게 처리
- 제목은 2~3줄 이내, 본문은 한 문단 3~4줄 이내로 조절하고 긴 스펙은 상세 보기로 이동
- 터치 대상은 최소 44픽셀 정도로 확보하고 고정 헤더와 비교 바가 앵커 이동 위치를 가리지 않도록 여백 적용
- 360픽셀, 390픽셀, 768픽셀과 1440픽셀에서 각각 확인


6 출시 알림 신청 흐름

현재 `1-Click 출시 알림`이라고 표시되지만 성함, 전화번호, 이메일과 개인정보 동의를 모두 요구하므로 실제 사용 방식과 이름이 맞지 않아 개인정보 동의도 처음부터 선택된 상태라 사용자가 직접 동의했다는 의미가 약해져

- 세 정보를 모두 받을 경우 이름을 `빠른 출시 알림 신청`으로 변경
- 정말 1-Click으로 만들 경우 이메일 또는 휴대폰 한 가지 정보만 먼저 받고 나머지는 선택 입력으로 전환
- 개인정보 필수 동의는 기본 선택을 해제
- 수집 항목, 이용 목적, 보유 기간과 동의 거부 시 제한을 바로 확인할 수 있게 제공
- 이름·전화번호·이메일 라벨을 입력 칸과 코드로 연결
- 전화번호 형식, 이메일 형식, 동의 누락과 서버 오류를 입력 칸 가까이 표시
- 신청 중, 성공, 중복 신청, 실패와 다시 시도하기 상태를 각각 설계
- 현재는 실제 전송 기능이 없는 화면 예시이므로 성공 문구도 `쿠폰이 발송되었습니다`보다 `신청 완료 화면 예시`로 표시



[2 배치 관점에서 부족한 부분과 보완 요구]

1 전체 리듬과 정보 밀도
현재는 굵은 테두리, 작은 라벨, 수치, 카드와 설명 상자가 거의 모든 섹션에서 반복돼 기능 설계는 잘 보이지만 브랜드의 속도와 냉각 감정은 아직 문장으로 설명되는 비중이 커 실제 렌더링에서도 Hero부터 16종 목록까지 대부분 사각형 카드로 이어져 섹션의 크기는 달라도 인상이 비슷해 보여
- 브랜드 서사 구간은 `메시지 1개 + 큰 이미지 1개 + 근거 1~2개 + 행동 1개`를 기본 단위로 설정
- 16종 상품과 비교 영역에서는 정보 밀도를 높이고 Hero, 철학, 대표 제품과 제작 과정에서는 카드 수를 줄이지 않고 상세 정보를 펼쳐보기 안으로 이동
- 섹션 사이에 여백만 늘리지 말고 흰 배경, 짙은 배경, 풀 너비 이미지와 제품 근접 이미지가 교차하도록 리듬 구성
- 같은 굵기의 테두리를 모든 요소에 사용하지 않고 핵심 행동, 정보 그룹과 보조 설명의 선 굵기를 구분

2 Hero
Hero에는 핵심 문장, 상세 설명, 가상 데이터 안내, 두 개의 행동, 제품 색상 선택과 여러 수치가 동시에 있어 첫 화면에서 무엇을 먼저 보아야 하는지 분산돼
- 배경 또는 오른쪽 영역에 아스팔트 열기 속 러너가 카라비너 퀵 스틱을 한 손으로 사용하는 큰 장면 배치
- `운동의 흐름을 멈추지 않는 선케어 기어`를 가장 큰 한 문장으로 유지
- 보조 문장은 `멈추지 않고 꺼내고, 묻히지 않고 덧바르는 노터치 쿨링 기어`처럼 한 줄로 압축
- -4.2℃와 3초 같은 수치는 근거 상태가 정리된 1~2개만 우선 노출하고 나머지는 제품 상세로 이동
- 색상 선택은 제품 렌더가 실제로 바뀌는 기능과 연결하고 선택 결과를 텍스트로도 표시
- 흑백 장면 안에서 쿨링 지점, 미스트 입자 또는 체온 변화선에만 아이스 블루를 사용

3 브랜드 철학
- 현재 선언문과 노터치·쿨링 메커니즘은 유지
- 설명 상자 여러 개보다 운동을 멈추고 손을 닦는 기존 장면과 HALO로 바로 덧바르는 장면을 하나의 대비 이미지로 구성
- 제품 철학은 `멈춤 제거`, `손 오염 제거`, `열기 전환` 세 가지 가치로 정리
- 알루미늄 카라비너, 롤러 헤드와 미스트 입자를 각각 실제 소재 근접 이미지 또는 기술 도해로 보여주기
- 철학 문단 아래의 수치는 검증 상태가 확정된 두 개만 남기고 나머지 설명은 기술 구간에서 확인하게 구성

4 대표 제품 01 퀵 스틱
- 제품 정면 렌더, 카라비너 체결 구조와 러닝 중 한 손 사용 장면의 세 가지 시각 자료를 서로 다른 역할로 배치
- 제품 렌더에서는 알루미늄, 무광 블랙과 롤러 헤드 재질을 강조
- 구조 도해에서는 `가방 체결 → 한 손 분리 → 노터치 도포 → 다시 체결` 순서를 네 단계로 표시
- 실제 사용 장면에서는 손가락 위치와 도포 방향이 보이게 크롭
- 스펙은 SPF, 용량, 사용 단계와 가상 성능 목표만 우선 표시하고 전체 데이터는 상세 보기로 연결

5 대표 제품 02 쿨링 미스트
- 퀵 스틱과 같은 레이아웃을 그대로 반복하지 말고 이미지와 정보의 좌우 위치를 반대로 배치한 현재 방향 유지
- 노즐 360도 분사, 미세 입자와 피부에 닿기 전 기화되는 흐름을 넓은 기술 도해로 표현
- 사이클링이나 야외 훈련 중 제품을 거꾸로 들어 분사하는 장면으로 퀵 스틱과 사용 차이를 구분
- 퀵 스틱의 단단한 금속 질감과 달리 미스트는 공기, 입자, 속도선과 차가운 투명감을 강조
- 두 대표 제품 모두 `기능`, `사용 장면`, `근거 상태`의 순서를 같게 해 비교 가능한 구조 유지

6 제작 과정
현재 네 개의 큰 가로 카드와 이전·다음 버튼을 추가한 것은 좋은 방향이야 여기에 각 단계의 시각 목적을 더 구체적으로 적어줘

- Discover는 인터뷰 사진, 땀·오염 위치 지도와 멈춤 행동 기록
- Engineer는 카라비너 CAD 분해도, 노즐 단면과 프로토타입 반복
- Validate는 러닝, 수상 스포츠와 피트니스 현장 시험 장면 및 가상 테스트 계획
- Certify는 실제 인증이 아니라면 인증 준비 항목과 확인 절차를 보여주는 체크리스트
- 모바일에서는 한 카드씩 보이고 현재 단계가 몇 번째인지 항상 표시
- 자동 재생보다 사용자가 직접 넘기는 방식을 기본으로 하고 동작을 줄이는 설정을 존중

7 Pre/In/Post 루틴
- 세 개의 독립 카드가 아니라 같은 사용자의 한 운동이 이어지는 장면으로 구성
- Pre는 출발 전 방수 젤과 피부 준비, In은 퀵 스틱과 미스트로 흐름을 유지하는 장면, Post는 세정·쿨링·회복으로 마무리
- 단계마다 제품을 여러 개 나열하기보다 대표 행동 하나와 추천 기어 1~2개를 우선 표시
- 단계 색상은 Pre의 중성 회색, In의 아이스 블루 또는 라임, Post의 낮은 채도 블루처럼 기능을 구분하되 브랜드 색 범위를 벗어나지 않게 제한
- 마지막에 `내 운동 단계로 기어 찾기`를 연결해 아래 필터의 운동 단계가 자동 선택되도록 구성

8 5대 컬렉션
- 현재 탭, 종목별 큰 장면, 대표 기술, 파생 기준과 대표 제품의 구조 유지
- 러닝은 아스팔트 열기와 휴대, 하이킹은 먼지·고도와 마찰, 수상 스포츠는 물방울과 염분, 테니스·골프는 반사광과 그립, 피트니스는 땀과 기구 마찰이라는 장면 기준 설정
- 컬렉션마다 대표 색을 새로 많이 만들지 말고 같은 흑백 기반에서 보조색의 위치와 사진 재질만 변화
- 대표 제품은 큰 제품 렌더로, 파생 제품은 작은 관계도나 단계 흐름으로 연결

## 누적 총요약
