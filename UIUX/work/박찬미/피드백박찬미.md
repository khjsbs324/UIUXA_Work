다만 현재 화면에는 `5대 스포츠 컬렉션 20종`이라고 적혀 있지만 실제로 보이는 상품은 러닝 컬렉션의 4개뿐이야 나머지 컬렉션 탭도 화면상 버튼만 있고 각 컬렉션의 상품이나 콘텐츠는 구현되어 있지 않아 포트폴리오에서 상품 구성이 충분하다는 것을 보여주려면 숫자만 20종이라고 쓰는 것이 아니라 최소 15개 이상의 상품이 실제 화면 구조 안에서 확인되어야 해

또 현재 브랜드 정보는 히어로에 있는 `노터치 쿨링 선케어 기어`, `손 오염 0%`, `-4.2℃ 미스트` 같은 기능 문구에 집중되어 있어 사용자는 HALO가 어떤 문제에서 출발한 브랜드인지, 왜 스포츠 활동에 특화된 선케어를 만드는지, 어떤 기술과 제작 기준을 가지고 있는지까지는 알기 어려워 상품을 추가하는 것과 함께 브랜드의 철학, 기술력, 성과와 제작 과정도 화면에 보강해야 해
현재 만들어 둔 아래 요소는 삭제하거나 처음부터 다시 만들지 말고 그대로 유지해 줘
- HALO 로고와 GNB
- 플래그십 히어로와 출시 알림 CTA
- 5대 스포츠 컬렉션 탭
- 러닝 상품 카드 4개
- Pre/In/Post 3단계 운동 루틴
- 카라비너 컬러 선택
- 출시 알림 신청 모달

새 화면을 만드는 방식이 아니라 기존 구조 사이에 브랜드와 제품을 설명하는 섹션을 추가하고, 지금 있는 상품 영역을 실제 15개 이상의 상품이 보이는 구조로 확장하면 돼
클라이언트 요구사항에도 기존 기능과 설계 요구를 삭제하지 말고 아래 내용을 추가해 줘
HALO는 상품 탐색 기능뿐 아니라 브랜드의 철학, 스포츠 환경에 특화된 기술력, 제품 개발 과정과 검증 가능한 성과가 시각적으로 드러나는 높은 디자인 완성도를 요구한다 최소 15개 이상의 상품을 스포츠 컬렉션별로 구성하되, 핵심 제품은 브랜드 이야기와 실제 사용 장면 속에서 먼저 강조하고 전체 상품은 별도의 모음 영역에서 한눈에 비교할 수 있도록 설계 진행한 다음에 반복적인 카드만 사용하지 않고 큰 이미지, 화면 분할, 좌우 교차 배치와 에디토리얼형 레이아웃을 활용하면 돼



현재 설정한 5대 스포츠 컬렉션을 유지하면 상품을 한곳에 몰아넣지 않고 자연스럽게 15개 이상 구성할 수 있어 각 컬렉션에 최소 3개씩 배치하면 총 15개가 돼
예:
1.시티 러닝·마라톤: 퀵 스틱, 쿨링 미스트, 풀코스 스타터 팩
2.트레일 하이킹·클라이밍: 고지대 UV 스틱, 방수 선 밤, 트레일 리커버리 패치
3.서핑·수상 액티브: 워터프루프 선 스틱, 솔트 리셋 미스트, 아쿠아 스포츠 키트
4.테니스·라운딩: 페이스 선 쿠션, 암 슬리브 선케어, 코트 리프레시 미스트
5.피트니스·크로스핏: 세범 컨트롤 스틱, 쿨다운 바디 미스트, 짐백 미니 키트

기존 러닝 상품 4개를 유지하고 싶다면 다른 4개 컬렉션에 3개씩 추가해 총 16개로 구성해도 돼 중요한 것은 파일 제목이나 설명에만 상품 수를 적는 것이 아니라 상품명, 사용 상황, 핵심 기능, 용량 또는 구성과 가격이 실제 카드나 상세 영역에 나타나는 거야
각 상품은 이름만 다르게 만들지 말고 스포츠 환경에 따른 차이가 보여야 해 러닝은 휴대성과 빠른 덧바름, 하이킹은 강한 자외선과 장시간 지속, 수상 스포츠는 방수, 테니스와 라운딩은 얼굴·팔 노출, 피트니스는 땀과 유분 관리처럼 컬렉션별 기준을 분명히 해 줘



상품 15개를 한꺼번에 카드로 나열하기 전에 HALO가 왜 만들어졌는지 설명하는 브랜드 섹션을 추가해 줘 이 부분은 긴 회사 소개문보다 큰 이미지와 짧은 문장으로 구성하는 것이 좋아
예:
- 브랜드 시작: 운동 중 선크림을 다시 바르기 어렵고 손이 오염되는 문제에서 출발
- 브랜드 철학: 운동의 흐름을 멈추지 않는 선케어
- 핵심 기술: 카라비너 결합, 노터치 도포, 쿨링 미스트와 스포츠 환경별 지속 설계
- 제작 과정: 스포츠 상황 관찰, 용기와 결합 방식 테스트, 땀·물·휴대성 검증, 최종 제품 제작
- 성과: 실제로 확인할 수 있는 테스트 결과, 인증, 사용자 조사 또는 개발 횟수만 사용

현재 사용한 `손 오염 0%`, `-4.2℃`, `끈적임 0%` 같은 수치는 시각적으로 강조하기 좋지만 실제 근거가 있는지 반드시 확인해야 해 확인되지 않은 수치는 확정된 성과처럼 사용하지 말고 `테스트 예정`, `목표 수치` 또는 일반적인 기능 설명으로 조정해 줘

중요 제품을 전체 상품 카드 안에만 넣으면 다른 상품과 동일하게 보여서 HALO의 대표성이 약해져 핵심 제품 3개 정도를 선정하고 브랜드 이야기나 사용 상황과 연결해 화면 중간중간에 따로 강조해 줘
예:
-핵심 제품 1: 카라비너 퀵 스틱 — 러닝 중 멈추지 않고 3초 안에 덧바르는 상황을 큰 이미지로 표현
-핵심 제품 2: 쿨링 미스트 — 활동 중 올라간 피부 열감을 식히는 장면과 분사 구조를 화면 분할로 설명
-핵심 제품 3: 스포츠 스타터 키트 — Pre/In/Post 루틴에 어떤 제품이 연결되는지 타임라인 형태로 표현

같은 제품을 반복해서 보여주더라도 매번 같은 카드로 복사하지 말고 역할을 다르게 해야 해 첫 번째는 대표 이미지와 메시지, 두 번째는 기술 구조, 세 번째는 실제 사용 상황이나 루틴을 보여주는 방식으로 바꿔 줘, 핵심 제품과 브랜드 이야기를 충분히 보여준 다음 페이지 후반부에 전체 상품을 한눈에 비교할 수 있는 `Shop All` 영역을 제공해주고
전체 상품 모음에서는 다음 정보가 일관되게 보여야 해
예:
- 상품 이미지 영역
- 컬렉션명과 상품명
- 적용 스포츠 또는 사용 시점
- 핵심 기능 한 줄
- 용량이나 세트 구성
- 가격
- 상세 보기 또는 출시 알림 버튼

5대 컬렉션 탭은 유지하되 `전체`, `러닝`, `하이킹`, `수상`, `테니스·라운딩`, `피트니스` 필터로 확장하면 좋아 탭을 눌렀을 때 실제 상품이 바뀌는 상태도 설계해 줘 와이어프레임 단계라면 각 탭에서 어떤 상품이 노출되는지 명세 패널에라도 명확히 기록해야 해
현재는 히어로를 제외하면 상품 카드 4개, 루틴 카드 3개와 명세 패널처럼 작은 박스가 반복돼 정보 구조는 이해되지만 포트폴리오 화면에서는 전체가 비슷한 밀도로 보여 디자인의 강약이 부족해질 수 있어
아래 예시처럼 같이 섹션마다 다른 레이아웃을 사용하면 좋지
- 브랜드 철학: 화면 전체 너비의 큰 스포츠 이미지와 한 문장 카피
- 핵심 제품 1: 왼쪽에 큰 제품 이미지, 오른쪽에 문제·해결·기능 설명
- 핵심 제품 2: 이미지와 설명 위치를 반대로 배치한 좌우 교차 구성
- 기술력: 제품 단면도와 카라비너 결합 구조를 보여주는 화면 분할
- 제작 과정: 관찰 → 설계 → 테스트 → 제작 순서의 가로 타임라인
- 성과: 검증 가능한 숫자와 짧은 설명을 크게 보여주는 지표 영역
- Pre/In/Post 루틴: 카드 3개가 아니라 사용자의 운동 흐름을 따라가는 에디토리얼형 스토리
- 전체 상품: 비교가 쉬운 규칙적인 그리드

모든 구역을 다르게 만들 필요는 없지만, 브랜드 이야기와 핵심 제품은 큰 이미지와 여백을 사용하고 전체 상품 비교가 필요한 곳에서만 반복 카드 그리드를 사용하는 것이 좋아

정리하면 현재 설계의 핵심인 `플래그십 히어로 + 5대 스포츠 컬렉션 + Pre/In/Post 루틴 + 출시 알림`은 그대로 유지하고, 그 사이에 HALO의 브랜드 철학, 기술, 제작 과정과 핵심 제품의 이야기를 추가하면 돼 최소 15개 상품은 5개 컬렉션에 나누어 실제로 보이게 만들고, 핵심 제품을 먼저 다양한 레이아웃으로 강조한 뒤 마지막 전체 상품 모음에서 비교할 수 있도록 정리해 줘
