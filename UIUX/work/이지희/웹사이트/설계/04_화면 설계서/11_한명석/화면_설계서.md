## 1. 5대 레이아웃 원형 기반 UI 구조 차별화 분석 (한명석 맞춤)

### 1.0 전사 공통 필수 3대 페이지 템플릿 탑재 기준 (제1원칙)
본 화면 설계서는 다음 **3대 공통 필수 페이지 템플릿을 기본 골격으로 전면 탑재**한 후, 한명석 클라이언트의 고유 킬러 기능을 결합하여 설계되었습니다:
1. **① 메인 페이지 (`W11-HOME`)**: 상단바(글로벌 GNB 헤더), 메인 캔버스(히어로/대표 큐레이션), 하단 푸터(사업자 정보, 고객센터, KTR 3無 공인 인증)
2. **② 상품 페이지 (`W11-CATALOG`)**: 20개 이상(20종 전수) 맞춤 상품 도감 및 6대 LNB 카테고리 필터
3. **③ 브랜드 페이지 (`W11-ABOUT`)**: 브랜드 세계관, 조향/추출 철학, 원료 원산지 및 헤리티지 스토리텔링


본 설계서는 획일화된 템플릿 나열을 탈피하여, **한명석 클라이언트의 5대 방문 목적과 고유 페르소나**에 최적화된 **`A-5 전통 시니어 고대비 큰글씨형 (Senior Well-Aging)`** 원형을 채택하여 설계되었습니다.

### 1.1 5대 독립적 서비스 이용 목적 정의 (Use Cases 1~5)

#### 📌 목적 1: 80℃ 황금온도 침출 발효티 처방 & 20pt 큰글씨 간편 주문
- **핵심 이동 경로**: `W11-HOME ➔ W11-CATALOG ➔ W11-DRAWER ➔ W11-DONE`
- **서비스 상세 로직**: 20pt 고대비 글씨로 지리산 야생 발효티 효능 확인 후 1-Click 큰 버튼 결제

#### 📌 목적 2: 혈당/혈압 안심 성분표 검증 & 60일 시니어 건강 정기구독
- **핵심 이동 경로**: `W11-HOME ➔ W11-CATALOG ➔ W11-DRAWER ➔ W11-DONE`
- **서비스 상세 로직**: 식약처 공인 무당/무카페인 성적서 확인 후 60일 주기 우체국 안심 배달 신청

#### 📌 목적 3: 전통 오동나무 상자 3D 패키징 & 한지 붓글씨 감사 카드 선물
- **핵심 이동 경로**: `W11-HOME ➔ W11-BUILD ➔ W11-DRAWER ➔ W11-DONE`
- **서비스 상세 로직**: 3D 오동나무 상자에 지리산 발효티를 담고 정갈한 붓글씨 감사 문구를 작성하여 예단/선물 발송

#### 📌 목적 4: 아침 10분 다도 묵상 가야금 음향 & 붓글씨 출석 도장
- **핵심 이동 경로**: `W11-HOME ➔ W11-RITUAL ➔ W11-COMM ➔ W11-DONE`
- **서비스 상세 로직**: 가야금과 맑은 물소리 음향을 들으며 10분간 차를 음미하고 건강 출석 도장 획득

#### 📌 목적 5: 성수 명원 1:1 전통 다도 세레머니 큰글씨 예약
- **핵심 이동 경로**: `W11-HOME ➔ W11-ESTIMATE ➔ W11-DONE ➔ W11-COMM`
- **서비스 상세 로직**: 큰글씨 캘린더에서 날짜를 선택하여 명원 프라이빗 다도회 1:1 예약 및 모바일 초대장 발급

## 2. 3대 공통 필수 템플릿 + 고유 킬러 기능 결합 아키텍처 (Screen Architecture)

### 2.1 Page 1: 메인 안식처 허브 (`W11-HOME`)
- **상단바 (GNB / Header)**: 브랜드 로고, 4~5대 글로벌 메뉴, 빠른 주문/장바구니 트리거
- `HERO-01`: 1200x380 스케일의 맞춤형 3D 비주얼 캔버스
- `SLOGAN-01`: 공식 브랜드 슬로건 ("문을 열고, 현실에서 벗어나세요 (Open the Door, Escape Reality)")
- `5-QUICK-DOCK`: 5대 목적 퀵 라우터 (80℃ 황금온도 침출 발효티 처방, 혈당/혈압 안심 성분표 검증, 전통 오동나무 상자 3D 패키징, 아침 10분 다도 묵상 가야금 음향, 성수 명원 1)
- `KILLER-MODULE-01`: **20pt 시니어 큰글씨 모드 (`SENIOR-FONT-01`) (메인 상단 60% 비중 인터랙티브 모듈)**
- `CUR-01`: **⭐ [명인 특화] 지리산 야생 80℃ 온수 발효 황차 팩** (🍵 지리산 야생 80℃ 온수 발효티 (4))
- `CUR-02`: **🌿 [혈당 안심] 공인 성적서 검증 무당 구기자 발효티** (🌿 혈당/혈압 안심 무당 성적서 팩 (4))
- `CUR-03`: **🪵 [명품 예단] 오동나무 함 발효차 2종 & 비단 보자기 세트** (🪵 전통 명품 오동나무 선물세트 (4))
- `RITUAL-01`: 180초 맞춤 브루잉 사운드 타이머

- **하단 푸터 (Footer)**: 사업자 정보, 고객센터, KTR 3無(무설탕/무카페인/무색소) 공인 성적서, 이용약관

### 2.2 Page 2: 전통 다도 & 시니어 발효티 다실 (Traditional Tea Room) (`W11-CATALOG` / `W11-ESTIMATE`)
- **한명석 맞춤 6대 LNB 카테고리 필터**:
  1. `전체 전통 발효티 (20)`
  2. `🍵 지리산 야생 80℃ 온수 발효티 (4)`
  3. `🌿 혈당/혈압 안심 무당 성적서 팩 (4)`
  4. `🪵 전통 명품 오동나무 선물세트 (4)`
  5. `🏺 장인 수제 분청사기 다기 세트 (4)`
  6. `📖 백세 건강 다이어리 & 60일 구독 (4)`
- **20대 전 상품 맞춤 리스팅 (`SEC-01` ~ `SEC-20`)**: 전 품목 맞춤형 카테고리 태그, 1:1 이미지 스펙 뷰박스, 🤍 찜하기, 🛒 1초 결제 드로어 연동

### 2.3 Page 3: 브랜드 스토리 & 스페셜 룸 (`W11-ABOUT` / `W11-PORTAL` / `W11-RITUAL`)
- 공식 브랜드 슬로건, 브랜드 목적 전문, '비밀정원 다과회' 세계관, 3대 핵심 가치
- 한명석 클라이언트 특화 오프라인/B2B/커뮤니티 인터랙션 룸
- `W11-DRAWER`: Aside Layer 슬라이드아웃 패스트 체크아웃 (1-Click 간편결제 / 30일 정기배송 / 견적서 발급)
