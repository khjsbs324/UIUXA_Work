## 1. 5대 레이아웃 원형 기반 UI 구조 차별화 분석 (이지민 맞춤)

### 1.0 전사 공통 필수 3대 페이지 템플릿 탑재 기준 (제1원칙)
본 화면 설계서는 다음 **3대 공통 필수 페이지 템플릿을 기본 골격으로 전면 탑재**한 후, 이지민 클라이언트의 고유 킬러 기능을 결합하여 설계되었습니다:
1. **① 메인 페이지 (`W08-HOME`)**: 상단바(글로벌 GNB 헤더), 메인 캔버스(히어로/대표 큐레이션), 하단 푸터(사업자 정보, 고객센터, KTR 3無 공인 인증)
2. **② 상품 페이지 (`W08-CATALOG`)**: 20개 이상(20종 전수) 맞춤 상품 도감 및 6대 LNB 카테고리 필터
3. **③ 브랜드 페이지 (`W08-ABOUT`)**: 브랜드 세계관, 조향/추출 철학, 원료 원산지 및 헤리티지 스토리텔링


본 설계서는 획일화된 템플릿 나열을 탈피하여, **이지민 클라이언트의 5대 방문 목적과 고유 페르소나**에 최적화된 **`C-1 비주얼 숏폼 인터랙션형 (Aurora Visual Lab)`** 원형을 채택하여 설계되었습니다.

### 1.1 5대 독립적 서비스 이용 목적 정의 (Use Cases 1~5)

#### 📌 목적 1: 실시간 오로라 수색 변환 및 3단 레이어링 번들 구매
- **핵심 이동 경로**: `W08-HOME ➔ W08-AURORA ➔ W08-DRAWER ➔ W08-DONE`
- **서비스 상세 로직**: pH 산도 슬라이더로 파랑 ➔ 보라 ➔ 핑크 실시간 수색 변화 확인 후 20% 세트 할인 결제

#### 📌 목적 2: 9:16 릴스 레시피 영상 시청 및 즉시 1초 결제
- **핵심 이동 경로**: `W08-HOME ➔ W08-REELS ➔ W08-DRAWER ➔ W08-DONE`
- **서비스 상세 로직**: 15초 릴스 레시피 영상 속 사용된 재료를 화면 터치 한 번으로 즉시 장바구니 담기 및 결제

#### 📌 목적 3: 빛 굴절 홀로그램 더블월 글래스 3D 각인 선물
- **핵심 이동 경로**: `W08-HOME ➔ W08-BUILD ➔ W08-DRAWER ➔ W08-DONE`
- **서비스 상세 로직**: 홀로그램 잔에 인스타그램 아이디를 3D 각인하고 오로라 엽서와 함께 카카오 선물 발송

#### 📌 목적 4: 1초 융해 숏폼 챌린지 영상 업로드 & 투표
- **핵심 이동 경로**: `W08-HOME ➔ W08-COMM ➔ W08-DONE ➔ W08-COMM`
- **서비스 상세 로직**: 내 수색 변환 영상을 업로드하여 실시간 주간 랭킹 1위 도전 및 100% 페이백 쿠폰 획득

#### 📌 목적 5: 오로라 포토 카드 에디터 & 한정판 굿즈 수령
- **핵심 이동 경로**: `W08-HOME ➔ W08-CATALOG ➔ W08-DRAWER ➔ W08-DONE`
- **서비스 상세 로직**: 나만의 오로라 감성 사진으로 모바일 포토 카드를 제작하고 본품과 함께 수령

## 2. 3대 공통 필수 템플릿 + 고유 킬러 기능 결합 아키텍처 (Screen Architecture)

### 2.1 Page 1: 메인 안식처 허브 (`W08-HOME`)
- **상단바 (GNB / Header)**: 브랜드 로고, 4~5대 글로벌 메뉴, 빠른 주문/장바구니 트리거
- `HERO-01`: 1200x380 스케일의 맞춤형 3D 비주얼 캔버스
- `SLOGAN-01`: 공식 브랜드 슬로건 ("문을 열고, 현실에서 벗어나세요 (Open the Door, Escape Reality)")
- `5-QUICK-DOCK`: 5대 목적 퀵 라우터 (실시간 오로라 수색 변환 및 3단 레이어링 번들 구매, 9, 빛 굴절 홀로그램 더블월 글래스 3D 각인 선물, 1초 융해 숏폼 챌린지 영상 업로드, 오로라 포토 카드 에디터)
- `KILLER-MODULE-01`: **실시간 오로라 수색 변환기 (`AURORA-FINDER-01`) (메인 상단 60% 비중 인터랙티브 모듈)**
- `CUR-01`: **⭐ [수색 시그니처] 갤럭시 블루 ➔ 바이올렛 변환 팩** (🌌 영롱한 오로라 버터플라이피 팩 (4))
- `CUR-02`: **💖 [핑크 오로라] 로즈 쿼츠 히비스커스 & 피치 블렌드** (💖 로즈 쿼츠 핑크 히비스커스 팩 (4))
- `CUR-03`: **💚 [네온 에메랄드] 라임 마테 형광 그린 믹서 스틱** (💚 에메랄드 시트러스 라임 팩 (4))
- `RITUAL-01`: 180초 맞춤 브루잉 사운드 타이머

- **하단 푸터 (Footer)**: 사업자 정보, 고객센터, KTR 3無(무설탕/무카페인/무색소) 공인 성적서, 이용약관

### 2.2 Page 2: 오로라 수색 & 비주얼 굿즈 갤러리 (Aurora Visual Gallery) (`W08-CATALOG` / `W08-ESTIMATE`)

  1. `전체 오로라 팩 (20)`

  3. `💖 로즈 쿼츠 핑크 히비스커스 팩 (4)`
  4. `💚 에메랄드 시트러스 라임 팩 (4)`
  5. `🥂 빛 굴절 홀로그램 더블월 글래스 (4)`
  6. `🎁 릴스 바이럴 스타터 킷 & 엽서 (4)`
- **20대 전 상품 맞춤 리스팅 (`SEC-01` ~ `SEC-20`)**: 전 품목 맞춤형 카테고리 태그, 1:1 이미지 스펙 뷰박스, 🤍 찜하기, 🛒 1초 결제 드로어 연동

### 2.3 Page 3: 브랜드 스토리 & 스페셜 룸 (`W08-ABOUT` / `W08-PORTAL` / `W08-RITUAL`)
