## 🎯 1. 핵심 통합 작동 원칙: 공통 기능 vs 선택적 고유 기능 분리

1명의 클라이언트 안에는 **5가지 고유 접속 목적**에 대응하는 상위 설계 산출물이 존재하며, **모든 클라이언트에게 획일적인 공통 화면을 강제하지 않고 페르소나별 킬러 기능을 중심**으로 스토리보드를 작성합니다:

### 1.1 공통 필수 커머스 코어 vs 선택적 고유 기능 원칙
- **공통 필수 기능**: 
  - 공식 브랜드 슬로건: `"문을 열고, 현실에서 벗어나세요 (Open the Door, Escape Reality)"`
  - 브랜드 목적: "바쁜 일상에 지친 2030 세대에게 노동 없는 3분간의 초현실주의적인 휴식(길티프리 리추얼) 공간을 제공하는 것입니다. 차를 마시는 행위 자체를 환상 공간으로 입장하는 특별한 의식으로 재해석하여, 일상과의 완벽한 단절 및 마법 같은 휴식을 선사합니다." (모기업: WONDERSCAPE)
  - 브랜드 세계관: '비밀정원 다과회 (WONDERSCAPE 캄테크 디지털 웰니스)'
  - 3대 핵심 가치: 1. Emotion Dial (감정 맞춤 추천), 2. Mixology (DIY 믹솔로지 & 블렌딩), 3. Zero-Labor (노동 없는 3분의 초현실 휴식)
  - 11인 개별 대표이사 및 사업장/CS 정보 1:1 바인딩
  - 상품 기본 스펙(SEC-01~15), 맞춤 주문/체크아웃 액션, 트랜잭션 완료 피드백, 신뢰 푸터
- **선택적 고유 기능 (타 유형 강제 금지)**:
  - **B2B형 (07 박지후, 04 임태경)**: 탕비실/호텔 대용량 견적 계산기, 0원 샘플 신청, 디스펜서 렌탈, 세금계산서 청구
  - **숏폼형 (08 이지민, 05 송아린)**: 실시간 수색 변환 슬라이더, 9:16 세로형 릴스 플레이어, 포토카드 에디터, 챌린지 랭킹
  - **데이터형 (09 윤기준)**: TDS 용출 곡선 차트, 수질 매칭 알고리즘, 터미널 Syntax 각인, JSON 로그 다운로더
  - **시니어형 (11 한명석, 10 서지안)**: 20pt 큰글씨 뷰, ☎️ 1588 전화 주문 콘솔, 혈당/혈압 무당 성분표, 10분 다도 묵상 오디오
  - **감성/선물형 (01 차은채, 02 신유진, 03 윤서연, 06 이도은)**: 3D 회전 선물 패키징, 이니셜 각인 스튜디오, TPO 무드 진단 퀴즈
> *(※ 01~11번 정식 확정 인원 기준 매핑이며, 12~20번 클라이언트는 향후 신규 기획 시 해당 유형으로 추가 편입 예정 - 현재 [미생성/백로그 대기])*

### 1.2 클라이언트 공식 모수 및 진행 상태 기준 (Client Scope & Status)
- **정식 확정 대상 (01~11번)**: `01 차은채` ~ `11 한명석` 총 11명을 정식 확정 마스터 모수로 삼아 1:1 스토리보드 세트를 생성하고 전수 동기화한다.
- **확장 로드맵 (12~20번)**: `[미생성 / 백로그(Backlog) 대기]` 상태로 규정하며, 신규 클라이언트 생성 지시 전까지는 자동 파이프라인에서 대기 상태를 유지한다.

### 1.3 가변형 화면 식별자 (Dynamic Screen ID Registry)
- 고정된 `PG-31`(각인), `PG-32`(타이머), `PG-33`(계산기) 강제를 폐지하고, 각 클라이언트의 **통합 사이트맵 및 서비스 흐름도에 정의된 실제 화면 ID(`WXX-HOME`, `WXX-CALCULATOR`, `WXX-REELS`, `WXX-TDS`, `WXX-PHONE` 등)**를 공식 Screen ID로 1:1 매핑합니다.

### 📄 1. `스토리보드$(클라이언트번호)_$(이름).md` (마스터 명세서)
1. **프로젝트 개요 및 5대 접속 목적 통합 매트릭스 (Unified 5-Goal Matrix)**
   - 공식 슬로건, 브랜드 목적, 3대 가치, 대표이사 및 페르소나 반영 요약
   - 5개 목적별 화면 접점, 핵심 인터랙션, 전환 목표 매핑표
2. **클라이언트 특화 15대 상품/기능 섹션(`SEC-01` ~ `SEC-15`) 1:1 상세 표 명세**
   - 컬럼 규격: `| 구분 (Section ID) | 목적 연계 | UI 요소 | 표시 데이터 | 사용자 행동 | 시스템 처리 / 모션 | 이동 대상 화면 ID | 상태별 변화 |`
   - 페르소나 원형에 맞추어 대시보드 위젯, 데이터시트, 비디오 피드, 대형 카드 등 차별화된 UI 컴포넌트로 명세
3. **15대 섹션 100% 이미지 영역 스펙 명세표**
   - `🖼️ [이미지: 대상설명 (16:9 / 4:3 / 1:1 / 9:16)]` 형식 준수
4. **KWCAG 2.2 접근성 요구사항 16개 항목 명세표** (시니어 클라이언트의 경우 20pt 글씨, 고대비, 음성/전화 대체 수단 필수 강조)
5. **정책 가정 및 확인 필요 사항 명세표 (12개 항목)** (결제, 정기구독, B2B 세금계산서, 전화 주문 정책 등)

- **좌측 사이드바 (`#sidebar`)**:
  - 클라이언트 고유 화면 ID 목록 네비게이터 (메인 허브, 2-Depth 특화 화면, 체크아웃 드로어/모달, 완료 상태 모달)

  - **좌측 영역**: 모노크롬 와이어프레임 뷰박스 (플레이스홀더 및 킬러 기능 인터랙티브 컴포넌트)
  - **우측 영역**: 스토리보드 상세 명세표 (사용자 행동, 시스템 처리, 이동 대상, 상태 변화)
- **실시간 상호 동기화**: 좌측 컴포넌트 클릭 시 우측 명세표 포커스, 우측 명세표 클릭 시 좌측 컴포넌트 하이라이트
