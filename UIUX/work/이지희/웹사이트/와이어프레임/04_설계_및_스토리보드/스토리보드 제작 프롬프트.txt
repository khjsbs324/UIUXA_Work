### 📝 제작 지침 및 규칙 (공통 필수 기능 vs 선택적 고유 기능 분리)

위 클라이언트의 5대 목적별 사이트맵과 서비스 흐름도, 화면 설계서, 클라이언트 분석서를 모두 읽고 분석·병합하여 **단 1개의 맞춤 통합 마스터 스토리보드 세트**를 UTF-8 인코딩으로 생성해줘.

> ⚠️ **주의**: 
> 1. 모든 클라이언트에게 획일적인 화면(3D 각인, 리추얼 타이머, 구독 계산기 등)을 강제하지 말고, 클라이언트의 고유 킬러 목적(B2B 견적, 숏폼 플레이어, TDS 계측, 시니어 전화 주문 등)을 중심으로 스토리보드를 구성해줘.
> 2. 공식 브랜드 슬로건("문을 열고, 현실에서 벗어나세요 (Open the Door, Escape Reality)"), 브랜드 목적 전문, 세계관('비밀정원 다과회'), 3대 핵심 가치, 11인 개별 대표이사/사업장 정보를 100% 일치시켜줘.

다음 3가지 통합 마스터 파일을 생성해줘:

1. `스토리보드$(번호)_$(이름).md`
   - 5대 접속 목적 통합 매트릭스 (Unified 5-Goal Matrix)
   - 클라이언트 특화 15대 상품/기능 섹션(`SEC-01` ~ `SEC-15`) 1:1 상세 표 명세 (구분, 목적, UI 요소, 표시 데이터, 사용자 행동, 시스템 처리/모션, 이동 대상 화면 ID, 상태별 변화)
   - 15대 섹션 100% 이미지 영역 스펙 명세표 (`🖼️ [이미지: 대상설명 (비율)]`)
   - KWCAG 2.2 접근성 요구사항 16개 항목 명세표
   - 정책 가정 및 확인 필요 사항 12개 항목 명세표

2. `스토리보드$(번호)_$(이름).html`
   - 외부 라이브러리 없이 브라우저에서 단독 실행 가능한 반응형 웹 스토리보드 뷰어
   - 상단 5대 접속 목적 탭 컨트롤러
   - 좌측 사이드바: 클라이언트 고유 화면 ID 네비게이터 (사이트맵/흐름도 기반 가변형 화면 목록)
   - 좌측 와이어프레임 뷰박스와 우측 스토리보드 상세 명세표가 실시간 동적 연동되는 2단 Split 레이아웃

3. `스토리보드_목록$(번호)_$(이름).json`
   - 클라이언트 정보, 5대 목적 매트릭스, 화면 목록, 15대 섹션별 요소와 시스템 로직 데이터를 구조화한 유효한 JSON 파일

작업 완료 후 생성한 파일 경로, 실행 방법, 품질 검증 결과를 간결하게 출력해줘.
