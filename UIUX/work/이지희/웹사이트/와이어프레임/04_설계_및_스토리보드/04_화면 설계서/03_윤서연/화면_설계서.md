## 1. 5대 레이아웃 원형 기반 UI 구조 차별화 분석 (윤서연 맞춤)

### 1.0 전사 공통 필수 3대 페이지 템플릿 탑재 기준 (제1원칙)
본 화면 설계서는 다음 **3대 공통 필수 페이지 템플릿을 기본 골격으로 전면 탑재**한 후, 윤서연 클라이언트의 고유 킬러 기능을 결합하여 설계되었습니다:
1. **① 메인 페이지 (`W03-HOME`)**: 상단바(글로벌 GNB 헤더), 메인 캔버스(히어로/대표 큐레이션), 하단 푸터(사업자 정보, 고객센터, KTR 3無 공인 인증)
2. **② 상품 페이지 (`W03-CATALOG`)**: 20개 이상(20종 전수) 맞춤 상품 도감 및 6대 LNB 카테고리 필터
3. **③ 브랜드 페이지 (`W03-ABOUT`)**: 브랜드 세계관, 조향/추출 철학, 원료 원산지 및 헤리티지 스토리텔링


본 설계서는 획일화된 템플릿 나열을 탈피하여, **윤서연 클라이언트의 5대 방문 목적(3D 데스크셋업 패키지 / 나이트 GABA 구독 / 린넨 보자기 선물 / 데스크 챌린지 / 디저트 페어링)**에 최적화된 **`A-2 감성 큐레이션 매거진형 (Aesthetic Deskterior)`** 원형을 채택하여 설계되었습니다.

## 2. 3대 공통 필수 템플릿 + 고유 킬러 기능 결합 아키텍처 (Screen Architecture)

### 2.1 Page 1: 감성 데스크테리어 메인 허브 (`W03-HOME`)
- **상단바 (GNB / Header)**: 브랜드 로고, 4~5대 글로벌 메뉴, 빠른 주문/장바구니 트리거
- `HERO-01`: 1200x380 스케일의 3D 데스크셋업 캔버스 (낮/밤 테마 스위처 연동)
- `SLOGAN-01`: 공식 브랜드 슬로건 ("문을 열고, 현실에서 벗어나세요 (Open the Door, Escape Reality)")
- `5-QUICK-DOCK`: 5대 목적 퀵 라우터 (3D셋업 / 나이트구독 / 린넨선물 / 챌린지 / 디저트페어링)
- `DESK-SIMULATOR-01`: 가상 테이블 위 3D 파스텔 틴, 린넨 매트, 글래스웨어 드래그 배치기
- `CUR-01`: **🎨 1. [데스크 오브제] 매트 파스텔 틴 & 린넨 매트 번들** (SEC-01, 04, 05, 08)
- `CUR-02`: **🌙 2. [심야 릴랙스] 미드나잇 GABA 0.00mg 무카페인 티** (SEC-02, 06, 09, 20)
- `CUR-03`: **🍰 3. [홈카페 페어링] 구움과자 x 스모키 얼그레이 티타임 팩** (SEC-03, 11, 15, 16)
- `RITUAL-01`: 432Hz 빗소리 사운드 & 180초 타이머

- **하단 푸터 (Footer)**: 사업자 정보, 고객센터, KTR 3無(무설탕/무카페인/무색소) 공인 성적서, 이용약관

### 2.2 Page 2: 데스크테리어 오브제 갤러리 (`W03-LOOKBOOK`)
- **윤서연 맞춤 6대 LNB 카테고리 필터**:
  1. `전체 데스크 오브제 (20)`
  2. `🎨 매트 파스텔 오브제 틴 (4)`
  3. `🌿 린넨 패브릭 매트 & 코스터 (4)`
  4. `🥂 빛 굴절 더블월 글래스웨어 (4)`
  5. `🌙 미드나잇 GABA 0.00mg 무카페인 (4)`
  6. `🍰 티 & 구움과자 디저트 페어링 (4)`
- **20대 전 상품 맞춤 리스팅 (`SEC-01` ~ `SEC-20`)**: 전 품목 맞춤형 카테고리 태그, 1:1 이미지 스펙 뷰박스, 🤍 찜하기, 🛒 1초 결제 드로어 연동

### 2.3 Page 3: 데스크 매거진 & 챌린지 (`W03-BUILD` / `W03-COMM`)
- 공식 브랜드 슬로건, 브랜드 목적 전문, '비밀정원 다과회' 세계관, 3대 핵심 가치
- `DESK-CHALLENGE-01`: #데스크테리어 실시간 사진 피드 & 에디터스 픽 뱃지 투표 보드
- `LINEN-WRAP-01`: 린넨 보자기 360도 패키징 시뮬레이터 & 감성 응원 엽서 에디터
- `NIGHT-SUB-01`: 30일 새벽배송 정기구독 플래너
- `W03-DRAWER`: Aside Layer 슬라이드아웃 1초 결제 드로어 (1-Click 간편결제 / 20% 세트 할인 / 카카오 선물)
