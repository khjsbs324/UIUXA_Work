## 1. 5대 레이아웃 원형 기반 UI 구조 차별화 분석 (신유진 맞춤)

### 1.0 전사 공통 필수 3대 페이지 템플릿 탑재 기준 (제1원칙)
본 화면 설계서는 다음 **3대 공통 필수 페이지 템플릿을 기본 골격으로 전면 탑재**한 후, 신유진 클라이언트의 고유 킬러 기능을 결합하여 설계되었습니다:
1. **① 메인 페이지 (`W02-HOME`)**: 상단바(글로벌 GNB 헤더), 메인 캔버스(히어로/대표 큐레이션), 하단 푸터(사업자 정보, 고객센터, KTR 3無 공인 인증)
2. **② 상품 페이지 (`W02-CATALOG`)**: 20개 이상(20종 전수) 맞춤 상품 도감 및 6대 LNB 카테고리 필터
3. **③ 브랜드 페이지 (`W02-ABOUT`)**: 브랜드 세계관, 조향/추출 철학, 원료 원산지 및 헤리티지 스토리텔링


본 설계서는 획일화된 템플릿 나열을 탈피하여, **신유진 클라이언트의 5대 방문 목적(홈파티 벌크 / 후각 다이얼 구독 / 3D 각인 선물 / 숏폼 챌린지 / 조향 포뮬러 등록)**에 최적화된 **`B-1 인터랙티브 쇼케이스형 (Viral Mixology Lab)`** 원형을 채택하여 설계되었습니다.

## 2. 3대 공통 필수 템플릿 + 고유 킬러 기능 결합 아키텍처 (Screen Architecture)

### 2.1 Page 1: 믹솔로지 실험실 메인 허브 (`W02-HOME`)
- **상단바 (GNB / Header)**: 브랜드 로고, 4~5대 글로벌 메뉴, 빠른 주문/장바구니 트리거
- `HERO-01`: 1200x380 스케일의 믹솔로지 랩 3D 인터랙티브 칵테일 쉐이커 캔버스
- `SLOGAN-01`: 공식 브랜드 슬로건 ("문을 열고, 현실에서 벗어나세요 (Open the Door, Escape Reality)")
- `5-QUICK-DOCK`: 5대 목적 퀵 라우터 (벌크계산기 / 후각다이얼 / 스타터선물 / 챌린지 / 조향랩)
- `PARTY-BULK-01`: 인원수(4~12인) 기반 60포 홈파티 황금비율 계산기 & 툴 세트 20% 번들 할인기
- `OLFACTORY-DIAL-01`: 8대 향미 슬라이더 수면/이완 처방 콘솔
- `CUR-01`: **🍹 1. [1초 스파클링] 0.1초 융해 버터플라이피 에이드** (SEC-01, 04, 06, 08)
- `CUR-02`: **🌙 2. [나이트 아로마] GABA 라벤더 수면 이완 블렌드** (SEC-02, 05, 07, 14)
- `CUR-03`: **🍸 3. [홈텐더 입문] 4+2 스타터 3D 각인 선물세트** (SEC-10, 11, 12, 13)
- `RITUAL-01`: 180초 아로마 디퓨징 타이머

- **하단 푸터 (Footer)**: 사업자 정보, 고객센터, KTR 3無(무설탕/무카페인/무색소) 공인 성적서, 이용약관

### 2.2 Page 2: 홈바 믹솔로지 & 레시피 스튜디오 (`W02-RECIPE`)
- **신유진 맞춤 6대 LNB 카테고리 필터**:
  1. `전체 믹솔로지 팩 (20)`
  2. `🍹 0.1초 융해 스파클링 에이드 (4)`
  3. `🌙 나이트 아로마 & 수면 이완 블렌드 (4)`
  4. `🍸 홈텐더 입문 바텐더 툴킷 (4)`
  5. `🧪 0.1g 비스포크 조향 포뮬러 킷 (4)`
  6. `🎉 홈파티 60포 대용량 리필 벌크 (4)`
- **20대 전 상품 맞춤 리스팅 (`SEC-01` ~ `SEC-20`)**: 전 품목 맞춤형 카테고리 태그, 1:1 이미지 스펙 뷰박스, 🤍 찜하기, 🛒 1초 결제 드로어 연동

### 2.3 Page 3: 믹솔로지 랩 브랜드 스토리 & 셰어링 (`W02-STUDIO` / `W02-COMM`)
- 공식 브랜드 슬로건, 브랜드 목적 전문, '비밀정원 다과회' 세계관, 3대 핵심 가치
- `FORMULA-REGISTER-01`: 0.1g 조향 고유 Hash ID 등록기 및 셰어링 로열티 정산 대시보드
- `REELS-CHALLENGE-01`: 15초 릴스 레시피 피드 & 실시간 투표 랭킹 보드
- `W02-DRAWER`: Aside Layer 슬라이드아웃 패스트 체크아웃 (1-Click 간편결제 / 30일 정기구독 / 카카오 선물)
