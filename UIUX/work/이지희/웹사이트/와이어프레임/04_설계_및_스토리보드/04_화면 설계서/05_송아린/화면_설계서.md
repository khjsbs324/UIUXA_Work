## 1. 5대 레이아웃 원형 기반 UI 구조 차별화 분석 (송아린 맞춤)

### 1.0 전사 공통 필수 3대 페이지 템플릿 탑재 기준 (제1원칙)
본 화면 설계서는 다음 **3대 공통 필수 페이지 템플릿을 기본 골격으로 전면 탑재**한 후, 송아린 클라이언트의 고유 킬러 기능을 결합하여 설계되었습니다:
1. **① 메인 페이지 (`W05-HOME`)**: 상단바(글로벌 GNB 헤더), 메인 캔버스(히어로/대표 큐레이션), 하단 푸터(사업자 정보, 고객센터, KTR 3無 공인 인증)
2. **② 상품 페이지 (`W05-CATALOG`)**: 20개 이상(20종 전수) 맞춤 상품 도감 및 6대 LNB 카테고리 필터
3. **③ 브랜드 페이지 (`W05-ABOUT`)**: 브랜드 세계관, 조향/추출 철학, 원료 원산지 및 헤리티지 스토리텔링


본 설계서는 획일화된 템플릿 나열을 탈피하여, **송아린 클라이언트의 5대 방문 목적과 고유 페르소나**에 최적화된 **`B-3 헬스 & 다이어트 인터랙티브형 (Zero Diet Spa)`** 원형을 채택하여 설계되었습니다.

### 1.1 5대 독립적 서비스 이용 목적 정의 (Use Cases 1~5)

#### 📌 목적 1: 0kcal 탄산수 0.1초 융해 믹솔로지 & 20% 세트 할인
- **핵심 이동 경로**: `W05-HOME ➔ W05-MIXER ➔ W05-DRAWER ➔ W05-DONE`
- **서비스 상세 로직**: 0.1초 만에 탄산수에 녹아드는 3D 수색 변화 시뮬레이션 및 4종 믹서 번들 20% 할인 결제

#### 📌 목적 2: 30일 바디프로필 챌린지 팩 & 식단 플래너 새벽구독
- **핵심 이동 경로**: `W05-HOME ➔ W05-CHALLENGE ➔ W05-DRAWER ➔ W05-DONE`
- **서비스 상세 로직**: KTR 0.00kcal 성적서 확인 후 30일 바디프로필 플랜 새벽배송 신청

#### 📌 목적 3: 트라이탄 쉐이커 보틀 3D 레이저 각인 친구 선물
- **핵심 이동 경로**: `W05-HOME ➔ W05-BUILD ➔ W05-DRAWER ➔ W05-DONE`
- **서비스 상세 로직**: 운동 메이트 이니셜과 목표 체중 문구를 보틀에 3D 각인하여 선물

#### 📌 목적 4: #0kcal클린티 릴스 챌린지 영상 업로드 & 투표
- **핵심 이동 경로**: `W05-HOME ➔ W05-COMM ➔ W05-DONE ➔ W05-COMM`
- **서비스 상세 로직**: 15초 탄산 융해 릴스 영상을 업로드하고 실시간 투표 랭킹 리워드 획득

#### 📌 목적 5: KTR 공인 0.00kcal 시험성적서 검증 & 1:1 영양 상담
- **핵심 이동 경로**: `W05-HOME ➔ W05-CATALOG ➔ W05-DRAWER ➔ W05-DONE`
- **서비스 상세 로직**: 당류 0g, 나트륨 0mg 시험 성적서 확인 및 피트니스 전문가 1:1 루틴 상담

## 2. 3대 공통 필수 템플릿 + 고유 킬러 기능 결합 아키텍처 (Screen Architecture)

### 2.1 Page 1: 메인 안식처 허브 (`W05-HOME`)
- **상단바 (GNB / Header)**: 브랜드 로고, 4~5대 글로벌 메뉴, 빠른 주문/장바구니 트리거
- `HERO-01`: 1200x380 스케일의 맞춤형 3D 비주얼 캔버스
- `SLOGAN-01`: 공식 브랜드 슬로건 ("문을 열고, 현실에서 벗어나세요 (Open the Door, Escape Reality)")
- `5-QUICK-DOCK`: 5대 목적 퀵 라우터 (0kcal 탄산수 0.1초 융해 믹솔로지, 30일 바디프로필 챌린지 팩, 트라이탄 쉐이커 보틀 3D 레이저 각인 친구 선물, #0kcal클린티 릴스 챌린지 영상 업로드, KTR 공인 0.00kcal 시험성적서 검증)
- `KILLER-MODULE-01`: **0kcal 영양 성분 계산기 (`CALORIE-CALC-01`) (메인 상단 60% 비중 인터랙티브 모듈)**
- `CUR-01`: **⭐ [0kcal 시그니처] 블루 오로라 버터플라이피 스파클링** (🍹 0kcal 버터플라이피 스파클링 (4))
- `CUR-02`: **💪 [부스팅 마테] 운동 전 버닝 에메랄드 라임 마테 팩** (💪 운동 전 부스팅 에메랄드 마테 (4))
- `CUR-03`: **🌙 [야식 방어] 야식 충동 차단 GABA 루이보스 팩** (🌙 야식 방어 0.00mg 무카페인 GABA (4))
- `RITUAL-01`: 180초 맞춤 브루잉 사운드 타이머

- **하단 푸터 (Footer)**: 사업자 정보, 고객센터, KTR 3無(무설탕/무카페인/무색소) 공인 성적서, 이용약관

### 2.2 Page 2: 0kcal 클린 스파클링 스토어 (Zero Clean Shop) (`W05-CATALOG` / `W05-ESTIMATE`)
- **송아린 맞춤 6대 LNB 카테고리 필터**:
  1. `전체 0kcal 클린팩 (20)`
  2. `🍹 0kcal 버터플라이피 스파클링 (4)`

  4. `🌙 야식 방어 0.00mg 무카페인 GABA (4)`
  5. `🏋️ 30일 챌린지 보틀 번들 팩 (4)`
  6. `🍓 비건 안토시아닌 루비 베리 믹서 (4)`
- **20대 전 상품 맞춤 리스팅 (`SEC-01` ~ `SEC-20`)**: 전 품목 맞춤형 카테고리 태그, 1:1 이미지 스펙 뷰박스, 🤍 찜하기, 🛒 1초 결제 드로어 연동

### 2.3 Page 3: 브랜드 스토리 & 스페셜 룸 (`W05-ABOUT` / `W05-PORTAL` / `W05-RITUAL`)
- 공식 브랜드 슬로건, 브랜드 목적 전문, '비밀정원 다과회' 세계관, 3대 핵심 가치
