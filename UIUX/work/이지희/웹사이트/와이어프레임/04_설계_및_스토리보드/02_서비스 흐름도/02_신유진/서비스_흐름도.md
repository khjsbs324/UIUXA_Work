## 1. 5대 서비스 흐름도 자동 생성 프레임워크 (Generation Framework)

본 가이드는 클라이언트 실행 명령 시 기존 흐름도와 중복되지 않는 **5개의 상호 배타적 이용 목적을 도출하고 서로 다른 형태의 다이어그램으로 자동 생성**하기 위한 표준 지침입니다.

### 1.1 5대 상호 배타적 도메인 축 (5 Distinct Domain Axes)
1. **축 ① [홈파티 대용량 & 바텐더 툴 견적형]**: 인원수(6~8인) 기반 원료 자동 계산, 0.00% 시험성적서 확인, 바텐더 글래스웨어/지거 번들 발주
2. **축 ② [긴급 힐링 & 무카페인 30일 정기구독형]**: 8대 후각 다이얼 진단, GABA 라벤더 성분 검증, 슬라이드아웃 Cart 1초 정기구독 결제
3. **축 ③ [홈카페 선물 & 3D 비스포크 각인형]**: [4+2 스타터] vs VIP 틴세트 비교, 4대 베이스 커스텀, 3D 레이저 각인 및 카카오톡 선물 전송
4. **축 ④ [SNS 숏폼 바이럴 & 1초 융해 챌린지 순환형]**: 릴스 연계 진입, 찬물 1초 융해 3D 층분리 검증, 3초 결제 ➔ SNS 영상 인증 ➔ 페이백 루프
5. **축 ⑤ [신규 조향 포뮬러 공식 등록 & UGC 셰어링형]**: 0.1g 단위 정밀 배합, 암호화 Hash ID 공식 인증서 발급, 셰어링 랩 랭킹 등극

### 1.2 목적별 6대 핵심 서비스 흐름 설계 지침 (6-Step Architecture)
모든 생성 파일은 다음 **6대 핵심 요소**의 흐름에 맞춰 빠짐없이 상세 명세표와 함께 작성됩니다:
```
[1. 시작 지점] ➔ [2. 핵심 행동] ➔ [3. 전환 목표] ➔ [4. 필요한 기능] ➔ [5. 예외 상황] ➔ [6. 완료 결과]
```

### 1.3 5대 다이어그램 형태(Topology) 차별화 강제 규칙
생성되는 5개 흐름도는 획일적 복제를 방지하기 위해 다음 **5가지 서로 다른 다이어그램 형태**로 작성됩니다:
- **목적 1**: `flowchart TD` (인원수 견적 ➔ 툴 번들 조합 ➔ 발주 트리형)
- **목적 2**: **`flowchart LR` (분기 없는 6단계 초고속 가로 직렬형 파이프라인)**
- **목적 3**: `flowchart TD` (2개 노드씩 짝지어진 4단 비스포크 스튜디오형)
- **목적 4**: **`flowchart TD` + Loop (마지막 노드 `F1`에서 `C01`로 이어지는 점선 `-.->` 순환 루프형)**
- **목적 5**: `flowchart TD` (0.1g 조향 ➔ 인증서 발급 ➔ 랭킹 등극 스테이지형)

### 1.4 서비스 흐름도 고유 설계 지침 (가변 스테이지 & 의사결정 분기 체계)
본 서비스 흐름도는 **획일적인 `Phase 1~4` 고정 템플릿을 전면 탈피**하고, 클라이언트의 5대 방문 목적별 비즈니스 로직에 맞춘 **가변 스테이지(Dynamic Stages) 및 의사결정 분기(`{ }`) / 예외 복구(Fallback)** 원칙을 준수하여 작성되었습니다:

1. **목적별 가변 여정 스테이지 (Dynamic Stages)**:
   - 각 목적의 실제 비즈니스 흐름에 따라 3~5단계의 가변 스테이지로 유연하게 재구성합니다.
   - 예: 시향 예약(공간탐색 ➔ 소믈리에 ➔ 잔여석검증 ➔ 패스발급), 구독(진단 ➔ 융해 ➔ 1초결제 ➔ 월간케어), 챌린지(피드 ➔ 투표 ➔ 영상업로드 ➔ 랭킹순환).
2. **조건 분기 및 예외 복구(Fallback) 메커니즘 필수 탑재**:
   - 타임슬롯 마감 시 취소 대기 접수, 결제 오류 시 대체 수단 전환, 글자수/규격 검증 오류 시 미세 보정 등 실제 사용자 이탈을 방지하는 예외 복구 파이프라인을 전수 수록합니다.
3. **Mermaid 프로세스 다이어그램 (Decision Diamonds)**:
   - 단순 1열 상자 나열이 아닌, 조건 판단 마름모 노드(`{ }`)와 분기 화살표(`-->|조건|`), 복구 순환 점선(`-.->`)이 포함된 실질적인 비즈니스 프로세스 다이어그램으로 구성합니다.

## 3. 목적별 핵심 시나리오 요약

### 🍸 목적 1: [홈파티 / 대용량 음료] (`TD 견적-발주 트리형`)
- **시작 ➔ 완료**: 검색 유입 ➔ 스모키 오크(SEC-03) & 60포 벌크(SEC-18) 스펙 확인 ➔ 6~8인 원료 계산 ➔ 툴 번들 20% 할인 결제 ➔ 레시피 PDF 발급

### 🌙 목적 2: [불면·힐링 / 정기구독] (`LR 가로 초고속 직렬형`)
- **시작 ➔ 완료**: 웰니스 캠페인 유입 ➔ 8대 후각 다이얼 진단 ➔ GABA 라벤더(SEC-02) 성적서 확인 ➔ 30일 맞춤 구독 1초 결제 ➔ 멤버십 발급

### 🎁 목적 3: [선물 / 입문 세트] (`TD 비스포크 선물 4단형`)
- **시작 ➔ 완료**: 선물 배너 유입 ➔ 입문 킷(SEC-10) vs VIP 틴세트(SEC-13) 비교 ➔ 4종 베이스 커스텀 & 3D 각인 ➔ 카카오 선물하기 결제 ➔ 모바일 카드 전달

### 🎬 목적 4: [SNS 바이럴 / 레시피 복제] (`TD + Loop 순환 루프형`)
- **시작 ➔ 완료**: 릴스 영상 유입 ➔ 오로라 블루(SEC-01) 1초 융해 3D 층분리 검증 ➔ 3초 패스트 결제 ➔ 영상 업로드 인증 ➔ **다음 챌린지 순환**

### 🧪 목적 5: [조향 공식 등록 / UGC 셰어링] (`TD 포뮬러 발급형`)
- **시작 ➔ 완료**: 실험실 홈 유입 ➔ 0.1g 정밀 배합 콘솔 조작 ➔ 고유 Hash ID 공식 등록증 발급 ➔ 셰어링 랩 업로드 ➔ 인기 레시피 랭킹 등극

## 4. ⚙️ 서비스 흐름도 자동 생성 실행 파이프라인 (Execution Pipeline)

사용자가 **"신유진 서비스 흐름도 실행"**을 명령할 경우 다음 절차가 자동으로 즉시 수행됩니다:
1. **[목적 매트릭스 검증]**: 상기 5대 목적의 6대 핵심 흐름 및 5종 토폴로지 적합성을 확인한다.
2. **[15개 파일 일괄 생성]**: `서비스_흐름도_목적1~5`의 `.md`, `.mmd`, `.svg` 파일을 빠짐없이 동시 생성한다.
3. **[SVG 벡터 컴파일]**: `@mermaid-js/mermaid-cli`를 통해 투명 배경 벡터 그래픽으로 일괄 렌더링한다.
4. **[정합성 검토 보고]**: 상·하위 문서 링크 및 6대 프레임워크 100% 준수 여부를 사용자에게 보고한다.
