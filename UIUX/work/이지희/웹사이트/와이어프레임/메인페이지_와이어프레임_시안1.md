## 🏛️ 1. 전사 11인 클라이언트 공통 장점 vs 고유 장점 비교 분석

본 통합 와이어프레임은 각 클라이언트 화면설계서의 **공통 핵심 베이스라인(Common Baseline)**을 견고히 유지하면서, 11명의 **상호 배타적인 킬러 기능(Killer Interactions)**을 단일 플래그십 인터랙티브 UI 안으로 집약한 마스터 설계서입니다.

### 1.1 공통 필수 베이스라인 (Common Baseline Strengths)
1. **브랜드 정체성 일관성**:
   - 공식 슬로건 `"문을 열고, 현실에서 벗어나세요"`
   - 3대 핵심 가치: `1. Emotion Dial(감정 맞춤)`, `2. Mixology(DIY 블렌딩)`, `3. Zero-Labor(1초 융해/180초 타이머)`
2. **KTR 3無(무설탕/무카페인/무색소) 공인 시험성적서 및 KWCAG 2.2 접근성 기반 100% 준수**
3. **20종 전수 맞춤 상품 도감 (Curated 20 Products)**:
   - 6대 공통 LNB 카테고리 필터 시스템 탑재
4. **올인원 멀티 체크아웃 드로어**:
   - D2C 1초 결제, B2B 세금계산서 청구, 시니어 1588 전화 연결 3-in-1 통합

## 🚀 3. 핵심 인터랙션 검증 가이드

1. **상단 뷰포트 스위처 (`switchPersonaView`)**:
   - `B2B`, `숏폼`, `데이터`, `시니어`, `에디토리얼` 버튼 클릭 시 해당 스튜디오 탭으로 스무스 스크롤 이동 및 자동 포커스.
2. **B2B 대량 견적기 (`updateB2BCalc`)**:
   - 슬라이더 조작 시 1,000세트(-20%), 3,000세트(-25%), 5,000세트(-30%) 티어 할인율과 세금계산서 청구 금액이 실시간 동적 렌더링.
3. **pH 산도 수색 변환기 (`updateColorShift`)**:
   - 산도 슬라이더(3.0~7.0) 조작 시 중앙 글래스 박스의 배경색이 딥 블루 ➔ 오로라 바이올렛 ➔ 로즈 핑크로 0.3초 트랜지션 애니메이션 적용.
4. **20pt 시니어 모드 토글 (`toggleSeniorMode`)**:
   - 클릭 시 `body.senior-mode` 클래스가 활성화되어 전역 폰트가 19~24pt로 즉시 확대되고 초고대비 레이아웃 적용.
5. **3-in-1 스마트 드로어 (`openDrawer` / `switchDrawerMode`)**:
   - 일반 D2C 결제, B2B 세금계산서 청구, 시니어 1588 직통 전화 모드가 탭으로 완벽히 분기 동작.
