### 📝 제작 지침 및 규칙

위 5대 접속 목적별 사이트맵과 서비스 흐름도, 클라이언트 분석서를 모두 읽고 분석·병합하여 **단 1개의 통합 마스터 스토리보드 세트**를 UTF-8 인코딩으로 생성해줘. Figma를 생성하거나 수정하지 말고, 문서와 브라우저에서 즉시 확인 가능한 파일로 만들어줘.

다음 3가지 통합 마스터 파일을 생성해줘:

1. `스토리보드$(번호)_$(이름).md`
   - 5대 접속 목적 통합 매트릭스 (Unified 5-Goal Matrix)
   - PG-01 메인 15대 상품 큐레이션 섹션(`SEC-01` ~ `SEC-15`) 1:1 상세 표 명세 (구분, 목적, UI 요소, 표시 데이터, 사용자 행동, 시스템 처리/모션, 이동 대상, 상태별 변화)
   - PG-01 메인 15대 상품 섹션 100% 이미지 영역 스펙 명세표 (`🖼️ [이미지: SEC-XX ... (비율)]`)
   - KWCAG 2.2 접근성 요구사항 16개 항목 명세표
   - 정책 가정 및 확인 필요 사항 12개 항목 명세표

2. `스토리보드$(번호)_$(이름).html`
   - 외부 라이브러리 없이 브라우저에서 단독 실행 가능한 반응형 웹 스토리보드 뷰어
   - 상단 5대 접속 목적 탭 컨트롤러 (`[목적 1: 브랜딩탐색]` ~ `[목적 5: 재방문소셜]`)
   - 좌측 사이드바 11대 전체 화면 네비게이터 (`PG-01` ~ `PG-04`, `PG-31` ~ `PG-33`, `PG-M01`, `EXP-01` ~ `EXP-03`)
   - 좌측 와이어프레임 뷰박스(회색 이미지 플레이스홀더 포함)와 우측 스토리보드 상세 명세표가 실시간 동적 연동되는 2단 Split 레이아웃

3. `스토리보드_목록$(번호)_$(이름).json`
   - 클라이언트 정보, 5대 목적 매트릭스, 15대 섹션별 요소와 시스템 로직 데이터를 구조화한 유효한 JSON 파일

작업 완료 후 생성한 파일 경로, 실행 방법, 품질 검증 결과를 간결하게 출력해줘.
