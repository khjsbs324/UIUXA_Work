## 1. 5대 서비스 흐름도 자동 생성 프레임워크 (Generation Framework)

본 가이드는 클라이언트 실행 명령 시 기존 흐름도와 중복되지 않는 **5개의 상호 배타적 이용 목적을 도출하고 서로 다른 형태의 다이어그램으로 자동 생성**하기 위한 표준 지침입니다.

### 1.1 5대 상호 배타적 도메인 축 (5 Distinct Domain Axes)
1. **축 ① [개발자 야간 몰입 & 0.1g 정밀 기어 번들형]**: PRECISION-DASH-01 3D 계측기 조작, 스마트 블루투스 타이머 번들 발주
2. **축 ② [월간 TDS 최적화 & HPLC 463종 검증 구독형]**: HPLC 성분표 검증, TDS 최적화 미네랄 워터 & 정밀 티 30일 정기배송
3. **축 ③ [테크 동료 선물 & 소스코드/깃허브 ID 각인형]**: 디지털 브루잉 스케일, 터미널 틴케이스 코드 레이저 각인 선물
4. **축 ④ [브루잉 데이터 아카이빙 & JSON 익스포트 루프형]**: 추출 파라미터 기록, JSON 내보내기, 깃허브 커밋 뱃지 획득 루프
5. **축 ⑤ [해커톤 & 개발팀 밤샘 코딩 부스팅 팩형]**: 팀 단위 0.1g 에너지 부스팅 티 & 브루잉 도구 대량 일괄 발주

### 1.2 목적별 6대 핵심 서비스 흐름 설계 지침 (6-Step Architecture)
```
[1. 시작 지점] ➔ [2. 핵심 행동] ➔ [3. 전환 목표] ➔ [4. 필요한 기능] ➔ [5. 예외 상황] ➔ [6. 완료 결과]
```

### 1.3 5대 다이어그램 형태(Topology) 차별화 강제 규칙
- **목적 1**: `flowchart TD` (데이터 계측 ➔ 타이머 기어 조합 트리형)
- **목적 2**: **`flowchart LR` (가로 초고속 엔지니어링 구독 파이프라인)**
- **목적 3**: `flowchart TD` (2개 노드씩 짝지어진 4단 테크 각인형)
- **목적 4**: **`flowchart TD` + Loop (JSON 추출 & 커밋 뱃지 순환 루프형 `-.->`)**
- **목적 5**: `flowchart TD` (해커톤 팀 팩 ➔ 대량 배송 스테이지형)

### 1.4 서비스 흐름도 고유 설계 지침 (가변 스테이지 & 의사결정 분기 체계)
본 서비스 흐름도는 **획일적인 `Phase 1~4` 고정 템플릿을 전면 탈피**하고, 클라이언트의 5대 방문 목적별 비즈니스 로직에 맞춘 **가변 스테이지(Dynamic Stages) 및 의사결정 분기(`{ }`) / 예외 복구(Fallback)** 원칙을 준수하여 작성되었습니다:

1. **목적별 가변 여정 스테이지 (Dynamic Stages)**:
   - 각 목적의 실제 비즈니스 흐름에 따라 3~5단계의 가변 스테이지로 유연하게 재구성합니다.
   - 예: 시향 예약(공간탐색 ➔ 소믈리에 ➔ 잔여석검증 ➔ 패스발급), 구독(진단 ➔ 융해 ➔ 1초결제 ➔ 월간케어), 챌린지(피드 ➔ 투표 ➔ 영상업로드 ➔ 랭킹순환).
2. **조건 분기 및 예외 복구(Fallback) 메커니즘 필수 탑재**:
   - 타임슬롯 마감 시 취소 대기 접수, 결제 오류 시 대체 수단 전환, 글자수/규격 검증 오류 시 미세 보정 등 실제 사용자 이탈을 방지하는 예외 복구 파이프라인을 전수 수록합니다.
3. **Mermaid 프로세스 다이어그램 (Decision Diamonds)**:
   - 단순 1열 상자 나열이 아닌, 조건 판단 마름모 노드(`{ }`)와 분기 화살표(`-->|조건|`), 복구 순환 점선(`-.->`)이 포함된 실질적인 비즈니스 프로세스 다이어그램으로 구성합니다.

## 3. 목적별 핵심 시나리오 요약

### 💻 목적 1: [개발자 야간 몰입 / 정밀 기어 번들] (`TD 데이터 계측 번들형`)
- **시작 ➔ 완료**: 개발 커뮤니티 유입 ➔ `W09-TDS` 정밀 파라미터 설정 ➔ 스마트 타이머 번들 선택 ➔ 결제 승인 ➔ 최적 브루잉 프로파일 발급

### 🔬 목적 2: [월간 TDS 최적화 / 성분 리포트 구독] (`LR 가로 초고속 구독 파이프라인`)
- **시작 ➔ 완료**: HPLC 데이터시트 확인 ➔ 30일 정기배송 선택 ➔ HPLC 리포트 신청 ➔ 1초 결제 ➔ 정기구독 확정

### 🎁 목적 3: [테크 동료 선물 / 소스코드 각인] (`TD 테크 각인 4단형`)
- **시작 ➔ 완료**: 기어 샵 유입 ➔ 브루잉 스케일 선택 ➔ 깃허브 핸들/코드 각인 입력 ➔ 선물 결제 ➔ 모바일 보증서 발급

### 🔄 목적 4: [브루잉 데이터 아카이빙 / JSON 내보내기] (`TD + Loop 순환 루프형`)
- **시작 ➔ 완료**: 브루잉 콘솔 실행 ➔ 추출 완료 데이터 JSON 내보내기 ➔ 커밋 뱃지 획득 ➔ **내일 브루잉 세션 순환**

### ⚡ 목적 5: [해커톤 / 개발팀 밤샘 코딩 부스팅] (`TD 해커톤 부스팅형`)
- **시작 ➔ 완료**: 해커톤 지원 링크 유입 ➔ 10인 개발팀 부스팅 팩 선택 ➔ 법인카드 간편결제 ➔ 해커톤 당일 특급 배송

## 4. ⚙️ 서비스 흐름도 자동 생성 실행 파이프라인 (Execution Pipeline)

사용자가 **"윤기준 서비스 흐름도 실행"**을 명령할 경우 다음 절차가 자동으로 즉시 수행됩니다:
1. **[목적 매트릭스 검증]**: 상기 5대 목적의 6대 핵심 흐름 및 5종 토폴로지 적합성을 확인한다.
2. **[15개 파일 일괄 생성]**: `서비스_흐름도_목적1~5`의 `.md`, `.mmd`, `.svg` 파일을 빠짐없이 동시 생성한다.
3. **[SVG 벡터 컴파일]**: `@mermaid-js/mermaid-cli`를 통해 투명 배경 벡터 그래픽으로 일괄 렌더링한다.
4. **[정합성 검토 보고]**: 상·하위 문서 링크 및 6대 프레임워크 100% 준수 여부를 사용자에게 보고한다.
