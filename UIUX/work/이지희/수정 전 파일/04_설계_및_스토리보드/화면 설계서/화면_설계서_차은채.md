## 3. 이커머스 핵심 인터랙션 명세

1. **🤍 찜목록 (Wishlist)**:
   - 각 상품 카드의 🤍 버튼 클릭 시 🖤 상태로 전환되며, GNB의 `찜목록` 뱃지 카운트 실시간 업데이트.
   - GNB의 `찜목록` 버튼 클릭 시 찜한 상품 목록 모달이 팝업되며 즉시 장바구니로 이동 가능.
2. **🛒 장바구니 (Cart)**:
   - 각 상품 카드의 `🛒 담기` 버튼 클릭 시 GNB의 `장바구니` 뱃지 카운트 증가.
   - GNB의 `장바구니` 버튼 클릭 시 총 결제 예상 금액 계산 및 1초 결제 모달 팝업.
3. **⏱️ 180초 브루잉 타이머**:
   - `▶ 시작` 클릭 시 1초 단위로 03:00 ➔ 00:00 카운트다운 진행 및 앰비언트 리추얼 상태 표시.
