## 🎯 2. 클라이언트 1인당 5대 접속 목적 (5-User-Goal Matrix)

입력 파일의 브랜드 정보, 사용자 유형, 사용자 목표, 주요 기능, 콘텐츠와 분석 결과를 빠짐없이 해석하여 아래 5가지 구별되는 접속 목적별 사이트맵을 설계합니다:

1. **[목적 1: 브랜딩/탐색 모드]**
   - 브랜드 아포테케리 스토리, 360도 3D 비주얼 공간 투어, 수색 비주얼 에세이 중심의 사이트맵
2. **[목적 2: 커머스/구독 모드]**
   - 맞춤 정기구독 시뮬레이터, 슬라이드아웃 Cart Drawer 결제, 빠른 1-Click 주문 흐름 사이트맵
3. **[목적 3: 커스텀/선물 모드]**
   - 라이브 3D 이니셜 각인 틴케이스 제작, 믹솔로지 커스텀 키트 및 프리미엄 선물 신청 사이트맵
4. **[목적 4: 리추얼/타이머 모드]**
   - 3분 뽀모도로/브루잉 정밀 타이머 실행, 앰비언트 사운드 힐링 및 모닝/나이트 리추얼 전용 사이트맵
5. **[목적 5: 재방문/소셜 모드]**
   - 숏폼 레시피 카루셀, 소셜 믹솔로지 챌린지 응모 및 팝업/이벤트 알림 신청 사이트맵

## 📐 4. 사이트맵 상세 설계 및 작성 규칙

1. **계층 구조 구분 (Depth 1 ~ 3)**:
   - 페이지를 **1차 (Depth 1 - GNB)**, **2차 (Depth 2 - Sub/Category)**, **3차 (Depth 3 - Detail/Modal/Action)** 깊이로 명확히 구분하고 상위·하위 관계를 명확히 표시합니다.
2. **영향 범위 및 영역 구분**:
   - **공통 영역**: Header, Footer, GNB, Quick Dock, 검색 모달, Cart Drawer
   - **회원 상태별 영역**: 비회원(로그인/가입 유도), 일반 회원, VIP 멤버십/특권 영역
   - **주요 사용자 여정(User Journey)**: 해당 접속 목적의 시작부터 최종 목적 달성까지의 핵심 이동 경로
   - **예외 페이지**: 404 Not Found, 결제 실패/취소 모달, 네트워크 오류, 장바구니 품절/오류 페이지
3. **`[가정]` 표기 원칙**:
   - 입력 파일에 명시되지 않은 사실이나 기획 세부사항은 임의로 확정하지 말고 반드시 `[가정]`으로 표시합니다.
4. **무결성 검토**:
   - 상위-하위 페이지 간 연결 링크가 끊긴 페이지(Dead Link)와 중복 명시된 페이지가 없도록 사전 검토 후 구성합니다.

## 📄 5. 세부 출력 파일별 구성 항목

### 1) 마크다운 문서 (`[클라이언트이름]_사이트맵_목적N_[목적명].md`)
아래 6가지 필수 항목을 포함하여 작성합니다:
- **프로젝트 개요**: 해당 클라이언트 브랜드 및 접속 목적 정의
- **설계 근거와 핵심 사용자 목표**: 리서치 기반 인사이트 및 본 사이트맵이 달성하고자 하는 핵심 목표
- **전역 내비게이션 구조**: GNB, LNB 및 공통 메뉴 체계
- **계층형 사이트맵**: 1차, 2차, 3차 깊이의 트리 구조 텍스트
- **페이지별 정의 표**: 아래 6개 컬럼 표로 작성
  | 구분 (Depth) | 페이지명 | 페이지 목적 | 핵심 콘텐츠 | 주요 기능 | 연결 페이지 |
  |---|---|---|---|---|---|
- **Mermaid 다이어그램**: `flowchart TD` 문법으로 작성한 사이트맵 다이어그램

### 2) Mermaid 전용 코드 (`[클라이언트이름]_사이트맵_목적N_[목적명].mmd`)
- `사이트맵.md`에 사용한 순수 Mermaid `flowchart TD` 코드만 포함하여 저장 (마크다운 펜스 블록 제외)

### 3) SVG 벡터 파일 (`[클라이언트이름]_사이트맵_목적N_[목적명].svg`)
- 한글이 깨지지 않으며 확대해도 정밀하게 읽을 수 있는 유효한 XML 백터 SVG 형식으로 생성
