다음 5가지 접속 목적별로 각각 UTF-8 인코딩 파일 세트(.md, .mmd, .svg)를 생성해줘:

3. 목적 3 [커스텀/선물 모드]: `서비스_흐름도$(클라이언트번호)_$(이름)_목적3_커스텀선물.md / .mmd / .svg` (수직 TB Y자형 병렬 커스텀 구도, 로즈/펄 톤)
4. 목적 4 [리추얼/타이머 모드]: `서비스_흐름도$(클라이언트번호)_$(이름)_목적4_리추얼타이머.md / .mmd / .svg` (수직 TD 180초 순환 루프 구도, 미드나잇/오로라 톤)
5. 목적 5 [재방문/소셜 모드]: `서비스_흐름도$(클라이언트번호)_$(이름)_목적5_재방문소셜.md / .mmd / .svg` (수직 TD 소셜 매트릭스 그리드 구도, 바이올렛/네온 톤)

시각적 차별화 & 클라이언트 니즈 매핑 필수 지침:
- `[사이트 분석] 가상클라이언트_$(이름)_위케티_분석결과.md`의 핵심 요구사항(REQ-01~05)을 반드시 탐독하고, 단계별 명세표(Table)의 `클라이언트 요구사항 (REQ ID)` 컬럼과 3대 요소 카드에 1:1로 매핑해줘.
- `서비스 흐름도 양식.md`에 기재된 표준 4대 페이즈 골격을 기본 베이스로 유지하여 가독성과 통일감을 확보하되, 5개 목적 특성에 맞게 서브그래프 박스, 방향, 노드 도형, 색상을 다채롭게 표현해줘:
  1. 목적 1 [브랜딩/탐색 모드]: `flowchart TD` (수직 상 ➔ 하 3D 갤러리 타임라인 구도, 웜 앰버/세이지 톤, `([캡슐형])` / `{{육각형}}` / `[/사선/]` 도형)
  2. 목적 2 [커머스/구독 모드]: `flowchart TD` (수직 상 ➔ 하 정밀 커머스 드롭다운 구도, 쿨 블루/골드 톤, `[직사각형]` / `{다이아몬드}` / `{{육각형}}` 도형)
  3. 목적 3 [커스텀/선물 모드]: `flowchart TB` (수직 상 ➔ 하 Y자형 병렬 커스텀 트랙 결합 구도, 로즈/퍼플 펄 톤, `{{육각형}}` / `[/평행사변형/]` / `([캡슐형])` 도형)
  4. 목적 4 [리추얼/타이머 모드]: `flowchart TD` (수직 상 ➔ 하 180초 순환 카운트다운 루프 구도 `A --> B --> C --> A`, 미드나잇/오로라 톤, `((원형))` / `(라운드)` / `{다이아몬드}` 도형)
  5. 목적 5 [재방문/소셜 모드]: `flowchart TD` (수직 상 ➔ 하 크리에이터 릴스 매트릭스 구도, 바이올렛/네온 시안 톤, `[/평행사변형/]` / `{{육각형}}` / 그리드 메쉬 연결)
- **화면 가운데 정렬**: `.md` 생성 시 모든 Mermaid 다이어그램 블록을 반드시 `<div align="center">` 마크업으로 감싸 화면 중앙에 정렬되도록 해줘.

작성 규칙 및 출력 파일 규격:
- 각 목적별로 총 3개 파일세트(.md, .mmd, .svg)를 반드시 생성해줘.
- .mmd 작성이 끝난 후 아래 CLI 명령을 실행하여 고품질 벡터 이미지(.svg) 파일을 반드시 생성해줘:
  `npx -y @mermaid-js/mermaid-cli -i <서비스_흐름도_파일명.mmd> -o <서비스_흐름도_파일명.svg> -b transparent`
- 시작점과 종료점을 명확히 표시해줘.
- 카드별로 [사용자 행동 → 화면 접점 → 서비스 반응] 3대 요소 및 [클라이언트 요구사항 REQ ID]를 필수 기재해줘.
- 모든 화면 이름은 사이트맵의 페이지 이름과 일치시켜줘 (1:1 라벨 동기화).
- 연결이 끊긴 단계나 도달할 수 없는 화면이 없는지 검토해줘.
- 작업 완료 후 생성한 파일(.md, .mmd, .svg)의 상대 경로와 각 파일의 용도를 짧게 출력해줘.
