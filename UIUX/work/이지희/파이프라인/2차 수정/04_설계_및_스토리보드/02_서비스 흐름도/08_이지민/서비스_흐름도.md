## 1. 5대 서비스 흐름도 자동 생성 프레임워크 (Generation Framework)

본 가이드는 클라이언트 실행 명령 시 기존 흐름도와 중복되지 않는 **5개의 상호 배타적 이용 목적을 도출하고 서로 다른 형태의 다이어그램으로 자동 생성**하기 위한 표준 지침입니다.

### 1.1 5대 상호 배타적 도메인 축 (5 Distinct Domain Axes)
1. **축 ① [시험기간 잠깨기 & 1초 수색 변환 에이드형]**: AURORA-SIM-01 수색 체인저 조작, 에너지 부스팅 에이드 & 글래스 구매
2. **축 ② [자취생 가성비 & 30일 홈카페 정기구독형]**: 학생증 20% 할인 인증, 30일 홈카페 구독 팩 1초 신청 및 무료 배송
3. **축 ③ [친구 생일 선물 & 파스텔 틴세트 카카오 선물형]**: 파스텔 틴케이스 세트, 감성 일러스트 각인, 카카오톡 선물하기
4. **축 ④ [홈카페 브이로그 숏폼 & 적립금 리워드 루프형]**: 유튜브/인스타 브이로그 영상 링크 인증, 5,000P 적립 및 피드 박제 루프
5. **축 ⑤ [대학 동아리 / 감성 일일 다도회 키트 대량 발주형]**: 축제 및 동아리 부스용 수색 변환 에이드 대용량 벌크 주문

### 1.2 목적별 6대 핵심 서비스 흐름 설계 지침 (6-Step Architecture)
```
[1. 시작 지점] ➔ [2. 핵심 행동] ➔ [3. 전환 목표] ➔ [4. 필요한 기능] ➔ [5. 예외 상황] ➔ [6. 완료 결과]
```

### 1.3 5대 다이어그램 형태(Topology) 차별화 강제 규칙
- **목적 1**: `flowchart TD` (수색 체인저 조작 ➔ 글래스 번들 결제 트리형)
- **목적 2**: **`flowchart LR` (가로 초고속 학생 구독 파이프라인)**
- **목적 3**: `flowchart TD` (2개 노드씩 짝지어진 4단 Z세대 선물형)
- **목적 4**: **`flowchart TD` + Loop (브이로그 인증 & 적립 순환 루프형 `-.->`)**
- **목적 5**: `flowchart TD` (동아리 행사 ➔ 대용량 킷 스테이지형)

### 1.4 서비스 흐름도 고유 설계 지침 (가변 스테이지 & 의사결정 분기 체계)
본 서비스 흐름도는 **획일적인 `Phase 1~4` 고정 템플릿을 전면 탈피**하고, 클라이언트의 5대 방문 목적별 비즈니스 로직에 맞춘 **가변 스테이지(Dynamic Stages) 및 의사결정 분기(`{ }`) / 예외 복구(Fallback)** 원칙을 준수하여 작성되었습니다:

1. **목적별 가변 여정 스테이지 (Dynamic Stages)**:
   - 각 목적의 실제 비즈니스 흐름에 따라 3~5단계의 가변 스테이지로 유연하게 재구성합니다.
   - 예: 시향 예약(공간탐색 ➔ 소믈리에 ➔ 잔여석검증 ➔ 패스발급), 구독(진단 ➔ 융해 ➔ 1초결제 ➔ 월간케어), 챌린지(피드 ➔ 투표 ➔ 영상업로드 ➔ 랭킹순환).
2. **조건 분기 및 예외 복구(Fallback) 메커니즘 필수 탑재**:
   - 타임슬롯 마감 시 취소 대기 접수, 결제 오류 시 대체 수단 전환, 글자수/규격 검증 오류 시 미세 보정 등 실제 사용자 이탈을 방지하는 예외 복구 파이프라인을 전수 수록합니다.
3. **Mermaid 프로세스 다이어그램 (Decision Diamonds)**:
   - 단순 1열 상자 나열이 아닌, 조건 판단 마름모 노드(`{ }`)와 분기 화살표(`-->|조건|`), 복구 순환 점선(`-.->`)이 포함된 실질적인 비즈니스 프로세스 다이어그램으로 구성합니다.

## 3. 목적별 핵심 시나리오 요약

### 🎨 목적 1: [시험기간 잠깨기 / 수색 변환 에이드] (`TD 인터랙션 탐색형`)
- **시작 ➔ 완료**: 인스타 스토리 유입 ➔ `W08-COLOR` 수색 체인저 조작 ➔ 부스팅 에이드 선택 ➔ 1초 결제 ➔ 제조 팁 PDF 수령

### 📦 목적 2: [자취생 가성비 / 30일 홈카페 구독] (`LR 가로 초고속 구독 파이프라인`)
- **시작 ➔ 완료**: 학생 할인 배너 유입 ➔ 학생증 간편 인증 ➔ 30일 구독 주기 설정 ➔ 결제 승인 ➔ 첫 달 30% 할인 적용

### 🎁 목적 3: [친구 생일 / 파스텔 틴세트 선물] (`TD Z세대 선물 4단형`)
- **시작 ➔ 완료**: 선물 큐레이션 유입 ➔ 파스텔 틴세트 선택 ➔ 감성 메시지 작성 ➔ 카카오 선물하기 결제 ➔ 모바일 기프트 카드 전송

### 📹 목적 4: [홈카페 브이로그 / 숏폼 챌린지] (`TD + Loop 순환 루프형`)
- **시작 ➔ 완료**: 브이로그 룸 접속 ➔ 유튜브/인스타 영상 링크 등록 ➔ 5,000P 적립 ➔ **다음 영상 챌린지 순환**

### 🎪 목적 5: [동아리 축제 / 일일 다도회 키트] (`TD 캠퍼스 축제형`)
- **시작 ➔ 완료**: 동아리 단체 주문 링크 유입 ➔ 축제용 대용량 키트 선택 ➔ 학생회 할인 결제 ➔ 축제 전날 캠퍼스 직배송
