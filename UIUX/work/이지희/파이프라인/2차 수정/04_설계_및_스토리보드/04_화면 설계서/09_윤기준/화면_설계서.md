## 1. 5대 레이아웃 원형 기반 UI 구조 차별화 분석 (윤기준 맞춤)

본 설계서는 획일화된 템플릿 나열을 탈피하여, **윤기준 클라이언트의 5대 방문 목적과 고유 페르소나**에 최적화된 **`C-3 엔지니어링 데이터 대시보드형 (Precision Data Brewing)`** 원형을 채택하여 설계되었습니다.

### 1.1 5대 독립적 서비스 이용 목적 정의 (Use Cases 1~5)

#### 📌 목적 1: 0.1g 정밀 계량 & 수온/시간 TDS 추출 프로파일링
- **핵심 이동 경로**: `W09-HOME ➔ W09-BUILD ➔ W09-DRAWER ➔ W09-DONE`
- **서비스 상세 로직**: 0.1g 계량 단위, 85℃ 수온, 180초 추출 TDS 수율 곡선 시뮬레이션 및 데이터시트 확인 후 발주

#### 📌 목적 2: 수질(경도/TDS) 데이터 매칭 & 맞춤 티백 처방
- **핵심 이동 경로**: `W09-HOME ➔ W09-CATALOG ➔ W09-DRAWER ➔ W09-DONE`
- **서비스 상세 로직**: 사무실 정수기 수질 TDS(45ppm) 입력 후 최적 용출 티백 자동 매칭 및 30일 정기배송

#### 📌 목적 3: 개발자 코드 구문(Syntax) 3D 레이저 각인 텀블러 선물
- **핵심 이동 경로**: `W09-HOME ➔ W09-BUILD ➔ W09-DRAWER ➔ W09-DONE`
- **서비스 상세 로직**: `git commit -m 'Relax'` 등 원하는 코드 문구를 텀블러에 3D 레이저 각인하여 선물

#### 📌 목적 4: 0.1초 단위 정밀 브루잉 타이머 & JSON 추출 로그 다운로드
- **핵심 이동 경로**: `W09-HOME ➔ W09-RITUAL ➔ W09-COMM ➔ W09-DONE`
- **서비스 상세 로직**: 밀리초 타이머로 브루잉 후 용출 농도 데이터를 JSON 파일로 다운로드 및 깃허브 연동

#### 📌 목적 5: 해커톤 48시간 올나잇 120포 집중력 팀팩 구매
- **핵심 이동 경로**: `W09-HOME ➔ W09-ESTIMATE ➔ W09-DRAWER ➔ W09-DONE`
- **서비스 상세 로직**: 개발팀 인원수 기반 해커톤 120포 번들 25% 할인 결제 및 새벽 당일 퀵배송
