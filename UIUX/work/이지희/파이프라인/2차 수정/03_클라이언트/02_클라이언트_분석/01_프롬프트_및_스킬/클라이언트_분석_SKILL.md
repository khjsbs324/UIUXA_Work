## 🔍 1. 클라이언트 자동 감지 및 선택 로직 (Client Selection Rule)

1. **[Phase 1] 기존 미완료 클라이언트 우선 처리**:
   - `03_사이트_분석/` 폴더에 아직 3단계 보고서가 작성되지 않은 기존 클라이언트(예: `신유진`, `임태경`, `한명석` 등)를 자동 감지하여 가장 빠른 번호의 클라이언트를 선택합니다.
   - 2단계 분석 보고서(`02_클라이언트_분석/`)가 이미 존재하는 경우 해당 보고서를 읽고 3단계 완결로 이동하며, 2단계 보고서도 없는 경우 2단계 보고서를 신규 작성합니다.
2. **[Phase 2] 신규 생성 클라이언트 처리**:
   - 모든 기존 클라이언트의 3단계 완결이 끝난 후에는 1단계(`가상클라이언트_SKILL.md`)에서 새로 창작된 **신규 가상 클라이언트 1명 기획서**를 자동으로 읽어 2단계 분석 보고서를 작성합니다.
3. **명시적 지정 시**: 사용자가 특정 클라이언트 이름(예: `윤서연`, `신유진`) 또는 파일 경로를 인수로 전달한 경우 해당 클라이언트를 읽습니다.
4. **네이밍 룰 고정**:
   - 기존 파일들과의 일관성을 100% 유지하도록 파일명을 다음 규격으로 고정합니다:
   - `[클라이언트$(번호)]_$(이름)_$(소속/역할)_$(핵심컨셉).md`
