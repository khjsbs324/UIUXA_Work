# WICKETA 가상 클라이언트 자동화 마스터 컨텍스트 (03_클라이언트)

본 `CLAUDE.md`는 WICKETA 가상 클라이언트 기획, 요구사항 분석, 레퍼런스 사이트 매핑 분석을 통합 통제하는 **최우선 마스터 시스템 스킬**입니다. 

사용자가 **"가상 클라이언트 실행 해"** 지시를 내리면 본 문서를 기준으로 **기존 미완료 클라이언트 3단계 완결 ➔ 완결 후 신규 1명 생성 및 3단계 완결** 파이프라인을 자동 연계 실행합니다.

---

## 🎯 마스터 실행 규칙 (Master Priority & Auto-Pipeline Rule)

사용자가 **"가상 클라이언트 실행 해"**라고 명령 시 AI는 아래 2가지 단계(Phase)에 따라 작동합니다:

### [Phase 1] 기존 미완료 클라이언트 우선 완결 (Prioritize Existing Incomplete Clients)
1. `03_사이트_분석/` 폴더를 점검하여 **3단계 사이트 분석이 완성되지 않은 기존 클라이언트**가 있는지 감지합니다.
2. 미완료된 기존 클라이언트가 존재할 경우:
   - 2단계 분석 보고서(`02_클라이언트_분석/`)가 없는 경우: 2단계 요구사항 분석 작성 ➔ 3단계 사이트 분석 완성
   - 2단계 분석 보고서는 있으나 3단계가 없는 경우: 해당 2단계 보고서를 읽고 3단계 사이트 분석 완성
3. 실행할 때마다 미완료된 클라이언트를 1명씩 선택하여 3단계까지 완결 처리합니다.

### [Phase 2] 신규 클라이언트 생성 ➔ 3단계 자동 파이프라인 (New Client Creation Pipeline)
1. 모든 기존 클라이언트의 3단계 사이트 분석이 100% 완료되면 자동으로 Phase 2 모드로 전환됩니다.
2. 이후 **"가상 클라이언트 실행 해"** 지시 시:
   - **1단계**: 기존 클라이언트들과 중복 0건인 **신규 가상 클라이언트 1명 새로 생성** (`01_가상_클라이언트/`)
   - **2단계**: 방금 생성된 신규 클라이언트의 **요구사항 분해 & IA 분석 작성** (`02_클라이언트_분석/`)
   - **3단계**: 2단계 보고서 기반으로 **9개 벤치마크 사이트 심층 분석 완성** (`03_사이트_분석/`)

## 🚀 "가상 클라이언트 실행 해" 자동 순차 실행 지침

1. **[1단계 확인 및 생성]**:
   - `01_가상_클라이언트` 폴더 내 미분석 클라이언트가 있는지 확인하고, 필요 시 세대별 페르소나 기획서를 신규 창작 생성합니다.
2. **[2단계 자동 연계]**:
   - 미분석 클라이언트 기획서와 `02_리서치_데이터/output/분류.md`(50개 신규 리서치 갱신 파이프라인 적용)를 읽고 `클라이언트_분석_SKILL.md`를 통해 `02_클라이언트_분석/[클라이언트$(번호)]_$(이름)_...md`를 생성합니다.
3. **[3단계 자동 연계 및 리서치 DB 매핑]**:
   - 2단계 분석 보고서와 `02_리서치_데이터`의 최신 통합 레퍼런스 DB(`output/레퍼런스병합.md` - 50개 단위 검증 링크 파이프라인 연동)를 매핑합니다.
   - 이전 클라이언트가 선정한 사이트와의 **중복 0건 규칙** 및 **접속 검증된 Active Link** 기준 하에 9개 벤치마크 사이트(디자인 3 / 사용성 3 / 디자인+사용성 3) 심층 분석 보고서(`03_사이트_분석/[사이트 분석] 가상클라이언트$(번호)_$(이름)_위케티_분석결과.md`)를 도출합니다.
