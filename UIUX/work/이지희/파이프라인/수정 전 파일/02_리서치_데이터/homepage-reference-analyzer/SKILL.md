# 리서치 데이터 수집 및 사실 확인 Skill

본 Skill은 주관적 해석, 가치 판단 및 임의 분석 보고서 생성을 철저히 배제하고, 레퍼런스 데이터베이스(`[리서치]*.txt` / `[리서치 결과]*.txt`) 및 입력 자료로부터 **객관적 데이터 수집, 원문 팩트 확인, 출처 검증 및 중복 정제**에만 온전히 집중합니다.

---

# 실행 조건

1. 기본 리서치 자료 확인:
   - `리서치/` 폴더 내 파일명에 `[리서치]` 또는 `[리서치 결과]`가 포함된 TXT/MD 파일 존재 여부를 확인합니다.
   - 기본 파일: `[리서치]_위케티_UIUX_레퍼런스_200.txt` (총 200개 브랜드 데이터베이스)

2. 지원 입력 형식:
   - md
   - txt

3. 필수 입력 자료:
   - `[리서치]` 지정 기본 레퍼런스 데이터베이스 파일
   - 사용자 동적 추가 리서치 자료 (`"리서치 자료 추가 입력"` 명령 시)

4. 입력 파일이 없을 경우:
   - 필요한 기본 파일이 존재하지 않으면 실행을 중단하고 사용자에게 안내합니다.

---

# 입력

1. 기본 입력 자료:
   - `리서치/[리서치]_위케티_UIUX_레퍼런스_200.txt` (200개 레퍼런스 팩트 데이터)

2. 수집 및 검증 대상 팩트 항목:
   - 브랜드명 (공식 명칭)
   - 웹사이트 주소 (URL 및 접속 링크)
   - 업종 / 카테고리
   - 브랜드 소개 (원문 사실 텍스트)
   - 비주얼 요소 (컬러 톤, 서체 명칭, 여백 및 레이아웃 팩트)
   - 주요 프론트엔드 명시 기능 (퀴즈 폼, 필터, 스티키 바, 시뮬레이터 등 팩트)
   - 원문 출처 구획 (`[기본 자료]` / `[추가 자료]`)

3. 동적 추가 입력 자료:
   - 사용자가 `"리서치 자료 추가 입력"` 명령 시 전달하는 추가 URL, 텍스트, 파일

---

# 목적

제공된 `Template.txt` 구조를 준수하되, **주관적 분석/해석/평가 기능을 완전히 제거**하고, 오직 레퍼런스 데이터의 **정확한 사실 수집, 중복 검증, 원문 팩트 매칭 및 출처 정리**만을 수행합니다.

다음 작업만 수행합니다:
- 레퍼런스 목록 및 출처 팩트 수집
- 객관적 팩트 항목별 데이터 정제 (브랜드명, URL, 카테고리, 명시된 기능)
- 중복 데이터 상호 교차 검증 및 정확한 출처 보존
- 주관적 분석이나 판단이 배제된 팩트 중심 데이터베이스 정리

---

# 작업 절차

## 1단계: 팩트 데이터 탐색 및 원문 검증
- `리서치/` 폴더에서 `[리서치]` 포함 파일 읽기
- 원문에 포함된 사실(Fact)만 추출하고 해석이나 미사여구 배제

## 2단계: 중복 데이터 검증 및 교차 확인
- 기본 자료 및 추가 자료 간의 동일 브랜드/URL 중복 여부 전수 조사
- 중복 발견 시 팩트 데이터를 하나로 합치고, 모든 출처(`[기본 자료: 파일명]`, `[추가 자료: URL]`)를 보존

## 3단계: 사실 기반 항목별 데이터 구조화
- 각 레퍼런스별로 팩트 항목 6가지 추출:
  1) 브랜드명
  2) 웹사이트 URL
  3) 업종/카테고리
  4) 원문 브랜드 설명
  5) 명시된 비주얼 톤 & 레이아웃 팩트
  6) 명시된 프론트엔드 실재 기능

## 4단계: 무분석/무추측 팩트 라벨링
- 자료에 기술되지 않은 정보는 절대로 추측하여 적지 않으며, "미기재" 또는 "확인 불가"로 명시

## 5단계: 정제된 팩트 데이터베이스 파일 생성
- 주관적 평가가 배제된 정제 팩트 리포트 작성 및 저장

---

# 작성 규칙

1. 주관적 분석 및 해석 완전 배제:
   - "좋다/나쁘다", "장점/단점", "인사이트", "추천 포인트" 등의 주관적 평가나 장단점 분석을 일체 작성하지 않습니다.

2. 데이터 수집 및 사실 확인 엄수:
   - 입력 데이터에 명시적으로 존재하는 사실(Fact)과 원문 내용만 수집하고 정리합니다.

3. 무할루시네이션 (No Guessing) 규칙:
   - 자료에 명시되어 있지 않은 사실을 지어내거나 추측하지 않으며, 확인할 수 없는 내용은 반드시 "확인 불가"로 기재합니다.

4. 정확한 출처 기록:
   - 모든 수집 데이터 항목에는 수집 출처(`[기본 자료]` / `[추가 자료]`)를 명확하게 표기합니다.

5. Template 구조 유지:
   - 제공된 Template.txt의 섹션 구조를 변형 없이 100% 유지합니다.

- 순수 데이터 수집 및 팩트 확인(원문 검증, URL/기능 확인, 출처 표시)에만 집중했는가
