# 홈페이지 레퍼런스 보고서 작성 및 분할 규칙 (Report Format & Rules)

본 문서는 3단계 출력 포맷 규칙과 6단계 8대 비교 분석 프로세스에 따른 보고서 작성 양식을 정의합니다.

---

## 1. 6대 필수 파일 생성 및 분할 규칙

1) **UTF-8 인코딩**: 모든 결과 파일은 UTF-8 .txt 파일로 작성합니다.
2) **파일당 최대 100개**: TXT 파일 1개당 최대 100개 홈페이지 분석 결과만 포함합니다.
3) **범위 지정 파일명**: 100개 초과 시 `001-100`, `101-200`처럼 번호 범위를 파일명 뒤에 지정합니다 (예: `02-홈페이지별_분석_001-100.txt`).
4) **계산 단위**: 홈페이지 1개 분석 건수를 결과 1개로 계산합니다.
5) **독립 파일 분리**: `자료목록`, `홈페이지별 분석`, `전체 비교 분석`, `최종 인사이트`를 각각 별도의 파일로 분리합니다.
6) **내용 분할 금지**: 한 홈페이지의 분석 내용 전체는 절대로 두 파일로 나누거나 쪼개지 않고 단일 파일 내에서 완결 처리합니다.

---

## 2. 생성 결과물 파일 구조 예시

- `output/01-자료목록_및_중복정리.txt`
- `output/02-홈페이지별_분석_001-100.txt` (100개 초과 시 101-200.txt 등 추가 생성)
- `output/03-전체비교분석.txt`
- `output/04-최종인사이트.txt`

---

## 3. 세부 파일별 작성 서식

### `output/01-자료목록_및_중복정리.txt`
```text
================================================================================
                    01. 리서치 자료 목록 및 중복 정리 결과
================================================================================

[기본 리서치 자료 목록]
- 파일명: ...
- 검색 및 추출된 홈페이지 수: ...

[추가 리서치 자료 목록] (추가 자료 입력 시)
- 파일명/URL/텍스트: ...

[중복 홈페이지 통합 관리 현황]
- 홈페이지명: ...
- 발견된 모든 출처: [기본 자료: 파일A.txt #L12], [추가 자료: URL_xxx]
```

### `output/02-홈페이지별_분석_001-100.txt`
```text
================================================================================
                    02. 홈페이지별 상세 분석 (001 - 100)
================================================================================

--------------------------------------------------------------------------------
[홈페이지 001] 홈페이지명
--------------------------------------------------------------------------------
- URL: ...
- 업종/분야: ...
- 자료 출처: [기본 자료 / 추가 자료]

1) 디자인 특징: ...
2) 화면 구성 (레이아웃): ...
3) 사용자 흐름: ...
4) 문구와 콘텐츠: ...
5) 주요 기능: ...
6) 장점과 단점: ...
7) 참고할 부분: ...
```

### `output/03-전체비교분석.txt`
```text
================================================================================
                    03. 전체 레퍼런스 종합 비교 분석
================================================================================

1. 그룹화 및 요소별 등장 횟수 / 비율
   - 상단 문의 버튼 배치: 80개 (80%) [공통 패턴]
   - 고객 후기 제공: 55개 (55%) [공통 패턴]
   ...

2. 패턴 구별 (공통 ≥30%, 반복 10~30%, 특이사례 <10%)
   ...

3. 공통점과 차이점 분석
   ...

4. 패턴별 장점과 문제점 (패턴명, 사용 홈페이지, 장점, 단점, 어울리는 상황)
   ...
```

### `output/04-최종인사이트.txt`
```text
================================================================================
                    04. 최종 레퍼런스 인사이트 및 적용 아이디어
================================================================================

1. 반드시 참고할 공통 방식 (근거 및 출처 연결)
2. 상황에 따라 선택할 방식
3. 차별화를 위해 참고할 독특한 방식
4. 새 홈페이지에 적용할 핵심 아이디어
5. 입력 자료만으로 부족한 판단 영역 및 추가 조사가 필요한 항목
```
