# 리서치 사이트 200개 분류 Skill

이 Skill은 제공된 200개의 리서치 사이트 목록과 '공통점_핵심컨셉_분석보고서'를 기반으로 카테고리를 분류하고, 분류 과정에서 파악된 전체 사이트의 공통 속성 요약과 WICKETA 4대 UI/UX 설계 전략에 따른 개별 사이트의 핵심 컨셉을 정리하여 리포트로 작성합니다.

제공되지 않은 가상의 사이트를 추가하지 않습니다. 200개 리서치 사이트 분류 범위를 이탈하지 않습니다. 최종 결과물은 200개 리서치 사이트 분류 리포트 MD 파일입니다.

> 공통 규칙(WICKETA 브랜드 컨셉, 4대 UI/UX 설계 전략 정의, 경로 통제)은 `CLAUDE.md`를 따른다. 아래는 이 단계 고유의 절차다.

---

# 실행 조건

1. 다음 입력 파일이 존재하는지 확인합니다.

지원 형식: md, txt, csv, json

필수 입력:
- 병합된 레퍼런스 데이터 (`output/레퍼런스병합.md` 또는 `[리서치_데이터] 위케티_200개_사이트_레퍼런스.txt`)
- 핵심 컨셉 및 설계 전략 데이터 (`[분석_보고서] WICKETA_UIUX_공통점_및_핵심컨셉_도출.txt` / 위치: `리서치 분석 분류/`)

2. 입력 파일이 없으면 필요한 파일을 안내한 후 종료합니다.

---

# 입력

사용자 요청: `$ARGUMENTS`

인수가 없으면 다음 위치에서 기본 입력을 찾습니다.

```text
input/
template/
references/
```

다음 문서를 사용합니다.
- 리서치 사이트 200개 목록 데이터 (`[리서치_데이터] 위케티_200개_사이트_레퍼런스.txt`)
- WICKETA 핵심 컨셉 및 4대 설계 전략 보고서 (`[분석_보고서] WICKETA_UIUX_공통점_및_핵심컨셉_도출.txt`)
- 카테고리 분류 기준 문서 (선택 사항)

---

# 목적

제공된 200개의 리서치 사이트를 체계적으로 분류(Categorize)하고, '공통점_핵심컨셉_분석보고서'에서 도출된 WICKETA 4대 UI/UX 설계 전략에 매핑하는 데 집중합니다.
분류 작업을 수행하며 전체 사이트의 주요 속성 교집합을 추출하고, 개별 사이트가 지닌 레퍼런스 가치를 'WICKETA 전략 컨셉 태그'로 요약하여 매핑합니다.

다음 내용을 추출하여 결과 문서에 반영합니다.
- WICKETA 브랜드 핵심 컨셉 ("Drink Me, Escape Reality : 현실에서 벗어나 마주하는 3분의 몽환적 안식처")
- 200개 사이트 기본 정보 (사이트명, URL)
- 카테고리 기준에 따른 전체 사이트의 공통 트렌드 요약 (서비스 모델, UIUX 교집합 등)
- WICKETA 4대 UI/UX 설계 전략 체계 수립 및 전체 사이트 매핑
- 매핑된 개별 사이트의 직관적인 '사이트 컨셉 태그' 도출

Template의 구조는 유지하며, 심층 분석보다는 정확한 분류 및 컨셉 매핑에 초점을 맞춥니다.

---

# 작업 절차

## 1단계
입력된 200개 리서치 사이트 목록과 '공통점_핵심컨셉_분석보고서'를 확인하고 분류를 위한 주요 축을 설정합니다.
- 사이트명 및 URL 확인
- 서비스 모델, 제공 데이터 방식, 주요 타겟층을 기준으로 1차 속성 분류

## 2단계
분류 기준을 세우는 과정에서 200개 사이트를 관통하는 공통 속성과 WICKETA 핵심 컨셉("Drink Me, Escape Reality") 교집합을 추출합니다.
- 공통으로 채택한 서비스 모델 및 데이터 제공 방식 교집합 도출
- 리서치 플랫폼 시장의 전반적인 UIUX 특징 및 4대 설계 전략 요약

## 3단계
추출된 속성을 바탕으로 카테고리를 정의하고 200개 사이트를 누락 없이 분류합니다.
- 카테고리 체계 정의 (예: 니치 프래그런스, 현대 다도, 웰니스 스킨케어 등 6대 산업군)
- 200개 사이트를 해당 카테고리에 정확히 매핑

## 4단계
카테고리에 매핑된 각 사이트의 레퍼런스 가치를 '공통점_핵심컨셉_분석보고서'의 WICKETA 4대 UI/UX 설계 전략 태그로 요약하여 추가합니다.
- 작성 예시:
  - [전략 1: 안식처 레이아웃] (오프화이트 여백, 0.5px 미세 구분선 모듈)
  - [전략 2: 공감각 시각화] (비주얼 아로마 휠, 테이스팅 게이지 모듈)
  - [전략 3: 감정 진단 퀴즈] (3단계 내면 상태 퀴즈 폼, 감성 찜 모듈)
  - [전략 4: 심리스 빌더] (커스텀 기프트 폼, 슬라이드아웃 Cart Drawer 모듈)

## 5단계
도출된 결과를 기반으로 Template 구조에 맞춰 마크다운 문서를 작성합니다.

---

# 출력 형식

다음 순서의 Markdown 문서를 생성합니다. 심층 분석이 아닌 분류와 매핑 결과 위주로 작성합니다.
- 리포트 제목 (200개 리서치 사이트 분류 리포트)
- WICKETA 핵심 브랜드 컨셉 및 4대 UI/UX 설계 전략 요약 (서두 배치)
- 종합 요약 및 카테고리별 통계
- 카테고리 체계 개요
- 카테고리별 사이트 매핑 및 분류 결과
  - 각 카테고리별로 속한 사이트 목록 나열
  - 사이트별 기본 정보(이름, URL)와 함께 WICKETA 4대 설계 전략 '사이트 컨셉 태그' 반드시 포함

최종 결과물은 200개 리서치 사이트 분류 리포트 MD 파일입니다.

# 작성 규칙

제공된 Template의 구조를 유지합니다. 심층 분석형 서술은 피하고, 명확한 분류(Categorize) 및 키워드컨셉 위주의 매핑 목적을 달성합니다. 새로운 섹션을 임의로 추가하거나 기존 섹션을 삭제하지 않습니다. 제공되지 않은 가상의 사이트를 생성하지 않습니다. 200개 사이트 전체가 누락 없이 분류되고 컨셉이 부여되어야 합니다. 최종 결과물은 반드시 200개 리서치 사이트 분류 리포트 MD 파일이어야 합니다.
