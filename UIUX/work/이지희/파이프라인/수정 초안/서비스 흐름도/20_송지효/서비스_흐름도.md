# WICKETA 송지효 서비스 흐름도  ## 고유 여정  - 클라이언트: 20 · 송지효 - 콘셉트: Vegan Community - 레이아웃: social - 핵심 인터랙션: 패키지 회수·재사용 미션과 투명한 인증 추적 - 상위 문서: [사이트맵](../../사이트맵/20_송지효/사이트맵.md)  ## 정상 흐름  1. `W20-HOME`에서 세계관 진입 2. `W20-DIAG`에서 감정·가용 시간·민감도 선택 3. `W20-MIX`에서 믹솔로지 레시피 3안 비교 4. `W20-RITUAL`에서 수색 변화와 180초 타이머 체험 5. `W20-BUILD`에서 제품·구독·패키지 조합 6. `W20-COMM`에서 리추얼 저장 또는 공유 7. `W20-DONE`에서 레시피 ID 확인  ## 오류와 대안  - 진단 결과 없음: 조건 완화와 전체 탐색 제공 - 재고 없음: 동일 감정 목표의 대체 베이스 티 제안 - 타이머 중단: 남은 시간과 레시피를 보존 - 저장 실패: 조합값 유지 후 재시도·복사 제공 - 접근성 모드: 사운드 없이 텍스트 진행 상태 제공  ```mermaid
