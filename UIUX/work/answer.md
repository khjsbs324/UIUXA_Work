# 학생 질문 답변

## 학생 이름

임연우

## 질문

“사용자가 기존 와이어프레임을 보완하기 위해 레퍼런스를 분류하고 분석한다는 내용이 있는 경우, 레퍼런스를 방대하게 찾기보다 사용자가 고른 형식과 가까운 레퍼런스를 찾고 사용성·심미성·무드 세 가지를 각각 분류·분석한다”는 내용을 기존 분류·분석 skill 파일에 넣어서 사용하는 것인지, 아니면 그 형식으로 별도의 분류·분석 파일을 작성해야 하는지 질문함.

## 답변

연우야 과부화 멈춰 ㅋㅋㅋ 전자가 맞아용~

지금 바로 저 형식으로 레퍼런스 분석 결과 파일을 따로 만들라는 뜻이 아니라, **기존에 사용하던 분류·분석 skill 파일 맨 아래에 저 내용을 규칙으로 추가**하라는 뜻이야.

그다음 수정한 skill을 사용해서 다시 실행하면, 레퍼런스를 무작정 많이 찾는 게 아니라 네가 원하는 사이트 형식과 가까운 사례를 찾고 결과를 **사용성·심미성·무드** 세 가지로 나눠서 분류하고 분석하게 만드는 거야.

정리하면 `기존 skill 내용은 그대로 유지 → 파일 아래에 새 규칙 추가 → 수정한 skill로 다시 실행 → 나온 결과 확인` 순서로 하면 됑!

## 참고한 내용

- 강사가 “기존에 있던 분석 파일에서 원하는 사이트 형식만 남길 수 있도록 파일을 추가 수정한다”고 설명한 내용
- “기존 내용을 수정하라는 말이 아님”이라고 기존 내용을 유지하도록 안내한 내용
- “파일 밑에 추가”라고 규칙을 넣을 위치를 구체적으로 안내한 내용
- 레퍼런스를 방대하게 찾기보다 학생이 선택한 사이트 형식과 가까운 사례를 찾도록 한 내용
- 레퍼런스를 `사용성`, `심미성`, `무드`의 세 기준으로 각각 분류하고 분석하도록 한 내용
- “분류 내용은 분류에, 분석 내용은 분석에”라고 결과의 역할을 구분하도록 안내한 내용

위 내용을 종합하여, 별도의 분석 결과 파일을 먼저 작성하라는 의미가 아니라 **기존 분류·분석 skill 파일 아래에 새로운 실행 규칙을 추가한 뒤 그 skill을 다시 사용하는 것**으로 답변했습니다.

분류·분석 skill 파일에 원하는 디자인·사용성·감성 기준을 추가하여 레퍼런스를 골라낸 이후, 수정한 분석 skill 파일을 기준으로 가상 클라이언트 생성 단계부터 다시 진행하면 되는지 질문함.

## 답변

응응 맞아 연우야! 이제 **수정한 분류·분석 skill로 나온 결과를 기준으로 가상 클라이언트 단계부터 다시 진행**하면 돼.

다만 기존에 만든 클라이언트와 설계 내용을 전부 삭제하고 처음부터 새로 만드는 건 아니야. 먼저 분석 결과에서 네가 가져오고 싶은 **사용성·디자인·감성의 장점**을 정리하고, 그 장점이 요구사항으로 들어가도록 기존 가상 클라이언트를 추가·보완해줘.

그다음 보완한 가상 클라이언트를 기준으로 설계 문서와 와이어프레임을 다시 실행하면 돼. 새 결과가 나오면 기존 와이어프레임에서 잘된 기능과 설계는 유지하고, 새로 보강된 디자인과 감성 표현을 비교해서 최종 병합해줘.

정리하면 `수정한 분석 skill 실행 → 선택한 레퍼런스 분석 결과 확인 → 기존 가상 클라이언트 요구사항 추가·보완 → 설계 문서와 와이어프레임 다시 실행 → 기존 결과의 장점과 새 결과 병합` 순서로 진행하면 됑!

## 참고한 내용

- 학생이 원하는 사용성·디자인·감성 기준에 맞는 레퍼런스만 남기도록 한 기존 지도 내용
- 기존 분석 내용을 삭제하지 않고 분류·분석 skill 아래에 새 규칙을 추가하도록 한 기준
- 현재 와이어프레임의 부족한 부분을 보완할 요구를 가상 클라이언트에 추가하도록 한 기준
- 기존 클라이언트와 설계 내용을 폐기하지 않고 요구사항을 추가·보완하도록 한 기준
- 기존 와이어프레임의 설계상 장점과 새 결과의 디자인·감성 장점을 최종 병합하도록 한 기준

# 학생 질문 답변

## 학생 이름

이은경

## 질문

와이어프레임을 단계별로 어떻게 진행하고 수정해야 하는지에 대한 피드백 요청.

## 답변

은경아, 와이어프레임은 아래 순서대로 단계별로 진행하면 돼.

### 와이어프레임 1단계

초반에 생성한 와이어프레임을 기반으로 초안을 생성해줘.

### 와이어프레임 2단계

최소 15개의 상품이 배치되도록 설계해줘.

### 와이어프레임 3단계

브랜드 정보와 최소 15개의 상품이 각 섹션에 조화롭게 배치될 수 있도록 수정해줘.

기존 클라이언트와 설계 내용은 삭제하거나 처음부터 다시 만들지 않고 그대로 유지하면 돼. 기존 설계 중심의 클라이언트 요구에는 **브랜드와 디자인 완성도를 중요하게 여기는 요구사항**을 추가하고, 회사의 철학, 기술력, 성과, 제작 과정 등 회사와 브랜드의 강점을 보여주는 내용도 보강해줘.

제품은 한곳에 모두 나열하지 말고, 중요한 제품을 관련된 이야기와 함께 여러 섹션에서 각각 강조해줘. 핵심 제품을 충분히 강조한 다음에는 전체 제품을 한눈에 볼 수 있는 모음 영역을 제공하면 돼.

반복적인 카드 구성만 사용하지 말고 큰 이미지, 화면 분할, 좌우 교차 배치, 에디토리얼형 구성 등 다양한 레이아웃을 적용해줘.

### 와이어프레임 4단계

3단계에서 진행한 와이어프레임을 기반으로 아래 내용을 진행하면 돼.

기존 내용을 빼는 방식보다 현재 결과에 필요한 요구사항과 콘텐츠를 추가하는 방향으로 진행해줘.

먼저 현재 와이어프레임의 부족한 부분을 **설계 관점**과 **디자인 관점**으로 나누어 최대한 구체적으로 분석해줘. 그다음 분석된 부족한 부분을 보완할 수 있는 요구사항을 가진 클라이언트를 추가하고, 추가한 클라이언트를 기반으로 설계와 와이어프레임을 다시 실행해서 최종 병합하면 돼.

레퍼런스는 방대하게 수집하지 말고 네가 선택한 사이트 형식과 가까운 사례를 찾아줘. 찾은 레퍼런스는 **사용성이 좋은 사이트**, **디자인이 좋은 사이트**, **감성을 잘 보여주는 사이트**로 각각 구분해서 분석하면 돼.

기존 분석 파일의 내용은 수정하거나 삭제하지 말고 파일 아래에 레퍼런스 탐색 기준과 분류·분석 규칙을 추가해줘. `분류`에는 레퍼런스를 사용성·심미성·무드로 나눈 결과를 작성하고, `분석`에는 각 사례에서 어떤 점을 참고하고 현재 와이어프레임의 무엇을 보완할지 작성하면 돼.

최종 메인페이지에는 필요한 정보를 충분히 담되 레퍼런스의 모든 요소를 그대로 넣지 말고, 각 레퍼런스의 장점을 목적에 맞게 선택해서 반영해줘. 마지막에는 기존 와이어프레임의 좋은 설계와 새로 보강한 디자인·감성의 장점을 하나의 결과로 병합하면 됑!

## 참고한 내용

- 초반에 생성한 와이어프레임을 기반으로 초안을 생성하는 1단계 진행 기준
- 최소 15개의 상품이 배치되도록 설계하는 2단계 진행 기준
- 브랜드 정보와 최소 15개의 상품을 각 섹션에 조화롭게 배치하는 3단계 수정 기준
- 기존 클라이언트와 설계 내용을 삭제하거나 처음부터 다시 만들지 않도록 한 유지 기준
- 브랜드와 디자인 완성도에 관한 요구사항과 회사·브랜드의 강점을 보여주는 내용을 보강하도록 한 기준
- 중요 제품을 여러 섹션에서 강조한 뒤 전체 제품 모음 영역을 제공하도록 한 기준
- 반복적인 카드 구성 외에 다양한 레이아웃을 적용하도록 한 기준
- 기존 결과를 삭제하기보다 필요한 요구사항과 콘텐츠를 추가하도록 한 4단계 기준
- 현재 와이어프레임의 부족한 부분을 설계 관점과 디자인 관점으로 구분해 구체적으로 분석하도록 한 기준
- 부족한 부분을 보완할 클라이언트를 추가하고 설계와 와이어프레임을 최종 병합하도록 한 기준
- 선택한 사이트 형식과 가까운 레퍼런스를 사용성·심미성·무드로 분류하고 분석하도록 한 기준
- 기존 분석 파일을 유지하면서 파일 아래에 탐색 기준과 분류·분석 규칙을 추가하도록 한 기준
- 최종 메인페이지에 필요한 정보를 충분히 담고 레퍼런스별 장점을 목적에 맞게 선택하여 반영하도록 한 기준

사용성, 디자인, 감성 기준으로 정리한 원하는 와이어프레임 방향과 CLI가 정리한 분석 내용을 가상 클라이언트 요구사항에 입력해도 되는지 질문함.

## 답변

응응 연우야 입력해도 돼! 지금 정리한 내용은 네가 원하는 와이어프레임의 방향이 구체적으로 잘 나와 있어서 가상 클라이언트 요구사항으로 사용하면 돼.

다만 분석 내용을 그대로 한 문단으로 넣기보다 사용성 요구사항, 페이지 구성 요구사항, 디자인과 감성 요구사항, 지양 사항으로 나눠서 입력해줘.

사용성 요구사항에는 과도한 구매 유도와 어려운 전문 용어를 지양하고, 직관적인 한글 네이밍과 카테고리별로 명확한 탐색 경로를 제공한다는 내용을 넣으면 돼.

페이지 구성 요구사항에는 메인페이지에 회사 소개, 대표 제품 Top 3, 사용자 후기를 배치하고, 전체 제품은 별도의 상품 카탈로그 서브페이지에서 카테고리별로 탐색할 수 있도록 구성한다는 내용을 넣어줘. 브랜드의 시작부터 현재까지의 이야기는 별도의 브랜드 소개 페이지에서 보여주도록 요구하면 돼.

- 핵심 제품 1: 카라비너 퀵 스틱 — 러닝 중 멈추지 않고 3초 안에 덧바르는 상황을 큰 이미지로 표현
- 핵심 제품 2: 쿨링 미스트 — 활동 중 올라간 피부 열감을 식히는 장면과 분사 구조를 화면 분할로 설명
- 핵심 제품 3: 스포츠 스타터 키트 — Pre/In/Post 루틴에 어떤 제품이 연결되는지 타임라인 형태로 표현

같은 제품을 반복해서 보여주더라도 매번 같은 카드로 복사하지 말고 역할을 다르게 해야 해 첫 번째는 대표 이미지와 메시지, 두 번째는 기술 구조, 세 번째는 실제 사용 상황이나 루틴을 보여주는 방식으로 바꿔 줘

### 5 전체 상품 모음 영역 제공하기

핵심 제품과 브랜드 이야기를 충분히 보여준 다음 페이지 후반부에 전체 상품을 한눈에 비교할 수 있는 `Shop All` 영역을 제공해 줘

전체 상품 모음에서는 다음 정보가 일관되게 보여야 해

- 상품 이미지 영역
- 컬렉션명과 상품명
- 적용 스포츠 또는 사용 시점
- 핵심 기능 한 줄
- 용량이나 세트 구성
- 가격
- 상세 보기 또는 출시 알림 버튼

5대 컬렉션 탭은 유지하되 `전체`, `러닝`, `하이킹`, `수상`, `테니스·라운딩`, `피트니스` 필터로 확장하면 좋아 탭을 눌렀을 때 실제 상품이 바뀌는 상태도 설계해 줘 와이어프레임 단계라면 각 탭에서 어떤 상품이 노출되는지 명세 패널에라도 명확히 기록해야 해

### 6 반복 카드 외에 다양한 레이아웃 적용하기

현재는 히어로를 제외하면 상품 카드 4개, 루틴 카드 3개와 명세 패널처럼 작은 박스가 반복돼 정보 구조는 이해되지만 포트폴리오 화면에서는 전체가 비슷한 밀도로 보여 디자인의 강약이 부족해질 수 있어

다음과 같이 섹션마다 다른 레이아웃을 사용해 봐

- 브랜드 철학: 화면 전체 너비의 큰 스포츠 이미지와 한 문장 카피
- 핵심 제품 1: 왼쪽에 큰 제품 이미지, 오른쪽에 문제·해결·기능 설명
- 핵심 제품 2: 이미지와 설명 위치를 반대로 배치한 좌우 교차 구성
- 기술력: 제품 단면도와 카라비너 결합 구조를 보여주는 화면 분할
- 제작 과정: 관찰 → 설계 → 테스트 → 제작 순서의 가로 타임라인
- 성과: 검증 가능한 숫자와 짧은 설명을 크게 보여주는 지표 영역
- Pre/In/Post 루틴: 카드 3개가 아니라 사용자의 운동 흐름을 따라가는 에디토리얼형 스토리
- 전체 상품: 비교가 쉬운 규칙적인 그리드

모든 구역을 다르게 만들 필요는 없지만, 브랜드 이야기와 핵심 제품은 큰 이미지와 여백을 사용하고 전체 상품 비교가 필요한 곳에서만 반복 카드 그리드를 사용하는 것이 좋아

### 7 추천 수정 순서

1 기존 클라이언트 요구사항과 현재 와이어프레임 구성 보존
2 브랜드와 디자인 완성도를 중요하게 여기는 요구사항 추가
3 현재 5대 스포츠 컬렉션 기준으로 최소 15개 상품 목록 확정
4 브랜드 철학, 기술력, 제작 과정과 검증 가능한 성과 자료 정리
5 핵심 제품 3개 선정 및 각 제품의 강조 목적 결정
6 큰 이미지, 화면 분할과 좌우 교차 레이아웃으로 핵심 제품 섹션 추가
7 Pre/In/Post 루틴에 대표 제품 연결
8 마지막에 전체 상품 모음과 컬렉션 필터 구성
9 실제 화면에서 상품 수, 정보 일관성, CTA 연결과 모바일 배치 확인

정리하면 현재 설계의 핵심인 `플래그십 히어로 + 5대 스포츠 컬렉션 + Pre/In/Post 루틴 + 출시 알림`은 그대로 유지하고, 그 사이에 HALO의 브랜드 철학, 기술, 제작 과정과 핵심 제품의 이야기를 추가하면 돼 최소 15개 상품은 5개 컬렉션에 나누어 실제로 보이게 만들고, 핵심 제품을 먼저 다양한 레이아웃으로 강조한 뒤 마지막 전체 상품 모음에서 비교할 수 있도록 정리해 줘

- 기존 박찬미 피드백에는 제출 파일 확인이 불가능한 상태로 기록되어 있었으나, 이번 작업에서는 `웹사이트/와이어프레임/와이어프레임_시안1.html`을 실제로 확인하여 답변함
- 결론: 기존 기능과 설계를 유지하면서 브랜드·디자인 요구를 추가하고, 5대 컬렉션에 최소 15개 상품을 실제 배치한 뒤 핵심 제품을 다양한 레이아웃으로 강조하고 마지막에 전체 상품 모음을 제공하는 방향으로 수정

# 학생 질문 답변

## 학생 이름

이은수

## 질문

`웹사이트/와이어프레임/와이어프레임_카테고리1.html`에서 최소 15개 상품을 유지하면서 제작 부담을 줄이고, 사단(士團)의 브랜드 정보와 핵심 상품이 조화롭게 보이도록 상품 구성과 레이아웃을 어떻게 수정해야 하는지 확인 요청

## 답변

은수야 `와이어프레임_카테고리1.html` 파일 확인해 봤어

현재 사단(士團) 카테고리 페이지에는 이미 16개 상품이 실제로 들어가 있어서 최소 15개 상품 조건은 충족하고 있어 1마패 3종, 2마패 4종, 3마패 4종, 웰니스 오브제 3종, 기프트 2종으로 분류한 구조도 사단 브랜드에 맞게 잘 잡혀 있어

그래서 이번에는 상품을 더 많이 추가하는 것보다 현재 16개를 유지하면서 각 상품이 사단의 어떤 향과 등급을 보여주는지 명확하게 만들고, 제작할 이미지의 수를 줄이면서도 서로 다른 상품처럼 보이도록 정리하는 것이 중요해

임연우 학생처럼 대표 상품 3개를 기반으로 15개를 새로 만드는 방식으로 똑같이 진행할 필요는 없어 사단은 이미 16개 상품과 5개 분류 체계가 있기 때문에 `최소 15개 유지`, `같은 기본 제품을 효율적으로 변형`, `핵심 상품을 먼저 강조한 뒤 전체 상품 모음 제공`이라는 큰 기준만 적용하면 돼

### 1 기존 16개 상품과 분류 체계 유지

현재 만들어 둔 아래 구성은 삭제하거나 처음부터 다시 만들지 말고 유지해 줘

- 1마패 일상 베이스 3종
- 2마패 감성 포인트 4종
- 3마패 올데이 시그니처 4종
- 웰니스 오브제 3종
- 비스포크·기프트 2종
- 전체 16종 필터와 향조 태그
- 1분 어사 조향 진단
- 디스커버리 킷과 브랜드 철학 페이지로 이동하는 CTA

지금 구조는 상품 수가 부족한 것이 아니라 16개가 대부분 같은 크기의 카드로 한꺼번에 보여서 어떤 상품이 대표 상품이고 어떤 상품이 보조 라인인지 강약이 약한 상태야

따라서 16개 상품 카드 자체는 유지하되 카테고리 상단에서 사단을 대표하는 향 3개를 먼저 크게 소개하고 그다음 전체 16종 아카이브로 연결하는 방식으로 수정하면 좋아

### 2 같은 보틀을 활용해 제작 시간을 줄이기

향수 11종은 제품마다 완전히 다른 용기 이미지를 새로 만들지 않아도 돼 하나의 기본 보틀 형태를 만든 뒤 등급과 향에 맞게 액상색, 라벨, 타이포그래피, 마패 캡과 포인트 컬러만 바꾸어 여러 상품에 활용하면 돼

예를 들면 아래처럼 기준을 정할 수 있어

- 1마패: 투명하거나 옅은 액상색, 밝은 한지 라벨, 청색·옥색 계열 포인트, 기본 금속 캡
- 2마패: 꽃과 감정의 성격에 맞춘 홍화색·매화색·치자색 포인트, 동일 보틀에 라벨 색상과 액상색 변화
- 3마패: 검정·먹색·짙은 적갈색 계열, 방짜유기 놋쇠 캡과 금박 라벨로 시그니처 등급 강조
- 웰니스 오브제: 향수 보틀과 구분하되 놋쇠 마패 문양, 한지 라벨과 동일 서체를 사용해 같은 브랜드로 연결
- 기프트: 기존 상품을 새 제품으로 다시 만드는 대신 대표 향 3종을 작은 용량으로 재구성한 디스커버리 킷과 패키지 세트로 확장

이렇게 하면 상품마다 새로운 제품 디자인과 이미지를 전부 제작하지 않아도 동일한 기본 에셋을 반복 활용할 수 있어 다만 색상만 무작위로 바꾸는 것이 아니라 각 색상이 향조와 마패 등급을 설명하도록 기준을 먼저 정해야 해

예를 들어 `유자 청송`은 옅은 유자색과 청송색, `적송 홍화`는 붉은 꽃과 적송을 연상시키는 적갈색, `백단 묵향`은 먹색과 놋쇠색처럼 상품명과 향의 인상이 시각적으로 연결되도록 만들어 줘

### 3 사단의 대표 상품 3개 먼저 선정

현재 16개 중 브랜드를 가장 잘 설명할 수 있는 대표 상품을 3개 정도 선정해 줘 파일의 디스커버리 킷 구성을 그대로 활용하면 아래 3개를 대표 향으로 잡을 수 있어

- 유자 청송: 1마패의 일상성과 한국 자연의 산뜻한 인상을 보여주는 입문 향
- 적송 홍화: 2마패의 감성적인 색과 포인트 레이어링을 보여주는 중간 향
- 백단 묵향: 송연묵, 백단과 방짜유기 캡으로 사단의 한국적 시그니처를 가장 강하게 보여주는 대표 향

이 3개는 전체 상품 그리드에만 넣지 말고 페이지 중간의 별도 섹션에서 각각 다른 방식으로 보여줘

- 유자 청송: 자연 재료와 일상 사용 장면을 넓은 이미지와 짧은 문장으로 표현
- 적송 홍화: 꽃과 적송의 두 가지 향조를 좌우 화면 분할로 보여주고 레이어링 방법 설명
- 백단 묵향: 송연묵, 천년 백단과 방짜유기 캡의 재료 및 제작 과정을 큰 제품 이미지와 함께 강조

같은 제품을 여러 번 보여주더라도 카드 이미지를 그대로 복사하지 말고 대표 이미지, 향의 재료, 제작 과정과 사용 장면처럼 역할을 다르게 나누면 돼

### 4 브랜드 이야기를 카테고리 페이지 안에 연결

현재 페이지 상단에는 `내가 머무는 공간과 시간의 깊이`, `어사 비밀 첩보`, `누적 12만병 완판`, `북촌·성수 아틀리에` 같은 문구가 있지만 이 내용들이 상품 카드와 직접 연결되지는 않아

카테고리 페이지에서도 긴 브랜드 소개 전체를 반복할 필요는 없지만 상품을 이해하는 데 필요한 사단의 핵심 기준은 보여줘야 해

- 사단이라는 이름과 마패 등급을 상품 분류에 사용한 이유
- 한국의 자연 재료와 전통 오브제를 현대 향수로 해석한 방향
- 방짜유기 놋쇠 캡, 한지 라벨, 흑도자기와 옻칠 오동나무 패키지의 제작 특징
- 1마패에서 3마패로 갈수록 향의 밀도와 존재감이 달라지는 기준
- 디스커버리 킷으로 먼저 시향한 뒤 자신에게 맞는 마패를 선택하는 과정

이 내용은 긴 본문 하나로 넣지 말고 각 상품 라인 사이에 짧게 나누어 배치해 줘

예를 들어 1마패 상품 뒤에는 일상에 은은하게 밀착되는 향의 기준을 설명하고, 2마패 뒤에는 감정과 장면을 바꾸는 레이어링 방식을 보여주고, 3마패 앞에는 방짜유기 캡과 시그니처 향료의 제작 이야기를 강조하면 상품과 브랜드 정보가 자연스럽게 이어져

### 5 전체 16종 카드의 정보 체계 정리

현재 상품 카드에는 등급, 용량, 상품명, 설명, 향 노트, 가격과 담기 버튼이 들어가 있어 기본 정보는 충분해 이 구조는 유지하면서 상품별 차이를 더 빠르게 비교할 수 있도록 정보 순서를 통일해 줘

- 마패 등급 또는 상품 유형
- 상품명과 한자명
- 한 줄 향의 인상
- TOP·MID·BASE 또는 핵심 소재
- 추천 시간대와 사용 장면
- 용량과 가격
- 시향하기 또는 담기 버튼

특히 향수는 이미지와 이름만으로 차이를 이해하기 어렵기 때문에 `출근 전`, `늦은 오후`, `저녁 모임`, `집중이 필요한 시간`, `공간 훈향`처럼 추천 TPO를 카드에서 바로 확인할 수 있게 해 줘

현재 향조 태그는 화면에 있지만 실제 상품 필터와 연결되는지가 명확하지 않아 향조 태그를 눌렀을 때 해당 상품만 남도록 만들거나 와이어프레임 명세에 필터 결과를 작성해 줘

### 6 반복 카드 외에 사단에 맞는 레이아웃 적용

현재 페이지는 16개 상품과 스페셜 굿즈가 대부분 3열 카드로 반복돼서 상품 수는 충분하지만 화면 전체가 비슷한 밀도로 보여

사단 브랜드에는 아래와 같은 레이아웃이 잘 맞아

- 브랜드 서문: 한지 질감이나 서고 장면의 큰 이미지와 짧은 문장
- 마패 등급 안내: 1마패·2마패·3마패를 세로로 비교하는 등급 체계 도해
- 유자 청송: 자연 원료 이미지와 제품을 크게 배치한 에디토리얼 구성
- 적송 홍화: 적송과 홍화 이미지를 좌우로 나눈 화면 분할
- 백단 묵향: 제품 이미지와 방짜유기 캡 제작 과정을 좌우 교차 배치
- 조향 과정: 원료 선택 → 향 조합 → 숙성 → 라벨·캡 제작 순서의 가로 타임라인
- 전체 상품: 비교와 필터 사용이 쉬운 3열 그리드
- 웰니스 오브제: 향수와 다른 사용 장면을 보여주는 공간 이미지 중심 구성
- 디스커버리 킷: 1마패·2마패·3마패의 대표 향을 한 번에 비교하는 세트 구성

모든 섹션을 다르게 만들 필요는 없지만 브랜드 이야기, 대표 향과 제작 과정은 큰 이미지와 여백을 사용하고 전체 16종을 비교하는 영역에서만 반복 카드 그리드를 사용하면 좋아

### 1 브랜드 메시지가 페이지 전체에 일관되게 연결됨

브랜드 문장이 한 화면에서만 끝나는 것이 아니라 실제 제품의 쓰임과 연결되어 있어서 SOAPHE가 무엇을 중요하게 생각하는 브랜드인지 비교적 쉽게 이해할 수 있어

### 2 비누와 받침대를 별개의 상품이 아니라 하나의 경험으로 구성함

비누 4종, 화강석·백자·강화유리 오브제 3종, 세트 3종을 단순히 분리해서 보여주지 않고 향, 소재, 욕실 공간과 사용 후 활용까지 이어지도록 구성한 점이 좋아

특히 아래 연결은 SOAPHE 브랜드에 잘 맞아

- 비누의 향과 거품을 보여주는 감각 섹션
- 화강석, 백자와 강화유리의 물성을 설명하는 소재 섹션
- 실제 욕실 분위기에 어울리는 제품을 비교하는 공간 시뮬레이터
- 비누를 다 쓴 뒤 키, 주얼리와 문구를 올려두는 두 번째 쓰임
- 비누와 오브제를 함께 선택하는 선물 구성

상품의 기능만 설명하지 않고 제품이 놓이는 공간과 사용 시간을 함께 보여줘서 브랜드 경험이 풍부해졌어

### 3 반복 카드 외에 다양한 레이아웃을 사용함

전체 화면을 같은 카드로만 구성하지 않고 스플릿 히어로, 3열 감각 화보, 향기 탭, 소재별 좌우 교차 에디토리얼, 욕실 시뮬레이터, 공간 아카이브, 선물 조합, 추천 퀴즈와 전체 제품 그리드로 나눈 점이 좋아

특히 소재 섹션에서 화강석, 백자와 강화유리를 좌우 교차로 배치한 부분은 각 소재의 특징을 강조하면서 화면의 리듬도 만들어 줘

### 4 사용자가 직접 탐색할 수 있는 기능이 다양함

화면에 단순한 설명만 있는 것이 아니라 사용자가 직접 선택하고 결과를 확인할 수 있는 기능이 들어가 있어

- 4대 향기 탭
- 욕실 스타일별 공간 시뮬레이터
- 선물 목적별 구성 변경
- 1분 맞춤 추천 퀴즈
- 세트·비누·오브제 필터
- 제품 상세 모달
- 미리보기 예약 폼과 오류·완료 상태

이런 기능은 포트폴리오에서 단순 화면 디자인뿐 아니라 사용 흐름과 상태 설계까지 보여줄 수 있는 장점이야

### 5 접근성 요소를 비교적 구체적으로 작성함

본문 바로가기 링크, 내비게이션의 `aria-label`, 탭의 `aria-selected`, 이미지 영역의 대체 설명, 폼의 `label`, 오류 메시지 연결과 완료 상태 안내가 포함되어 있어

모바일 빠른 메뉴도 별도로 제공해서 긴 페이지에서 주요 섹션으로 다시 이동하기 쉽도록 한 점이 좋아

### 6 전체 상품의 정보 체계가 비교적 명확함

전체 제품 보기에서 세트 3종, 비누 4종과 오브제 3종을 구분하고 각 상품에 코드, 이름, 소재 또는 구성, 추천 공간, 선택 이유와 행동 버튼을 제공한 점이 좋아

필터 결과와 예약 폼의 상품 선택 목록도 같은 데이터로 연결되어 있어 화면 간 정보 일관성을 유지하려는 구조가 확인돼

## 수정해야 할 부분

### 1 최소 15개 상품 조건이 아직 충족되지 않음

현재 전체 제품 아카이브에 실제 등록된 상품은 세트 3종, 비누 4종, 오브제 3종으로 총 10개야

SOAPHE는 현재 제품 체계가 잘 잡혀 있으므로 전혀 다른 상품을 무리하게 추가하지 말고 기존 비누와 오브제의 변형으로 확장하면 돼

예를 들면 아래처럼 구성할 수 있어

- 비누 4종 유지: 순수 무향, 편백 숲, 웜 앰버, 맑은 유자
- 비누 변형 2종 추가: 미니 체험 비누, 계절 한정 향 또는 동일 향의 다른 용량
- 오브제 3종 유지: 화강석 아치, 백자 폴드, 강화유리 헤일로
- 오브제 변형 2종 추가: 동일 형태의 색상·표면 마감·크기 변형
- 세트 3종 유지: 각 비누와 오브제의 대표 조합
- 선물 또는 디스커버리 구성 2종 추가: 4종 비누 미니 세트와 오브제 선택형 기프트 세트
- 리필 또는 보관 구성 1종 추가: 비누 리필 패키지 또는 오브제 케어 키트

이렇게 하면 기존 제품을 버리지 않고 같은 비누 형태, 같은 오브제 형태와 기존 소재 이미지를 반복 활용하면서 최소 15개를 만들 수 있어

색상만 바꿀 때도 무작위로 바꾸지 말고 소재와 공간에 맞는 기준이 필요해 예를 들어 화강석은 라이트 그레이와 차콜, 백자는 백자색과 샌드 베이지, 강화유리는 투명과 앰버처럼 재질의 성격을 유지하는 범위에서 변형해 줘

### 2 실제 이미지가 아니라 이미지 설명용 자리 표시자가 남아 있음

HTML에는 `<img>` 태그가 없고 히어로, 소재, 제품 카드와 공간 장면이 `[STILL LIFE]`, `[TEXTURE]`, `[SPATIAL]` 같은 설명형 텍스트 영역으로 구성되어 있어

와이어프레임 단계에서는 어떤 이미지가 필요한지 알 수 있어 좋지만 포트폴리오 완성 단계에서는 실제 이미지나 완성도 있는 시각 자료로 교체해야 해

이미지를 생성할 때는 아래 목적을 구분해 줘

- 브랜드 히어로: 비누와 오브제가 함께 있는 밝은 정물 화보
- 향기: 무향, 편백, 앰버와 유자의 원료 및 거품 질감
- 소재: 화강석 표면, 백자 유약과 강화유리 굴절의 확대 이미지
- 사용 장면: 화이트·베이지·차콜·컴팩트 욕실에 배치된 제품
- 두 번째 쓰임: 현관 키 트레이, 서재 문구 트레이와 주얼리 보관 장면
- 상품 카드: 동일한 각도와 조명으로 촬영된 15개 이상의 제품 이미지

### 3 히어로에 `h1`이 4개 들어가 있음

히어로 슬라이드마다 `h1`이 하나씩 작성되어 문서 전체에 `h1`이 4개 존재해 화면상 슬라이드로는 자연스럽지만 문서 구조와 접근성 관점에서는 페이지의 대표 제목을 하나로 정리하는 것이 좋아

첫 번째 브랜드 제목만 `h1`으로 유지하고 나머지 슬라이드 제목은 `h2` 또는 일반 제목 요소로 변경해 줘 숨겨진 슬라이드가 보조 기술에서 반복적으로 읽히지 않도록 활성 상태와 숨김 상태도 함께 관리해야 해

### 4 브랜드 소개와 메인 상품 탐색의 경계가 조금 흐려짐

현재 페이지는 브랜드 감성, 향, 소재, 공간, 후기, 선물, 추천, 전체 상품, 예약과 FAQ까지 모두 들어가 있어 풍부하지만 사용자가 중간에서 무엇을 먼저 봐야 하는지 놓칠 수 있어

각 섹션의 역할을 아래처럼 더 명확하게 나눠 줘

- 브랜드 이해: 히어로, 브랜드 철학과 소재
- 제품 이해: 향, 대표 비누와 대표 오브제
- 사용 장면: 욕실 시뮬레이터와 두 번째 쓰임
- 구매 탐색: 전체 15개 이상 상품, 필터와 상세 보기
- 전환: 맞춤 추천, 선물 구성과 미리보기 예약

상단 GNB의 메뉴 수가 많기 때문에 데스크톱에서도 우선 메뉴와 보조 메뉴를 구분하고 모바일 메뉴가 현재 위치를 알려주는 상태도 추가하면 좋아

### 5 대표 상품의 우선순위를 더 명확히 해야 함

전체 10개 상품이 데이터로 잘 정리되어 있지만 SOAPHE를 대표하는 제품이 무엇인지 한눈에 결정하기는 어려워

현재 내용상 대표 제품은 아래 3개 세트로 볼 수 있어

- 시그니처 아치 세트: 화강석 아치와 순수 무향 비누
- 백자 폴드 세트: 백자 오브제와 편백 숲 비누
- 플루티드 헤일로 세트: 강화유리 오브제와 맑은 유자 비누

이 3개를 전체 상품 카드에만 넣지 말고 브랜드 철학, 소재와 공간 사용 장면에서 각각 먼저 강조한 뒤 전체 상품 모음으로 연결해 줘

### 6 검증되지 않은 수치와 효능 표현을 확인해야 함

현재 화면에는 `4주 저온 숙성`, `2mm 인체공학적 곡면`, `100%`, `자극 0%`, `1250°C`, `420g`처럼 구체적인 수치와 기능 표현이 포함되어 있어

실제 브랜드 자료나 제품 설정에서 확인된 정보라면 유지해도 되지만 AI가 생성한 가상 정보라면 실제 시험 결과나 보장된 효능처럼 보이지 않도록 점검해야 해 특히 `자극 0%`, `화학 향료 배제`, 영유아와 민감성 피부 관련 표현은 근거 없이 확정적으로 사용하지 않도록 수정해 줘

### 7 브랜드 이야기 링크와 파일 연결을 확인해야 함

푸터의 브랜드 이야기 링크가 `브랜드소개페이지_스토리보드_2차보완.html`로 연결되어 있는데 현재 이은경 폴더에서 같은 이름의 파일은 확인되지 않아

실제 브랜드 소개 페이지 파일명과 링크를 일치시키고 메인, 브랜드 소개와 상품 페이지의 GNB가 모두 상대 경로로 정상 이동하는지 확인해 줘

### 8 히어로와 인터랙션의 정보량을 조금 줄일 필요가 있음

히어로는 좌우에 각각 4개의 슬라이드와 여러 제목, 미디어 설명, CTA와 상태 표시가 들어가 있어 첫 화면에서 전달되는 정보가 많아

브랜드 첫인상을 위해 가장 중요한 메시지 한 개와 대표 제품 한 개를 먼저 보여주고 나머지 슬라이드는 사용자가 선택할 수 있는 보조 탐색으로 정리하면 좋아 자동 전환이 있다면 정지 버튼, 현재 슬라이드 번호와 키보드 조작 상태도 명확히 제공해 줘

### 9 후기와 성과 콘텐츠의 출처를 구분해야 함

공간 아카이브에 사용 후기 형식의 카드가 여러 개 들어가 있는데 실제 사용자 후기인지 가상 클라이언트 설정인지 구분이 필요해

실제 후기가 아니라면 실사용자 발언처럼 보이지 않도록 `사용 장면 예시`, `가상 사용자 시나리오` 또는 `예상 활용 방식`으로 표시해 줘

- 대표 제품과 파생 제품의 관계 표시
- 스포츠 환경별 문제와 선택 기준 제공
- 러닝은 휴대성과 빠른 덧바름, 하이킹은 장시간 지속, 수상 스포츠는 방수, 코트 스포츠는 그립 유지, 피트니스는 땀과 유분 관리로 기준 구분
- 상품 카드에 운동 단계, 사용 부위, 제형, 용량, 지속 시간과 추천 상황 표시

### 2 상품 필터는 있지만 비교와 선택 흐름이 부족함

현재 5개 필터로 상품을 나누는 기능은 있지만 필터를 적용한 다음 어떤 상품을 선택해야 하는지 비교할 기준은 부족해

아래 기능 또는 명세를 추가하면 좋아

- 운동 종목뿐 아니라 Pre/In/Post 사용 시점 필터
- 스틱·미스트·젤·밤·쿠션과 키트 등 제형 필터
- 방수, 쿨링, 피지 조절과 휴대성 기능 비교
- 최대 2~3개 제품을 선택해 차이를 확인하는 비교 상태
- 선택 결과가 없을 때의 빈 상태와 필터 초기화
- 상품 상세에서 목록으로 돌아왔을 때 기존 필터와 스크롤 위치 유지

### 3 출시 알림 폼의 입력 구조와 상태가 부족함

현재 출시 알림 폼에는 이름, 휴대폰과 이메일 입력이 있지만 `<label>`이 하나만 확인되고 나머지는 placeholder에 의존하고 있어

각 입력에 명확한 레이블을 연결하고 아래 상태를 설계해 줘

- 필수 입력 누락
- 휴대폰과 이메일 형식 오류
- 개인정보 동의
- 제출 중 로딩과 중복 제출 방지
- 접수 완료와 수정 또는 취소
- 서버 오류와 다시 시도

### 4 구체적인 임상·성과 표현의 근거가 불분명함

현재 `-4.2℃`, `98.4%`, `42.195km 필드 테스트`, `공인 연구소 임상`, `20인의 스포츠 선수단`, `6시간 지속 방수`처럼 구체적인 수치가 많이 들어가 있어

실제 자료가 있다면 출처와 시험 조건을 연결하고 AI가 만든 가상 설정이라면 실제 검증 결과처럼 단정하지 않도록 `목표 수치`, `테스트 콘셉트` 또는 `검증 필요`로 구분해 줘

### 5 상품 상세와 외부 구매 경로의 실제 연결이 부족함

상품 카드에서 상세 모달은 열리지만 실제 상품 페이지, 비교, 장바구니 또는 출시 알림으로 이어지는 역할이 명확하지 않아

포트폴리오 단계에서 모두 구현하지 않더라도 각 버튼의 다음 상태와 페이지 이동 목적을 명세해 줘 푸터의 네이버 브랜드 스토어와 무신사 링크도 현재 `#`이므로 실제 링크가 없으면 준비 중 상태로 표시하는 것이 좋아

### 6 페이지의 섹션 역할이 6개에 집중됨

현재 HTML에는 히어로, 브랜드 철학, 대표 제품, 제작 과정, 운동 루틴과 전체 상품의 6개 주요 섹션이 확인돼 핵심 정보는 있지만 브랜드와 사용자 경험을 충분히 보여주려면 중간 연결이 더 필요해

새 섹션을 무작정 늘리기보다 아래 콘텐츠를 기존 섹션 사이에 추가해 줘

- 스포츠별 실제 사용 장면
- 대표 제품의 카라비너 체결 및 노터치 사용 구조
- 5대 컬렉션 선택 기준
- 대표 제품과 파생 제품 관계
- 검증 가능한 사용자 테스트 또는 개발 기록
- 사용 전·중·후 제품 조합 예시

## 디자인 관점에서 부족한 부분

### 1 흑백 와이어프레임이라 HALO만의 색과 재질이 보이지 않음

현재 파일명과 제목처럼 전체가 모노크롬 와이어프레임으로 구성되어 정보 구조를 확인하기에는 좋지만 HALO가 스포츠 선케어 브랜드라는 인상은 약해

최종 병합에서는 모든 화면을 화려하게 바꾸기보다 아래 기준을 정해 줘

- 기본색은 블랙·화이트와 메탈 실버로 스포츠 기어 인상 유지
- 러닝, 하이킹, 수상, 코트와 피트니스 컬렉션별 포인트 컬러 구분
- 쿨링 기능은 아이스 블루, 자외선 차단은 선 옐로, 익스트림 방수는 딥 네이비처럼 기능색 사용
- 카라비너 알루미늄, 스틱의 매트 표면과 미스트 입자 등 재질 표현 추가

### 2 실제 제품 이미지 없이 이모지와 설명 영역이 중심임

현재 HTML에는 실제 `<img>` 요소가 없고 상품과 사용 상황이 이모지 또는 설명형 영역으로 표시되어 있어

최종 포트폴리오에서는 아래 이미지가 필요해

- 카라비너 퀵 스틱의 제품 정면과 측면
- 러닝 벨트나 배낭에 결합한 사용 장면
- 장갑을 낀 상태에서 한 손으로 사용하는 장면
- 쿨링 미스트의 분사 구조와 입자 표현
- 5대 스포츠 컬렉션별 대표 사용 장면
- 동일한 조명과 구도의 16개 상품 이미지

### 3 반복적인 상품 카드의 시각적 강약이 부족함

16개 상품이 실제로 모두 들어간 점은 좋지만 마지막에 동일한 카드 형태로 길게 이어져 대표 제품과 일반 제품의 우선순위가 약해

아래처럼 레이아웃을 나눠 줘

- 브랜드 철학은 풀 너비 스포츠 이미지와 짧은 선언문
- 퀵 스틱은 큰 제품 이미지와 사용 장면을 좌우 분할
- 쿨링 미스트는 분사 구조와 온도 변화를 보여주는 기술 도해
- 5대 스포츠 컬렉션은 종목별 큰 이미지와 대표 제품 1개씩 강조
- 전체 16종은 비교가 쉬운 일정한 카드 그리드
- Pre/In/Post 루틴은 카드 3개보다 운동 시간의 흐름을 보여주는 가로 타임라인

### 4 텍스트와 수치가 많아 첫 화면과 중간 섹션의 밀도가 높음

브랜드 철학, 대표 상품과 제작 과정에서 설명과 수치가 연속으로 나오기 때문에 중요한 메시지가 서로 경쟁할 수 있어

각 섹션마다 핵심 문장 1개, 대표 이미지 1개와 근거 2~3개만 먼저 보여주고 자세한 정보는 펼쳐보기, 상세 모달 또는 보조 영역으로 분리해 줘

### 5 브랜드 감성이 기능 중심에 머물러 있음

HALO의 기능과 기술은 잘 보이지만 사용자가 운동을 멈추지 않고 몰입을 유지하는 감정과 장면은 상대적으로 적어

러닝의 페이스, 산 정상의 강한 햇빛, 서핑 직전의 준비, 테니스 경기 중 교대 시간과 운동 후 열감을 낮추는 순간처럼 실제 사용자의 흐름을 짧은 카피와 이미지로 보여주면 브랜드 감성이 더 분명해져

## 추가할 가상 클라이언트 방향

기존 클라이언트를 삭제하지 말고 아래 요구를 가진 `브랜드·디자인 완성도 보완 클라이언트`를 추가하면 돼

### 클라이언트 요구사항 예시

> HALO의 기존 정보 구조, 16개 상품, 5대 스포츠 컬렉션, 대표 제품, 제작 과정, Pre/In/Post 루틴과 출시 알림 기능을 삭제하지 않는다 사용자는 운동 종목, 사용 시점, 제형과 핵심 기능을 기준으로 제품을 비교하고 자신에게 맞는 상품을 선택할 수 있어야 한다 카라비너 퀵 스틱과 쿨링 미스트뿐 아니라 5대 컬렉션별 대표 제품을 실제 사용 장면과 함께 강조한 뒤 전체 16종 모음으로 연결한다 디자인은 스포츠 기어의 블랙·화이트·메탈 재질을 기본으로 유지하되 컬렉션과 기능별 포인트 컬러를 사용한다 반복 카드만 사용하지 않고 큰 스포츠 이미지, 화면 분할, 제품 구조 도해, 시간 흐름과 에디토리얼 레이아웃을 활용한다 검증되지 않은 임상 수치와 성과를 실제 사실처럼 추가하지 않고 모든 입력과 필터에 오류·빈 상태·로딩·완료와 복구 방법을 제공한다

이 클라이언트를 기반으로 새 설계와 와이어프레임을 생성한 뒤 기존 시안2의 장점과 새 결과를 비교해 병합하면 돼

## 레퍼런스 탐색 기준

레퍼런스는 많이 찾는 것이 목적이 아니야 HALO와 가까운 스포츠 기어, 기능성 뷰티, 아웃도어 장비 또는 퍼포먼스 브랜드 중에서 각 목적에 맞는 사례를 소수로 선택해 줘

### 사용성이 좋은 사이트

다음 기준을 확인해 줘

- 종목, 사용 시점과 기능별 필터가 이해하기 쉬운가
- 제품 간 차이를 비교하기 쉬운가
- 상세 정보와 구매 또는 알림 신청으로 자연스럽게 이동하는가
- 필터 결과 없음, 오류와 완료 상태가 명확한가
- 모바일에서 긴 상품 목록과 필터를 사용하기 쉬운가

### 디자인이 좋은 사이트

다음 기준을 확인해 줘

- 스포츠 기어의 재질과 제품 구조를 어떻게 보여주는가
- 큰 이미지, 분할 화면과 기술 도해를 어떻게 조합하는가
- 대표 제품과 전체 상품의 시각적 우선순위가 분명한가
- 컬렉션별 색상을 사용하면서 브랜드 통일성을 유지하는가
- 모바일에서 타이포그래피와 이미지 비율이 유지되는가

### 감성을 잘 보여주는 사이트

다음 기준을 확인해 줘

- 운동의 몰입과 흐름을 어떤 이미지와 짧은 문장으로 전달하는가
- 러닝, 하이킹, 수상 스포츠, 코트와 피트니스의 장면이 어떻게 다르게 표현되는가
- 기능 설명이 사용자 감정과 실제 상황에 어떻게 연결되는가
- 브랜드 철학이 제품과 사용 장면 사이에서 반복되는가

## 기존 분석 파일에 추가할 규칙

기존 분석 파일의 내용은 수정하거나 삭제하지 말고 파일 마지막에 아래 내용을 추가해 줘

### 레퍼런스 탐색 기준

- HALO와 가까운 스포츠 기어, 기능성 뷰티, 아웃도어 및 퍼포먼스 브랜드 사례를 우선 탐색
- 자료의 수보다 현재 와이어프레임의 부족한 부분을 직접 보완할 수 있는 관련성을 우선 평가
- 동일한 목적의 레퍼런스를 과도하게 수집하지 않고 사용성·심미성·무드별 핵심 사례만 선정

### 분류

- 사용성: 필터, 비교, 상세 탐색, 신청 흐름과 상태 설계가 좋은 사례
- 심미성: 제품 재질, 큰 이미지, 화면 분할, 기술 도해와 레이아웃이 좋은 사례
- 무드: 운동의 몰입, 속도, 열감, 쿨링과 스포츠별 감성을 잘 전달하는 사례

### 분석

각 레퍼런스마다 아래 내용을 작성해 줘

- 참고할 요소
- 현재 HALO 시안에서 부족한 부분
- HALO에 적용할 방식
- 그대로 복제하지 않고 변경할 부분
- 적용할 섹션과 목적
- 모바일 적용 시 확인할 내용

`분류`에는 사이트가 사용성·심미성·무드 중 어디에 해당하는지만 작성하고 `분석`에는 무엇을 참고하여 HALO의 어떤 부족한 부분을 보완할지를 구체적으로 작성하면 돼

## 최종 병합 기준

새 결과가 나왔을 때 전체를 교체하지 말고 아래 기준으로 병합해 줘

### 기존 시안2에서 유지

- HALO 핵심 메시지와 브랜드 철학
- 대표 제품 2종의 기본 내용
- 제작 과정과 성과 구간
- Pre/In/Post 루틴
- 5대 스포츠 컬렉션과 16개 상품
- 상품 필터, 상세 모달과 출시 알림

### 새 결과에서 선택하여 추가

- 스포츠·사용 시점·제형·기능별 선택 기준
- 5대 컬렉션별 대표 제품과 사용 장면
- 비교, 빈 상태, 오류, 로딩과 복구 흐름
- 컬렉션별 포인트 컬러와 제품 재질 표현
- 큰 이미지, 화면 분할, 기술 도해와 타임라인
- 모바일 필터와 긴 상품 목록의 탐색 방식

## 진행 순서

1 기존 시안2와 클라이언트 파일 보존

접근성도 추가로 확인해야 해 상품 상세 모달에는 대화상자 역할과 제목 연결을 제공하고, 모든 닫기 버튼에는 `닫기`라는 접근 가능한 이름을 넣어 줘 모달을 열면 첫 입력이나 제목으로 포커스가 이동하고, Tab 키가 모달 안에서 순환하며, ESC로 닫힌 뒤 원래 누른 버튼으로 포커스가 돌아오도록 설계해야 해 필터 버튼의 선택 상태, FAQ의 펼침 상태와 폼 레이블도 화면 표시뿐 아니라 코드에서 확인할 수 있게 연결해 줘

정리하자면 현재 시안2는 브랜드 이야기, 대표 제품 3종, 라이프스타일 큐레이션과 실제 15개 상품을 한 페이지로 병합한 방향이 잘 잡혀 있어 이 구조는 유지하면 돼 이번 수정에서는 새로운 섹션을 계속 늘리기보다 고객용 메인페이지와 내부 브랜드 가이드 정보를 구분하고, 대표 제품과 전체 제품의 관계, 상품 선택 기준, 필터와 신청 상태를 보강해 줘 그다음 검증되지 않은 인증·효능·성과·후기·가격 표현을 정리하고 실제 제품 이미지와 섹션별 시각적 강약을 적용하면 포트폴리오 완성도가 훨씬 높아질 거야

각 컬렉션 소개에 `대표 기술`, `파생 기준`과 `추천 상황`을 짧게 추가해줘 예를 들어 러닝은 퀵 스틱의 노터치·휴대 기술이 미스트, 스타터 팩과 엔듀런스 젤에 어떻게 확장되는지 연결하고, 하이킹은 장벽 보호를 중심으로 파우더와 리커버리 패치가 운동 중·후 역할을 나누는 방식으로 정리하면 돼 상품 카드에도 `대표`, `파생`, `보조` 역할을 표시하면 16종의 체계가 더 명확해져

세 번째로 필터와 컬렉션 탭의 관계를 더 명확하게 보여줘 위의 5대 컬렉션 탭을 누르면 아래 16종 목록도 함께 필터링되지만 두 영역이 떨어져 있어서 사용자는 컬렉션 장면만 바뀐 것으로 생각할 수 있어 탭을 선택했을 때 전체 상품 영역으로 이동하거나 `현재 컬렉션 필터: 러닝`처럼 선택 상태를 필터 패널에도 표시해줘 `필터 전체 초기화`는 운동 시점·제형·기능만 초기화하고 선택한 컬렉션은 그대로 유지하므로, 버튼 이름을 `상세 필터 초기화`로 바꾸거나 컬렉션까지 모두 초기화되도록 동작을 맞춰야 해

네 번째로 상세 모달에서 비교함에 담는 기능을 수정해야 해 현재 상세 모달의 `비교함 담기`는 상품 카드의 체크 표시와 연결되지 않고, 같은 상품을 반복해서 누르면 비교 목록에 중복으로 들어갈 수 있어 이미 담긴 상품은 다시 추가되지 않도록 막고 상품 카드 체크박스, 하단 비교 바와 상단 개수가 항상 같은 상태가 되도록 동기화해줘 비교 모달은 2~3개 상품을 비교할 때 의미가 크므로 1개만 선택한 경우에는 한 개를 더 선택하라는 안내를 보여주는 것도 좋아

다섯 번째로 모바일 내비게이션과 긴 목록을 다시 설계해야 해 현재 반응형 규칙에서는 주요 콘텐츠가 1열 또는 2열로 바뀌지만 고정 GNB의 메뉴와 두 개의 액션 버튼을 모바일용으로 전환하는 규칙이 없어 좁은 화면에서 로고, 다섯 개 메뉴, 비교함과 출시 알림이 한 줄에 겹치거나 잘릴 가능성이 커

- 모바일 GNB를 햄버거 메뉴 또는 가로 스크롤 메뉴로 변경
- 비교함과 출시 알림 중 핵심 액션 하나만 상단에 유지
- 16개 상품을 한 줄 가로 스크롤로만 보여주지 말고 1열 목록 또는 `다음 상품` 위치가 보이는 구조로 조정
- 하단 비교 바에서 상품명이 여러 개 쌓일 때 화면을 가리지 않도록 축약·가로 스크롤·접기 상태 제공

- 모달의 닫기 버튼과 폼 입력 영역이 390px 화면에서도 잘리지 않는지 확인

여섯 번째로 접근성과 상태 표현을 보완해줘 컬렉션 탭과 필터의 선택 상태가 시각적 `active` 클래스에만 의존하고 있고 모달은 키보드 포커스 이동과 ESC 닫기를 지원하지 않아

- 모달을 열 때 첫 요소로 포커스 이동, 모달 안에 포커스 유지, ESC로 닫기와 닫은 뒤 원래 버튼으로 복귀
- 비교함 최대 3개 경고와 신청 완료 상태를 화면 읽기 프로그램도 알 수 있도록 상태 영역 제공
- 입력창에 화면에 보이는 이름, 이메일 라벨을 연결하고 개인정보 동의 오류 메시지 제공

일곱 번째로 아직 실제 이미지 대신 `[단면 도해]`, `[실물 분해도]`, `[360도 분사 다이어그램]`, 이모지와 설명형 자리 표시자가 많이 남아 있어 와이어프레임의 의도는 이해되지만 포트폴리오 완성본으로는 보이지 않아 브랜드 철학에는 실제 스포츠 장면, 대표 제품에는 제품 렌더와 사용 모습, 기술 영역에는 카라비너 체결 구조와 분사 구조, 컬렉션에는 종목별 환경 이미지가 들어가도록 교체해줘 같은 제품을 다시 보여줄 때도 대표 이미지, 기술 구조, 실제 사용 장면이라는 서로 다른 역할이 드러나야 해

여덟 번째로 파일과 화면의 버전 표기를 정리해줘 파일명은 `와이어프레임_시안3.html`인데 브라우저 제목은 `최종 통합 와이어프레임 v2.0`으로 되어 있어 검토할 때 어떤 버전이 최신인지 혼동될 수 있어 문서 제목, 화면 내부 버전과 파일명을 시안3 기준으로 일치시켜줘

아홉 번째로 ANCORS처럼 레이아웃을 크게 사용하고 싶다면 현재의 굵은 테두리와 작은 정보 박스를 단순히 확대하는 방식이 아니라, 한 화면에 하나의 메시지만 남기는 방향으로 정보 밀도부터 줄여야 해 ANCORS는 모던하고 절제된 미니멀리즘을 브랜드 정체성으로 사용하고, 포트폴리오에서도 제품과 고객 브랜드가 중심이 되도록 큰 시각 자료와 짧은 설명을 구분하고 있어 HALO도 이 특성을 그대로 복제하기보다 `차갑고 빠르며 정밀한 스포츠 기어`라는 무드에 맞게 변형해서 적용하면 돼

- Hero는 작은 수치 카드 3개를 동시에 강조하기보다 화면 높이를 크게 사용한 스포츠 장면과 `운동의 흐름을 멈추지 않는 선케어 기어` 한 문장을 중심으로 구성
- 브랜드 철학은 여러 설명 박스를 나열하지 말고 풀 너비 운동 이미지, 짧은 선언문과 핵심 근거 1~2개로 압축
- 대표 제품은 한 화면에 한 제품만 배치하고 제품 렌더, 실제 사용 장면과 핵심 기술 하나를 크게 표현
- 퀵 스틱은 카라비너 결합과 노터치 도포, 쿨링 미스트는 입자와 분사 구조처럼 제품별 대표 장면을 다르게 설정
- 제작 과정은 작은 카드 4개보다 큰 이미지가 전환되는 스크롤 스토리나 넓은 가로 타임라인으로 구성
- 5대 컬렉션은 텍스트 탭만 바뀌는 구조보다 종목별 풀 너비 이미지와 대표 제품 1개가 함께 바뀌도록 설계
- Pre/In/Post는 동일한 카드 3개보다 운동 전 준비, 운동 중 몰입과 운동 후 회복이 화면 단위로 이어지는 시퀀스로 확장
- 16개 전체 상품은 브랜드 서사가 끝난 후에만 규칙적인 그리드로 보여주어 큰 브랜드 섹션과 상품 탐색 영역의 역할을 구분

큰 레이아웃에서는 섹션의 개수보다 각 섹션의 체류 이유가 중요해 한 섹션 안에 제목, 설명, 수치, 표, 태그와 버튼을 모두 넣지 말고 `메시지 1개 + 대표 이미지 1개 + 근거 1~2개 + 행동 1개` 정도로 우선순위를 정해줘 상세 스펙과 비교 정보는 펼쳐보기나 모달로 이동하고 본문에서는 사용자가 스크롤하면서 HALO의 속도, 열기, 냉각과 재질을 먼저 느낄 수 있게 구성하면 돼

ANCORS의 부드럽고 미니멀한 코스메틱 무드를 그대로 가져오면 HALO의 스포츠 기어 정체성이 약해질 수 있어 넓은 여백과 큰 이미지라는 레이아웃 원칙만 참고하고 색상, 재질과 모션은 HALO에 맞게 변경해줘 흑백 바탕에 냉각을 상징하는 아이스 블루 또는 전기적인 라임을 제한적으로 사용하고, 알루미늄 카라비너의 금속 질감, 미스트 입자, 땀과 아스팔트 열기를 가까이 보여주면 큰 화면 안에서도 HALO만의 무드를 유지할 수 있어

모바일에서는 데스크톱의 큰 화면 높이와 여백을 그대로 축소하지 말고 이미지 초점과 메시지를 다시 배치해야 해 큰 이미지는 세로 비율로 크롭하고 제목은 2~3줄 이내로 유지하며, 스크롤 고정 효과가 길어지지 않도록 일반적인 세로 시퀀스로 전환해줘

정리하면 이번 시안3은 이전 피드백의 구조와 기능 요구를 대부분 반영했어 다음 단계에서는 새로운 섹션을 더 늘리기보다 아래 내용을 우선 수정하면 돼

2. 컬렉션별 대표 제품과 파생 제품의 관계 표시
3. 컬렉션 탭과 상세 필터의 선택 상태 및 초기화 범위 정리
4. 상세 모달 비교함의 중복 추가와 체크 상태 동기화 수정
5. 모바일 GNB, 상품 목록, 비교 바와 비교표 최적화
6. 탭·필터·모달·폼의 키보드 및 화면 읽기 접근성 보완
7. 자리 표시자를 실제 목적별 이미지와 기술 도해로 교체
8. 시안3 파일명과 페이지 버전 표기 일치
9. ANCORS의 큰 이미지와 절제된 정보 구조를 HALO의 스포츠 기어 무드로 변형하여 적용

현재 시안의 HALO 메시지, 16종 상품 체계, 종목별 사용 장면, 다양한 레이아웃과 탐색·비교 기능은 유지하고 위의 일관성, 상태 동기화, 모바일과 접근성을 먼저 정리해서 다시 보여주면 됑!

현재 작업 상태 문서에는 아직 `제품 후보 생성 전`이라고 적혀 있고 다음 작업도 약 200개 제품 후보 생성으로 되어 있는데, 다른 상태 문서에는 사이트맵 V3까지 재생성됐다고 적혀 있어 그런데 실제 폴더에는 이미 V1·V2·V3 설계, 스토리보드와 와이어프레임이 여러 버전으로 만들어져 있어서 작업 순서가 서로 맞지 않아

결과물도 현재 질문 폴더 안에 MD 파일이 약 1,500개, HTML이 약 220개까지 늘어나 있고 같은 페이지가 원본, V2, 개별 보완과 최종 등의 이름으로 반복되어 있어 이 정도면 결과가 부족해서 갈피를 잃은 것이 아니라 결과가 너무 많이 생성되어 무엇을 기준으로 봐야 하는지 구분하기 어려워진 상태야

특히 현재 기준에는 아직 브랜드명이 `내 브랜드`로 남아 있고 제품 후보 생성도 시작 전으로 표시되어 있는데 메인, 브랜드 소개, 카테고리, 기록 방식과 여러 와이어프레임이 먼저 만들어졌어 브랜드와 제품 기준이 확정되지 않은 상태에서 화면을 계속 생성하니까 기록 시작, 카테고리 탐색, 브랜드 소개와 제품 비교 같은 비슷한 구조가 반복해서 나오는 거야

지금까지 한 작업을 전부 버릴 필요는 없어 V1·V2·V3 파일도 삭제하지 말고 참고 자료로 보관하면 돼 다만 새 결과 생성은 멈추고 아래 내용부터 먼저 확정해줘

1. 실제 사용할 브랜드명과 브랜드가 다루는 제품 또는 서비스 한 줄 정의
2. 51명의 클라이언트 중 최종 화면 판단에 사용할 핵심 사용자와 요구만 선정
3. 약 200개 제품 후보를 만들 것인지, 현재 포트폴리오에서 필요한 대표 상품 15개를 먼저 확정할 것인지 결정
4. 메인, 브랜드 소개와 핵심 카테고리처럼 먼저 완성할 대표 페이지 3개 지정
5. V1·V2·V3 중 어느 문서를 기준본으로 사용할지 하나만 표시
6. 기준본에 없는 새 메뉴, 기능과 화면은 더 만들지 않도록 중단 조건 작성

그다음에는 51명 각각의 와이어프레임을 계속 만드는 방식보다 공통 요구를 묶어서 대표 흐름만 만들면 돼 예를 들어 기록 시작과 재개, 제품·카테고리 탐색, 브랜드 신뢰와 정보 확인처럼 서로 다른 핵심 흐름을 정하고 한 흐름마다 대표 화면을 하나씩 검토하는 방식으로 줄여줘 같은 구조에서 문구와 사용자 이름만 달라지는 결과는 더 만들 필요 없어

우선 지금 만들어진 화면 중 메인 1개, 브랜드 소개 1개와 카테고리 또는 핵심 기능 페이지 1개만 골라서 보내줘 세 화면에서 유지할 부분, 겹치는 부분과 삭제할 부분을 먼저 확인한 다음 그 기준으로 나머지를 확장하면 돼

정리하면 현재 작업은 실패한 것이 아니라 자동화 결과가 너무 많이 쌓여 기준을 잃은 상태야 지금은 와이어프레임 추가 생성보다 `현재 단계 정정 → 기준본 1개 확정 → 대표 페이지 3개 비교 → 중복 제거` 순서로 돌아오는 것이 먼저야 여기까지 정리한 뒤 다시 진행하면 됨!

## 답변

민경아 지금은 파일을 더 만드는 작업보다 이미 만들어진 파일의 역할을 다시 정리하는 작업이 먼저야 아래 순서대로 진행하면 돼 기존 파일은 바로 삭제하지 말고 기준본, 참고본과 보관본으로만 구분해줘

```text

        ↓

        ↓
같은 페이지가 원본·V2·보완·최종으로 반복 생성
        ↓
어느 파일을 수정해야 하는지 판단하기 어려움

[정리 목표]
생성 중지
   ↓

   ↓
기준본 1개 선정
   ↓

   ↓

   ↓
```

### 1단계 — 새 파일 생성을 먼저 멈추기

- 새 가상 클라이언트 생성
- V7, V8처럼 클라이언트 버전 추가 생성
- 약 200개 제품 후보 생성
- 사이트맵 재생성
- 스토리보드와 와이어프레임 일괄 생성
- 반복 검증 회차 추가

이 작업을 멈추는 이유는 결과가 부족해서가 아니라 기준본을 정하지 않은 상태에서 새 결과가 기존 결과 위에 계속 쌓이고 있기 때문이야

| `V2-설계자료` | 사이트 구조·서비스 흐름·화면 연결 검토 후보 | 대표 페이지 구조 비교 |

### 6단계 — 제품 작업을 와이어프레임보다 먼저 확정하기

현재 상태 문서에는 약 200개 제품 후보 생성이 아직 시작되지 않은 것으로 기록되어 있어 제품 기준이 없는 상태에서 상품 페이지와 와이어프레임을 계속 만들면 카드 구조만 반복될 가능성이 커

아래 두 방향 중 어떤 범위로 진행할지 먼저 선생님과 확인해줘

```text
[A안: 전체 자동화 과정]
약 200개 제품 후보 생성
        ↓
중복·카테고리 검토
        ↓

        ↓

        ↓
대표 상품 15개와 선정 이유 확정
        ↓

        ↓
```

메인에서는 YOVIA의 차이를 가장 잘 보여주는 대표 상품 3개 정도를 큰 이미지와 설명으로 먼저 강조하고, 같은 메인페이지 안에서 나머지 12개 이상을 일정한 카드 그리드나 상품 레일로 이어서 보여줘 대표 상품과 일반 상품의 크기와 정보량은 달라도 사용자가 메인만 보았을 때 최소 15개 상품의 상품명과 차이를 확인할 수 있어야 해 전체 상품 페이지는 더 자세한 필터와 비교를 위한 화면으로 유지하면 돼

확정된 상품이 15개보다 적다면 나머지를 실제 출시 상품처럼 만들지 말고 `조합 제안`, `기획 중` 또는 `정보 확인 필요` 상태로 구분해줘 상품 카드의 디자인은 같아도 확정 상태가 다르다는 것이 보이도록 배지나 짧은 안내를 넣으면 돼

메인 상품 영역에서는 상품을 같은 카드 15개로만 길게 나열하지 말고 기존 제품 구조에 따라 묶어서 보여줘 다만 새로운 상품군을 임의로 만들지는 말고 실제 기획 자료에 있는 팩, 퓨레, 토핑과 조합 상품의 구분을 그대로 사용해야 해

대표 상품 3개는 웹디자인 시안의 큰 컬러 카드나 제품 중심 레이아웃을 사용하고, 나머지 12개 이상은 더 간결한 카드로 구성하면 메인페이지에서 15개를 모두 보여주면서도 화면의 강약을 유지할 수 있어

```text
[대표 상품 영역]
대표 상품 3개
큰 이미지 + 핵심 특징 + 용량·구성 + 상태 + CTA
```

메인페이지를 처음 열었을 때 최소 15개 상품이 모두 HTML에 배치되고 화면에서도 확인되어야 해 상품 레일을 사용한다면 첫 화면에 일부만 보이더라도 좌우 이동과 `1–3 / 15` 같은 전체 개수 표시를 제공해서 메인에 15개가 있다는 사실과 끝까지 탐색하는 방법이 분명해야 해 필터를 사용한다면 `전체` 상태에서 15개가 모두 검색되는지 결과 수를 표시해줘 상품 카드만 15개 만들어 놓고 이름, 용량과 버튼이 서로 다르게 연결되는지도 마지막에 확인해야 해

5. 각 상품명, 상품군, 용량·구성, 상태와 CTA가 일치하는지 확인
6. 같은 상품이 이름만 바뀌어 중복 배치되지 않았는지 확인
7. 모바일에서 15개 상품을 끝까지 탐색할 수 있는지 확인
8. 미확정 가격·영양·효능·구독 정책이 확정 정보처럼 표시되지 않았는지 확인

## 답변

지혜야, 지금 `와이어프레임_시안1.html` 확인해 봤어. 현재 시안은 `시간과 손길이 만드는 고요한 에코 리추얼`이라는 브랜드 메시지와 4無 공정, 4차 정련 과정, 소재 특성, 체험팩, 자수, 쇼룸, B2B까지 브랜드가 가진 이야기는 충분히 들어가 있어. 다만 지금은 상품 카드가 6개라서 메인페이지에서 보여야 하는 최소 15개 기준에는 9개가 부족하고, 10개 정도의 섹션이 모두 비슷한 크기와 정보량으로 이어져 브랜드 감성보다 기능과 설명이 먼저 보이는 상태야.

`LE-EL UPPERHOUSE` 사이트의 느낌을 참고하고 싶다면 고급스러운 색이나 큰 글씨만 가져오는 것이 아니라, **한 화면에 하나의 메시지와 하나의 대표 장면만 남기는 방식**을 참고하면 돼. 해당 사이트처럼 큰 이미지·영상, 넓은 여백, 짧은 문장과 절제된 전환을 사용하되, 주거 브랜드의 분위기를 그대로 복사하지 말고 플로뜰리에의 소창, 물, 햇빛, 바람, 직조 조직과 손의 감각이 크게 보이도록 바꿔줘.

먼저 Hero는 지금의 브랜드 문장을 유지하고, 소창이 바람에 움직이거나 피부에 닿는 장면을 화면 높이만큼 크게 보여줘. Hero 안에는 설명, 배지와 버튼을 여러 개 넣지 말고 `시간과 손길이 만드는 고요한 에코 리추얼` 한 문장과 핵심 행동 버튼 하나 정도만 남기면 돼. 4無와 4차 정련 과정도 작은 카드 여러 개를 한꺼번에 보여주기보다, 원단의 표면과 정련 장면을 크게 보여주면서 핵심 근거를 한두 개씩 읽게 만들어줘. 이렇게 해야 사용자가 스크롤할 때 브랜드의 고요한 리듬을 먼저 느낄 수 있어.

상품은 **메인페이지 안에 서로 다른 고유 상품이 최소 15개 실제로 보여야 해.** 같은 상품을 영역만 바꿔 반복하거나 색상 이름만 바꿔 15개로 세면 안 돼. 현재 구현된 6개를 기준으로 최소 9개를 더 구성하되, 기획에서 확인된 용도·겹수·크기·세트 구성 등의 차이가 실제로 있는 상품으로 추가해줘. 아직 확정되지 않은 상품명, 가격과 효능을 임의로 판매 중인 것처럼 쓰지 말고 `기획 상품` 또는 `제안 상품`으로 구분하면 돼.

15개를 모두 같은 크기의 카드로 한꺼번에 강조하면 레퍼런스의 여백과 브랜드 감성이 사라지기 때문에 다음처럼 강약을 나눠줘.

```text
[브랜드 감성 영역]
풀 화면 Hero 이미지/영상
        ↓
4無 철학 — 큰 원단 이미지 + 핵심 근거 1~2개
        ↓
4차 정련 — 큰 공정 장면이 이어지는 스크롤 서사
        ↓
[대표 상품 영역]
대표 상품 1 — 제품 전체 모습 + 사용 장면
대표 상품 2 — 직조와 겹수의 확대 장면
대표 상품 3 — 건조·수납 등 사용 맥락
        ↓
[상품 탐색 영역]
전체 상품 15종 — 규칙적인 그리드와 필터
        ↓
[보조 경험 영역]
체험팩·자수·쇼룸·B2B를 중요도에 따라 압축
```

대표 상품 3개는 화면을 넓게 사용해서 각각 다른 이야기를 보여주고, 그 아래 `전체 상품 15종` 영역에서는 대표 상품을 포함한 고유 상품 15개를 한 번에 탐색할 수 있게 정리해줘. 즉 대표 상품이 위에서 한 번 강조되더라도 전체 컬렉션에도 다시 포함될 수 있지만, **고유 상품 수 자체는 반드시 15종 이상**이어야 해. 필터 첫 항목에도 `전체 15`처럼 현재 상품 수를 표시하고, 필터를 선택했을 때 카드와 결과 개수가 함께 바뀌게 연결하면 돼.

전체 상품 카드는 감성 영역보다 단정하고 규칙적으로 구성해도 괜찮아. 대신 모든 카드의 정보 순서를 아래처럼 통일해줘.

```text
상품 이미지
상품명
주요 용도
겹수·크기·구성 등 실제 차이
확정된 가격 또는 기획 상태
상세 보기
```

현재의 체험팩, 자수 아틀리에, 쇼룸 예약, 웰니스 명상, B2B와 13인 가상 클라이언트 큐레이션을 모두 같은 비중으로 유지하면 메인페이지가 다시 복잡해져. 메인에서 반드시 필요한 기능만 한두 개의 큰 행동으로 남기고, 나머지는 상품 영역 뒤쪽에서 짧게 묶거나 상세 화면으로 이동시켜줘. 특히 `13인 가상 클라이언트`는 제작 과정의 내부 자료처럼 보일 수 있으니 실제 고객에게 보여줄 콘텐츠인지 먼저 구분해야 해.

색상은 현재 브랜드의 자연 소재 감성을 유지하면서 아이보리, 마른 소창의 백색, 짙은 녹색이나 먹색 정도로 절제하고, 카드마다 그라데이션과 효과를 반복하기보다 원단의 조직, 물기, 햇빛과 손의 움직임을 보여주는 큰 시각 자료에 집중해줘. 움직임도 빠른 효과보다 천천히 나타나는 페이드나 이미지 전환 정도가 어울려. 모바일에서는 큰 장면을 세로 비율로 바꾸고 상품 15종은 한 줄 가로 스크롤에만 숨기지 말고 1열 또는 2열 목록으로 끝까지 확인할 수 있게 해줘.

그리고 현재 화면에 있는 `KATRI`, `Dermatest 최고 등급`, `100℃`, 건조 시간, 수납 배수, 가격, 인증 번호 같은 표현은 실제 근거가 확인되는 정보만 사용해야 해. 증빙이 없는 값은 확정 사실처럼 노출하지 말고 `검증 예정`, `기획 예시` 등으로 상태를 표시해줘.

정리하면 다음 수정에서 가장 먼저 확인할 내용은 아래 다섯 가지야.

1. 메인페이지에 서로 다른 고유 상품을 최소 15종 실제 배치하기
2. 대표 상품 3종은 큰 이미지와 사용 장면으로 먼저 강조하고, 전체 15종은 후반의 규칙적인 컬렉션에서 다시 탐색하게 만들기
3. 작은 카드와 설명 상자를 줄이고 한 화면에 메시지 1개, 이미지 1개, 근거 1~2개, 행동 1개만 남기기
4. 체험팩·자수·쇼룸·B2B·가상 클라이언트의 우선순위를 정해 메인페이지의 정보량 줄이기
5. 인증, 성능 수치와 가격의 근거를 확인하고 모바일에서 15개 상품 전체가 보이는지 점검하기

지금 시안의 브랜드 문장과 4無·4차 정련이라는 핵심 이야기는 유지하면 돼. 새로운 섹션을 계속 추가하기보다, 기존 내용을 크게 보여줄 것과 뒤로 보낼 것으로 나누고 상품 15종의 실제 차이를 먼저 정리해서 다시 보여줘.
