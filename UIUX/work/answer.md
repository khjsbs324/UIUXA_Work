# 학생 질문 답변

## 학생 이름

박찬미

## 질문

`카테고리_시안2.html`의 현재 반영 상태를 확인하고 카테고리 페이지에서 유지할 부분과 다음 수정 우선순위를 알려 달라는 요청

## 답변

찬미야, `카테고리_시안2.html` 확인했어

현재는 5개 스포츠 컬렉션과 16종 상품이 모두 들어가 있고, 운동 시점·제형·기능 필터, 선택 조건 표시, 검색 결과 수, 두 종류의 초기화, 최대 3개 상품 비교, 상세 보기와 출시 알림까지 연결되어 있어서 카테고리 페이지가 맡아야 할 `상품 탐색과 비교` 역할은 분명하게 잡혀 있어

특히 시안1과 비교하면 #01·#05·#08·#14 대표 상품의 이름과 용량을 `브랜드소개_시안3.html` 기준으로 수정했고, 대표·파생·보조 관계와 추천 상황을 카드에서 확인할 수 있게 한 부분은 유지하면 돼

다만 지금은 화면을 더 추가하는 것보다 16종 기준 데이터와 필터 기준을 먼저 통일해야 해

[가장 먼저 수정할 부분]

메인페이지와 카테고리·브랜드 소개가 아직 같은 상품을 서로 다르게 표시하고 있어

- #01은 카테고리와 브랜드 소개에서 `카라비너 퀵 쿨링 선 스틱 20g`이지만 메인 시안5에는 이전 이름과 22g이 남아 있음
- #05는 카테고리와 브랜드 소개에서 60ml이지만 메인 시안5에는 50ml로 표시됨
- #08은 카테고리와 브랜드 소개에서 `오션 세이프 징크 미네랄 리프 쉴드 50g 크림`이지만 메인 시안5에는 이전 이름과 100ml 젤이 남아 있음
- #14는 카테고리와 브랜드 소개에서 20g이지만 메인 시안5에는 30g으로 표시됨

먼저 16종 기준표 하나를 확정하고 상품 번호, 이름, 대표·파생·보조 역할, 컬렉션, 운동 시점, 제형, 사용 부위, 핵심 기능, 용량, 가격, 추천 상황과 현재 검증 상태를 세 페이지가 같은 기준표에서 가져오게 해줘

[필터 기준 수정]

현재 필터 이름과 상품 데이터가 맞지 않는 항목도 있어

- #06은 상품명이 선 파우더인데 제형은 스틱으로 등록되어 있어 파우더 필터와 연결되지 않음
- #11은 상품명이 쿨링 쿠션인데 제형은 밤으로 등록되어 있어 쿠션 필터와 연결되지 않음
- #08은 크림으로 수정됐지만 제형 필터에는 크림 선택 항목이 없음
- #03과 #16은 키트인데 카드에서는 패치로 표시되어 패치와 키트를 구분하기 어려움
- `All`로 표시한 상품은 실제 사용 시점을 Pre·In·Post 중에서 다시 정리해야 함

필터 문구도 `-4.2℃ 급속 쿨링`, `80분 내수성`, `세범 제로`처럼 결과를 단정하는 수치보다 `쿨링`, `내수성`, `유분 관리`, `휴대`처럼 사용자가 고르는 목적을 먼저 보여주는 것이 좋아

[수치와 검증 상태]

현재 화면에는 `가상 임상 검증 수치`라고 적혀 있지만 상품 설명과 비교표에서는 다시 `입증`, `검증`, `통과`, `인증`으로 단정하고 있어 상태가 충돌해

수치를 모두 없앨 필요는 없지만 `브랜드 설정`, `설계 목표`, `시험 계획`, `확인 완료`, `인증 완료`로 상태를 나누고 실제 자료가 없는 숫자는 목표나 시험 계획으로 표시해줘

상품 상세와 비교표에서도 `임상 데이터`만 크게 강조하지 말고 어떤 환경을 가정한 값인지, 현재 어느 상태인지와 확인 자료가 있는지를 함께 보여줘

[카드와 비교 정보 순서]

전체 상품을 같은 카드 규칙으로 보여주는 방향은 카테고리 페이지에 맞아 다만 현재는 상품 이름보다 대표·파생 관계 상자가 먼저 보여서 사용자가 어떤 상품인지 알기 전에 내부 분류부터 읽게 돼

카드는 `상품 번호와 이름 → 용량과 가격 → 운동 시점·제형·기능 → 대표·파생·보조 역할 → 추천 상황과 상세 보기` 순서로 정리해줘 파생 기준의 긴 설명은 지금처럼 펼쳐보기에 두되 기본 화면에서는 상품 선택에 필요한 정보가 먼저 읽혀야 해

비교표에는 컬렉션, 운동 시점, 제형, 기능, 용량과 가격뿐 아니라 사용 부위, 추천 상황과 검증 상태를 함께 넣어야 사용자가 실제로 무엇을 골라야 하는지 판단할 수 있어

[모바일과 출시 알림]

모바일 화면에서는 상세 필터가 보이지 않고 16개 카드가 한 줄로 길게 이어져서 데스크톱에서 만든 탐색 장점이 사라져

모바일 상단에 `필터 열기`와 현재 선택 조건·결과 수를 유지하고, 비교함은 화면을 많이 가리지 않도록 접힌 상태를 기본으로 보여줘

출시 알림은 개인정보 동의가 처음부터 선택된 상태이고 15% 쿠폰이 확정 혜택처럼 표시되어 있어 이전 피드백이 아직 반영되지 않았어 동의는 기본 해제하고 실제 확정 내용이 아니라면 `출시 캠페인 기획안`으로 상태를 표시해줘

정리하면 현재 카테고리 페이지의 구조는 유지하면 돼 먼저 16종 기준표를 확정해 세 페이지의 데이터를 통일하고, 제형과 사용 시점 필터가 실제 상품과 정확히 연결되게 수정한 다음 수치 상태와 카드 정보 순서를 정리해줘 마지막으로 모바일에서도 필터·결과·비교 흐름이 유지되는지 확인하면 됨
