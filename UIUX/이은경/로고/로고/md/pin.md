# Pinterest 로고 레퍼런스 수집 가이드

## 실행 명령

사용자가 **`로고 초안 N번 실행시작`** (예: `로고 초안 1번 실행시작`, `로고 초안 2번 실행시작`) 또는 **`내가 레퍼런스 수집 시작해`**라고 명령하면 아래 작업을 즉시 실행한다. 파일이 정상적으로 존재하면 추가 질문이나 재확인 없이 진행한다.

1. 사용자가 N번을 지칭한 경우 `input` 폴더에서 해당 N번에 매칭되는 초안 이미지(`로고초안1.png`, `로고초안_1.png` 등 N번 파일)를 확인한다.
2. 배경의 보조 그리드 선은 분석에서 제외하고 **진하게 그린 핵심 선과 면만** 참고하여 지정 초안의 형태·구조·선·분위기를 분석한다.
3. `레퍼런스` 폴더의 이미지 파일(`image.png`)을 모두 확인하고, 사용자가 선호하는 시각 스타일과 결과물의 품질 기준을 분석한다.
4. 두 기준을 결합해 Pinterest에서 유사한 개별 로고 핀을 검색한다.
5. `로고 초안 N번 실행시작` 명령의 경우 **3장의 최적 유사 레퍼런스 이미지**를 수집한다.
6. 찾은 이미지는 Pinterest UI 전체가 아니라 **로고 이미지가 보이는 영역만 캡처**한다.
7. 결과를 실제 JPEG 형식으로 변환해 **`output/[N번]/`** 폴더(예: `output/1번/`, `output/2번/`)를 자동 생성하여 저장한다.
8. 저장한 JPG 3장을 다시 열어 로고, 잘림, 팝업, 워터마크, 목업, 빈 화면 여부를 육안 검증한다.

결과 파일은 `output/[N번]/` 폴더 내에 `similar_logo_01.jpg`, `similar_logo_02.jpg`, `similar_logo_03.jpg` 순서로 저장한다.

### 입력 우선순위

- 형태와 구조: `input` 폴더의 N번 지정 초안을 우선한다.
- 스타일, 색감, 표현 방식, 결과 이미지 구성: `레퍼런스` 폴더를 우선한다.

### 캡처의 의미

- “캡처”는 Pinterest 화면 전체를 그대로 저장한다는 뜻이 아니다.
- 로고가 선명하게 보이는 이미지 영역만 결과로 남긴다.
- Pinterest 로그인 창, 메뉴, 버튼, 검색창 등 사이트 UI가 결과 JPG에 포함되면 실패로 간주한다.

## 목표

지정된 N번 로고 초안을 시각적으로 분석한 뒤, 형태와 분위기가 유사한 Pinterest 로고 레퍼런스를 3장 수집하고 분석한다.

## 브랜드 방향

- **브랜드명**: SOAPHE (오브제 라이프스타일 비누 브랜드)
- **브랜드 컨셉**: **"오래 남는 온기를 선물하다."** 공간 속에 남아 일상과 함께하는 오브제형 비누 브랜드
- **배경색**: 흰색 (`#FFFFFF` / Clean White Background)
- **로고색**: 검정 단색 (`#000000` / Pure Black Monochrome)
- **조형 키워드**: 원형 그리드(Circle Grid), 기하학(Geometric), 2D 플랫(Flat Vector), 미니멀(Minimalist)

## 초안 분석 항목

검색 전에 아래 항목을 한 문장씩 기록한다. (배경에 그려진 구도/그리드 선은 분석에서 완전 제외하고, **진하게 그린 선과 면만** 참고한다)

1. **형태 구조 (input 기준)**: 지정 N번 초안의 진하게 표현된 선과 면의 기하학 구조 (단순 독립 원의 나열이 아닌, **연결되고 교차하는 유기적 흐름** 유지).
2. **스타일 규격 (레퍼런스 기준)**: `레퍼런스/image.png` 스타일북의 **2D 단색 흑백 플랫 벡터(Monochrome Flat Vector)** 표현 방식 적용.
3. 선의 특징: 단선, 단색 굵기, 2D 플랫 라인
4. 전체 인상: 유기적 미니멀, 기하학적 정교함, SOAPHE 오브제 감성

## 검색어 작성 규칙

한 번에 긴 문장을 검색하지 않는다. 아래 구조로 영어 검색어를 3~5개 만든다.

`[핵심 형태] + [구성 방식] + [스타일] + logo mark`

우선 검색어:

- `geometric circle grid logo design`
- `circle grid logo mark minimalist`
- `minimalist monochrome logo design flat`
- `flat vector logo black and white white background`
- `object lifestyle brand logo black and white`

## 금지 조건

- 로고가 제품, 간판, 명함 등에 합성된 목업 이미지 및 3D 렌더링
- 검색 결과 목록 전체의 스크린샷
- Pinterest 로그인 또는 가입 팝업이 포함된 캡처
- 유색/컬러 로고, 그래디언트, 그림자 및 입체 효과 적용 로고

## 파일 규칙

- 입력: `input/` 폴더 내 N번 지정 초안 이미지
- 출력 폴더: `output/[N번]/` (예: `output/1번/`, `output/2번/`)
- 파일명 및 수량: `similar_logo_01.jpg`, `similar_logo_02.jpg`, `similar_logo_03.jpg` (총 3장)
- 형식: 실제 JPEG 파일

## 완료 보고

각 결과에 대해 다음 정보를 제공한다.

- 지정 초안 번호 (N번)
- 저장 파일 경로 목록 (3장)
- 갱신된 `output/[N번]/flow.md` 경로
- 초안과 유사하다고 판단한 이유 1~2문장
