# SOAPHE Unified 최종 메인페이지 스토리보드

## 1. 통합 범위

- 반영 결과: Bath, Care, Studio, Gift, Space, Collective, 마음배송, Atelier, Object, Loop
- 핵심 여정: 목적 발견 → 컬렉션 비교 → 제품 탐색 → 맞춤 구성 → 근거 확인 → 상담·샘플·알림 접수
- 제외 범위: 회원가입, 로그인, 장바구니, 결제, 주문·구독 확정
- 표현 기준: 브랜드 색상을 제외한 흰색·회색·검정 저충실도 와이어프레임

## SCR-100 · 통합 홈

| 스토리보드 항목 | 최종 명세 |
|---|---|
| 화면 목적 | 열 가지 SOAPHE 경험을 하나의 브랜드 가치와 핵심 CTA로 연결한다. |
| 진입 / 종료 | 직접·검색·SNS 진입 → SCR-110 목적 진단 또는 SCR-190 접수 |
| Visual Layout | `[무채색 Sticky Header] → [Hero 카피 + 회색 오브젝트] → [목적 CTA] → [컬렉션 미리보기] → [근거] → [Footer]` |
| UI / 인터랙션 | GNB 앵커, 목적 찾기, 컬렉션 카드, 상담·알림 CTA, 스크롤 위치 표시 |
| 데이터 정책 | 확정되지 않은 가격·효능·환경 효과·납기는 생성하지 않는다. |
| 5대 상태 | 기본: Hero·CTA / 로딩: 텍스트 우선·회색 스켈레톤 / 빈 상태: 추천 경로 / 오류: 대체 링크 / 완료: 선택 목적 유지 |
| 반응형 / 접근성 | PC 2열 Hero·3열 카드, 태블릿 2열, 모바일 1열·44px CTA. 순차 헤딩·키보드 GNB·구체적 대체 텍스트·7:1 대비 |

| 5대 상태 | 기본 / 답변 로딩 / 검색 결과 없음 / 링크 오류 / 답변 확인 완료 |
| 반응형 / 접근성 | `details/summary` 또는 동등한 버튼 패턴, 펼침 상태 제공 |

## SCR-404 · SCR-500 · SCR-510 시스템 상태

| 스토리보드 항목 | 최종 명세 |
|---|---|
| 화면 목적 | 잘못된 경로·통신 실패·로딩·빈 결과에서 사용자를 복구한다. |
| 진입 / 종료 | 시스템 조건 → 홈·이전 화면·재시도 |
| Visual Layout | `[상태 코드] [평이한 설명] [입력 보존 여부] [주 행동] [대체 행동]` |
| UI / 인터랙션 | 홈, 이전 화면, 재시도, 필터 초기화 |
| 데이터 정책 | 오류 세부정보·민감값 노출 금지. 입력 보존 여부를 명시한다. |
| 5대 상태 | 404 / 500 / 로딩 / 빈 결과 / 복구 완료 |
| 반응형 / 접근성 | 초점이 상태 제목으로 이동하고 행동 버튼의 결과를 명확히 명명한다. |
