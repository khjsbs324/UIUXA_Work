# SOAPHE Unified 최종 브랜드소개페이지 스토리보드

## BRD-100 · 브랜드 철학

| 스토리보드 항목 | 최종 명세 |
|---|---|
| 화면 목적 | 비누의 기능적 불편을 해결하고 사용 후에도 공간과 루틴에 남는 SOAPHE의 관점을 전달한다. |
| 진입 / 종료 | GNB Story·Footer → BRD-110 또는 컬렉션 |
| Visual Layout | `[무채색 Hero] [문제 정의] [기능·심미·지속 사용 3원칙] [10개 경험 지도] [관련 CTA]` |
| UI 구성요소 | 선언문, 문제·해법 비교, 원칙 카드, 경험 지도, 관련 링크 |
| 사용자 액션 | 원칙 탐색, 컬렉션·공정 이동 |
| 데이터 정책 | 브랜드 관점과 객관적 사실을 구분하고 “최초·유일” 등 검증 불가 표현을 금지한다. |
| 5대 상태 | 기본 / 미디어 로딩 / 이미지 없음 / 콘텐츠 오류 / 관련 경로 이동 완료 |
| 반응형 | PC 넓은 여백·3열, 태블릿 2열, 모바일 1열 |
| 웹 접근성 | 장식 이미지는 빈 alt, 정보 이미지는 구체적 alt, 본문 16px 이상, 7:1 대비 |

## BRD-110 · 문제에서 해법까지

| 스토리보드 항목 | 최종 명세 |
|---|---|
| 화면 목적 | 비누 무름·받침대 오염·공간 부조화·선택 과부하·반복 이용 단절을 해법과 연결한다. |
| 진입 / 종료 | BRD-100 → BRD-120 제작 과정 |
| Visual Layout | `[문제 5카드] → [설계 원칙] → [공중 건조·오브젝트·큐레이션·회수 해법]` |
| UI 구성요소 | 문제 필터, 전후 비교, 해법 카드, 관련 컬렉션 |
| 사용자 액션 | 문제 선택, 해당 해법·컬렉션 이동 |
| 데이터 정책 | 해결 효과는 구조와 사용 방식으로 설명하며 의학·환경 효과를 단정하지 않는다. |
| 5대 상태 | 기본 / 카드 로딩 / 관련 해법 없음 / 링크 오류 / 연결 완료 |
| 반응형 / 접근성 | 전후 비교를 DOM 순서대로 배치하고 색상 없이 제목으로 구분한다. |

## BRD-120 · 제작·검수·포장

| 스토리보드 항목 | 최종 명세 |
|---|---|
| 화면 목적 | 원료 확인부터 성형·검수·포장까지의 과정과 확인 범위를 설명한다. |
| 진입 / 종료 | BRD-100·110·제품 상세 → BRD-130 |
| Visual Layout | `[공정 목차] [01 원료] [02 제작] [03 건조·성형] [04 검수] [05 포장] [한계]` |
| UI 구성요소 | 공정 스테퍼, 회색 자료 이미지, 설명, 검증 배지, 관련 제품 |
| 사용자 액션 | 단계 선택, 근거 펼치기, 관련 제품 이동 |
| 데이터 정책 | 출처·확인일·검증 상태를 표시하며 수공예·업사이클 범위를 제품별로 구분한다. |
| 5대 상태 | 기본 / 자료 로딩 / 공개 자료 없음 / 자료 불일치 / 과정 탐색 완료 |
| 반응형 / 접근성 | PC 교차 타임라인, 모바일 단일 축. DOM·시각 순서 일치 |

## BRD-130 · 사용 이후의 순환

| 스토리보드 항목 | 최종 명세 |
|---|---|
| 화면 목적 | 트레이의 공간 이동과 Loop 리필·회수의 차이를 명확히 설명한다. |
| 진입 / 종료 | BRD-120·Object·Loop → 회수 기준·알림 |
| Visual Layout | `[사용] → [완전 건조] → [오브젝트 전환 또는 리필] → [회수 기준] → [처리 상태]` |
| UI 구성요소 | 두 경로 비교, 회수 가능·불가 탭, 진행 스테퍼, 알림 CTA |
| 사용자 액션 | 경로 선택, 기준 확인, 주기 계산·알림 이동 |
| 데이터 정책 | 회수 파트너·정량 감축량은 검증 완료 전 공개하지 않는다. 계산은 예상 범위로 표시한다. |
| 5대 상태 | 기본 / 상태 로딩 / 처리 기록 없음 / 연결 오류 / 확인 완료 |
| 반응형 / 접근성 | 모바일 세로 흐름, 단계 번호·상태 텍스트, 모션 축소 지원 |

## BRD-140 · 검증 근거와 한계

| 스토리보드 항목 | 최종 명세 |
|---|---|
| 화면 목적 | 검증 완료·진행·자료 준비 중 정보를 분리해 그린워싱과 오인을 방지한다. |
| 진입 / 종료 | BRD-120·130·제품 상세 → FAQ·문의 |
| Visual Layout | `[상태 필터] [검증 완료 카드] [진행 카드] [자료 준비 카드] [업데이트 원칙] [문의]` |
| UI 구성요소 | 상태 필터, 근거 카드, 출처·갱신일, 외부 문서 안내, 문의 CTA |
| 사용자 액션 | 상태 필터, 근거 열기, 문의 이동 |
| 데이터 정책 | 정량 수치는 직접 출처가 있을 때만 표시하고 미확정 정보의 갱신 기준을 제공한다. |
| 5대 상태 | 기본 / 근거 로딩 / 공개 근거 없음 / 문서 링크 오류 / 확인 완료 |
| 반응형 / 접근성 | 상태명을 텍스트로 병기하고 새 창·문서 형식을 사전 안내한다. |

## BRD-150 · 제작자·파트너·사용자 기록

| 스토리보드 항목 | 최종 명세 |
|---|---|
| 화면 목적 | 제작자 협업, 기업·공간 적용, 개인 사용 기록을 맥락과 함께 제공한다. |
| 진입 / 종료 | BRD-100·140 → 컬렉션·협업 문의 |
| Visual Layout | `[목적 필터] [제작자] [개인] [선물] [기업·공간] [협업 CTA]` |
| UI 구성요소 | 목적 필터, 기록 카드, 인용문, 관련 컬렉션 링크 |
| 사용자 액션 | 기록 필터, 상세 펼치기, 관련 상담 이동 |
| 데이터 정책 | 후기의 목적·사용 기간·조건을 보존하고 대표성이 있는 통계처럼 표현하지 않는다. |
| 5대 상태 | 기본 / 기록 로딩 / 해당 기록 없음 / 미디어 오류 / 관련 경로 이동 완료 |
| 반응형 / 접근성 | PC 3열, 모바일 1열. 인용문 출처와 이미지 설명 제공 |
