# SOAPHE Unified 최종 카테고리페이지 스토리보드

## CAT-100 · 통합 컬렉션·제품 탐색

| 스토리보드 항목 | 최종 명세 |
|---|---|
| 화면 목적 | Bath부터 Loop까지 10개 컬렉션과 제품·키트를 목적 중심으로 탐색한다. |
| 진입 / 종료 | GNB·홈·목적 진단 → CAT-110 결과 또는 CAT-120 상세 |
| Visual Layout | `[무채색 Header] [카테고리 설명] [목적 탭] [필터] [결과 수·정렬] [3열 카드]` |
| UI 구성요소 | 목적·유형·향·공간·대상·수량 필터, 정렬, 적용 조건, 카드, 초기화 |
| 사용자 액션 | 조건 복수 선택, 개별 해제, 정렬, 상세 보기, 맞춤 구성 이동 |
| 데이터 정책 | 카드에 이름·컬렉션·핵심 속성·검증 상태를 표시하고 미확정 가격·재고는 생성하지 않는다. |
| 5대 상태 | 기본 / 카드 스켈레톤 / 결과 없음·유사 제안 / 필터 오류 / 결과 갱신 완료 |
| 반응형 | PC 필터 사이드바+3열, 태블릿 2열, 모바일 필터 드로어+1열 |
| 웹 접근성 | 필터 그룹명, 선택 상태 텍스트, 결과 수 `aria-live`, 드로어 초점 복귀 |

## CAT-110 · 목적별 결과·비교

| 스토리보드 항목 | 최종 명세 |
|---|---|
| 화면 목적 | 선택한 조건의 결과를 비교하고 차이를 빠르게 이해시킨다. |
| 진입 / 종료 | CAT-100 필터·진단 결과 → CAT-120 또는 조건 수정 |
| Visual Layout | `[목적 요약] [적용 필터 칩] [비교 선택 최대 3] [결과 카드] [빈 상태]` |
| UI 구성요소 | 필터 해제, 비교 체크, 속성 비교표, 유사 컬렉션 추천 |
| 사용자 액션 | 최대 3개 비교, 조건 수정, 상세·구성 이동 |
| 데이터 정책 | 비교 필드는 소재·향·크기·용도·관리·맞춤 가능 여부로 고정한다. |
| 5대 상태 | 기본 / 비교 로딩 / 결과·선택 없음 / 비교 수 초과 / 비교표 완료 |
| 반응형 | 모바일 비교표는 가로 스크롤 대신 항목별 세로 카드 사용 |
| 웹 접근성 | 비교 개수 안내, 체크박스 레이블, 표 머리글 연결 |

## CAT-120 · 제품·구성 상세

| 스토리보드 항목 | 최종 명세 |
|---|---|
| 화면 목적 | 선택 결정에 필요한 사실·사용법·관리·근거와 다음 행동을 제공한다. |
| 진입 / 종료 | CAT-100·110 → 맞춤 구성·공간 보기·접수 |
| Visual Layout | `[회색 이미지 갤러리] [제품 요약] [속성표] [공간·사용] [근거] [관련 구성] [CTA]` |
| UI 구성요소 | 갤러리, 속성표, 가이드 아코디언, 검증 배지, 관련 상품, CTA |
| 사용자 액션 | 이미지 전환, 정보 펼치기, 맞춤·상담·알림 선택 |
| 데이터 정책 | 효능·환경 효과·가격·납기는 출처와 확정 상태가 있을 때만 표시한다. |
| 5대 상태 | 기본 / 이미지·데이터 로딩 / 이미지 없음 / 상세 불러오기 오류 / 선택 전달 완료 |
| 반응형 | PC 이미지·정보 2열, 태블릿 균등 2열, 모바일 정보 우선 1열 |
| 웹 접근성 | 구체적 대체 텍스트, 속성표 제목, 확대 버튼명, 아코디언 상태 |

## CAT-130 · 필터 결과 없음

| 스토리보드 항목 | 최종 명세 |
|---|---|
| 화면 목적 | 막힌 경로를 설명하고 가장 가까운 대안을 제공한다. |
| 진입 / 종료 | CAT-100·110 조건 결과 0개 → 조건 초기화·유사 컬렉션 |
| Visual Layout | `[결과 없음 제목] [활성 조건] [충돌 설명] [개별 해제] [전체 초기화] [유사 제안]` |
| UI 구성요소 | 적용 필터, 해제 버튼, 초기화, 유사 결과 카드 |
| 사용자 액션 | 조건 하나 해제, 전체 초기화, 유사 상세 이동 |
| 데이터 정책 | 결과가 없다는 사실 외에 품절·단종 등을 임의로 추론하지 않는다. |
| 5대 상태 | 빈 상태 중심, 재계산 로딩·오류·결과 복구 완료 포함 |
| 반응형 / 접근성 | 상태 제목에 초점, 초기화 후 결과 수 낭독, 장식 이미지 생략 가능 |
