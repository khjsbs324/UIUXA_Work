# 🔍 project-pef.com (Vylumn) vs 스토리보드 병합 1차 입체 비교 분석 보고서

---

## 📌 Executive Summary

* **`project-pef.com` (Vylumn):** **단일 시그니처 세럼 제품의 럭셔리 브랜드 감성과 과학적 성분 메커니즘**을 전달하기 위해 인터랙티브 스크롤 모션(GSAP, Lenis)을 극대화한 **'단일 페이지(Single-Page Linear Flow) 브랜드 랜딩'**입니다.
* **`스토리보드 병합/1차` (SOAPHE Unified):** **10개 다각화 컬렉션과 다양한 사용자 목적(개인/선물/기업/순환)**을 수용할 수 있도록 시스템화된 **'다계층 모듈형 와이어프레임(Multi-Page Modular System)'**입니다.

---

## 📐 1. 설계 관점 (Information Architecture & UX System) 비교

| 비교 항목 | 🌐 `project-pef.com` (Vylumn) | 📄 `스토리보드 병합/1차` (SOAPHE Unified) | 설계적 시사점 & 평가 |
| :--- | :--- | :--- | :--- |
| **정보 구조 (IA)** | **선형적 싱글 페이지 (Single-Page Linear Flow)**<br>- 상단 GNB 클릭 시 해당 앵커 섹션(`#philosophy`, `#serum`, `#science`, `#reserve`)으로 동적 스크롤 이동.<br>- 깊이가 얕고 1차원적인 서사 구조. | **계층형 다중 페이지 (Multi-Page Modular IA)**<br>- `SCR-100`(통합홈), `SCR-110`(목적진단), `SCR-120`(컬렉션허브), `SCR-150`(맞춤구성), `BRD/CAT` 전문 페이지 분치.<br>- 복합적인 사용자 저니(User Journey) 수용. | **Vylumn:** 단일 시그니처 제품 집중도 우수.<br>**SOAPHE 1차:** 복수 상품 카탈로그 및 큐레이션 확장에 압도적으로 유리한 구조. |
| **전환 경로 (Conversion)** | **스토리텔링 ➔ 하단 Contact 폼 및 외부 몰 연결**<br>- 브랜드 서사 고조 후 하단 `Reserve Yours` 문의 폼 작성 또는 Shopee, Naver Store 등 외부 플랫폼으로 유도. | **목적 진단 ➔ 맞춤 구성 ➔ 동적 폼 제출 (Interactive Flow)**<br>- `SCR-110` 목적 진단으로 니즈를 분류한 뒤 `SCR-150` 맞춤 구성 ➔ `SCR-190` 통합 폼 제출로 연결되는 닫힌 루프. | **Vylumn:** 입점 몰 링크 중심의 브랜딩 사이트.<br>**SOAPHE 1차:** 서비스 내에서 직접 맞춤 견적/구성 및 폼 접수를 완료하는 커스텀 엔진. |
| **상태 관리 (State)** | **프론트엔드 인터랙션 상태 중심**<br>- `sessionStorage` 기반 스크롤 위치 복원, 탭 전환(Mechanism/OSA Matrix/Origin/Safety), PristineJS 폼 검증. | **엄격한 5대 상태 (Default / Loading / Empty / Error / Success) Matrix**<br>- 전 화면 스켈레톤 UI, 빈 결과 대안, 통신 실패, 404/500 복구 경로 100% 명세. | **Vylumn:** 애니메이션 연출을 위한 UX 상태 관리.<br>**SOAPHE 1차:** 개발 및 예외 처리(Error Resilience) 관점에서 완성도가 뛰어남. |
| **신뢰 정보 (Proof)** | **마케팅 스토리텔링 중심**<br>- "Deep Enough To Matter", "20nm", "OSA Matrix™" 등 차별화 기술명 소구. | **그린워싱 방지 및 데이터 정책 명시**<br>- 미확정 가격/효능/환경 효과 생성 금지.<br>- 검증 완료/진행 중/자료 준비 중 3단계 근거 분리 명시. | **Vylumn:** 마케팅 임팩트 중심.<br>**SOAPHE 1차:** 허위/과장 마케팅을 방지하는 엄격한 신뢰 데이터 검증 명세. |

## 💡 3. 시너지 및 향후 개발 가이드

1. **`Vylumn`이 `SOAPHE 스토리보드`에 주는 시사점 (디자인/모션 보강)**
   * SOAPHE의 `BRD-120` (제작 과정) 및 `SCR-170` (공정) 영역에 Vylumn 특유의 **'스크롤 기반 텍스트-이미지 모핑'**과 **'GSAP 인터랙티브 탭 연출'**을 도입하면 브랜드 감성 수치를 대폭 끌어올릴 수 있습니다.

2. **`SOAPHE 스토리보드`가 `Vylumn` 대비 가지는 구조적 우위점 (설계 완성도)**
   * Vylumn은 단순 브랜딩용 단일 랜딩페이지 구조로서, 카탈로그 선택지가 늘어나거나(예: **상품 최소 15개 이상**), 맞춤 구성/옵션 계산/다각화 폼 제출을 수용하기 어렵습니다.
   * 반면 SOAPHE 1차 스토리보드는 **목적 진단(`SCR-110`) ➔ 15개+ 필터링 카탈로그(`CAT-100`) ➔ 맞춤 구성기(`SCR-150`) ➔ 5대 상태 Matrix**가 다면적으로 완비되어 있어, 향후 **실제 커머스/플랫폼으로 확장 시 압도적인 설계 우위**를 지닙니다.
