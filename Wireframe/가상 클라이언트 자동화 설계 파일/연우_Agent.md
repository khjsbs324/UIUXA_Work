## 📋 2. 3단계 자동화 프로세스 명세

### [Step 1] 가상클라이언트 자동 생성 명세
- **목적**: 기획 문서 및 원본 소스 데이터를 종합하여 표준 가상클라이언트 브리프 파일 생성
- **소스 경로**: `C:\yyw\가상클라이언트 생성\` 루비 파일 및 `브랜드 가상클라이언트\` 폴더 내 파일 전량
- **생성 규칙**:
  1. 기존 `C:\yyw\가상 클라이언트 모음\가상클라이언트\` 내 기존 클라이언트(1~6번) 및 타깃과 겹치지 않도록 **중복 생성 차단**
  2. 번호는 **`가상클라이언트_7` (7번)**부터 시작하여 `가상클라이언트_N`까지 순차 부여
  3. 공통 평가 조건 및 브랜드 기본 정보(이름, 직책, 업종, 브랜드명, 출시일, 목적) 추출
  4. 페르소나의 핵심 문제, 타깃층, 서비스 내용, 디자인 방향, 필수 콘텐츠 설정
- **저장 위치**: `C:\yyw\가상 클라이언트 모음\가상클라이언트\가상클라이언트_{N}_{타깃명}.txt` (N >= 7)

---

### [Step 2] 분석 스킬 발동 & 작성 양식 맞춤 변환 명세
- **목적**: 생성된 가상클라이언트를 `분석_스킬`의 5대 영역과 양식 규격에 맞춰 분석 보고서로 변환
- **소스 경로**: Step 1 생성 파일 + `C:\yyw\md_skill\분석_스킬\SKILL.md` + `가상 클라이언트 기반 분석 결과 작성 양식.md`
- **양식 항목 (6대 영역)**:
  1. 가상 클라이언트 (프로젝트 주제, 제작 목적, 제공 자료, 적용 매체)
  2. 클라이언트 요구사항 (요청 내용, 중요도, 관련 자료, 필요 기능)
  3. 정보 구조 (IA, 5대 핵심 영역 분석)
  4. 내비게이션 & 사용자 흐름 (User Flow)
  5. 화면 구성 (레이아웃 & 와이어프레임)
  6. 검토 결과 (누락/중복, 개선점, 차별화 전략)
- **저장 위치**: `C:\yyw\가상 클라이언트 모음\가상클라이언트 분석\가상클라이언트_{N}_{타깃명}_분석결과.md` (N >= 7)

---

### [Step 3] 가상클라이언트 기준 210개 레퍼런스 분석 명세
- **목적**: 210개 레퍼런스 사이트를 각 가상클라이언트 관점에서 벤치마킹하여 "메뉴, 콘텐츠, 기능" 분석 결과 도출
- **소스 경로**: Step 2 분석 보고서 + `20개 리서치`, `50개 리서치`, `140개 리서치` 폴더 데이터 (총 210개)
- **출력 포맷 명세**:
  - **[메뉴 (Menu)]**: GNB 5대 계층 구조, 뎁스(Depth 3이내), 타깃별 이동 동선
  - **[콘텐츠 (Content)]**: 메인 카피라이팅, 에디토리얼 룩북/매크로 뷰, 원천 기술/알고리즘 스펙, 찐후기 & 신뢰 배지
  - **[기능 (Function)]**: 바이오피드백 데이터 UI, 타깃 액션 UI(카톡 1-Click 공유, O2O 지도 검색, 네이버페이 1-Click 등), Floating Sticky CTA Bar
- **저장 위치**: `C:\yyw\가상 클라이언트 모음\사이트 분석 결과\사이트분석결과_가상클라이언트_{N}_{타깃명}.md` (N >= 7)
