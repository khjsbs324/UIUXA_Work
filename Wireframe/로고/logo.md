# Pinterest 로고 레퍼런스 수집 가이드

## 실행 명령

사용자가 **`레퍼런스 수집 시작해`**라고 명령하면 아래 작업을 즉시 실행한다. 파일이 정상적으로 존재하면 추가 질문이나 재확인 없이 진행한다.

1. `input` 폴더의 이미지 파일을 모두 확인하고, 찾으려는 로고의 형태·구조·선·분위기를 분석한다.
2. `레퍼런스` 폴더(사용자가 말하는 “레퍼런스 폴더”)의 이미지 파일을 모두 확인하고, 사용자가 선호하는 시각 스타일과 결과물의 품질 기준을 분석한다.
3. `input`은 **무엇과 비슷한 로고를 찾을지** 판단하는 기준으로 사용한다.
4. `레퍼런스` 폴더는 **어떤 스타일과 표현 방식의 이미지를 선택할지** 판단하는 기준으로 사용한다.
5. 두 기준을 결합해 Pinterest에서 유사한 개별 로고 핀을 검색한다.
6. `레퍼런스` 폴더 이미지와 비슷한 스타일이면서 `input` 이미지의 핵심 형태를 유지한 후보만 선택한다.
7. 찾은 이미지는 Pinterest UI 전체가 아니라 **로고 이미지가 보이는 영역만 캡처**한다.
8. 로그인 팝업 때문에 정상 캡처가 불가능하면 개별 핀의 공개 대표 이미지(`og:image`)를 가져오되, 실제 핀 이미지와 일치하는지 확인한다.
9. 결과를 실제 JPEG 형식으로 변환해 `output` 폴더에 저장한다.
10. 저장한 JPG를 다시 열어 로고, 잘림, 팝업, 워터마크, 목업, 빈 화면 여부를 육안 검증한다.

기본 수집 개수는 사용자가 별도로 지정하지 않으면 **1장**이다. 결과 파일은 기존 파일을 덮어쓰지 않고 `similar_logo_01.jpg`, `similar_logo_02.jpg`처럼 사용되지 않은 다음 번호로 저장한다.

### 입력 우선순위

- 형태와 구조: `input` 폴더를 우선한다.
- 스타일, 색감, 표현 방식, 결과 이미지 구성: `레퍼런스` 폴더를 우선한다.
- 두 기준이 충돌하면 형태 유사성을 먼저 지키고, 그 안에서 레퍼런스 스타일에 가장 가까운 후보를 고른다.
- `input` 또는 `레퍼런스` 폴더가 없거나 지원되는 이미지가 하나도 없을 때만 작업을 멈추고 누락된 항목을 알린다.

### 캡처의 의미

- “캡처”는 Pinterest 화면 전체를 그대로 저장한다는 뜻이 아니다.
- 로고가 선명하게 보이는 이미지 영역만 결과로 남긴다.
- Pinterest 로그인 창, 메뉴, 버튼, 검색창 등 사이트 UI가 결과 JPG에 포함되면 실패로 간주한다.
- 공개 대표 이미지를 직접 저장한 경우에도 최종 결과를 열어 확인했다면 캡처 결과로 인정한다.

## Flow 이미지 생성 프롬프트 작성

### 목적

`output` 폴더에 수집된 로고 레퍼런스를 분석하여 Flow의 이미지 생성 기능에 바로 사용할 수 있는 프롬프트를 작성한다. 이 단계에서는 이미지를 직접 생성하지 않고 프롬프트만 작성한다.

### 실행 규칙

1. `output` 폴더에서 JPG, JPEG, PNG, WebP 이미지 파일을 찾는다.
2. 각 이미지를 실제로 열어 심볼의 구조, 도형, 선, 구성, 여백, 색상, 질감, 분위기를 분석한다.
3. 분석 내용을 바탕으로 Flow 이미지 생성 기능에 사용할 수 있는 구체적인 프롬프트를 작성한다.
4. 프롬프트 본문은 반드시 **영문**으로 작성한다.
5. 프롬프트에는 다음 내용을 자연스러운 영어 문장으로 포함한다.
   - 생성할 로고의 핵심 심볼과 구조
   - 곡선, 선 굵기, 대칭 또는 회전 방식
   - 브랜드 인상과 웰니스 콘셉트
   - 배경색과 로고 색상
   - 미니멀 벡터 로고, 정면 배치, 충분한 여백 등 출력 방식
   - 목업, 사진, 3D, 워터마크, 불필요한 문자 등을 배제하는 조건
6. 레퍼런스를 그대로 복제하거나 기존 브랜드·작가·상표명을 모방하도록 지시하지 않는다. 형태적 특징과 디자인 원리만 추출해 새로운 로고를 생성하도록 작성한다.
7. 작성 결과는 `output/flow.md`에 저장한다.

### 중복 실행 방지

- `output/flow.md`에 이미지 파일명이 대제목으로 이미 존재하면 해당 이미지는 처리 완료로 간주한다.
- 처리 완료된 이미지의 프롬프트는 사용자가 **`재실행`**이라고 명령하기 전까지 다시 분석하거나 수정하거나 중복 작성하지 않는다.
- 새 이미지가 `output`에 추가되면 기존 항목은 유지하고 새 이미지 항목만 문서 끝에 추가한다.
- 사용자가 **`재실행`**이라고 명령하면 `output`의 현재 이미지들을 다시 분석하고, 각 파일명에 해당하는 기존 프롬프트를 최신 분석 결과로 교체한다. 같은 파일명의 대제목을 중복 생성하지 않는다.
- `flow.md` 자체는 분석 대상 이미지에서 제외한다.

### flow.md 작성 형식

각 이미지의 **확장자를 포함한 파일 이름**을 Markdown 대제목(`#`)으로 작성하고, 바로 아래에 영문 프롬프트를 작성한다.

```markdown
# similar_logo_01.jpg

Create an original minimalist vector logo featuring ...

# similar_logo_02.jpg

Create an original wellness logo with ...
```

- 파일명 대제목과 프롬프트 사이에는 빈 줄을 한 줄 넣는다.
- 이미지 하나당 프롬프트 하나만 작성한다.
- 프롬프트 외의 분석 메모, 한국어 설명, 출처 URL은 `flow.md`에 넣지 않는다.
- 저장 후 `flow.md`를 다시 읽어 파일명 누락, 한글 프롬프트, 중복 대제목이 없는지 확인한다.

## 목표

`input` 폴더의 로고 초안을 먼저 시각적으로 분석한 뒤, 형태와 분위기가 유사한 Pinterest 로고 레퍼런스를 찾는다. 검색 결과 페이지 전체가 아니라 개별 로고 이미지가 선명하게 보이는 자료만 수집한다.

## 브랜드 방향

- 바쁜 일상 속에서도 바른 자세와 건강한 습관을 자연스럽게 만들어 주는 웰니스 브랜드
- 몸과 마음의 균형을 표현하는 친근하고 따뜻한 인상
- 흰색 배경과 검은색 심볼을 우선
- 유기적인 곡선, 연결, 순환, 균형, 호흡을 연상시키는 형태

## 초안 분석 항목

검색 전에 아래 항목을 한 문장씩 기록한다.

1. 기본 도형과 개수: 원, 타원, 소용돌이, 잎, 선 등의 구성
2. 배치 방식: 방사형, 대칭형, 회전형, 연결형 등
3. 선의 특징: 굵기, 단선/면, 끝 처리, 손그림 여부
4. 전체 인상: 유기적, 미니멀, 안정적, 역동적 등
5. 반드시 유지할 특징 2~3개와 제외할 특징

## 검색어 작성 규칙

한 번에 긴 문장을 검색하지 않는다. 아래 구조로 영어 검색어를 3~5개 만든다.

`[핵심 형태] + [구성 방식] + [스타일] + logo mark`

우선 검색어:

- `organic spiral circles minimalist logo mark`
- `connected circular line wellness logo`
- `radial swirl black and white logo symbol`
- `five circle rotation abstract logo mark`
- `balance wellness organic line logo`

검색 결과가 부족하면 형태 단어를 하나씩 바꾼다.

- spiral → swirl, loop, circular flow, rotation
- connected → interlocking, continuous line, linked
- wellness → balance, holistic, mind body, yoga
- minimalist → monoline, geometric, organic, abstract

Google 검색을 병행할 때는 검색어 앞에 `site:pinterest.com/pin`을 붙여 개별 핀을 우선 찾는다.

## 검색 및 선정 절차

1. 초안의 핵심 특징을 바탕으로 서로 다른 검색어를 최소 3개 실행한다.
2. 검색 결과에서 개별 Pinterest 핀 URL(`/pin/…`)만 후보로 수집한다.
3. 후보마다 초안과 아래 항목을 비교한다.
   - 형태 유사성
   - 배치와 흐름의 유사성
   - 선의 스타일
   - 브랜드 분위기 적합성
4. 세 항목 이상이 유사한 후보만 채택한다.
5. 동일 이미지, 워터마크가 심한 이미지, 해상도가 낮은 이미지는 제외한다.
6. 요청된 개수만 저장한다. 사용자가 “우선 1개”라고 하면 정확히 1개만 처리한다.

## 금지 조건

- 로고가 제품, 간판, 명함 등에 합성된 목업 이미지
- 검색 결과 목록 전체의 스크린샷
- Pinterest 로그인 또는 가입 팝업이 포함된 캡처
- 로고보다 UI가 더 크게 보이는 페이지 캡처
- 초안과 관계없는 단순 원형 아이콘
- 사진, 3D 렌더링, 과도한 그라데이션 위주의 로고
- 출처 URL을 확인할 수 없는 이미지

## Pinterest 팝업 대응 및 저장 규칙

Pinterest 페이지는 로그인 팝업과 동적 로딩 때문에 화면 캡처가 불안정할 수 있다. 다음 순서로 처리한다.

1. 개별 핀 페이지를 연다.
2. 팝업 없이 로고 이미지가 충분히 크게 보이면 이미지 영역만 캡처한다.
3. 로그인 팝업이 이미지를 가리면 페이지 전체를 캡처하지 않는다.
4. 이 경우 해당 핀의 공개 대표 이미지(`og:image`, 일반적으로 `i.pinimg.com`)를 확인한다.
5. 대표 이미지가 실제 핀 이미지와 일치하는지 열어 검증한 뒤 저장한다.
6. PNG나 WebP인 경우 JPG로 변환하고, 단순히 확장자만 바꾸지 않는다.
7. 저장 후 파일을 다시 열어 팝업, 깨짐, 빈 화면, 과도한 UI, 잘못된 후보가 없는지 확인한다.

## 파일 규칙

- 입력: `input/로고 초안.jpeg`
- 출력 폴더: `output`
- 파일명: `similar_logo_01.jpg`, `similar_logo_02.jpg` 순서
- 형식: 실제 JPEG 파일
- 권장 크기: 긴 변 기준 1000px 이상. 원본이 더 작으면 억지로 확대하지 않는다.
- 기존 파일은 사용자의 명시적 요청 없이 덮어쓰지 않는다.

## 완료 보고

각 결과에 대해 다음 정보를 제공한다.

- 저장 파일 경로
- Pinterest 원본 핀 URL
- 초안과 유사하다고 판단한 이유 1~2문장
- 워터마크나 낮은 해상도 등 품질상 주의점

저장 성공 메시지만 믿지 말고, 결과 JPG를 실제로 열어 육안 검증한 뒤 완료로 보고한다.
