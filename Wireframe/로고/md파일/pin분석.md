# Pinterest 레퍼런스 분석 및 Flow 프롬프트 작성

## 목적

`../output`에 수집된 Pinterest 로고 레퍼런스를 실제로 분석하고, Flow 이미지 생성 기능에 바로 사용할 수 있는 영문 프롬프트를 작성한다. 이 절차에서는 이미지를 직접 생성하지 않고 프롬프트만 작성한다.

## 입력과 출력

- 분석 대상: `../output`의 JPG, JPEG, PNG, WebP 이미지
- 결과 문서: `../output/flow.md`
- `flow.md`는 분석 대상 이미지에서 제외한다.

## 분석 절차

각 이미지를 실제로 열고 다음 항목을 확인한다.

1. 핵심 심볼과 도형의 개수
2. 연결, 반복, 회전, 대칭 구조
3. 곡선과 선의 굵기 및 끝 처리
4. 색상, 배경, 대비
5. 여백, 정렬, 심볼 크기
6. 미니멀, 유기적, 안정적, 따뜻함 등의 분위기
7. 웰니스 브랜드에 활용할 수 있는 디자인 원리

레퍼런스의 상표나 구체적 디자인을 복제하지 않는다. 형태적 특징과 디자인 원리만 추출하여 독창적인 새 로고를 만들 수 있도록 분석한다.

## Flow 프롬프트 규칙

프롬프트 본문은 반드시 영문으로 작성하며 다음 내용을 자연스러운 문장으로 포함한다.

- 생성할 로고의 핵심 심볼과 구조
- 곡선, 선 굵기, 대칭 또는 회전 방식
- 순환, 연결, 균형, 호흡을 표현하는 웰니스 콘셉트
- 배경색과 심볼 색상
- 미니멀 벡터 로고, 정면 배치, 충분한 여백
- 선명한 실루엣과 작은 크기에서도 유지되는 가독성
- 목업, 사진, 3D, 워터마크, 서명, 불필요한 문자를 제외하는 조건

기존 브랜드명, 작가명, 상표명 또는 “exact copy”와 같은 복제 지시는 포함하지 않는다.

## 중복 실행 방지

- `../output/flow.md`에 이미지 파일명이 대제목으로 존재하면 해당 이미지는 처리 완료로 간주한다.
- 처리 완료 이미지는 사용자가 **`재실행`**이라고 명령하기 전까지 다시 분석하거나 수정하거나 중복 작성하지 않는다.
- 새 이미지가 추가되면 기존 내용을 유지하고 새 이미지 항목만 문서 끝에 추가한다.
- 사용자가 **`재실행`**이라고 명령하면 현재 `output` 이미지들을 다시 분석하고 기존 프롬프트를 교체한다.
- 재실행 시에도 같은 파일명의 대제목을 중복 생성하지 않는다.

## flow.md 출력 형식

이미지의 확장자를 포함한 파일명을 Markdown 대제목(`#`)으로 쓰고, 빈 줄 하나 아래에 영문 프롬프트를 작성한다.

```markdown
# similar_logo_01.jpg

Create an original minimalist vector logo featuring ...

# similar_logo_02.jpg

Create an original wellness logo with ...
```

작성 규칙:

- 이미지 하나당 대제목 하나와 프롬프트 하나만 작성한다.
- 프롬프트 외의 분석 메모, 한국어 설명, 출처 URL을 넣지 않는다.
- 기존 항목을 임의로 삭제하거나 순서를 바꾸지 않는다.
- 저장 후 문서를 다시 읽어 파일명 누락, 한글 프롬프트, 중복 대제목이 없는지 확인한다.
