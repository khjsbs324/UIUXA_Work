# Pinterest 로고 레퍼런스 수집

## 실행 명령

사용자가 **`레퍼런스 수집 시작해`**라고 명령하면 이 문서의 절차를 즉시 실행한다. 필요한 폴더와 이미지가 존재하면 추가 질문 없이 진행한다.

## 입력과 출력

- 형태 기준: `../input` 폴더의 이미지
- 스타일 기준: `../레퍼런스` 폴더의 이미지
- 결과 저장: `../output`
- 기본 수집 개수: 사용자가 지정하지 않으면 1장
- 파일 형식: 실제 JPEG
- 파일명: `similar_logo_01.jpg`, `similar_logo_02.jpg`처럼 사용되지 않은 다음 번호
- 기존 결과는 명시적인 요청 없이 덮어쓰지 않는다.

## 분석 기준

검색 전에 `input`과 `레퍼런스` 폴더의 지원 이미지(JPG, JPEG, PNG, WebP)를 모두 실제로 연다.

### input 분석

1. 기본 도형과 개수
2. 방사형, 대칭형, 회전형, 연결형 등의 배치
3. 선 굵기, 단선 또는 면, 끝 처리, 손그림 여부
4. 유기적, 미니멀, 안정적, 역동적 등의 전체 인상
5. 반드시 유지할 형태적 특징 2~3개

### 레퍼런스 분석

1. 색상과 명도
2. 선과 면의 표현 방식
3. 여백과 정렬
4. 심볼이 제시되는 방식
5. 결과물로 선호하는 시각적 완성도

형태와 구조는 `input`을 우선하고, 스타일과 표현 방식은 `레퍼런스`를 우선한다. 두 기준이 충돌하면 형태 유사성을 먼저 지킨다.

## 브랜드 방향

- 바쁜 일상 속 바른 자세와 건강한 습관을 돕는 웰니스 브랜드
- 몸과 마음의 균형을 표현하는 친근하고 따뜻한 인상
- 흰색 배경과 검은색 심볼 우선
- 연결, 순환, 균형, 호흡을 연상시키는 유기적 곡선

## Pinterest 검색어 작성

검색어는 `[핵심 형태] + [구성 방식] + [스타일] + logo mark` 구조의 영어 문구로 만든다. 서로 다른 검색어를 최소 3개 사용한다.

권장 검색어:

- `organic spiral circles minimalist logo mark`
- `connected circular line wellness logo`
- `radial swirl black and white logo symbol`
- `five circle rotation abstract logo mark`
- `balance wellness organic line logo`

결과가 부족하면 다음 대체어를 조합한다.

- spiral → swirl, loop, circular flow, rotation
- connected → interlocking, continuous line, linked
- wellness → balance, holistic, mind body, yoga
- minimalist → monoline, geometric, organic, abstract

일반 검색을 병행할 때는 `site:pinterest.com/pin`을 붙여 개별 Pinterest 핀을 우선 찾는다.

## 검색과 선정 절차

1. 서로 다른 영어 검색어를 최소 3개 실행한다.
2. 개별 Pinterest 핀 URL(`/pin/…`)만 후보로 수집한다.
3. 형태, 배치와 흐름, 선 스타일, 브랜드 분위기를 각각 비교한다.
4. 네 항목 중 세 항목 이상이 유사한 후보만 채택한다.
5. 요청된 개수만 최종 저장한다.

## 제외 조건

- 제품, 간판, 명함 등에 합성된 목업
- Pinterest 검색 결과 화면 전체
- 로그인 또는 가입 팝업이 포함된 캡처
- Pinterest 메뉴, 버튼, 검색창 등 UI가 포함된 이미지
- 초안과 관계없는 단순 원형 아이콘
- 사진, 3D 렌더링, 과도한 그라데이션
- 심한 워터마크 또는 낮은 해상도
- 출처 핀 URL을 확인할 수 없는 이미지

## 캡처와 저장

1. 개별 핀 페이지에서 로고 이미지가 충분히 크게 보이는지 확인한다.
2. Pinterest UI 전체가 아니라 로고가 보이는 이미지 영역만 캡처한다.
3. 로그인 팝업이 이미지를 가리면 페이지 전체 캡처를 저장하지 않는다.
4. 이 경우 핀의 공개 대표 이미지(`og:image`, 일반적으로 `i.pinimg.com`)를 확인한다.
5. 대표 이미지가 실제 핀과 일치하는지 열어 검증한 뒤 저장한다.
6. PNG나 WebP는 실제 JPEG로 변환하며 확장자만 바꾸지 않는다.
7. 긴 변 1000px 이상을 권장하되 작은 원본을 억지로 확대하지 않는다.
8. 저장한 JPG를 다시 열어 잘림, 팝업, UI, 워터마크, 목업, 빈 화면 여부를 육안 검증한다.

## 완료 보고

- 저장 파일 경로
- Pinterest 원본 핀 URL
- 초안 및 레퍼런스와 유사한 이유 1~2문장
- 워터마크나 해상도 등 품질상 주의점

파일 저장 성공 메시지만으로 완료 처리하지 않는다. 결과 JPG를 실제로 확인한 뒤 보고한다.
