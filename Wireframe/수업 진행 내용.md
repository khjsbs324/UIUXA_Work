*분석 skill이 발동되면 가상 클라이언트가 리서치 사이트를 경험한 결과를 도출
1.분석 skill을 발동시킨다
  §skill이 발동되면 [가상클라이언트 기반 분석 결과 작성 양식.md]를 기반으로 결과를[작성한다]
  §[가상클라이언트]는 []를 기반으로 작동 시킨다

2.사이트 분석 결과를 도출시킨다
 -분석 기준은 "가상 클라이언트"로 삼는다
 -분석 결과는 "메뉴, 콘텐츠, 기능"으로 출력한다

-------------------------------------------------------------> 실습/다 하면 단톡방 올리기

3.사이트 구조맵과 사이트 맵 제작한다
4.서비스 흐름도를 제작한다
5.화면 설계서를 제작한다
6.화면 설계서를 기반으로 와이어프레임 제작한다

(자동화)
*작동 방식
[가상 클라이언트 제작] -> [1번] -> [2번]*n회 -> [3번][4번][5번] 수정 -> 와이어프레임 수정*n회

[가상 클라이언트 제작][1번][2번] 반복 자동화
[3번][4번][5번] 내용을 기반으로 와이어프레임 수정
