### 1. 메인페이지 스토리보드 제작용 최종 프롬프트 작성
현재 `설계 출력물` 폴더 안에 있는 파일을 기반으로 메인페이지 스토리보드를제작할 예정이다.
스토리보드는 화면 1개당 하나의 표 형식으로 작성한다.
`스토리보드 결과`라는 폴더를 새로 생성하고, 해당 폴더 안에 결과물을 저장한다.

스토리보드 제작에 사용할 최종 프롬프트는 `설계 프롬프트\Antigravity 프롬프트.txt` 파일을 참고하여 작성한다.

### 2. 최종 프롬프트를 기반으로 스토리보드 제작
`메인페이지_스토리보드_최종_프롬프트.txt`의 내용을 기준으로 메인페이지 스토리보드를 제작한다.
결과물은 `메인페이지_스토리보드.md` 파일로 작성한다.

### 3. 스토리보드를 HTML/CSS 와이어프레임으로 제작
[메인페이지_스토리보드.md]결과물을 기준으로 자바스크립트 제외, html,css 코드만으로 결과물 생성

  제작 조건:
  - JavaScript를 사용하지 않는다.
  - HTML과 CSS 코드만 사용한다.
  - 완성형 비주얼 디자인은 적용하지 않는다.
  - 출력 화면은 회색 박스와 텍스트 중심으로 표현한다.
  - 이미지가 필요한 영역은 회색 플레이스홀더로 표현한다.
  - 반응형 웹 구조로 제작한다.

  ### 통합 프롬프트
  현재 작업 폴더의 `가상 클라이언트 설계 결과\설계 출력물` 안에 있는 파일을 기반으로 스밈(SEUMIM) 메인페이지 스토리보드와 와이어프레임을 제작해줘.

  먼저 `설계 프롬프트\Antigravity 프롬프트.txt`를 참고하여 메인페이지 스토리보드 제작용 최종 프롬프트를 작성해줘.

  스토리보드는 메인페이지 한 화면을 기준으로 작성하고, 화면 1개당 하나의 독립된 표 형식을 사용해줘. 헤더, 히어로, 통계, 제품, 기술, AI 데이터 케어, 오프라인 센터, 후기, FAQ, CTA, 푸터 등 메인페이지의 모든 영역을 표의 행으로 구분해줘.

  결과물은 새로 생성한 다음 폴더에 저장해줘.
  `가상 클라이언트 설계 결과\설계 출력물\스토리보드 결과`

  생성할 스토리보드 파일:
  - `메인페이지_스토리보드_최종_프롬프트.txt`
  - `메인페이지_스토리보드.md`

  스토리보드 작성 후에는 해당 문서를 기준으로 메인페이지 저충실도 와이어프레임을 제작해줘.

  와이어프레임 제작 조건:
  - JavaScript 사용 금지
  - 외부 라이브러리 사용 금지
  - HTML과 CSS 파일만 사용
  - HTML과 CSS는 별도 파일로 분리
  - 완성형 비주얼 디자인 적용 금지
  - 회색 박스, 테두리, 텍스트만 사용
  - 실제 이미지 대신 회색 플레이스홀더 사용
  - 데스크톱, 태블릿, 모바일 반응형 구성
  - 키보드 탐색과 기본적인 웹 접근성 반영
  - 모든 내부 링크가 정상적으로 연결되도록 구성

  생성할 와이어프레임 파일:
  - `메인페이지_스토리보드.html`
  - `메인페이지_스토리보드.css`

  입력 자료에 없는 정책, 수치, 사용자 후기, 센터 정보, 제품 상세 내용은 임의
  로 확정하지 말고 `가정` 또는 `확인 필요`로 표시해줘.
